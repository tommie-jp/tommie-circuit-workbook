# archive

教科書に置かない回路を、**参考回路**として残す置き場。

## 方針

- **載せる物**: 回路の規模が教科書の上限 (README の「書き方」の「回路の規模」) を超える物、作者が組む予定の無い物のうち、読む人の参考になりそうな物
- **載せる条件**: 検査を通した物だけ。フェンスの検査 (`npm run all` のネットリストの突き合わせ) と、数を確かめた LTspice などを通した状態で凍結する。下書きや検査を通していない物は載せない
- **載せない物**: 借りた回路の写し (出典を書いて描き直した物はよい)、公開しない事情を含む物
- **保守しない**: 作者は新しく作らず、直しもしない。フェンスの版を上げても検査しない (`npm run all` と Pages の図の書き出しの対象外。markdownlint だけは通す)
- **閉じた置き場にする**: 教科書から archive を指すのは章の README の 1 行だけで、題の本文からは指さない。archive から教科書の題へのリンクは「前の題」程度にとどめ、教科書の側を直しても archive は直さない
- **図は同梱する**: 図 (SVG) はこの下にコミットし、画像の行は相対パスにする。GitHub 上でそのまま図つきで読める

## 置き方

- 置き場は `NN-名前/` (2 桁の番号を先頭に付ける。足した順で、番号は詰め直さない)。中のファイルも番号で始める
- 各置き場の `README.md` に、何の回路か・**実機で測ったかどうか**・**凍結したコミットとフェンスの版**・保守しないことを書く
- 01-dram の中の `06-` `07-` は、教科書にあったときの題の番号で、本文の「1-6」「1-7」の言及と合わせるため変えていない
