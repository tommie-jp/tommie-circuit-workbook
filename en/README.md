# tommie-circuit-workbook (English edition)

> [!WARNING]
> This book was written by an AI (Claude) and has not been reviewed by a human expert. Circuits, numbers and procedures
> may be wrong. Check them yourself before you build.

[日本語](../README.md) is the source. This edition is a translation in progress: an exercise that is not translated yet
links to the Japanese file. Terms and style are in [GLOSSARY.md](GLOSSARY.md).

Four of the five books are being translated, in this order: 01-circuits, 02-analog-discovery, 03-nanovna,
06-fpga, then the extra projects in 05-etc. 04-denken prepares for a Japanese licensing exam and is not translated.

Figures are drawn from [tommie-fence](https://github.com/tommie-jp/tommie-fence) fences. GitHub does not draw them,
so each fence is followed by an image of the figure.
