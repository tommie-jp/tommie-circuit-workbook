# 8-10 方向性結合器

> **値はシミュレーション (LTspice) と式で出したもので、実機では測っていない。** トロイダルの AL 値 (350 nH/回²) と
> 巻線の結合係数 (0.99) は仮定で、巻き方で変わる。

**方向性結合器** (directional coupler) は、主線を通る波のうち**片方の向きの波だけ**を、決まった割合で取り出す 4 端子の部品。
SWR 計・通過形の電力計・送信機の ALC がこれで動き、VNA の中でも反射を測る心臓部にある。
この題では、HF 帯 (1〜30 MHz) で働く**トランス 2 つの結合器** (結合 20 dB) を銅張り基板に Manhattan 式で組み、
**結合度・アイソレーション・方向性 (ディレクティビティ)** の 3 つを VNA で測る。

| 端子 | 名前 | 働き |
| --- | --- | --- |
| P1 | IN | 主線の入口 |
| P2 | OUT | 主線の出口 |
| P3 | FWD | P1 → P2 の向きの波 (進行波) の 1/10 が出る |
| P4 | REF | P2 → P1 の向きの波 (反射波) の 1/10 が出る |

## この実験で確かめる式

主線の電圧を V、電流を I とする (Z<sub>0</sub> = 50 Ω (オーム))。

- **T1 (電流を見るトランス)**: 主線が 1 回、2 次は中点のある 20 回。2 次には I / 20 の電流が流れ、P3 と P4 の 50 Ω を
  逆向きに通るので、P3 に +50 I / 20、P4 に −50 I / 20 が出る
- **T2 (電圧を見るトランス)**: 20 回を主線から GND へ、1 回を T1 の中点へ。中点に V / 20 が乗り、P3 と P4 の両方に同じ向きで出る
- 足すと **V<sub>3</sub> = (V + 50 I) / 20**、**V<sub>4</sub> = (V − 50 I) / 20**

P1 から入って P2 へ行く波は V = 50 I なので V<sub>3</sub> = V / 10、V<sub>4</sub> = 0。逆向きの波は V = −50 I で、V<sub>3</sub> = 0、V<sub>4</sub> = V / 10。

| 量 | 定義 | 理想の値 |
| --- | --- | --- |
| 結合度 C | S31 (P1 → P3) | 20 log (1/10) = **−20 dB** |
| アイソレーション I | S32 (P2 → P3) | −∞ dB |
| 方向性 D | I − C (dB の差) | ∞ dB |
| 挿入損失 | S21 | 1 % の電力が P3 へ行くぶん、**−0.044 dB** |

実物では、主線 1 回の巻線が磁束を漏らす (結合係数 k < 1)。漏れは周波数とともに効き、**アイソレーションが先に崩れる**。
方向性は「反射を何 dB まで正しく読めるか」の上限で、方向性 20 dB の結合器で SWR 1.2 (反射損失 21 dB) を読むと、
漏れが反射と同じ大きさになり、読みが 2 倍狂うこともある。

- **T1**: FT37-43 に 2 次の 20 回 (0.3 mm のポリウレタン線を 10 回巻き、中点を引き出してもう 10 回) を巻き、穴に**主線の線を 1 本通す** (これが 1 回)。
  図の T1 の左のコイルが主線の 1 回、右が 10 + 10 回で、中点 (CT) が T2 へ行く
- **T2**: FT37-43 に 20 回を巻き、一方の端を主線 (P2 側) に、他方を GND に。穴に**中点からの線を 1 本通して** GND へ落とす (これが 1 回。図の T2 の右)
- 2 つのトランスの巻く向きを取り違えると、P3 と P4 の役が入れ替わる (P3 に反射波が出る)。測って P3 が −20 dB にならなければ、T2 の 1 回の線を逆向きに通し直す
- 図は線を 2 か所で跨ぐ (黒丸の無い所はつながっていない)

- **トロイダルの図は描けないので、巻線を 1 本ずつコイルで描いた**。T1A (主線の 1 回) と T1B・T1C (10 回ずつ) は同じ FT37-43 の 1 つの芯、
  T2A (20 回) と T2B (1 回) がもう 1 つの芯。T1 の芯は島 A と B の間に置き、島 A から島 B へ渡す線 (T1A) を芯の穴に通す
- T2A の GND の端と T2B の GND の端は、島の外の銅 (表の GND) に直に半田付けする
- 30 MHz での波長は 10 m なので、島の間の線の長さ (数 cm) は効かない。効くのは**巻線の漏れ**で、それは基板では直せない

## 掃引の設定

計器は VNA (NanoVNA-H4。LiteVNA64 でも同じ)。2 ポートの VNA なので、**4 端子のうち 2 つを CH0・CH1 に、残る 2 つを 50 Ω の終端で塞いで**、
組み合わせを替えて 3 回測る。AD3 とオシロは使わない (S パラメータを見る題)。

| 測るもの | CH0 | CH1 | 50 Ω で塞ぐ | 画面 |
| --- | --- | --- | --- | --- |
| 挿入損失 S21・S11 | P1 | P2 | P3・P4 | 図3 |
| 結合度 S31 | P1 | P3 | P2・P4 | 図4 の結合 |
| アイソレーション S32 | P2 | P3 | P1・P4 | 図4 のアイソレーション |

| 項目 | 値 |
| --- | --- |
| 範囲 | 500 kHz〜50 MHz |
| 点数 | 201 |
| 校正 | SOLT。CH0・CH1 のケーブルの先で。範囲は 3 回とも同じ |

主線 (図3) は受け身の画面なので、等価回路で描ける。T1 の 2 次の 100 Ω (P3 と P4 の直列) が 1/20² になって主線に**直列 0.25 Ω**、
T2 の 1 回に見える 25 Ω (P3 と P4 の並列) が 20² 倍になって**並列 10 kΩ**、そこに T2 の 20 回のインダクタンス (**140 µH**) が並列に入る。


![NanoVNA の画面](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/08-amplifiers/vna/10-directional-coupler.svg)

- S21 は 0.04〜0.06 dB しか落ちない。**結合度 20 dB の結合器は、通る電力の 1 % しか取らない**
- 1 MHz より下で S11 が上がる (Smith の点が中心から上へ離れる) のは T2 の 140 µH が主線を GND へ逃がすため。下の端は T2 の巻数で決まる

結合とアイソレーションは 4 端子の量なので `dut:` では描けない。LTspice で計算した線を図4 に置く。

![グラフ](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/08-amplifiers/graph/10-directional-coupler.svg)

- **結合度は 1〜7 MHz で −20.1〜−20.4 dB**。30 MHz で −23 dB に下がるのは、T1 の主線 1 回の漏れが電流の読みを減らすため
- **アイソレーションは 2 MHz の −43 dB が底**で、上でも下でも上がる。下は T2 の 20 回のインダクタンスが足りず電圧の読みが減るため、
  上は漏れのため。2 つの量の釣り合いが崩れると、打ち消すはずの反射波の側が残る
- 結合係数を 0.999 にすると (巻線を芯にきつく沿わせる)、アイソレーションは 7 MHz で −52 dB まで下がる

## 見るべき値

LTspice の計算値 (結合係数 0.99 の仮定)。方向性 = アイソレーション − 結合度。

| 周波数 | S21 (挿入損失) | S11 | 結合度 S31 | アイソレーション S32 | 方向性 |
| --- | --- | --- | --- | --- | --- |
| 1 MHz | −0.05 dB | −30.8 dB | −20.1 dB | −42.2 dB | 22.0 dB |
| 7 MHz | −0.04 dB | −43.0 dB | −20.4 dB | −36.1 dB | 15.7 dB |
| 30 MHz | −0.03 dB | −38.4 dB | −23.0 dB | −28.0 dB | 5.0 dB |

- **方向性が 20 dB を超えるのは 1〜2 MHz だけ**で、30 MHz では 5 dB しか無い。結合係数 0.999 なら 7 MHz で 32 dB、30 MHz で 23 dB (LTspice)。
  **実物の方向性は巻線の結合で決まる**ので、測った方向性から「どの周波数まで SWR 計として信じられるか」を読む
- P4 (REF) も同じ形で測れる (P2 → P4 が結合、P1 → P4 がアイソレーション)。2 つの値がそろわなければ、巻線の向きか中点の位置がずれている
- 測るとき、CH0 の出力のままで構わない。部品は受け身なので CH1 の上限 (0-3) には届かない

## LTspice での確かめ

`sim/10-directional-coupler.cir` で図1 を `.ac` にかけ、P1 から入れたとき (S21・S31・S41・S11) と P2 から入れたとき (S32) を読んだ。
信号源 2 V・50 Ω で入射波を 1 にし、測らない端子は 50 Ω で終端した。FT37-43 の AL 値 (350 nH/回²) と結合係数 (0.99、0.999) は仮定で、
コアの損失 (43 材は 10 MHz より上で損失が大きい) は入れていない。実測ではない。

| 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| 結合度 S31 (1 MHz、k 0.99) | −20 dB (式) | −20.13 dB | 合う |
| 結合度 S31 (7 MHz、k 0.999) | −20 dB (式) | −20.03 dB | 合う |
| 挿入損失 S21 (7 MHz) | −0.044 dB (式) | −0.041 dB | 合う |
| P1 → P4 (S41、7 MHz、k 0.99) | 0 (式、理想) | −36.2 dB | 漏れのぶん。S32 (−36.1 dB) とほぼ同じ |
| 方向性 (7 MHz、k 0.99) | — | 15.7 dB | 図4 のとおり |
| 図3 の S21 (1 MHz、等価回路) | −0.05 dB | −0.046 dB | 合う |
| 図3 の S11 (1 MHz、等価回路) | 49.8 + j2.8 Ω (−31.0 dB) | −30.8 dB | 合う |

## 出典

自作。2 つのトランスで電流と電圧を別々に取り出して足し引きする形は、SWR 計や VNA の反射ブリッジで広く使われる方向性結合器の一つ。
