# 8-11 ウィルキンソン分配器 (マイクロストリップ、2.4 GHz)

> **値は式と LTspice (損失の無い伝送線路) で出したもので、実機では測っていない。** FR4 の比誘電率 4.4 と誘電正接 0.02 は仮定。

1 つの信号を 2 つに等しく分ける (逆に 2 つを 1 つにまとめる) 部品が**電力分配器**。抵抗 3 本の分配器は 6 dB 落ちるが、
**ウィルキンソン分配器** (Wilkinson divider) は損失なしで 3 dB ずつに分け、**しかも 2 つの出力の間を切り離す (アイソレーション)**。
2.4 GHz の Wi-Fi や BLE の 2 本のアンテナへの分配、アンテナの組み合わせ、LO の分配に使われる。
この題では、FR4 の銅張り基板に **λ/4 (4 分の 1 波長) の 70.7 Ω (オーム) の線 2 本と 100 Ω 1 本**で組み、
NanoVNA V2 で 3 dB の分配と出力間のアイソレーションを見る。

## この実験で確かめる式

ポート P1 (入力) から 2 本の腕 (特性インピーダンス Z<sub>a</sub>、長さ λ/4) が分かれ、腕の先が P2・P3 (出力)。腕の先どうしを R<sub>w</sub> でつなぐ。

- **P1 から入れたとき**: P2 と P3 は同じ電圧なので R<sub>w</sub> に電流は流れない。腕 1 本は 50 Ω を λ/4 線路で Z<sub>a</sub>² / 50 に変える (5-8 の
  λ/4 変成器)。2 本が並ぶと Z<sub>a</sub>² / 100。これが 50 Ω になる条件が **Z<sub>a</sub> = √2 × 50 = 70.7 Ω**。電力は半分ずつ、**S21 = S31 = −3.01 dB**
- **P2 から入れたとき**: 腕を回って P3 へ行く波と、R<sub>w</sub> を通って P3 へ行く波が逆相で打ち消し合う。その条件が **R<sub>w</sub> = 2 × 50 = 100 Ω**。
  **S32 = 0 (−∞ dB)** で、P2 に戻る反射も 0。P2 に入った電力の半分は P1 へ、半分は R<sub>w</sub> で熱になる
- λ/4 はその周波数の 1 点だけで成り立つ。外れると S11 と S32 が上がる (2.0 GHz と 2.8 GHz で −21 dB、LTspice)

FR4 (厚さ 1.6 mm、比誘電率 4.4) で 50 Ω は幅 **3.06 mm**、70.7 Ω は幅 **1.6 mm** (図の線路のラベルで 71.0 Ω)。
1.6 mm の線の 2.4 GHz での λ/4 は約 **17.6 mm** (図2 の腕のラベルで 90°)。

## 回路図

```circuit
# 回路図 (tommie-fence の circuit フェンス)
title: 図1 ウィルキンソン分配器 (2.4 GHz、腕は 70.7 Ω の 4 分の 1 波長)
parts:
  J1: sma 2,4 mirror P1
  T1: tline 5,2 9,2 70.7 l=$\mathrm{17mm}$
  T2: tline 5,6 9,6 70.7 l=$\mathrm{17mm}$
  RW: resistor 10,2 10,6 100
  J2: sma 13,2 P2
  J3: sma 13,6 P3
  GJ1: ground 2,5
  GJ2: ground 13,3
  GJ3: ground 13,7
wires:
  - J1.1 -- 4,4
  - 4,4 -- 4,2 -- 5,2
  - 4,4 -- 4,6 -- 5,6
  - 9,2 -- 10,2 -- J2.1
  - 9,6 -- 10,6 -- J3.1
  - J1.2 -- 2,5
  - J2.2 -- 13,3
  - J3.2 -- 13,7
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/08-amplifiers/circuit/11-wilkinson-divider.svg)

- T1・T2 はマイクロストリップの腕 (図の線路の記号。値は Z<sub>0</sub>)。腕の GND は裏のベタ
- RW (100 Ω) は**腕の先どうしを最短で**つなぐ。ここに線が足されると打ち消しの位相がずれ、アイソレーションが崩れる

## 実体配線図

FR4 (厚さ 1.6 mm、比誘電率 4.4 と仮定) の両面銅張り基板。裏は全面 GND。

```copper
# 銅張り基板の寸法図 (tommie-fence の copper フェンス)
title: 図2 ウィルキンソン分配器を銅張り基板に組む
f: 2.4G
style:
  back: off
sheets:
  - name: 分配器
    board:
      size: 45x40mm
      ground: back
    copper:
      Lin: line 0,25 12,25 3.06mm
      A1: line 12,25 12,18.7 19,18.7 19,23 1.6mm
      A2: line 12,25 12,31.3 19,31.3 19,27 1.6mm
      O1: line 19,23 25,23 25,10 45,10 3.06mm
      O2: line 19,27 25,27 25,40 3.06mm
    parts:
      J1: sma left 25 P1
      J2: sma right 10 P2
      J3: sma bottom 25 P3
      RW: resistor/3216 20,25 r90 100
    notes:
      - dim 12,15.5 19,15.5
  - name: スルー
    board:
      size: 68x16mm
      ground: back
    copper:
      L3: line 0,8 68,8 3.06mm
    parts:
      J4: sma left 8 CH0
      J5: sma right 8 CH1
```

![銅張り基板の寸法図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/08-amplifiers/copper/11-wilkinson-divider.svg)

| 何 | 寸法・置き方 |
| --- | --- |
| 入力の線 (Lin) | 幅 3.06 mm (50 Ω)、長さ 12 mm |
| 腕 (A1・A2) | **幅 1.6 mm (71.0 Ω)**、中心線で 6.3 + 7 + 4.3 = **17.6 mm** (2.4 GHz で 90°)。入力の線の端で上下に分かれる |
| 出力の線 (O1・O2) | 幅 3.06 mm。腕の先から右へ 6 mm 出してから上・下へ曲げ、P2・P3 の縁へ |
| RW (100 Ω、3216) | 2 本の出力の線の付け根 (腕の先から 1 mm) を跨いで縦に載せる。線の間は約 1 mm |
| スルー (図2 (2枚め)) | 幅 3.06 mm・長さ 68 mm。P1 から P2 までの中心線の道のり (12 + 17.6 + 39 ≈ 68 mm) と同じにして、線の損失を差し引く基準にする |

- 3 つの出力が同じ銅でつながっているので、`check` は RW の両方の端が同じ銅に乗ると言う (ERC)。分配器ではそれが正しい形で、承知のうえで残す
- **腕は 3 か所で曲がる**。角は 45° に落とすのが本式 (この図は直角)。直角の角は余分な容量になり、中心の周波数を少し下げる
- RW は 1608 では線の間に届かないので、長さ 3.2 mm の 3216 にした。2.4 GHz では抵抗の胴のインダクタンス (約 1 nH の目安) も効く

## 掃引の設定

計器は NanoVNA V2 (2.4 GHz は H4 の 1.5 GHz を超える)。LiteVNA64 でも同じ。AD3 とオシロは使わない (S パラメータを見る題)。

| 測るもの | CH0 | CH1 | 50 Ω で塞ぐ |
| --- | --- | --- | --- |
| 分配 S21・入力の反射 S11 | P1 | P2 | P3 |
| 分配 S31 | P1 | P3 | P2 |
| アイソレーション S32・出力の反射 S22 | P2 | P3 | P1 |

| 項目 | 値 |
| --- | --- |
| 範囲 | 1〜3 GHz |
| 点数 | 201 |
| 校正 | SOLT。CH0・CH1 のケーブルの先で。先にスルー (図2 (2枚め)) の S21 を記録する |

P1 から入れた画面は、2 本の腕を 1 本の線にまとめた形で描ける。P2 と P3 が同じ電圧なので RW には電流が流れず、
**腕 2 本 = 35.4 Ω (70.7 Ω の半分) の λ/4 の線 1 本**、P3 の終端は CH1 の手前の 50 Ω の並列になる。λ/4 は空気中の 31.2 mm で書いた。

```vna
# NanoVNA の画面 (tommie-fence の vna フェンス)
device: v2
sweep: 1G-3G 201
title: 図3 P1 → P2 の S21 と P1 の S11 (腕 2 本を 1 本にまとめた等価回路)
dut:
  - line 35.36 31.23mm vf 1
  - shunt R 50
traces:
  - S21 logmag
  - S11 logmag
markers:
  - 2G
  - 2.4G
  - 2.8G
expect:
  - match: S21 LOGMAG は掃引の中で
    why: S21 が帯域でほぼ平らなことを、S11 の谷と同じ尺度で並べて見せる図
```

![NanoVNA の画面](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/08-amplifiers/vna/11-wilkinson-divider.svg)

- **S21 は 2.4 GHz で −3.01 dB**、2.0・2.8 GHz でも −3.05 dB で、ほとんど平ら。電力を等しく分ける働きは帯域が広い
- **S11 は 2.4 GHz で深い谷**になり、2.0・2.8 GHz では −21 dB。整合の帯域が分配器の使える帯域を決める
- アイソレーション S32 は奇の励振 (P2 と P3 が逆の電圧) の量で、この形の `dut:` では描けない。LTspice の値を下の表に置く

## 見るべき値

理想の線路の計算値 (LTspice、設計の 70.7 Ω・90°)。実物は FR4 の損失 (誘電正接 0.02 の仮定で約 0.08 dB/cm、P1 から P2 まで約 7 cm で約 0.55 dB) の分だけ S21 が下がる。

| 周波数 | S21 (= S31) | S11 | S22 | アイソレーション S32 |
| --- | --- | --- | --- | --- |
| 2.0 GHz | −3.05 dB | −20.8 dB | −41.4 dB | −20.7 dB |
| 2.4 GHz | −3.01 dB | −76 dB (理想の谷。図3 は −77 dB) | −82 dB | −82 dB (理想の谷) |
| 2.8 GHz | −3.05 dB | −20.8 dB | −41.4 dB | −20.7 dB |

- 実物の S21 は −3.5 dB 前後 (理想 −3.01 dB と線の損失)。スルーの S21 を引けば −3.0〜−3.1 dB に戻る
- S21 と S31 の差は 0.2 dB 以内、位相の差は数度以内が目安。差が大きければ腕の長さか幅が左右でずれている
- **アイソレーションの谷は 20〜30 dB ほどに浅くなる** (実物では RW の寄生分と角の容量で打ち消しが崩れる)。谷の周波数が 2.4 GHz から
  下にずれていれば、腕が電気的に長い (比誘電率が仮定より大きい。9-7 で確かめる)
- 腕が 71.0 Ω で電気長が 2° 長い (92°) と、2.4 GHz の S11 は −37.7 dB、S32 は −38.1 dB (LTspice)。2° のずれでも谷はこの深さで止まる

## LTspice での確かめ

`sim/11-wilkinson-divider.cir` で図1 を `.ac` にかけた (損失の無い伝送線路 T、信号源 2 V・50 Ω、使わない端子は 50 Ω で終端)。
腕を設計の値 (70.7 Ω・90°) と、幅 1.6 mm の 71.0 Ω で長さが 2° 長い場合 (92°) の 2 通りで回した。損失・角・RW の寄生分は入れていない。実測ではない。

| 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| S21・S31 (2.4 GHz) | −3.01 dB (式) | −3.010 dB・−3.010 dB | 合う |
| S11 (2.4 GHz) | 0 (式) | −76.4 dB | 合う (計算の丸めの残り) |
| S32 (2.4 GHz) | 0 (式) | −82.2 dB | 合う |
| S12 (P2 → P1、2.4 GHz) | −3.01 dB (式) | −3.010 dB | 合う |
| S11 (2.0 GHz・2.8 GHz) | 図3 の −20.81 dB・−20.80 dB | −20.81 dB・−20.81 dB | 合う |
| S11・S32 (2.4 GHz、71.0 Ω・92°) | — | −37.7 dB・−38.1 dB | 見るべき値のとおり |
