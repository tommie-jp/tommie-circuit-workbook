# 5-4 断線・短絡の位置 (TDR)

アンテナに繋いだケーブルの具合が悪いとき、「途中で切れているのか、
どこかで芯線とシールドが接触しているのか」を、ケーブルを切らずに調べたい。
5-1 の TDR を使うと、**山の位置**からその距離が分かる。断線 (開放) と
短絡それぞれで、山の位置は同じだが山の形は同じに見える、という TDR の
弱点も確かめる。

## 回路図

```circuit
title: 図1 4 m の所で断線 (開放) したケーブル
parts:
  J1: sma b2 mirror
  G1: ground c2
wires:
  - J1.1 -- b8
  - J1.2 -- c2
notes:
  - text a2 center: CH0
  - text e5 center: 4 m の所で断線 (先は開放)
  - text b8a2: 開放
```

先 (b8) は断線した先という意味で、意図して開放のままにする。

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜900 MHz |
| 点数 | 401 (TDR には等間隔の掃引が要る) |
| 校正 | SOLT。ケーブルの根元 (CH0 の SMA) で Open / Short / Load / Thru |
| 表示 | S11 の TDR (速度係数 0.66) |

見えるはずの画面 (理想の模型)。断線 (開放) の場合。

```vna
device: h4
sweep: 1M-900M 401
title: 図2 4 m の所で断線 (開放) した場合の TDR
dut:
  - line 50 4m vf 0.66
  - open
traces:
  - S11 tdr vf 0.66
```

同じ距離で、断線ではなく**芯線とシールドが短絡**した場合。

```vna
device: h4
sweep: 1M-900M 401
title: 図3 4 m の所で短絡した場合の TDR
dut:
  - line 50 4m vf 0.66
  - short
traces:
  - S11 tdr vf 0.66
```

## 見るべき値

| 項目 | 開放 (断線) | 短絡 |
| --- | --- | --- |
| 山の位置 | 約 4 m | 約 4 m (同じ) |
| 山の形 (この TDR) | 上向きの山 | 上向きの山 (見分けが付かない) |

分かること:

- **山の位置さえ読めれば、断線・短絡どちらでも故障箇所までの距離が分かる。**
  ケーブルを引き回した壁の中や屋根の上まで登らなくても、根元で測るだけで
  見当が付く
- 一方、この TDR (S11 を帯域通過のまま逆フーリエ変換したもの) は**開放か
  短絡かを見分けない** — 山の向きも高さもほぼ同じになる。見分けるには
  低い周波数まで含めたステップ応答型の TDR (専用の測定器) か、
  DC 抵抗をテスターで別に当たるしかない
- 実際の現場では「テスターで通電を見てから距離だけ TDR で当たる」のが早い。
  TDR は**距離を当てる**道具、導通の有無は別の道具、と役割分担する
