# 5-12 平行 2 線 (ラダーライン)

同軸と並ぶもう 1 つの給電線が、2 本の線を平行に並べた**平行 2 線**。窓の
開いた絶縁物で 2 本を支えた物は、はしごに見えるので**ラダーライン**と呼ばれる。
誘電体がほとんど空気なので**損失が小さく速度係数が高い**が、特性インピーダンスは
数百 Ω と大きい。市販の 450 Ω ラダーライン 1 m を、5-10 の方法 (先端の開放・
短絡) で測り、Z₀ と速度係数を読む。

## この実験で確かめる式

- Z₀ = √(Zoc · Zsc) (5-10)。長さが λ/8 の周波数では |X| がそのまま Z₀
- 開放で X が 0 を通る周波数 (長さ λ/4) から **vf = 4 · l · f / c**

ここでは Z₀ = 450 Ω、vf = 0.91 を**仮定**する (市販品のカタログによくある値。
品によって 0.88〜0.95 くらいまで違う)。1 m なら λ/8 は 34.10 MHz、λ/4 は 68.20 MHz。

## 回路図

```circuit
title: 図1 450 Ω のラダーライン 1 m を CH0 へ。先を開放・短絡
parts:
  J1: sma b2 mirror CH0
  TL1: tline b3 b6 450 l=$\mathrm{TL}_1$
  S1: switch b7 d7
  G1: ground c2
  G2: ground d7
wires:
  - J1.1 -- b3
  - b6 -- b7
  - J1.2 -- c2
notes:
  - text b4h5 center: 平行 2 線・1 m
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/05-transmission-lines/circuit/12-ladder-line.svg)

- 図の GND は「2 本のうちの片方」。平行 2 線には外皮が無く、2 本は対等
  (平衡)。CH0 の SMA の芯線に 1 本、外側に 1 本を、それぞれ 1 cm 以下の短い
  線でつなぐ (SMA のメス - ねじ端子の変換が使いやすい)
- S1 は「先端を開放 (開) か短絡 (閉) にする」ことを表す。短絡は 2 本の先を
  短い線でつなぐだけ
- 線は**まっすぐ張り、金属 (机の脚・壁の中の配線) から 10 cm 以上離す**。
  平行 2 線は周りの物の影響を受けやすい

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜100 MHz (λ/8 と λ/4 を中に) |
| 点数 | 199 (0.5 MHz おき) |
| 校正 | SOLT。CH0 のケーブルの先 (SMA - ねじ端子の変換を挿す手前) で Open / Short / Load |
| 表示 | S11 のリアクタンス (X) と Smith |

見えるはずの画面 (理想の模型)。まず先端開放。

```vna
device: h4
sweep: 1M-100M 199
title: 図2 先端開放 — λ/8 で X = −450 Ω、λ/4 (68.2 MHz) で 0 を通る
dut:
  - line 450 1m vf 0.91
  - open
traces:
  - S11 x
  - S11 smith
markers:
  - 34.1M
  - 68.2M
```

![NanoVNA の画面](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/05-transmission-lines/vna/12-ladder-line-1.svg)

先端短絡。短絡では λ/4 (68.2 MHz) で X が無限大に跳ね、X の枠の目盛が
数千 Ω に広がって 450 Ω が読めなくなる。そこで**掃引を λ/8 の周り
(20〜50 MHz) に絞った** (図2 と違うのは掃引とマーカーの数だけ)。

```vna
device: h4
sweep: 20M-50M 61
title: 図3 先端短絡 (20〜50 MHz に絞る) — λ/8 で X = +450 Ω
dut:
  - line 450 1m vf 0.91
  - short
traces:
  - S11 x
  - S11 smith
markers:
  - 34.1M
```

![NanoVNA の画面](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/05-transmission-lines/vna/12-ladder-line-2.svg)

## 見るべき値

計算値 (損失の無い理想の線路)。

| マーカー | 周波数 | 開放の X | 短絡の X | 読めること |
| --- | --- | --- | --- | --- |
| 1 | 34.1 MHz (λ/8) | −450 Ω | +450 Ω | Z₀ = √(450 × 450) = **450 Ω** |
| 2 | 68.2 MHz (λ/4) | 0 Ω | 非常に大きい (並列共振。図3 の掃引の外) | vf = 4 × 1 m × 68.2 MHz / c = **0.91** |

- Smith チャートでは、どちらも外周を回る (損失が無いので R = 0)。ただし 450 Ω は
  50 Ω の 9 倍なので、λ/8 の点 (±j9 の円の上) は右端のごく近くに寄って読みにくい。
  **数は X の枠とマーカーの表で読む**
- 同じ 1 m でも、同軸 (vf 0.66、5-7) の λ/4 は 49.47 MHz、ラダーライン
  (vf 0.91) では 68.2 MHz。**誘電体が空気に近いほど電波は速く、同じ長さが
  電気的に短くなる**

分かること:

- 平行 2 線も同軸と同じ式 (Zoc・Zsc、λ/4 の反転) で扱える。違うのは Z₀ の
  大きさと vf だけ
- Z₀ が大きいので、50 Ω 系の NanoVNA で直に測ると反射が大きく、S21 や SWR では
  特性がつかみにくい。**開放・短絡で X を読む方法が向いている**
- 実物では、測定器側が不平衡 (同軸) なので、線の外側を流れる電流 (コモンモード)
  が乗って値がずれることがある。ずれが気になるときは 1:1 の電流バラン
  (7-8 で扱う) を根元に入れる
