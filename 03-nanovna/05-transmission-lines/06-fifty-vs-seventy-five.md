# 5-6 50 Ω と 75 Ω の違い

無線機や NanoVNA は 50 Ω 系だが、テレビ・CATV の同軸 (RG-6 など) は 75 Ω 系。
特性インピーダンスが違う線路をつなぐと、**line の Z0 と系の Z0 (50 Ω) の比
だけ**で反射が生まれる。75 Ω のケーブルを、(1) その先を正しく 75 Ω で
終端した場合と、(2) 先をうっかり 50 Ω で終端してしまった場合で比べる。

## 回路図

```circuit
title: 図1 75 Ω のケーブルを 50 Ω 系につなぐ
parts:
  J1: sma b2 mirror
  G1: ground c2
wires:
  - J1.1 -- b8
  - J1.2 -- c2
notes:
  - text a2 center: CH0 (50 Ω)
  - text e5 center: 75 Ω のケーブル
  - text b8a2: 先端 (75 Ω または 50 Ω で終端)
```

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜300 MHz |
| 点数 | 301 |
| 校正 | SOLT。ケーブルの根元 (CH0 の SMA、50 Ω の基準) で Open / Short / Load / Thru |
| 表示 | S11 の SWR |

先を正しく 75 Ω で終端 — 線路のどこにも反射を起こす場所が無いので、
入口 (50/75 の境目) の分だけの一定の SWR になる。

```vna
device: h4
sweep: 1M-300M 301
title: 図2 75 Ω ケーブル・先端を 75 Ω で終端 — SWR は一定
dut:
  - line 75 2m vf 0.66
  - series R 75
  - short
traces:
  - S11 swr
```

先を (75 Ω ではなく) **50 Ω で終端してしまった**場合 — 入口と先端の
両方で反射が起き、線路の長さぶんだけ位相が回るので、SWR が周波数で揺れる。

```vna
device: h4
sweep: 1M-300M 301
title: 図3 75 Ω ケーブルの先を 50 Ω で終端 (間違い) — SWR が揺れる
dut:
  - line 75 2m vf 0.66
  - series R 50
  - short
traces:
  - S11 swr
markers:
  - 24.73M
  - 49.47M
```

## 見るべき値

計算値。75 Ω を 75 Ω で正しく終端すると、線路のどこを切っても
入口から見た Z は 75 Ω のまま変わらない。一方、先を 50 Ω で終端すると、
入口 (50/75) と先端 (75/50) の両方に段差ができ、線路の長さぶんの位相が
2 つの反射の間で回るので、λ/4 の奇数倍で最大、偶数倍で最小になる。
2 m・vf 0.66 の線路では λ/4 = 24.73 MHz おき。

| 項目 | 値 |
| --- | --- |
| 75 Ω で終端したときの SWR | 75 / 50 = **1.5 (周波数によらず一定)** |
| 50 Ω で終端したときの SWR の最大 (24.73 MHz、λ/4 の奇数倍) | 75² / 50² = **2.25** |
| 50 Ω で終端したときの SWR の最小 (49.47 MHz、λ/2 の整数倍) | **1.0 (たまたま合って見える)** |

分かること:

- **正しく終端していれば、50/75 の違いは「入口の 1.5」だけで済む。** これは
  よくある BNC 変換や測定器の入力インピーダンスの違いとほぼ同じ扱いで、
  実用上は気にしなくてよいことが多い
- **終端を間違えると、ケーブルの長さと周波数で SWR が暴れる。** 75 Ω の
  ケーブルをうっかり 50 Ω の負荷で終端すると、λ/2 の整数倍の周波数では
  SWR がちょうど 1 になって「たまたま良く見える」が、その中間 (λ/4 の
  奇数倍) では 2.25 まで悪化する — **周波数を 1 点しか測らないと見誤る**典型
- 75 Ω の CATV 分配器やテレビのアンテナ線を 50 Ω の無線機につなぐときは、
  **入口と先端の両方**を意識する。片方だけ 75 Ω に合わせても、もう片方が
  ずれていれば揺れが残る
