# 5-1 ケーブルの S21 と長さ (TDR)

同軸ケーブルの先が開放か短絡かだけなら S11 の位相からも分かるが、**どこまでの
長さがあるか**は周波数領域の図からは読み取りにくい。S11 を逆フーリエ変換した
**TDR (時間領域反射)** を使うと、山の位置がそのまま距離になる。長さ 5 m の
同軸ケーブル (先端は開放) で確かめる。

## 回路図

CH0 に 5 m のケーブルをつなぎ、先端は開放のまま。

```circuit
title: 図1 先を開放した 5 m のケーブル
parts:
  J1: sma b2 mirror
  G1: ground c2
wires:
  - J1.1 -- b8
  - J1.2 -- c2
notes:
  - text a2 center: CH0
  - text e5 center: 5 m の同軸ケーブル
  - text b8a2: 開放
```

先端 (b8) は何にもつながず、意図して開放のままにする。

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜900 MHz |
| 点数 | 401 (TDR には等間隔の掃引が要る) |
| 校正 | SOLT。ケーブルの根元 (CH0 の SMA) で Open / Short / Load / Thru |
| 表示 | S11 の TDR (速度係数 0.66) と Log Mag |

見えるはずの画面 (理想の模型)。

```vna
device: h4
sweep: 1M-900M 401
title: 図2 先を開放した 5 m のケーブルの TDR
dut:
  - line 50 5m vf 0.66
  - open
traces:
  - S11 tdr vf 0.66
  - S11 logmag
```

## 見るべき値

TDR の横軸は距離 (速度係数から換算)。山の位置がケーブルの先端までの距離。
この模型と掃引で `check` が報告する山の位置は **4.99 m** — 401 点の離散化に
よる誤差で、ケーブルの物理長 5 m とほぼ一致する。

| 項目 | 値 |
| --- | --- |
| 山の位置 | 約 5 m (計算値 4.99 m。物理長そのもの) |
| S11 Log Mag | 0 dB (全反射。損失の無い理想の線路なので周波数によらず一定) |

分かること:

- **TDR の山の位置を読むだけで、ケーブルの長さが分かる。** 巻いてあって
  端が見えないケーブルでも、長さや途中の状態が調べられる
- 一方 Log Mag (S11) は**全反射である限り常に 0 dB** — 開放でも短絡でも
  同じ 0 dB になるので、Log Mag だけでは「開放か短絡か」も「どこまでの
  長さか」も分からない。TDR が要る理由がここにある
- 横に見える範囲は掃引の点の間隔で決まる (1 / 点間隔)。5 m より遠くまで
  見たいときは点数を増やすか、範囲を狭くする
