# 5-18 ケーブルを曲げると何が変わるか

同軸ケーブルを曲げると、何が変わり、何が変わらないのか。ゆるく曲げただけなら、
**損失と反射はほとんど変わらず、位相がわずかに動く** (5-17)。ところが、許される半径より
きつく曲げたり、踏んだり、結束バンドで締め上げたりして**断面が潰れる**と、そこだけ
Z₀ が下がり、TDR に山が立つ。2 m の RG-58 の真ん中を 2 cm だけ潰したときに、
H4 の TDR と S11 に何が出るかを見る。

## この実験で確かめる式

同軸の Z₀ = (60 / √ε<sub>r</sub>) × ln(b / a) (ε<sub>r</sub> (イプシロン) は誘電体の比誘電率、a は芯線の半径、
b は外部導体の内半径)。RG-58 (a = 0.405 mm、b = 1.43 mm、ε<sub>r</sub> = 2.30) で 49.9 Ω (オーム)。

潰れて外部導体が芯線に近づくと b が小さくなり、Z₀ が下がる。**b が 2 割縮んで 1.15 mm に
なると Z₀ = 41.3 Ω**。ここでは丸めて、潰れた所を **40 Ω・2 cm の線**と**仮定**する
(実物の値は潰れ方で変わる。測って読むのがこの題)。

潰れた所の入口の反射係数は Γ (ガンマ) = (40 − 50) / (40 + 50) = **−0.11**。出口では +0.11 で、
2 つの反射の間は 2 cm (往復 4 cm) しかないので、周波数が低いと打ち消し合い、高いほど目立つ。

## 回路図

```circuit

parts:
  J1: sma 2,2 mirror CH0
  TL1: tline 3,2 5,2 50 l=$\mathrm{TL}_1$
  TL2: tline 6,2 8,2 40 l=$\mathrm{TL}_2$
  TL3: tline 9,2 11,2 50 l=$\mathrm{TL}_3$
  R1: resistor 12,2 12,4 50
  G1: ground 2,3
  G2: ground 12,4
wires:
  - J1.1 -- 3,2
  - 5,2 -- 6,2
  - 8,2 -- 9,2
  - 11,2 -- 12,2
  - J1.2 -- 2,3
notes:
  - text 4,2.7 center: 1 m
  - text 7,2.7 center: 潰れた 2 cm
  - text 10,2.7 center: 1 m
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/05-transmission-lines/circuit/18-cable-bend.svg)

- TL1〜TL3 は 1 本の RG-58 (2 m、速度係数 0.66)。TL2 は潰れた所の**等価回路**
- R1 は校正キットの Load (50 Ω)。先を終端して、潰れた所の反射だけを見る
- 潰すのは**捨ててよいケーブル**で。万力に挟むか、細い棒の上で結束バンドをきつく締める

## 掃引の設定

計器は VNA。この本の図は NanoVNA-H4 で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。

この題は実体配線図を付けない — ケーブルを曲げ・潰して測る題で、組む回路が無い。

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜1.5 GHz (H4 の上の端まで。2 cm を見るには範囲を広く取る) |
| 点数 | 401 (TDR には等間隔の掃引が要る) |
| 校正 | SOLT。TL1 の根元 (CH0 の SMA) で Open / Short / Load / Thru |
| 表示 | S11 の TDR (速度係数 0.66) と Log Mag |

手順: (1) まっすぐのまま測る (TDR は平ら) → (2) 真ん中を直径 10 cm の輪に曲げて測る →
(3) 真ん中を 2 cm だけ潰して測る。(1) と (2) はほとんど同じ画面になる。見えるはずの画面 (3)
(理想の模型)。


## 見るべき値

計算値 (40 Ω・2 cm の仮定による)。

| 項目 | 値 |
| --- | --- |
| 図2 の TDR の山 | **1.005 m** (潰れた所。高さ 0.10) |
| 図2 の S11 (300 MHz) | −27.42 dB |
| 図2 の S11 (900 MHz) | −18.36 dB |
| 図2 の S11 (1.5 GHz) | −14.88 dB |
| ゆるい輪 (手順 2) | TDR は平ら、S11 は −40 dB より下のまま (目安) |

- **ゆるく曲げても Z₀ は変わらない**。断面の形 (b / a) が保たれるから。曲げで動くのは主に位相
  (5-17・9-8) で、損失もほとんど変わらない。RG-58 を繰り返し曲げてよい半径は、外径の 10 倍
  (50 mm) ほどが目安 (メーカーの資料で確かめる)
- **潰れると、その場所だけ Z₀ が下がる**。TDR は 1 m の所に高さ 0.10 の山を出す (|Γ| = 0.11 に近く、
  窓のぶん少し低い)。山の位置で、どこが潰れたかが分かる
- S11 は低い周波数でほぼ 0 (入口と出口の反射が打ち消す)。300 MHz で −27 dB、1.5 GHz で −15 dB と
  **周波数とともに増える**。低い周波数で使うぶんには気付かず、GHz で使って初めて困る
- この図の TDR (帯域通過) は山の高さしか言わない。H4 の TDR を **LOW PASS STEP** (2-7) にすると、
  潰れた所は 50 Ω の線より**下にへこむ** (Z₀ が低い)。芯線がずれて離れた所や、外れかけたコネクタは
  **上に出る** (Z₀ が高い)。**山の向きで、潰れか開きかを見分ける**
- 一度潰れたケーブルは、伸ばしても戻らない。山が立ったケーブルは GHz の測定には使わない

## LTspice での確かめ

`sim/18-cable-bend.cir` で、図の `dut:` の模型を LTspice の AC 解析にかけた (50 Ω の電源、先は 50 Ω で終端、損失の無い T 素子)。理想の模型どうしの比べで、実測ではない。

| 図 | 周波数 | 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- | --- | --- |
| 図2 | 300 MHz | S11 | −27.42 dB | −27.42 dB | 合う |
| 図2 | 900 MHz | S11 | −18.36 dB | −18.36 dB | 合う |
| 図2 | 1.5 GHz | S11 | −14.88 dB | −14.88 dB | 合う |

.meas は \|S11\| を線形で出すので (0.0426・0.121・0.180)、20 log₁₀ で dB に直した。

TDR の山の位置は AC 解析では出ないので、算術で確かめた。潰れた所の入口は 1 m で、往復 2 × 1 / (0.66 × 2.998 × 10⁸) = 10.1 ns。
入口と出口 (1.02 m) の 2 つの反射は 2 cm しか離れず、H4 の 1.5 GHz の分解能 (0.066 m、2-7 の式) より近いので 1 つの山に融け、
check の読みは真ん中寄りの 1.005 m になる。Z₀ = 41.3 Ω (b = 1.15 mm) も上の式の算術。
