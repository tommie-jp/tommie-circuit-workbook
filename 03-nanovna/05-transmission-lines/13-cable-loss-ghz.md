# 5-13 GHz でのケーブル損失 (2.4 GHz)

5-3 では 1 m の同軸ケーブル (RG-58 相当) の損失を 430 MHz まで見た。ここでは同じ 1 m を
**3 GHz まで**掃引し、無線 LAN (Wi-Fi・Bluetooth) の 2.4 GHz でどれだけ落ちるかを読む。
H4 は 1.5 GHz で止まるので、V2 で測る。比べるために、細い RG-174 (SMA のピッグテールに
よく使う) も同じ長さで測る。

GHz では損失の中身が変わる。導体の表皮効果の損失は周波数の平方根で増えるが、
誘電体の損失は**周波数に比例**して増えるので、上へ行くほど誘電体の割合が増す。

## この実験で確かめる式

1 m あたりの減衰 α (アルファ、dB/m) は、導体の損失 α<sub>c</sub> と誘電体の損失 α<sub>d</sub> の和。

- α<sub>c</sub> = 8.686 × R<sub>s</sub> / (2η (イータ)) × (1/a + 1/b) / ln(b/a)。R<sub>s</sub> = √(π (パイ) f µ₀ / σ (シグマ)) (µ₀ (ミュー) は真空の透磁率、σ は銅の導電率)、
  η = 376.7 Ω (オーム) / √ε<sub>r</sub> (イプシロン。ε<sub>r</sub> は誘電体の比誘電率)。a は芯線の半径、b は外部導体の内半径
- α<sub>d</sub> = 8.686 × π f √ε<sub>r</sub> tan δ (デルタ) / c

寸法は 5-3 と同じ (RG-58: a = 0.405 mm、b = 1.43 mm、ε<sub>r</sub> = 2.30、tan δ = 2 × 10⁻⁴ と仮定)。
RG-174 は誘電体の外径 1.52 mm (b = 0.76 mm) と仮定し、50 Ω になる芯線 (a = 0.215 mm) で計算した。

  (変換 1 個で 2.4 GHz の反射と損失が増え、ケーブルの損失と分けられない。5-9・5-19)

## 掃引の設定

計器は VNA。この題の図は NanoVNA V2 (歴史的な機種) で書いてあり、標準の LiteVNA64 でも同じ手順で測れる (2.4 GHz は H4 の範囲の外)。AD3 とオシロは使わない (S パラメータを見る題)。

この題は実体配線図を付けない — ケーブルそのものを測る題で、基板に載せる回路が無い。

| 項目 | 値 |
| --- | --- |
| 範囲 | 50 MHz〜3 GHz |
| 点数 | 301 |
| 校正 | SOLT。CH0・CH1 から来るケーブルの先 (TL1 を挿す所) で。Thru は SMA の中継 (J-J) で |
| 表示 | S21 の Log Mag (0.2 dB/目盛)。平均化を 4〜8 回 (目安) |

`line` の理想の模型は損失を持たないので、見えるはずの画面 (理想) は **0 dB の上端に乗ったまま**。
丸の印は上の式で計算した RG-58 の損失で、実測はこの丸のあたり (実物は 1.5〜2 倍下) に沈む。


## 見るべき値

上の式からの計算値 (1 m あたり。実測ではない)。マーカーの読み値は理想の模型なので 3 点とも 0.00 dB。

| 周波数 | RG-58 の α<sub>c</sub> | RG-58 の α<sub>d</sub> | RG-58 の計 | RG-174 の計 |
| --- | --- | --- | --- | --- |
| 900 MHz | 0.34 dB | 0.03 dB | **0.36 dB** | 0.66 dB |
| 1.5 GHz | 0.44 dB | 0.04 dB | **0.48 dB** | 0.86 dB |
| 2.4 GHz | 0.55 dB | 0.07 dB | **0.62 dB** | 1.11 dB |

- 5-3 の 430 MHz (0.25 dB) から 2.4 GHz (5.6 倍の周波数) へ、導体の損失は √5.6 = 2.4 倍になる。
  誘電体の損失は 0.01 dB から 0.07 dB へ 5.6 倍で、2.4 GHz では全体の 1 割を超える
- 実物の RG-58 は撚り線の芯線と編組の外部導体で、この見積りの **1.5〜2 倍** (目安) に出る。
  2.4 GHz で 1 m あたり 1 dB 前後を読めば、だいたい合っている
- RG-174 は外径が半分ほどで、損失は **ほぼ 2 倍**。α<sub>c</sub> はおよそ 1/b に比例するので、
  細いケーブルほど GHz で損をする。1 m の RG-174 で 2.4 GHz の 2 dB は、送信の電力の 4 割に当たる
- アンテナまで 5 m 引くなら、RG-58 でも 2.4 GHz で 3〜5 dB (目安)。**GHz の給電線は短く太く**、
  損失の少ない発泡の誘電体のケーブルを選ぶ理由

測り方の注意:

- 0.5 dB ほどの小さな落ち込みを読むので、**校正の Thru に使う中継の損失**と、端の SMA の
  反射による波打ち (±0.05 dB ほど、目安) が効く。波打ちの山と谷の真ん中を読む
- V2 の S21 の雑音は平均化で下げる (9-9)。読む周波数の前後の点を見て、ばらつきの幅も書いておく
- ケーブルを動かすと位相と振幅がわずかに動く (5-17・5-18)。校正の後は CH0・CH1 側のケーブルを動かさない

## LTspice での確かめ

`sim/13-cable-loss-ghz.cir` で 2 つを確かめた。理想の模型どうしの比べで、実測ではない。

1. 図2 の `dut:` (損失の無い T 素子、50 Ω の電源と 50 Ω の終端) の S21
2. 損失を入れた線路 (LTspice の LTRA)。1 m あたりの R を、上の式の α<sub>c</sub> + α<sub>d</sub> (Np/m) から
   R = 2 Z₀ (α<sub>c</sub> + α<sub>d</sub>) で決めた。LTRA は G を持てないので誘電体の損失も R に寄せた
   (損失が小さいときは同じ減衰になる)。R は周波数で変わるので、周波数ごとに 1 本ずつ置いた

| 図・模型 | 周波数 | 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- | --- | --- |
| 図2 (損失なし) | 900 MHz | S21 | 0.00 dB | 0.00 dB | 合う |
| 図2 | 2.4 GHz | S21 | 0.00 dB | 0.00 dB | 合う |
| LTRA (RG-58) | 900 MHz | S21 | −0.36 dB | −0.36 dB | 合う |
| LTRA (RG-58) | 1.5 GHz | S21 | −0.48 dB | −0.48 dB | 合う |
| LTRA (RG-58) | 2.4 GHz | S21 | −0.62 dB | −0.62 dB | 合う |

.meas は \|S21\| を線形で出すので (0.959・0.946・0.931)、20 log₁₀ で dB に直した。式の α を線路の R に置き換えても、同じ減衰が出ることを確かめた。
