# 9-1 1.5 GHz より上へ — スルーで 3 GHz まで見る (ケーブルとコネクタで何 dB 落ちるか)

計画の機種は H4 だが、**H4 は 1.5 GHz までしか出ない**。この題そのものが
「1.5 GHz より上へ行くには何が要るか」を確かめる題なので、1.5〜3 GHz の実際の
掃引は **V2 に持ち替えて**行う。H4 でできるのは 1.5 GHz までの手前の確認だけ。
(前書きに「必須の題は全部 H4 でできる」とあるのは 50 題全体の話で、この題は
機種の壁そのものを扱うため例外的に V2 が要る。)

2 本のケーブルをバレルアダプタでつないだだけの「スルー」を、50 kHz から
3 GHz まで掃引し、ケーブルとコネクタでどれだけ落ちるかを見る。

## この実験で確かめる式

同軸ケーブルの損失は**周波数の平方根にほぼ比例**する (表皮効果が主な原因)。
ある周波数 f_ref での損失 α_ref [dB/m] が分かれば、**α(f) ≈ α_ref × √(f / f_ref)**
という近似が使える。

細い同軸 (RG316 など) の 1 GHz での損失を目安の**α_ref ≈ 0.75 dB/m**とすると、
1 m (0.5 m × 2 本) での計算値:

| 周波数 | 計算値 (ケーブル損失のみ) |
| --- | --- |
| 1.5 GHz | 0.92 dB |
| 2.0 GHz | 1.06 dB |
| 3.0 GHz | 1.30 dB |

これにコネクタ (SMA 4 個・バレルアダプタ 1 個) の損失が乗る。1 組あたり
0.05〜0.1 dB程度が目安で、ここでは計算値に含めない (実測で上乗せ分として見る)。

## 回路図

板は使わず、ケーブル 2 本をバレルアダプタで直結しただけ。

```circuit
title: 図1 ケーブル 2 本をバレルアダプタで直結
parts:
  J1: sma b2 mirror CH0
  J2: sma b10 CH1
  G1: ground c2
  G2: ground c10
wires:
  - J1.1 -- J2.1
  - J1.2 -- c2
  - J2.2 -- c10
notes:
  - text a6 center: バレルアダプタ (ここで 2 本のケーブルをつなぐ)
```

- 回路図としては 1 本の線と変わらない (同軸ケーブルは伝送線路なので、この本の
  circuit フェンスには専用の記号は無い。ただの導線として描き、注記で
  アダプタの位置だけ示す)

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 50 kHz〜3 GHz (**V2 でないと 1.5 GHz より上は出ない**) |
| 点数 | 401 |
| 校正 | SOLT (V2 に持ち替えたら再校正。1-4 参照) |
| 表示 | S21 の Log Mag |

**フェンスの制約**: この本のフェンス (vna 0.1.0) の `dut: line` は**損失を
考えない理想の伝送線路**なので、ケーブル損失で右肩下がりになる実際の画面は
描けない。ここでは位相だけ正しい**理想 (損失なし) の画面**を示し、
実際に予想される減衰は上の表の計算値で示す。

```vna
device: v2
sweep: 50k-3G 401
title: 図2 2 本のケーブル (計 1 m) のスルー (理想、損失なし)
dut:
  - line 50 0.5m vf 0.66
  - line 50 0.5m vf 0.66
traces:
  - S21 logmag
markers:
  - 1.5G
  - 3G
```

- 理想の画面は損失が無いので S21 は 0 dB のまま平ら (フェンスの制約)。
  **実際に NanoVNA-V2 で測ると、上の表のとおり右肩下がりになるはず**
- H4 はそもそも 1.5 GHz より上を掃引できないので、この画面 (1.5〜3 GHz) は
  V2 でしか出ない

## 見るべき値

計算値 (√f 近似、メーカー公表値の目安から)。

| 周波数 | 使う機種 | S21 (計算値、ケーブル損失のみ) |
| --- | --- | --- |
| 500 MHz | H4 でも V2 でも可 | −0.53 dB |
| 1.5 GHz | H4 の上限。ここまでは H4 で | −0.92 dB |
| 2.0 GHz | V2 が必要 | −1.06 dB |
| 3.0 GHz | V2 の上限付近 | −1.30 dB |

- **H4 の壁は 1.5 GHz。** それより上を見るには V2 (〜3 GHz) か Plus4 (〜4.4 GHz)
  に持ち替える (0-1 参照)
- ケーブル損失は周波数が上がるほど増えるが、1 m 程度・3 GHz までなら
  1.3 dB 程度で、多くの測定では無視できる範囲。GHz 帯で厳密に扱うなら
  デエンベディング (3-8) でケーブル分を差し引く

## 出典

自作。同軸ケーブルの損失が周波数の平方根にほぼ比例するのは、表皮効果に基づく
一般的な近似 (メーカーのデータシートに載る値の目安から α_ref を仮定した)。
