# 3-6 治具の限界周波数 — どこまで信じるか

3-3 のスルー治具は理想では 0 Ω だが、実物には**中心導体をつなぐ線の
長さぶんのインダクタンス**が残る。周波数を上げるとこのインダクタンスの
リアクタンスが無視できなくなり、「治具のせいで DUT の値がずれて見える」
限界が来る。その限界を見積もり、**線の長さでどれだけ変わるか**を
5×7 cm のユニバーサル基板の幅いっぱいの線で確かめる。

## 回路図

3-3 と同じ形のスルー治具。中心導体をつなぐ線の長さがそのまま寄生インダクタンス
になる。

```circuit
title: 図1 スルー治具 (3-3 と同じ形)
parts:
  J1: sma b2 mirror
  J2: sma b8
  G1: ground c2
  G2: ground c8
wires:
  - J1.1 -- b8
  - J2.1 -- b8
  - J1.2 -- c2
  - J2.2 -- c8
notes:
  - text a2 center: CH0
  - text a8 center: CH1
```

## 実体配線図

```perfboard
board:
  size: 7x5cm
  slots: on
title: 図2 GND を信号の線の隣に通したスルー
parts:
  J1: sma/female-edge i1 h0 j0
  J2: sma/female-edge i24 j25
wires:
  - i1 -- i24
  - j0 -- j25 black
```

![ユニバーサル基板の実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/03-fixtures/perfboard/06-fixture-limit.svg)

図 2 は、3-3 と同じ 5×7 cm のユニバーサル基板のスルー (部品面から見た図)。中心導体の間はユニバーサル基板の幅
いっぱいの 23 穴 (5.8 cm) になる。GND は凹の腕どうし (j0〜j25) を信号の線のすぐ
隣でつなぎ、帰り道を短くする。

- J1 から J2 までの i 行の線が長いほど、寄生インダクタンスが大きくなる。
  8-3 の直線の導線の経験式 L (nH) ≈ 0.2 l {ln(2l/d) − 0.75} (l は長さ mm、d は線径 0.64 mm)
  で見積もると、線の長さと限界は次のとおり (目安)。4-7 の「リード線 1 cm で約 7 nH」は
  短いピンの目安で、数 cm の線では経験式のほうが実物に近い

| 線 | 長さ | 線のインダクタンス | S11 が −20 dB になる周波数 |
| --- | --- | --- | --- |
| 図 2 の基板 (i1〜i24、幅いっぱい) | 23 穴 (5.8 cm) | 約 52 nH | 約 31 MHz |
| 12 穴 | 3.0 cm | 約 23 nH | 約 69 MHz |
| 6 穴 | 1.5 cm | 約 9.5 nH | 約 170 MHz |
| 3 穴 | 7.6 mm | 約 3.7 nH | 約 430 MHz |

- 5×7 cm のユニバーサル基板の幅いっぱいの線は長く、**30 MHz あたりで −20 dB の目安を超える**。
  この治具で信じられるのは HF (30 MHz 以下) まで。経験式の L は長さより速く減るので、
  線を縮めると限界は長さの比より大きく上がる。それでも 300 MHz まで測るには
  SMA から測る点までを 3 穴 (1 cm 以下) にする必要がある (4 穴で約 290 MHz)
- この見積もりは信号の線だけを数えている。GND の帰り道が遠回りなら、そのぶん
  インダクタンスが足されて限界はさらに下がる。図 2 のように GND を信号の線の
  すぐ隣に通すのは、帰り道を信号の線と同じ長さに抑えるため
- 以下の模型は図 2 の基板の 52 nH で描く

## 掃引の設定

計器は VNA。この本の図は NanoVNA-H4 で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜100 MHz |
| 点数 | 101 |
| 校正 | SOLT。ケーブルの先 (治具の SMA に挿す手前) で Open / Short / Load / Thru |
| 表示 | S21 の Log Mag、S11 の Log Mag |

0 Ω のスルーに寄生インダクタンス 52 nH を直列に足した模型。

```vna
device: h4
sweep: 1M-100M 101
title: 図3 52 nH が残るスルー — S11 は 31 MHz で −20 dB
dut:
  - series R 0 esl 52.1n
traces:
  - S21 logmag
  - S11 logmag
markers:
  - 10M
  - 30.7M
  - 100M
notes:
  - text 50M -60dB: S11 が −20 dB を超える所が限界の目安
```

## 見るべき値

| 周波数 | S21 (計算値) | S11 (計算値) |
| --- | --- | --- |
| 10 MHz | 0.00 dB | −29.70 dB |
| 30.7 MHz | −0.04 dB | −20.00 dB |
| 100 MHz | −0.44 dB | −10.14 dB |

- **S21 はほとんど動かない。** 52 nH のリアクタンスは 31 MHz で 10 Ω、100 MHz でも
  33 Ω 程度で、通り抜ける量は −0.4 dB しか減らない。図3 の S21 が上端の 0 dB から
  離れないのは意図どおりで、動かないことを見る線
- **S11 のほうがずっと敏感。** 10 MHz では −30 dB (十分小さい) だが、
  31 MHz で −20 dB、100 MHz では −10 dB まで悪化する。**S11 が −20 dB (VSWR 約 1.22) を
  超えて悪化し始める周波数が、この治具を信じられる目安**になる
- 3-1・3-2 で 100 Ω や大きな値の部品を測るときも、この治具そのものの
  限界より高い周波数では**部品の値と治具の寄生分が区別できなくなる**。
  3-1・3-2 のユニバーサル基板も、SMA から部品までの線を短くするほど限界が上がる

**治具を作ったら、まず DUT 無し (このスルー) を測って自分の治具の限界を
知っておく。** 線を短くするほど寄生インダクタンスが減り、限界周波数は
上がる (23 穴を 12 穴に縮めると L は 52 nH → 23 nH と半分より小さくなり、
−20 dB の目安は約 2.2 倍の 69 MHz まで伸びる)。
