# 1-13 校正の点数 (101 vs 1001) と Saver の分割掃引

校正は、**掃引の点ごとに**補正の係数 (誤差の項) を覚える (1-1)。測るときの点が校正の点と
同じなら、その点の係数をそのまま使う。範囲や点数を変えて点がずれると、近くの 2 点の係数から
**まっすぐな線で補間**する。この補間が、校正ケーブルが長いと効いてくる。何点で校正すれば
足りるかを、ケーブルの長さから決める。

## 補間はどこで起きるか

| 場面 | 何が起きるか |
| --- | --- |
| 本体 (H4、DiSlord 版) で、校正と同じ範囲・点数で測る | 補間なし。画面左の校正の印は大文字の **C** |
| 本体で、範囲の中で掃引を狭めた・点数を変えた | 隣の 2 点から直線で補間。印は小文字の **c** (色も変わる) |
| 本体で、校正の範囲の外へ出た | 端の点の係数を使い続ける (1-4 の狂い方) |
| NanoVNA-Saver の校正 (2-9) で、同じ範囲・セグメント数で測る | 補間なし |
| Saver で、校正と違う点で測る | 校正の点の間を直線で補間 (ソースの `slinear`) |

本体の点数の上限は、DiSlord 版の H4 で 401 点 (51・101・201・301・401 から選ぶ)。それより
細かく校正したいなら、Saver で 101 点のセグメントを並べる (10 セグメントで 1010 点。2-4)。

## なぜケーブルが長いと補間が効くか

誤差の項には、計器の中の橋から**校正ケーブルの先 (基準面) までの往復の遅れ**が入っている。
長さ L・速度係数 VF のケーブルなら往復の遅れは 2τ = 2L ÷ (VF × c) で、係数の位相は周波数とともに
360° × f × 2τ の速さで回る。隣り合う校正の点 (間隔 Δf) では、位相が

Δφ = 360° × Δf × 2τ

だけ違う。大きさ 1 で位相が Δφ 違う 2 つの値を直線で結ぶと、真ん中の点は円の内側へ落ち、
大きさが cos(Δφ ÷ 2) に縮む。**反射の読みが、点と点の真ん中で最大 1 − cos(Δφ ÷ 2) だけ小さく出る**。

## 掃引の設定

計器は VNA。この本の図は NanoVNA-H4 で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。

この題は実体配線図を付けない — 校正の点数を決める題で、組む物が無い (測るのは校正ケーブルの先の開放)。

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜900 MHz (図2・図3 は点の間隔を同じにして 55〜145 MHz を拡大) |
| 点数 | 101 と 1001 (Saver なら 101 点の 10 セグメントで 1010)。図2 は 11 点、図3 は 101 点で同じ間隔 |
| 校正 | 図2・図3 は校正を外す (ケーブルの回りを見るため)。確かめの手順では 101 点で SOLT |
| 表示 | S11 の位相と極 (polar) |

1 m のケーブルの先の開放を、1〜900 MHz を 101 点で掃引したときと同じ 9 MHz おきの点で見たとき (理想の模型。55〜145 MHz だけを拡大)。点の間で位相が 32.7° 回る。

- 位相は 99 MHz ごとに 1 周する (1 ÷ 10.1 ns)。9 MHz おきでは 1 周を 11 点ほどで描くので、
  極の図 (右) では半径 1 の円が **11 角形** になる。辺の真ん中は円の内側に落ちる — これが補間の縮み。
  校正の係数も、この辺のように点の間を直線で結ばれる
- 0.9 MHz おき (図3) では 110 角形で、円との差は目で見えない
- マーカーの 100 MHz・104.5 MHz・109 MHz は、どちらの図でも模型を計算した値 (−3.9°・−20.3°・−36.6°)。
  101 点の校正で 104.5 MHz を測ると、係数は 100 MHz 付近と 109 MHz 付近の 2 点から作られる

## 何点で校正すればよいか

1〜900 MHz を校正したときの、点の間の位相 Δφ と、真ん中の点で反射の読みが縮む割合 (最悪の値、計算値)。

| 校正ケーブル (VF 0.66) | 往復の遅れ | 101 点 (8.99 MHz おき) | 401 点 (2.25 MHz おき) | 1010 点 (Saver、0.89 MHz おき) |
| --- | --- | --- | --- | --- |
| 30 cm | 3.03 ns | 9.8°、0.37 % (−0.032 dB) | 2.5°、0.02 % | 1.0°、0.00 % |
| 1 m | 10.1 ns | 32.7°、4.05 % (−0.36 dB) | 8.2°、0.25 % (−0.022 dB) | 3.2°、0.04 % |
| 3 m | 30.3 ns | 98.1°、34.5 % (−3.67 dB) | 24.5°、2.28 % (−0.20 dB) | 9.7°、0.36 % (−0.031 dB) |

**この教科書の決め**: 点の間の位相 Δφ が 10° 以下になる点数で校正する (縮みが 0.4 % 以下)。
目安は「点数 ≥ 36 × 範囲 × 往復の遅れ」(上の Δφ の式から)。30 cm なら 101 点で足り、
1 m なら 401 点、3 m なら Saver で 1010 点。**掃引を狭めて拡大したいときは、狭めた範囲で
校正し直すのが一番確か** (1-4)。

## 確かめの手順

1. 1 m の校正ケーブルで、1〜900 MHz・101 点で SOLT する (印は C)
2. 付属の Short をつなぎ、掃引を 95〜115 MHz に狭める (印が c に変わる)
3. S11 の Log Mag を 0.1 dB/目盛で見る。校正の点 (99.9 MHz・108.9 MHz) では 0 dB、その真ん中
   (104.4 MHz 付近) で最大 −0.36 dB へ下がる、9 MHz 周期の波が見える
4. 同じことを 401 点の校正で繰り返し、波が −0.02 dB ほどに小さくなるのを確かめる

## 見るべき値

| 項目 | 値 |
| --- | --- |
| 1 m のケーブルの往復の遅れ | 10.1 ns (位相は 99 MHz で 1 周) |
| 図2・図3 の S11 の位相 (100 / 104.5 / 109 MHz) | −3.9° / −20.3° / −36.6° (どちらの図も同じ。模型の計算値) |
| 101 点の点の間の位相 Δφ | 32.7° (図2) |
| 1001 点の点の間の位相 Δφ | 3.3° (図3。1010 点なら 3.2°) |
| 101 点の校正の後、点の真ん中での Short の読み | 最大 −0.36 dB (4.05 % 縮む) |
| 401 点の校正の後、同 | 最大 −0.022 dB |

## LTspice での確かめ

`sim/13-cal-points-segments.cir` で、図2・図3 の模型 (1 m・VF 0.66 の線の先を開放) を LTspice の AC 解析にかけた。理想の模型で、実測ではない。

| 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| S11 の位相 (100 / 104.5 / 109 MHz) | −3.9° / −20.3° / −36.6° | −3.89° / −20.26° / −36.64° | 合う |
| 101 点の隣り合う校正の点 (99.89 MHz と 108.88 MHz) の位相差 | 32.7° | 32.71° | 合う |
| その 2 点の値を直線で結んだ真ん中の大きさ | 4.05 % 縮む (−0.36 dB) | 0.9595 (−0.359 dB) | 合う |

真ん中の大きさは、LTspice の 2 点の複素数の値を平均した算術 (補間の計算そのものは LTspice の対象外)。
表の 30 cm・3 m・401 点・1010 点の行は Δφ の式と 1 − cos(Δφ ÷ 2) の算術。
