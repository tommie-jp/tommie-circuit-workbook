# 1-6 校正の保存スロットと呼び出し

NanoVNA は校正した補正係数を**複数のスロット**に保存できる。よく使う
範囲ごとに 1 つずつ校正して保存しておけば、そのつど 9 手順 (1-1) を
やり直さずに呼び出せる。

## スロットの使い分けの例

| スロット | 範囲 | 用途 |
| --- | --- | --- |
| 0 | 1 MHz〜300 MHz | 部品・治具・フィルタを見る、いつもの範囲 (1-1) |
| 1 | 130 MHz〜160 MHz | 144 MHz 帯のアンテナ調整 (7-2 の 2 m バンド) |
| 2 | 400 MHz〜470 MHz | 430 MHz 帯のアンテナ調整 (7-3) |

**範囲を切り替えるたびに校正し直すのではなく**、あらかじめそれぞれの
範囲で校正してスロットに保存しておき、使うときは呼び出すだけにする。
呼び出しても再校正にはならない — **保存したときの範囲と点数のままの
補正係数が戻ってくる**だけなので、範囲を変えたいならそのスロットを
上書きする (1-4)。

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 130 MHz〜160 MHz (スロット 1 の例) |
| 点数 | 101 |
| 校正 | スロット 1 に保存済みのものを呼び出す |
| 表示 | S21 の Log Mag、S11 の Log Mag |

スロットを呼び出した直後に Thru を測り直すと、保存したときと同じ
理想値に戻るはずである。

```vna
device: h4
sweep: 130M-160M 101
title: 図1 スロット 1 を呼び出した直後の Thru
dut: series R 0
traces:
  - S21 logmag
  - S11 logmag
markers:
  - 130M
  - 144M
  - 160M
```

## 見るべき値

| 確かめること | 期待する値 | 分かること |
| --- | --- | --- |
| 呼び出し直後の Thru の S21 | 0 dB (計算値) | 保存・呼び出しが正しい |
| 呼び出し直後の Thru の S11 | 検出限界以下 (計算値) | 反射の補正も保存されている |
| 呼び出した掃引範囲・点数 | 保存したときと同じ | 範囲を変えたいなら上書き保存が要る (1-4) |

**電源を切っても保存したスロットは消えない。** ただし校正の有効期間
(温度・経年、1-9) には限りがあるので、しばらく使っていなかったスロットは
Thru を測り直して確かめてから使う。
