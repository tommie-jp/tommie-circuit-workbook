# 1-4 範囲を変えたら再校正 — 変えずに測るとどう狂うか

校正で求まる補正係数は、**校正したときの周波数の点そのもの**に対して
計算される。掃引の開始・終了・点数を変えると、新しい点は校正した点と
ずれるので、**古い校正のままでは補正が合わなくなる**。

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 元の範囲 | 1 MHz〜300 MHz、101 点 (1-1 で校正した範囲) |
| 変えたい範囲 | 300 MHz〜900 MHz、101 点 |
| 校正 | 範囲を変えたら SOLT をやり直す |
| 表示 | S21 の Log Mag、S11 の Log Mag |

範囲を変えて**やり直した**あとの Thru は、元の範囲のときと同じ理想値になる。

```vna
device: h4
sweep: 300M-900M 101
title: 図1 300〜900 MHz を再校正した後の Thru
dut: series R 0
traces:
  - S21 logmag
  - S11 logmag
markers:
  - 300M
  - 900M
```

- 再校正すれば、範囲が変わっても S21 = 0 dB・S11 は検出限界以下のまま
- **再校正しないまま範囲だけ広げると**、新しい点の一部 (特に元の範囲の外)
  には校正のときの補正係数が無い。NanoVNA は近い点から補って表示するので、
  **元の範囲の外に出た分だけ値が信じられなくなる** — Thru を測ってすら
  0 dB からずれて見えることがある
- **範囲の中に収まっていても点数が違えば**、補正係数を新しい点に当てはめ
  直す (補間) 分だけ誤差が乗る。狭い範囲への変更は影響が小さいが、
  広げる変更ほど誤差が目立つ

## 見るべき値

| 状況 | Thru の S21 (理想) | 実際に起きること |
| --- | --- | --- |
| 範囲を変えて再校正した | 0 dB | 信じてよい |
| 範囲を変えず測った | 0 dB | 変わらず信じてよい (範囲が同じなら校正も同じ) |
| 範囲を広げて再校正を忘れた | 0 dB のはずが実測はずれる | **信じてはいけない** — 特に元の範囲の外側 |

**範囲を変えたら、まず SOLT をやり直す**が鉄則。校正の要・不要を都度
確かめる手間を惜しむと、測った値そのものが無意味になる。
