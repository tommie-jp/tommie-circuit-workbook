# 1-9 校正の有効期間 — 温度と時間

校正は「校正したときの NanoVNA とケーブル」の狂いを覚えて差し引く (1-1)。
NanoVNA の中の回路もケーブルも、**温度が変わるとわずかに特性が変わる**。
校正した後に温度が動けば、覚えた狂いと今の狂いがずれ、そのずれが測定値に乗る。
校正はいつまでも正しいわけではない。**いつ校正し直すかを、Load と Thru を
測り直して決める**。

## 何が動くか

| 動くもの | 原因 | 画面での見え方 |
| --- | --- | --- |
| NanoVNA の中の回路 | 電源を入れた直後は中が温まっていく。部屋の温度の変化 | Load の反射が少しずつ増える。Thru の S21 が 0 dB からずれる |
| ケーブル | 温度で長さと誘電体が変わる。曲げ直すと形が変わる (5-18) | 位相がずれる。高い周波数ほど大きい (ケーブルの温度は 5-11) |
| コネクタ | 挿し直すたびに締め方が変わる (0-2) | 挿し直した所だけ値が跳ぶ |

## 校正し直す目安 (この教科書の決め)

| 場面 | すること |
| --- | --- |
| 電源を入れた直後 | **10〜15 分待ってから校正する** (中が温まって落ち着くのを待つ。目安) |
| 測り始める前・1 時間ごと | Load と Thru を測り直して、下の判定の表で確かめる |
| 部屋の温度が 5 °C 以上動いた (暖房を入れた、窓を開けた) | 校正し直す |
| ケーブルを替えた・曲げ直した | 校正し直す (基準面が変わる、1-5) |
| 範囲や点数を変えた | 校正し直す (1-4) |
| 保存したスロットを久しぶりに呼び出した | Load と Thru を測り直してから使う (1-6) |

数字は目安で、機体・ケーブル・部屋で変わる。**自分の機体の実際の変わり方は、
下の「確かめ方」で一度測っておく。**

## 回路図

判定では、校正に使った Load をもう一度 CH0 につなぐ (Thru は 1-3 と同じつなぎ方)。

```circuit
title: 図1 校正に使った Load を測り直す
parts:
  M1:
    type: device
    at: 2,2
    label: NanoVNA
    pins: [CH0, CH1]
    turn: mirror
  R1: resistor 5,1.88 5,3.88 50
  G1: ground 5,3.88
wires:
  - M1.CH0 -| 5,1.88
notes:
  - text 5.5,3.5 blue: Load
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/01-calibration/circuit/09-cal-lifetime.svg)

## 掃引の設定

計器は VNA。この本の図は NanoVNA-H4 で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。

この題は実体配線図を付けない — 校正に使った Load を測り直す手順の題で、組む回路が無い。

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜300 MHz (スロット 0 の範囲、1-6) |
| 点数 | 101 |
| 校正 | 範囲の全体で SOLT。その後、時間をおいて Load と Thru を測り直す |
| 表示 | S11 の Log Mag、S11 の Smith チャート |

校正の直後の Load は、S11 が −40 dB より下 (Smith の真ん中) に来る。時間とともに
これが持ち上がる。下の図は、**校正し直す境目の −30 dB** が画面でどう見えるかを、
50 Ω から少し外れた抵抗 (53 Ω) の模型で示したもの (ずれの見え方の例で、実際の
ずれは周波数によって大きさが変わる)。

```vna
device: h4
sweep: 1M-300M 101
title: 図2 校正し直す境目 — Load の読みが −30 dB まで上がった
dut:
  - series R 53
  - short
traces:
  - S11 logmag
  - S11 smith
markers:
  - 100M
notes:
  - text 120M -20dB: −30 dB を超えたら校正し直す
```

![NanoVNA の画面](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/01-calibration/vna/09-cal-lifetime.svg)

- 読み値は −30.71 dB、Smith では 53.0 Ω + j0.0 Ω。SWR にすると 1.06
- 校正の直後の読み (−40 dB より下) と並べて記録しておくと、どれだけ動いたかが分かる

## 判定の表 (この教科書の目安)

| 測り直すもの | 校正の直後 | このままでよい | 校正し直す |
| --- | --- | --- | --- |
| Load の S11 (範囲の中の最大) | −40 dB より下 | −30 dB より下 | **−30 dB より上** |
| Thru の S21 | 0.00 dB | ±0.1 dB の中 | **±0.1 dB を超える** |
| Thru の S21 の位相 | 0° | ±1° の中 | **±1° を超える** |

−30 dB は、Load の読みに 53 Ω 相当のずれが出た所 (上の図)。このずれは、測る物の
反射にほぼ同じ大きさで乗る (1-7 と同じ理屈) ので、SWR 1.1 前後のアンテナを見るなら
これより前に校正し直す。

## 確かめ方

1. 電源を入れてすぐに SOLT する (わざと温まる前に)
2. すぐに Load と Thru を測り、100 MHz の S11 と S21 を控える
3. そのまま 10 分ごとに 1 時間、同じ所を測って控える (記録の書き方は 2-10)
4. 1 時間たったら校正し直し、もう 1 時間同じことをする
5. 前の 1 時間と後の 1 時間で、動き方を比べる

電源を入れた直後の校正のほうが大きく動くなら、その機体は温まるのを待つ必要がある。
後の 1 時間でも −30 dB を超えるなら、校正し直す間隔を 1 時間より短くする。

## 見るべき値

| 見る所 | 値 | 分かること |
| --- | --- | --- |
| 図 2 の 100 MHz の S11 | −30.71 dB (計算値) | 校正し直す境目の見え方 |
| 図 2 の Smith の読み値 | 53.0 Ω + j0.0 Ω (計算値) | Load に 3 Ω のずれがあるのと同じ |
| 校正の直後の Load の S11 | −40 dB より下 (目安) | 校正がうまくできた |
| 1 時間後の Load の S11 | 自分の機体で測る | 校正し直す間隔を決める |
