# 1-8 Load の 50 Ω を DC で測って確かめる

校正の Load は「ちょうど 50 Ω」として使われる (1-7)。低い周波数では、Load は
ほぼただの抵抗なので、**テスターの抵抗レンジで測れば値を確かめられる**。
50 Ω からのずれは、そのまま低い周波数で読める反射の下限になる。付属の Load、
自作の Load (3-4)、検査片の 100 Ω (0-5) をテスターで測る。

## 回路図

```circuit
title: 図1 Load の中心導体と外皮の間をテスターで測る
parts:
  J1: sma b2 mirror
  R1: resistor b4 d4 50
  M1: ohmmeter b6 d6
wires:
  - J1.1 -| b4
  - b4 -- b6
  - J1.2 |- d4
  - d4 -- d6
notes:
  - text a3 blue center: Load の中 (J1 と R1)
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/01-calibration/circuit/08-load-dc-check.svg)

- R1 は Load の中の抵抗 (理想の 50 Ω)。テスター (M1) は赤のリードを中心導体の
  ピンに、黒のリードを外皮 (ねじの部分) に当てる
- **Load は NanoVNA から外して測る。** つないだまま測ると、テスターの電圧が
  CH0 に掛かる
- テスターの抵抗レンジの電流は 1 mA 程度 (目安)。50 Ω で消費は 50 µW で、Load を
  傷めない

## 手順

| # | 手順 | なぜ |
| --- | --- | --- |
| 1 | テスターを 200 Ω レンジ (オートレンジなら抵抗) にする | 0.1 Ω の桁まで読むため |
| 2 | 赤と黒のリードの先を当てて、読みを控える (0.1〜0.3 Ω)。REL (相対) のボタンがあれば押して 0 にする | リードの抵抗を引く |
| 3 | Load の中心導体と外皮に当てて読む。当て方を変えて 3 回読む | ピンの接触の抵抗のばらつきを見る |
| 4 | 手順 2 のリードの抵抗を引く (REL を使ったなら不要) | |
| 5 | Short は 0.2 Ω 以下、Open は OL (測れない大きさ) になることも確かめる | 3 つとも中が壊れていない |

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜30 MHz (Load がほぼ抵抗のままの低い範囲) |
| 点数 | 101 |
| 校正 | 市販の Load (無ければ別の Load) で SOLT し、測る Load を DUT としてつなぐ |
| 表示 | S11 の Log Mag、S11 の Smith チャート |

テスターで **51.0 Ω** と読めた Load を、NanoVNA で見たときの画面。

```vna
device: h4
sweep: 1M-30M 101
title: 図2 DC で 51.0 Ω の Load は −40.09 dB (51.0 Ω + j0.0 Ω)
dut:
  - series R 51
  - short
traces:
  - S11 logmag
  - S11 smith
markers:
  - 10M
notes:
  - text 15M -25dB: 1 Ω のずれで −40 dB の反射
```

![NanoVNA の画面](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/01-calibration/vna/08-load-dc-check.svg)

- 反射係数は Γ = (51 − 50) / (51 + 50) = 0.0099。20 log₁₀ 0.0099 = **−40.09 dB**
- Smith の読み値は 51.0 Ω + j0.0 Ω。**DC で読んだ値と、低い周波数の NanoVNA の
  読み値が同じになる** — これが「Load がこの範囲では抵抗のまま」の確かめになる
- 周波数を上げると、足やチップのインダクタンスで反射が増えていく (1-7)。DC で
  確かめられるのは抵抗の値だけ

## 見るべき値

テスターで読んだ R と、その Load の反射 (計算値)。

| DC の R | S11 Log Mag | SWR | 判定 (この教科書の目安) |
| --- | --- | --- | --- |
| 45 Ω | −25.58 dB | 1.11 | 校正には使わない |
| 48 Ω | −33.80 dB | 1.04 | 使えるが、反射の小さい物は測れない |
| 49 Ω | −39.91 dB | 1.02 | よい |
| 49.5 Ω | −45.98 dB | 1.01 | よい (1 % の抵抗の範囲) |
| 50.5 Ω | −46.06 dB | 1.01 | よい (1 % の抵抗の範囲) |
| 51 Ω | −40.09 dB | 1.02 | よい |
| 52 Ω | −34.15 dB | 1.04 | 使えるが、反射の小さい物は測れない |
| 55 Ω | −26.44 dB | 1.10 | 校正には使わない |

- **1 % の範囲 (49.5〜50.5 Ω) に入っていれば −46 dB より良い。** 自作の Load
  (100 Ω 2 本の並列、3-4) も、1 % の抵抗ならこの範囲に入る
- 2 Ω 以上ずれた Load (−34 dB より悪い) は、その Load で校正すると −34 dB より
  小さい反射が読めない (1-7 と同じ理屈)
- 検査片の 100 Ω (0-5) も同じ手順で測り、DC の値を控えておく。NanoVNA の 10 MHz の
  読み値と比べれば、校正の確かめにも使える
