# 2-5 Touchstone (.s1p / .s2p) に保存する

測った S パラメータは **Touchstone** という共通のテキスト形式で保存できる。
NanoVNA-Saver・NanoVNA-App、本体の SD カード保存のどれも同じ系統の形式を
書き出す。保存しておけば、あとから別のソフトで開いたり、他の測定と
重ねたりできる。

## ファイルの種類

| 拡張子 | 内容 |
| --- | --- |
| `.s1p` | 1 ポート分 (S11 だけ)。DUT を 1 端子で測ったとき (部品の Z など) |
| `.s2p` | 2 ポート分 (S11・S21・S12・S22)。CH0–CH1 間の DUT を測ったとき |

中身は 1 行が **周波数・S パラメータの数値の組**のテキスト。数値の書き方は
`RI` (実部・虚部)、`MA` (大きさ・角度)、`DB` (dB・角度) の 3 通りがあり、
どれも 50 Ω を基準にしている。

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜300 MHz |
| 点数 | 101 |
| 校正 | 保存する前に SOLT を済ませておく |
| 表示 | S21 の Log Mag、S11 の Log Mag と Smith |

3-1 の直列治具に 100 Ω を入れた例で考える。**理想値はこの `dut:` の
1 行から計算できる**が、実際に保存した Touchstone をこのファイルの隣に
置いて `data:` に書き足すと、実測が実線で重なって出る (3-1 を参照)。
この題ではまだ実測が無いので、理想値だけを示す。

```vna
device: h4
sweep: 1M-300M 101
title: 図1 保存前の理想値 (100 Ω を直列に入れた治具)
dut: series R 100
traces:
  - S21 logmag
  - S11 logmag
  - S11 smith
markers:
  - 10M
  - 300M
```

## 見るべき値

| ファイル | 中身 | この題で使うなら |
| --- | --- | --- |
| `2-5-100ohm.s2p` (保存すれば) | 100 Ω を入れたときの実測の S11・S21 | このファイルの隣に置いて `data:` に書く |
| フェンスの `dut:` | 理想値 (計算) | 保存が無くても「見るべき値」の図が出る |

保存した Touchstone は、Python (2-13、`scikit-rf`) で読んだり、回路
シミュレータ (8-17) に渡したりできる。**測る前に理想値を、測った後に
実測を**、同じ図に重ねられるのがこの教科書のフェンスの利点になる。
