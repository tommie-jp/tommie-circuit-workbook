# 2-2 マーカー 4 つと読み方

NanoVNA は画面に**マーカーを最大 4 つ**置ける。周波数を指定すると、
その点の読み値 (dB・度など) が表に出る。LC ローパスフィルタを例に、
4 つのマーカーで通過域・遮断点・阻止域を読む練習をする。

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜200 MHz |
| 点数 | 201 |
| 校正 | この題は理想値の確認なので不要 |
| 表示 | S21 の Log Mag、S11 の Log Mag |

DUT は shunt C 68 pF – series L 180 nH – shunt C 68 pF の 3 次 LC
ローパス (6-1 で作るものと同じ考え方)。

```vna
device: h4
sweep: 1M-200M 201
title: 図1 4 つのマーカー — LC ローパスの読み所
dut:
  - shunt C 68p
  - series L 180n
  - shunt C 68p
traces:
  - S21 logmag
  - S11 logmag
markers:
  - 30M
  - 69M
  - 90M
  - 150M
```

- **マーカー 1 (30 MHz)** — 通過域。S21 はほぼ 0 dB
- **マーカー 2 (69 MHz)** — **遮断周波数**。S21 が −3 dB まで落ちる点
  (整合が取れているので S11 もほぼ同じ −3 dB になる)
- **マーカー 3 (90 MHz)** — 遷移域。急に落ち始める
- **マーカー 4 (150 MHz)** — 阻止域。S21 が大きく減衰している

## 見るべき値

| マーカー | 周波数 | S21 Log Mag | S11 Log Mag |
| --- | --- | --- | --- |
| 1 | 30 MHz | −0.11 dB | −15.91 dB |
| 2 | 69 MHz | −3.02 dB | −3.00 dB |
| 3 | 90 MHz | −9.62 dB | −0.50 dB |
| 4 | 150 MHz | −24.05 dB | −0.02 dB |

**マーカー 2 で S21 と S11 がほぼ同じ値 (−3 dB) になるのは偶然ではない。**
損失の無い回路では、通り抜けた分と跳ね返った分を足すと必ず 100% になる
(|S21|² + |S11|² = 1)。半分ずつ (−3 dB ずつ) になる点が遮断周波数の
目安になる。
