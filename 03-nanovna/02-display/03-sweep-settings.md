# 2-3 掃引の設定 — 開始・終了・中心・スパン

NanoVNA の掃引範囲は**開始・終了**でも、**中心・スパン**でも入力できる。
どちらで入れても同じ点の並びになるので、目的に合わせて使い分ける。

## 変換の式

```text
開始 = 中心 − スパン / 2
終了 = 中心 + スパン / 2

中心 = (開始 + 終了) / 2
スパン = 終了 − 開始
```

たとえば 144 MHz 帯のアンテナ (7-2) を調整するとき、**中心 144 MHz・
スパン 20 MHz**と入れれば、開始 134 MHz・終了 154 MHz と同じ範囲になる。
「共振点を追いかける」ときは中心・スパンのほうが、共振周波数を中心に
置いたまま幅だけ変えられて扱いやすい。

## 掃引の設定

| 入れ方 | 値 |
| --- | --- |
| 中心・スパンで入力 | 中心 144 MHz、スパン 20 MHz |
| 開始・終了に換算すると | 134 MHz〜154 MHz |
| 点数 | 101 |
| 校正 | この題は理想値の確認なので不要 |

この教科書のフェンスは開始–終了の書き方だけを取るので、中心・スパンで
考えた範囲も開始–終了に直してから書く。

```vna
device: h4
sweep: 134M-154M 101
title: 図1 中心 144 MHz・スパン 20 MHz を開始–終了に直す
dut: series R 0
traces:
  - S21 logmag
  - S11 logmag
markers:
  - 134M
  - 144M
  - 154M
```

## 見るべき値

| 入れ方 | 開始 | 終了 | 中心のマーカーが指す周波数 |
| --- | --- | --- | --- |
| 中心 144 MHz・スパン 20 MHz | 134 MHz | 154 MHz | 144 MHz |
| 開始 134 MHz・終了 154 MHz | 134 MHz | 154 MHz | 144 MHz (計算どおり一致) |

**点数を変えても中心・スパンは変わらない。** 点数は範囲の中に何点
打つかだけを決める (点数と分解能の話は 1-13)。
