# 4-7 リード線 1 cm のインダクタンス

部品の値ではなく、**部品を挿すためのただの導線**にもインダクタンスがある。
3-1 のスルー治具の解説で触れた「太い銅線を入れる」実験をやり直し、直径
0.5 mm・長さ 1 cm の裸銅線 (部品のリード線と同じくらいの太さ) 自体の
インダクタンスを読む。

## 回路図

```circuit
title: 図1 直列治具に 1 cm の裸銅線
parts:
  J1: sma b2 mirror CH0
  J2: sma b8 CH1
  G1: ground c2
  G2: ground c8
wires:
  - J1.1 -- b4
  - b4 -- b6
  - b6 -- J2.1
  - J1.2 -- c2
  - J2.2 -- c8
notes:
  - text b5h0 center: "1 cm の裸銅線"
```

部品を置かず、ただの配線でつなぐ。

## 実体配線図

```perfboard
board:
  size: 16x8
  slots: on
title: 図2 perfboard の直列治具を裸銅線でつなぐ
points:
  GND: h2
parts:
  J1: sma/female-edge e1 d0 f0
  J2: sma/female-edge e16 f17
wires:
  - e1 -- e6
  - e6 -- e11 yellow
  - e11 -- e16
  - f0 -- f2 black
  - f2 -- GND black
  - f17 -- f15 black
  - f15 -- h15 black
  - h15 -- GND black
```

e6〜e11 (5 穴ぶん、2.54 mm 間隔で約 1.27 cm) を裸銅線でまたぐ。3-1 の R1 の
足の長さとほぼ同じで、**「部品を挿すと本当は何が増えるか」**を、部品そのものを
外して確かめる形。

直線の導線のインダクタンスは近似式 L ≈ (µ₀l / 2π)(ln(2l/r) − 0.75) で見積もれる。
直径 0.5 mm (半径 0.255 mm)・長さ 1 cm の銅線では L ≈ 7 nH。

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 10 MHz〜1.5 GHz |
| 点数 | 301 |
| 校正 | SOLT。ケーブルの先 (治具の SMA) で Open / Short / Load / Thru |
| 表示 | S11 の X (Ω)。最後を短絡にして 1 端子の Z 測定にする |

見えるはずの画面 (理想の模型)。

```vna
device: h4
sweep: 10M-1500M 301
title: 図3 1 cm の裸銅線 (L ≈ 7 nH) の X
dut:
  - series L 7n
  - short
traces:
  - S11 x
markers:
  - 10M
  - 100M
  - 500M
  - 1G
```

## 見るべき値

計算値。X = ωL、R ≈ 0 (裸銅線の抵抗は無視できるほど小さい)。

| 周波数 | X |
| --- | --- |
| 10 MHz | 0.44 Ω |
| 100 MHz | 4.40 Ω |
| 500 MHz | 22.0 Ω |
| 1 GHz | 44.0 Ω |

分かること:

- **「ただの導線」でも、1 GHz では 44 Ω ものリアクタンスになる。** 3-1 で
  100 Ω の抵抗を挿したときに周波数を上げると値がずれていったのは、抵抗の
  ESL の前に、まずこのリード線ぶんのインダクタンスがある
- 部品を治具に挿すときの**リードは短いほど正しい値に近づく**。4-1〜4-6 で
  見積もった ESL の多くは、この裸銅線の値 (7 nH/cm) をリード長で比例させた
  ものに近い
- 逆に言えば、**この 7 nH/cm という数字さえ覚えておけば**、他の部品の ESL が
  リード線由来なのか部品自身の構造 (巻線や溝) 由来なのかの見当が付く
