# 4-5 フェライトビーズ — R と X の交差

フェライトビーズはノイズを**熱として吸収する**部品で、そのために低い周波数では
コイルらしく (X が大きく)、高い周波数では抵抗らしく (R が大きく) 振る舞う。
3-1 の直列治具に小型のフェライトビーズを挿して、R と X が入れ替わる様子を見る。

## 回路図

```circuit
title: 図1 直列治具にフェライトビーズを挿す
parts:
  J1: sma b2 mirror CH0
  L1: inductor b4 b6 100n
  J2: sma b8 CH1
  G1: ground c2
  G2: ground c8
wires:
  - J1.1 -- b4
  - b6 -- J2.1
  - J1.2 -- c2
  - J2.2 -- c8
notes:
  - text b4h0 center: フェライトビーズ
```

フェライトビーズはコイルの記号で描く (材質までは記号で描き分けられない)。

## 実体配線図

```perfboard
board:
  size: 16x8
  slots: on
title: 図2 perfboard の直列治具にフェライトビーズ
points:
  GND: h2
parts:
  J1: sma/female-edge e1 d0 f0
  J2: sma/female-edge e16 f17
  L1: inductor e6 e11 100n
wires:
  - e1 -- e6
  - e11 -- e16
  - f0 -- f2 black
  - f2 -- GND black
  - f17 -- f15 black
  - f15 -- h15 black
  - h15 -- GND black
```

小型 SMD フェライトビーズの低周波でのインダクタンスは L ≈ 100 nH、
直流抵抗 (R) ≈ 0.3 Ω が代表値。

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 100 kHz〜50 MHz |
| 点数 | 401 |
| 校正 | SOLT。ケーブルの先 (治具の SMA) で Open / Short / Load / Thru |
| 表示 | S11 の R と X (Ω)。最後を短絡にして 1 端子の Z 測定にする |

見えるはずの画面 (理想の模型)。


## 見るべき値

計算値。単純に R (一定) と L だけの模型では、交差は ωL = R の 1 点だけ。

| 周波数 | R | X | どちらが優勢か |
| --- | --- | --- | --- |
| 100 kHz | 0.30 Ω | 0.06 Ω | R (抵抗性) |
| 477 kHz (交差、ωL = R) | 0.30 Ω | 0.30 Ω | 同じ大きさ |
| 5 MHz | 0.30 Ω | 3.14 Ω | X (誘導性) |
| 50 MHz | 0.30 Ω | 31.4 Ω | X (誘導性) |

分かること:

- **この単純な模型では、477 kHz から先はずっと X が R を上回り続ける。**
  実物のフェライトビーズのデータシートを見ると、たとえば 100 MHz 付近でもう一度
  R が X を上回る (R と X がもう 1 回交差し、その間に |Z| の山ができる)
- これは**芯材の損失 (透磁率の虚部) が周波数とともに増える**ためで、
  R が周波数によらず一定というこの模型の単純化では再現できない。
  データシートの「インピーダンス @ 100 MHz」は、この R がもっとも効いている
  あたりの合成値であることが多い
- つまりこの部品は**測ってみて初めて実物の R-X 交差 (2 回目) が見える**部品。
  理想線 (この図) からの実測のずれそのものが、フェライト材の効きを表す
