# 11-6 FM 送信機の出力と高調波

回路の教科書の 9-28 は、9-4 の FM 送信機 (1 石のコルピッツ、80 MHz) の電波を
tinySA のアンテナで**空中から拾った**。拾った高さはアンテナの向きや机の反射で
±15 dB 動き、高調波の高さは「搬送波の 20 dB 下・30 dB 下」と仮定するしかなかった。

この題では空中を通さず、**送信機の出口を同軸でパッド越しに tinySA へつなぐ** (伝導での測定)。
距離や向きに左右されないので、搬送波の電力 (dBm) と高調波の比 (dBc、搬送波に対する dB) が
回路で決まる数として読める。LTspice の答えと 1 dB の桁で突き合わせられる。

> [!WARNING]
> 測るあいだ送信機のアンテナ線 (9-4 の図2 の WIRE) は外し、出口は tinySA だけにつなぐ。
> 同軸の先は tinySA の 50 Ω (オーム) の入力で終わるので電波はほとんど出ない。
> 下の計算では出口から 50 Ω へ約 1.3 mW 出せる。**この出口を屋外のアンテナや
> 増幅器につながない** (9-4 の電波法の注意)。

## 回路図

送信機は 9-4 の図1 のままで、箱にまとめて描く (中はコルピッツ発振)。Cant (2.2 pF) の先の
ANT の島に同軸の芯線を、すぐ隣の GND の via に網線を半田付けし、11-4 の 20 dB パッド
(43 Ω・11 Ω・43 Ω) を通して tinySA の RF へ入れる。

```circuit
# 回路図 (tommie-fence の circuit フェンス)
title: 図1 9-4 の送信機の出口を 20 dB パッドで tinySA へ
parts:
  X1:
    type: device
    at: 1,2
    label: FM TX 9-4
    pins: [COL, GND]
    turn: mirror
  Cant: capacitor 5,2 7,2 2.2p
  P1: resistor 8,2 10,2 43
  P2: resistor 10,2 10,4 11
  P3: resistor 10,2 12,2 43
  X2:
    type: device
    at: 14,2
    label: tinySA
    pins: [RF, GND]
  GX: ground 4,4
  GP: ground 10,4
  GM: ground 13,4
wires:
  - X1.COL -| 5,2
  - 7,2 -- 8,2
  - 12,2 -| X2.RF
  - X1.GND -| 4,4
  - X2.GND -| 13,4
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/11-spectrum-analyzer/circuit/06-fm-transmitter-output.svg)

- **周波数が下がる**: 空中に出すときの Cant の先はアンテナ線 (数 pF) だが、
  50 Ω をつなぐと Cant (80 MHz で約 904 Ω) の先がほぼ GND になり、2.2 pF がそのまま
  タンクに並ぶ。LTspice の模型では 9-4 の L1 (260 nH) のままで **約 69.2 MHz** に下がり、
  FM 放送帯 (76〜95 MHz) から外れる。**コイルの巻きを広げて 80 MHz に合わせ直す**
  (模型では 260 nH → 約 197 nH)。アンテナに戻すときは巻きを戻す
- **パッドを挟む理由**: パッドが無いと出口から 50 Ω へ約 +1.3 dBm (計算値) 入り、
  tinySA の推奨の上限 0 dBm を超える (絶対最大は +6 dBm、11-1)。パッドの先では約 −18.5 dBm

この題は実体配線図を付けない。送信機は 9-4 の銅張り基板 (図2) をそのまま使い、
パッドは 11-4 の図2 (perfboard、端面 SMA) を使う。80 MHz の送信機はブレッドボードには組まない
(9-4 の「銅張り基板に組む」の理由)。同軸は RG316 などの細いものを 10 cm ほどにし、網線は ANT の島に一番近い via に付ける。

## 計器の設定

計器は tinySA Ultra。AD3 は 9-4 のとおり電源 (Supplies の 5 V) にだけ使う (80 MHz は Scope の範囲の外)。

| 一般の名前 | 値 | tinySA Ultra のメニュー |
| --- | --- | --- |
| 開始・終了 | 0〜449 MHz、450 点 (1 点 = 1 MHz。80 MHz の 1〜5 倍が点の真上に載る) | `FREQUENCY` → `START` / `STOP`、`DISPLAY` → `SWEEP POINTS` |
| RBW | 300 kHz (FM の振れ数十 kHz は 1 本の線に収まる) | `FREQUENCY` → `RBW` |
| 基準レベル | −10 dBm (搬送波が上端から約 1 目盛下) | `LEVEL` → `REF LEVEL` |
| 入力アッテネータ | 10 dB (手動) | `LEVEL` → `ATTENUATE` |
| 高調波の測定 | 搬送波 80 MHz を入れる | `MEASURE` → `HARMONIC` |

- **アッテネータを 10 dB にする理由**: tinySA Ultra の入力が 50 Ω になるのは内部の減衰が
  10 dB 以上のとき (公式の仕様)。また仕様は「よい測定には入力を −25 dBm より下に」とする。
  10 dB 入れればミキサーに届くのは約 −28.5 dBm。画面の読みは減衰を補正して出るので、
  搬送波の読み (−18.5 dBm) は変わらず、ノイズフロアだけが 10 dB 上がる
- `HARMONIC` は基本波に基準のマーカー、2〜4 倍に差 (dBc) のマーカーを自動で置く。
  公式の説明は、基本波を −20 dBm 以下 (できれば −30 dBm 以下) にし、**減衰を 5〜10 dB 増やしても
  高調波の dBc が変わらないこと**を確かめよ、としている。変わるなら tinySA の中で
  作られた高調波が混じっている (見分け方は 11-10)

送信機の電源を入れてから、上の広い掃引で搬送波を探す。80 MHz から外れていたら
中心 80 MHz・スパン 2 MHz・RBW 10 kHz に狭めて、コイルの巻きで合わせる。

## 見るべき値

LTspice の模型の計算値 (2SC3355 は 9-4 と同じ仮定のモデル、浮遊容量なし)。
実物は島の浮遊容量・トランジスタの個体で数 dB 動く。

| 次数 | 周波数 | tinySA の読み (パッドの先) | 搬送波との差 | コレクタでの差 |
| --- | --- | --- | --- | --- |
| 1 (搬送波) | 80 MHz | −18.5 dBm | 0 dB | 0 dB |
| 2 | 160 MHz | −29.5 dBm | −11.0 dBc | −17.0 dBc |
| 3 | 240 MHz | −32.9 dBm | −14.4 dBc | −23.8 dBc |
| 4 | 320 MHz | −40.1 dBm | −21.6 dBc | −33.4 dBc |
| 5 | 400 MHz | −51.1 dBm | −32.6 dBc | −46.3 dBc |

分かること:

- **出口の高調波は、コレクタの高調波より高い。** Cant (2.2 pF) は 50 Ω に対して
  インピーダンスが大きく (80 MHz で約 904 Ω)、50 Ω に流れる電流はほぼ Cant で決まる。
  コンデンサの電流は周波数に比例するので、n 倍の高調波は 20 log₁₀ n だけ持ち上がる
  (2 倍で +6.0 dB、3 倍で +9.5 dB)。表の「コレクタでの差」と「搬送波との差」の開きが
  ちょうどその値になっている
- 9-28 の「2 倍は 20 dB 下・3 倍は 30 dB 下」は空中で拾ったときの仮定で、伝導で見ると
  −11 dBc・−14 dBc と大きい。空中で拾う高さは、短いアンテナの放射の効率
  (周波数で変わる) と受ける側のアンテナにも左右されるので、同じにならなくてよい
- 搬送波の電力 (パッドの手前で約 +1.3 dBm、約 1.3 mW) は、出口が 50 Ω に出せる電力の目安。
  アンテナ線 20 cm はこれよりずっと小さな電力しか放射しない (9-4 の電界強度の上限に収める設計)
- **高調波を下げたいなら**、Cant の先に 6-1 のようなローパスを入れる (6-17 の送信機の高調波
  フィルタと同じ考え)。この題では足さない

## LTspice での確かめ

`sim/06-fm-transmitter-output.cir` で、9-4 の図1 の Cant の先に 20 dB パッドと tinySA の 50 Ω を
つないで過渡解析を走らせ、発振が落ち着いた 4〜5 µs (マイクロ秒) の `.four` で高調波を読んだ。
Q1 は 9-4 と同じ 2SC3355 の代用モデル (仮定)。L1 はパラメータにして 260 nH と 196.9 nH の 2 通りで走らせた。

| 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| L1 = 260 nH のままの発振周波数 | 約 69.2 MHz | 69.21 MHz | 合う |
| L1 = 196.9 nH の発振周波数 | 80 MHz | 79.97 MHz | 合う |
| 搬送波 (パッドの先) | −18.5 dBm | 37.60 mV<sub>p</sub> → −18.50 dBm | 合う |
| 2 倍 / 3 倍 | −11.0 / −14.4 dBc | −11.01 / −14.40 dB | 合う |
| 4 倍 / 5 倍 | −21.6 / −32.6 dBc | −21.58 / −32.64 dB | 合う |
| コレクタの 2 倍 / 3 倍 | −17.0 / −23.8 dBc | −17.0 / −23.8 dB | 合う |
| パッドの手前の電力 | 約 +1.3 dBm | −18.50 + 19.76 = +1.26 dBm (パッドの減衰は 11-4 の値) | 合う |

出口とコレクタの差 6.0 dB (2 倍)・9.4 dB (3 倍) は 20 log₁₀ 2 = 6.02 dB・20 log₁₀ 3 = 9.54 dB と合う。
模型の発振中のエミッタ電流は 3.2 mA (9-4 の直流の 0.69 mA から増える。9-27 と同じ)。
浮遊容量・ピンのインダクタンスを入れると周波数はさらに下がり、高調波の比も動く (9-27)。

## 出典

自作。送信機は回路の教科書の 9-4、空中で拾う手順は 9-28。パッドは 11-4 (0-3 と同じ 20 dB T 型)。
tinySA Ultra の入力の条件 (減衰 10 dB 以上で 50 Ω、−25 dBm 以下を推奨、絶対最大 +6 dBm) は
[公式の仕様](https://tinysa.org/wiki/pmwiki.php?n=TinySA4.Specification)、
高調波の測り方 (`HARMONIC` と、減衰を変えて確かめる手順) は
[公式の Harmonic 測定の頁](https://tinysa.org/wiki/pmwiki.php?n=TinySA4.IMD) (2026-11-14 に確認)。
電波法の微弱無線局の技術基準は電波法施行規則第 6 条。
