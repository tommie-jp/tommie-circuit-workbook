# 11-11 ゼロスパン — 時間の軸で見る

スペアナはふつう周波数を掃引して、横軸を周波数にする。**スパンを 0 にすると、周波数を 1 点に止めたまま
時間だけが進み、横軸が時間になる** (ゼロスパン)。画面に出るのは、その周波数の RBW の窓に入った信号の
大きさ (包絡線) の時間変化。AM の振れ、バースト (電波を出したり止めたりする信号) の長さ、
周期的に強くなる妨害などを、周波数を選んだまま時間で見られる。

この題では 11-7 と同じ 9-7 の AM 変調器 (686 kHz、1 kHz で m = 0.3) をゼロスパンで見て、
包絡線から m を読み、11-7 の側波の dBc と突き合わせる。回路図と実体配線図は載せない
(回路は 9-7 の図1、tinySA のつなぎ方は 9-29 の図1、発生器の振幅は 11-7 の 1.88 V)。

## ゼロスパンで見えるもの

- **RBW が包絡線の速さを決める**。RBW の窓は中心の ±RBW/2 だけを通すので、1 kHz の振れ (側波が ±1 kHz) を
  見るには RBW を 2 kHz より十分広くする。**RBW を 200 Hz にすると側波が窓の外に出て、包絡線はほぼ平らになる**
  (11-7 では側波を分けるために狭くした。目的が逆)
- **縦軸は線形の単位にする**。dBm の目盛では 1 + m sin の包絡線が上下で非対称に歪む
  (m = 0.3 で上に +2.3 dB、下に −3.1 dB)。`LEVEL` → `UNIT` を Vrms にすると、包絡線がそのまま正弦波で出る
  (公式の AM の頁も、遅い変調はゼロスパンと線形の単位で見よ、とする)
- **オシロとの違い**: AD3 のオシロは 686 kHz の方形波そのもの (と高調波全部) を時間で見る (9-7 の図3)。
  ゼロスパンは 686 kHz の RBW の窓の中だけを検波するので、周波数を選べる。中心を 3 倍の 2058 kHz に移すと、
  3 倍の高調波の包絡線だけが見え、m は同じ 0.3 になる (11-7 の図2 と同じ理由)。強い信号の隣の弱い信号の
  時間変化も見られる。代わりに波形 (位相) は分からない

## 計器の設定

計器は tinySA Ultra。音声は 9-29 の発生器 (1 kHz・1.88 V)。オシロは比べるとき 9-7 の図3 のとおり。

| 一般の名前 | 値 | tinySA Ultra のメニュー |
| --- | --- | --- |
| 中心 | 686 kHz (先に 11-7 の図1 の設定で搬送波を探し、`MARKER -> CENTER` で合わせる) | `FREQUENCY` → `MARKER -> CENTER` |
| スパン | 0 (ゼロスパン) | `FREQUENCY` → `ZERO SPAN` |
| RBW | 10 kHz | `FREQUENCY` → `RBW` |
| 掃引時間 | 5 ms (1 kHz の 5 周期。設定できる最短は RBW と機種で変わる、目安) | `DISPLAY` → `SWEEP TIME` |
| 単位 | Vrms、目盛は 1 mV/div (中央を 9.85 mV に) | `LEVEL` → `UNIT`、`SCALE/DIV` |
| 入力アッテネータ | 20 dB (手動。11-7 と同じ理由) | `LEVEL` → `ATTENUATE` |
| トリガ | NORMAL、レベル 11 mV、上がり (UP) | `LEVEL` → `TRIGGER` |

- **アッテネータ**: tinySA は内部の AGC が速い振れについていけず、ゼロスパンの AM に細い針のような
  山が出ることがある (公式の FAQ)。11-7 と同じく「搬送波 − 減衰 < −45 dBm」にする。それでも出るなら
  公式の FAQ のとおり AGC を切る (`CONFIG` の奥の設定)
- **トリガ**: 包絡線が 11 mV を上へ横切った所で掃引を始めると、画面が止まる。トリガが無いと、掃引ごとに
  包絡線の位相がずれて流れる
- 中心をぴったり搬送波に置くと、±1 dB ほどの揺れが出ることがある (公式の FAQ)。そのときは中心を
  RBW の 1/4 (2.5 kHz) ずらす

## 計器の画面

ゼロスパン・Vrms の画面を、時間の軸の図 (scope の図) で描いた。**見えるはずの画面** (計算値。
RBW 10 kHz の窓で側波が 0.1 dB ほど削れる分は下の表)。

```scope
# オシロスコープの画面 (tommie-fence の scope フェンス)
title: 図1 ゼロスパンの包絡線 (Vrms) — 最大と最小から m = 0.30
time: 500us/div
trigger: ch1 rising 9.846mV
ch1: {wave: sine 1kHz 2.93mV offset 9.846mV, range: 1mV/div, position: -9.846div}
measure: [vmax, vmin, freq]
```

![オシロスコープの画面](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/11-spectrum-analyzer/scope/11-zero-span.svg)

- 縦は tinySA の読み (RBW の窓に入った成分の実効値)。中央の 9.85 mV が搬送波だけの大きさ (−27.1 dBm)
- 横は時間。1 kHz の振れが 5 周期入る
- 図のトリガは 9.85 mV (包絡線の中央) にした。実機のトリガ 11 mV でも同じ周期の波が止まる (始まりの位相が違うだけ)

## 見るべき値

計算値 (搬送波 −27.1 dBm = 9.84 mV rms、m = 0.3。11-7 と同じ値)。

| 確かめること | 期待する値 |
| --- | --- |
| 包絡線の最大・最小 (Vrms) | 12.78 mV・6.92 mV (理想は 9.84 × 1.3 = 12.79・9.84 × 0.7 = 6.89 mV) |
| 包絡線の周期 | 1 ms (1 kHz) |
| 包絡線から読む m = (最大 − 最小) ÷ (最大 + 最小) | 0.30 (RBW 10 kHz の模型で 0.297) |
| 単位を dBm に戻したとき | 最大 −24.8 dBm・最小 −30.2 dBm (上下が非対称) |
| RBW を 200 Hz に狭めたとき | 包絡線はほぼ平ら。読める m は 0.03 (側波が窓の外) |
| 中心を 2058 kHz (3 倍) に移したとき | 大きさは約 1/3 (−9.7 dB) に下がるが、m は同じ 0.30 |

分かること:

- 包絡線の m と、11-7 の側波の dBc から逆算した m (2 × 10<sup>(−16.5/20)</sup> = 0.30) が同じになれば、
  時間の軸と周波数の軸で同じ変調を見たことになる
- RBW は「周波数の分解能」であると同時に「時間の分解能」でもある。広い RBW は速い変化を通し、
  狭い RBW は遅い変化しか通さない (公式の仕様では、RBW 850 kHz のゼロスパンで 50 µs (マイクロ秒) のバーストまで正しく測れる)

## LTspice での確かめ

`sim/11-zero-span.cir` で、686 kHz の AM (13.91 mV<sub>p</sub>、m = 0.3、1 kHz) をスペアナの検波の模型
(686 kHz で I/Q に下ろし、RBW の半分を角にした 1 次の RC で絞り、√(I² + Q²) を実効値にする) に通し、
10〜12 ms の包絡線の最大・最小を読んだ。RBW の模型は 1 次の RC で、tinySA の本当のフィルタの形ではない (仮定)。

| RBW | 本文の数字 (最大 / 最小 / m) | LTspice | 判定 |
| --- | --- | --- | --- |
| 10 kHz | 12.78 / 6.92 mV / 0.297 | 12.78 / 6.92 mV / 0.297 | 合う |
| 200 Hz | ほぼ平ら、m = 0.03 | 10.14 / 9.55 mV / 0.030 | 合う |

搬送波 9.84 mV rms (−27.1 dBm)、dBm に直した最大・最小 (−24.8・−30.2 dBm)、
3 倍の高調波の −9.7 dB は算術と 11-7 の LTspice の値で合う。AGC の乱れは計器の性質で、SPICE の対象外。
