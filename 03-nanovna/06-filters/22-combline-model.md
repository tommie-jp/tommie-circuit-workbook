# 6-22 コムラインの模型

**コムライン**は、平行に並べた短い線路の**同じ側の端**を GND に落とし、反対の端に小さな
コンデンサを付けた共振器を並べたフィルタ。櫛 (コーム) の歯のように並ぶので この名がある。
線路は λ/4 (λ (ラムダ) は線路の上の波長) より短くてよく (ここでは 60° ぶん)、
共振の周波数は端のコンデンサで合わせられる。

2.4 GHz 帯 (Wi-Fi・Bluetooth) を通す 2 本のコムラインを銅張り基板に作り、
**2 本の共振器の結合の強さ (結合係数 k) を、2 つに割れた山の間隔から測る**。
そのあと入出力の位置 (タップ) を上げてフィルタとして測る。H4 は 1.5 GHz までなので
この題は V2 (か LiteVNA64) で測る。

## この実験で確かめる式

2 本の共振器を近づけると、1 つだった共振が 2 つに割れる。2 本が同じ向きに振れる
**偶モード**と、逆向きに振れる**奇モード**で、周波数 f<sub>e</sub>・f<sub>o</sub> が違うからだ。
その割れ方が結合の強さで、

**k = |f<sub>o</sub>² − f<sub>e</sub>²| / (f<sub>o</sub>² + f<sub>e</sub>²)**

2 段のバターワースで帯域の幅 BW を作るには、k = BW / (f₀ √(g₁g₂)) (g₁ = g₂ = 1.414)。
入出力の強さは外部 Q (Q<sub>e</sub> = g₁ f₀ / BW) で、タップを GND の端から上げるほど
Q<sub>e</sub> が下がる (帯域が広がる)。

この題の寸法 (FR4、厚さ 1.6 mm、比誘電率 4.4 と仮定) での計算値:

| 量 | 値 | 求め方 |
| --- | --- | --- |
| 線路の幅 w | 1.5 mm | 1 本だけなら 73 Ω。実効比誘電率 3.15 |
| 長さ L | 11.5 mm | 2.44 GHz で 60° |
| 2 本の隙間 s | 3.5 mm | 偶モード 79.0 Ω・奇モード 68.6 Ω (Garg と Bahl の近似式。目安) |
| 端のコンデンサ C<sub>L</sub> | 0.5 pF | 1608 の C0G |
| GND の端 | 基板の縁を銅箔テープで裏の GND へ巻く | インダクタンス 0.1 nH と仮定 |
| f<sub>e</sub>・f<sub>o</sub> (タップを一番下にしたとき) | 2.332 GHz・2.516 GHz | 結合線路の計算 |
| k | 0.076 | 上の式 |
| 帯域の幅の目安 | k × f₀ × 1.414 ≈ 260 MHz | 2.31〜2.57 GHz。Wi-Fi の 2.400〜2.4835 GHz を余裕を持って含む |
| タップ | GND の端から 1.6 mm | Q<sub>e</sub> ≈ 14 になる位置 (結合線路の計算で山を平らにした) |

隙間の近似式は、s が基板の厚さの 2 倍を超える所では精度が落ちる。だから隙間は**作ってから
測って確かめる** (下の手順 1)。コムラインは端のコンデンサで周波数を、タップで Q<sub>e</sub> を
後から合わせられるが、**k は隙間で決まり、切った後には直せない**。

## 回路図

2 本の共振器を、偶・奇モードを持つ「結合した線路」として描けないので、等価回路で描く:
各共振器を GND に落とした線路 (タップの下と上に分けた) と端のコンデンサ、2 本の結合を
上の端の間の小さな容量 C<sub>K</sub> にまとめた。C<sub>K</sub> は部品ではない。

## 掃引の設定

計器は VNA (NanoVNA V2。LiteVNA64 でも同じ手順で測れる)。AD3 とオシロは使わない (S パラメータを見る題)。

| 項目 | 値 |
| --- | --- |
| 範囲 | 1.5 GHz〜3 GHz (V2 の上限まで) |
| 点数 | 301 (5 MHz おき) |
| 校正 | SOLT。CH0・CH1 のケーブルの先 |
| 表示 | S21 と S11 の Log Mag |

手順:

1. **k を測る**: まず入出力の線を共振器の下の端 (縁から 0.3 mm) に付ける (タップを下げる)。
   結合が弱いので、S21 に**山が 2 つ**立つ (計算では 2.332 GHz と 2.516 GHz、間は −19 dB)。
   2 つの山の周波数から k を出し、計算の 0.076 と比べる
2. **周波数を合わせる**: 2 つの山の真ん中 (√(f<sub>e</sub> f<sub>o</sub>) = 2.42 GHz) が
   2.44 GHz から外れていたら、C1・C2 を同じ値ずつ替える (小さくすると上がる)
3. **フィルタにする**: 入出力の線を縁から 1.6 mm まで上げる。2 つの山が 1 つの平らな山につながる

手順 3 の後の、見えるはずの画面 (等価回路の模型。線路の速度係数 vf = 1/√3.15 = 0.563)。
模型の値は、結合した線路の計算の S21 に合うよう選んだ (線路 94.9 Ω、C<sub>L</sub> 0.446 pF、
C<sub>K</sub> 0.0631 pF)。マーカーは Wi-Fi の帯域の両端と、その外 ±240 MHz ほど。

## 見るべき値

図3 の読み値と、結合した線路 (偶・奇モード) の計算 (損失なし)。

| 周波数 | 図3 (等価回路) S21 / S11 | 結合線路の計算 S21 / S11 |
| --- | --- | --- |
| 2.2 GHz | −11.18 / −0.34 dB | −12.20 / −0.27 dB |
| 2.4 GHz | −0.58 / −9.03 dB | −0.40 / −10.60 dB |
| 2.4835 GHz | −0.01 / −27.80 dB | −0.19 / −13.78 dB |
| 2.7 GHz | −12.41 / −0.26 dB | −13.24 / −0.21 dB |

| 項目 | 図3 (等価回路) | 結合線路の計算 |
| --- | --- | --- |
| −3 dB の帯域 | 2.279〜2.562 GHz | 2.307〜2.565 GHz |
| 1.5 GHz の S21 | −45.1 dB | −29.6 dB |
| 3 GHz の S21 | −22.8 dB | −21.5 dB |

- 通過帯域と、その外 ±250 MHz までは 2 つの計算の S21 が 1〜2 dB で合う (S11 の谷の深さは合わない)。**等価回路は帯域の
  すぐ近くでしか使えない**。1.5 GHz では 15 dB も違う (結合を 1 つの容量にまとめたため)。
  帯域から遠い所は、測った値か結合線路の計算で読む
- 損失を入れていない。FR4 の線路の共振器の Q<sub>u</sub> を 80 (目安) とすると、山は
  4.343 × (2.44 / 0.26) × 2.83 / 80 ≈ **1.4 dB** 下がる。実物の山がそれより大きく下がっていたら、
  縁の銅箔テープの半田付け (GND の端) を疑う
- 手順 1 で測った k が 0.076 から外れていたら、近似式の誤差。k が大きすぎれば帯域が広がり、
  小さすぎれば山の頂が下がる。隙間を作り直すときは、s を 0.5 mm 広げるごとに k が約 0.01
  小さくなるとして見積もる (計算では s = 3 mm で 0.087、3.5 mm で 0.076、4 mm で 0.066)
- 2 GHz より下と 2.9 GHz より上の床 (−20〜−30 dB) は、コムラインの数段では深くできない。
  深く落としたい所が決まっているなら、市販のチップのバンドパスや減衰極を持つフィルタと組み合わせる

## LTspice での確かめ

`sim/22-combline-model.cir` で、図の `dut:` の模型を LTspice の AC 解析にかけた (50 Ω の電源と 50 Ω の終端。線路は損失なしの T 素子)。
理想の模型どうしの比べで、実測ではない。

| 図 | 周波数 | 項目 | 図の読み値 | LTspice | 判定 |
| --- | --- | --- | --- | --- | --- |
| 図3 | 2.2 GHz | S21 / S11 | −11.18 dB / −0.34 dB | −11.18 dB / −0.34 dB | 合う |
| 図3 | 2.4 GHz | S21 / S11 | −0.58 dB / −9.03 dB | −0.58 dB / −9.03 dB | 合う |
| 図3 | 2.4835 GHz | S21 / S11 | −0.01 dB / −27.80 dB | −0.01 dB / −27.80 dB | 合う |
| 図3 | 2.7 GHz | S21 / S11 | −12.41 dB / −0.26 dB | −12.41 dB / −0.26 dB | 合う |

4 点すべて図の読み値と合う。

結合した線路 (偶・奇モード) の計算は LTspice に結合線路の素子が無いので、Python で
偶・奇モードの線路の Y 行列を組み、節点の方程式を解いた (算術)。表の「結合線路の計算」の列と、
f<sub>e</sub>・f<sub>o</sub>・k・帯域の幅の目安はこの計算による。

## 出典

自作。結合したマイクロストリップの偶・奇モードの式は Garg と Bahl の近似
(R. Garg, I. J. Bahl, "Characteristics of Coupled Microstriplines", IEEE Trans. MTT, 1979)、
1 本の線路は Hammerstad と Jensen の式による。
