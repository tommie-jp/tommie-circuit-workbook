# 6-15 2.4 GHz バンドパス (インターディジタル / ヘアピン)

2.4 GHz 帯 (Wi-Fi・Bluetooth) のバンドパスを、部品を 1 つも使わずに銅張り基板の線路だけで作る。
共振器は**半波長 (λ (ラムダ)/2) の線路**で、それを U の字に折り曲げたのが**ヘアピン**。隣どうしの U の腕が
隙間を挟んで並び、電界と磁界で結合する。線路の端を GND に落とす 1/4 波長の共振器を櫛の歯のように
互い違いに並べたのが**インターディジタル**で、考え方は同じ (この題は via の要らないヘアピンで組む)。
3 段のヘアピンを設計して彫り、NanoVNA V2 で 3 GHz まで測る。

## この実験で確かめる式

目標は中心 2.45 GHz、リップル 0.1 dB の 3 段チェビシェフ、帯域幅 200 MHz (比帯域 FBW = 0.2 / 2.45 = 8.2 %)。
g 値は g1 = g3 = 1.032、g2 = 1.147。結合フィルタの設計では、この値を 2 つの数に直す。

| 量 | 式 | 値 |
| --- | --- | --- |
| 隣の共振器との結合係数 k | FBW / √(g1 g2) | 0.0750 |
| 入出力の外部 Q (Q<sub>e</sub>) | g0 g1 / FBW | 12.6 |

**結合 → 隙間**: 隣どうしの腕を λ/4 の結合線路と見ると、偶モードと奇モードの Z0 (Z<sub>0e</sub>・Z<sub>0o</sub>) の比で
(Z<sub>0e</sub> − Z<sub>0o</sub>) / (Z<sub>0e</sub> + Z<sub>0o</sub>) = J / (1 + J²)、J = (π (パイ)/2) k = 0.118 になればよい。
幅 3.06 mm (50 Ω (オーム)) の線を厚さ 1.6 mm・比誘電率 4.4 の FR4 に並べると、Garg と Bahl の近似式で
**隙間 2.0 mm** (Z<sub>0e</sub> = 55.6 Ω、Z<sub>0o</sub> = 44.0 Ω) になる。

**外部 Q → タップの位置**: 入出力の 50 Ω の線を共振器の途中に直に付ける (タップ)。共振器の真ん中 (U の底の中央) は
電圧が 0 で、そこから電気角 θ (シータ) 離れた点に付けると Q<sub>e</sub> = (π/2) / sin²θ (共振器も 50 Ω のとき。算術で導いた)。
Q<sub>e</sub> = 12.6 なら **θ = 20.6°**、長さにして中央から 3.8 mm。U の底の半分が 3.0 mm なので、**外側の腕の付け根から 0.8 mm 上**。

**共振器の長さ**: 線路の実効比誘電率は 3.33 で、2.45 GHz の管内波長は 67.0 mm。λ/2 は 33.5 mm で、
開放端の延び (片側 0.62 mm、Hammerstad の式) を引いて**中心線で 32.3 mm** (U の底 6 mm + 腕 13.1 mm × 2)。

隙間・タップ・長さはどれも近似式の値で、電磁界の計算をしていない。**目安**として作り、測って合わせる (下の「合わせ方」)。

## 回路図

ヘアピンの線路は SPICE や回路図の記号で描けないので、**同じ帯域と損失の LC の等価回路** (6-12 と同じ作り方。
形の目安) を描く。損失は FR4 の上の線路の共振器の Q を 70 と見積もって入れた (目安)。

```circuit
# 回路図 (tommie-fence の circuit フェンス)
title: 図1 ヘアピン 3 段の等価回路 (共振器 3 つを結合)
parts:
  J1: sma 2,2 mirror CH0
  L1: inductor 4,2 4,4 0.257n
  C1: capacitor 6,2 6,4 16.42p
  L2: inductor 7,2 9,2 45.65n
  C2: capacitor 9,2 11,2 0.09243p
  L3: inductor 12,2 12,4 0.257n
  C3: capacitor 14,2 14,4 16.42p
  J2: sma 16,2 CH1
  G1: ground 2,3
  G2: ground 4,4
  G3: ground 6,4
  G4: ground 12,4
  G5: ground 14,4
  G6: ground 16,3
wires:
  - J1.1 -- 4,2 -- 6,2 -- 7,2
  - 11,2 -- 12,2 -- 14,2 -- J2.1
  - J1.2 -- 2,3
  - J2.2 -- 16,3
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/06-filters/circuit/15-hairpin-bpf.svg)

- 3 つの共振 (L1 と C1、L2 と C2、L3 と C3) が、図2 の R1・R2・R3 に当たる。どれも 2.45 GHz で共振する
- 実物にこの L と C の部品は無い。銅の線路の長さと隙間がこの働きをする

## 実体配線図

2.4 GHz は perfboard の目安 (300 MHz) をはるかに超え、Z0 の決まった線路そのものが部品になるので、銅張り基板に彫る。
FR4 は 1 GHz を超えると損失とばらつきが増える。それでも安く手に入るので FR4 で作り、損失 (Q 70、目安) を図に織り込んだ。
両面の FR4 (1.6 mm、比誘電率 4.4) で、裏は全面の銅 (GND)。5×7 cm から 58 mm × 30 mm を切り出す。

```copper
# 銅張り基板の寸法図 (tommie-fence の copper フェンス)
board:
  size: 58x30mm
  ground: back
title: 図2 ヘアピンのバンドパス (3 段、2.45 GHz)
f: 2.45G
copper:
  IN: line 0,21.16 14.94,21.16 3.06mm
  R1: line 14.94,8.86 14.94,22 20.94,22 20.94,8.86 3.06mm
  R2: line 26,8.86 26,22 32,22 32,8.86 3.06mm
  R3: line 37.06,8.86 37.06,22 43.06,22 43.06,8.86 3.06mm
  OUT: line 43.06,21.16 58,21.16 3.06mm
parts:
  J1: sma left 21.16 CH0
  J2: sma right 21.16 CH1
notes:
  - dim 14.94,4 20.94,4
```

![銅張り基板の寸法図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/06-filters/copper/15-hairpin-bpf.svg)

| 何 | 寸法・置き方 (線の中心で測る) |
| --- | --- |
| 線の幅 | どれも 3.06 mm (50 Ω、図のラベル) |
| R1〜R3 | 腕の中心の間 6 mm (図の寸法線)、腕 13.1 mm (y = 8.86〜22)、U の底は y = 22 |
| 隙間 | 隣の U の腕の間 2.0 mm (図の `s2mm`) |
| タップ | IN と OUT は y = 21.16 (U の底の中心線から 0.84 mm 上) で外側の腕に付く |
| 端面 SMA | 左右の縁の y = 21.16。外皮の脚は縁で裏のベタへ |

- 図のラベルの 173° は R1〜R3 の中心線の電気長 (2.45 GHz)。開放端の延びを足して 180° になる
- 腕の先 (開放端) が一番電圧の高い所。手や工具を近づけると中心がずれる (9-5)

**合わせ方**: 測った中心が低ければ、6 本の腕の先を同じだけ削る (共振器の長さ 33.5 mm に対して 1 mm 縮めると約 3 % 上がる。腕 1 本なら 0.5 mm。目安)。
帯域の幅は隙間で決まり、削っては直せない。**隙間を 1.5・2.0・2.5 mm にした 3 枚を最初に作って比べる**のが早い。

## 掃引の設定

計器は VNA。2.4 GHz は H4 の範囲 (1.5 GHz まで) の外なので、この題の図は NanoVNA V2 (3 GHz まで) で書いてある。
標準の LiteVNA64 でも同じ手順で測れる。

| 項目 | 値 |
| --- | --- |
| 範囲 | 1.8〜3.0 GHz |
| 点数 | 241 (5 MHz おき) |
| 校正 | SOLT。ケーブルの先で (9-2) |
| 表示 | S21 と S11 の Log Mag |

## 見るべき値

計算値 (等価回路による)。

| マーカー | 周波数 | S21 | S11 | 意味 |
| --- | --- | --- | --- | --- |
| 1 | 2.35 GHz | −3.60 dB | −14.68 dB | 帯域の下の端の近く |
| 2 | 2.45 GHz | **−2.41 dB** | −23.95 dB | 中心。損失は共振器の Q (70) から |
| 3 | 2.55 GHz | −3.19 dB | −15.75 dB | 帯域の上の端の近く |
| 4 | 2.70 GHz | −17.90 dB | −0.69 dB | 中心から 250 MHz 上 |

- 2.4 GHz 帯 (塗った帯) の中で S21 は −2.41〜−2.65 dB。−3 dB の幅は 2.32〜2.59 GHz (計算値)
- **損失の 2.4 dB は FR4 の上の共振器の Q (70、目安) から来る**。損失の小さい基板 (PTFE など) なら Q が上がり、損失は減る
- ヘアピンの共振器は λ/2 なので、**2 倍の 4.9 GHz あたりでまた通る**。V2 の 3 GHz では見えない。
  2.4 GHz の送信機の 2 倍の高調波を落としたいなら、ローパス (6-14 の形) を足す

分かること:

- 線路の長さが中心の周波数を、隙間が帯域の幅を、タップの位置が入出力の整合を決める。
  **3 つは別々に効く**ので、1 つずつ変えた基板を比べると何が何を決めるかが見える
- 測った S11 が帯域の中で −10 dB より悪ければ、タップの位置がずれている (Q<sub>e</sub> が合っていない)。
  タップを U の底から離すほど Q<sub>e</sub> が下がり (結合が強くなり)、近づけるほど上がる

## LTspice での確かめ

`sim/15-hairpin-bpf.cir` で、図の `dut:` の等価回路を LTspice の AC 解析にかけた (50 Ω の電源と 50 Ω の終端。LTspice のコイルに付く既定の直列抵抗は 1 µΩ (マイクロオーム) に固定)。
理想の模型どうしの比べで、実測ではない。結合線路そのもの (隙間とタップ) は SPICE で扱えないので、上の式の算術で確かめた。

| 周波数 | 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- | --- |
| 2.35 GHz | S21 / S11 | −3.60 dB / −14.68 dB | −3.60 dB / −14.68 dB | 合う |
| 2.45 GHz | 同 | −2.41 dB / −23.95 dB | −2.41 dB / −23.95 dB | 合う |
| 2.55 GHz | 同 | −3.19 dB / −15.75 dB | −3.19 dB / −15.75 dB | 合う |
| 2.70 GHz | 同 | −17.90 dB / −0.69 dB | −17.90 dB / −0.69 dB | 合う |

算術: k = 0.082 / √(1.032 × 1.147) = 0.0750、Q<sub>e</sub> = 1.032 / 0.082 = 12.6、sin²θ = π / (2 × 12.6) → θ = 20.6°。
R1〜R3 の中心線の長さ 6 + 13.14 × 2 = 32.3 mm は図2 の電気長 173° (copper フェンスの計算) と合う。

## 出典

自作。結合係数と外部 Q による設計は結合共振器フィルタの標準的な方法、結合マイクロストリップの Z<sub>0e</sub>・Z<sub>0o</sub> は
Garg と Bahl (1979) の近似式、線路の Z0 と開放端の延びは Hammerstad の式による。タップの式は、λ/2 の開放共振器の
サセプタンスの傾きから導いた。
