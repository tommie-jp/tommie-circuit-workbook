# 7-25 RFID 13.56 MHz のループ

交通系の IC カードや NFC のタグを読む装置 (読み取り装置) は、13.56 MHz の**ループ** (数回巻いた線の輪) で
タグと磁界を結ぶ。波長は 22 m もあり、手のひらほどのループはほとんど電波を出さない。ループは**コイル**として
タグに磁界を届け、タグのコイルと変成器のように結合する。

読み取り装置の送信回路は 50 Ω (オーム) を前提にしているので、ループ (1 µH (µ はマイクロ) のコイルと小さな損失) を 13.56 MHz で
50 Ω に見せる**整合回路**が要る。ここでは直列の C1 と並列の C2 の 2 つのコンデンサで整合し、
Q (クオリティファクタ) を下げる**ダンピング抵抗** R1 を入れて、タグの返事 (側帯波) が通る帯域を確保する。
ループの近くに置いたタグの共振は 7-26 で測る。

## この実験で確かめる式

| 式 | 意味 |
| --- | --- |
| **X<sub>L</sub> = ωL = 2πfL** | ループのリアクタンス。L = 1.0 µH・13.56 MHz で 85.2 Ω。ω (オメガ) は角周波数、π (パイ) は円周率 |
| **Q = ωL / (R<sub>loss</sub> + R1)** | ループの Q。損失 R<sub>loss</sub> = 0.5 Ω だけなら 170、R1 = 3.3 Ω を足すと 22.4 |
| **B = f / Q** | 3 dB の帯域の目安。Q 22.4 で 605 kHz |
| **f<sub>sc</sub> = f / 16 = 847.5 kHz** | ISO/IEC 14443 のタグが返事に使う副搬送波。側帯波は 13.56 ± 0.85 MHz に立つ |
| **C2 で R を上げ、C1 で X を消す** | 並列の C2 が直列の小さな R (3.8 Ω) を 50 Ω まで持ち上げ、残った誘導性を直列の C1 で打ち消す (7-4 の L 型整合と同じ考え方) |

読み取り装置のループの Q は 20〜30 くらいに抑えるのが普通 (目安)。Q 170 のままでは帯域が 80 kHz しか無く、
タグの返事の側帯波を削ってしまう。R1 はそのための部品で、電力を少し捨てて帯域を買う。

## 回路図

ループ L1 は基板の外に張り、両端を基板に半田付けする。R<sub>loss</sub> (0.5 Ω) はループの線の損失で、部品ではない。

```circuit
# 回路図 (tommie-fence の circuit フェンス)
title: 図1 13.56 MHz のループと整合回路 (C1・C2) とダンピング抵抗 (R1)
parts:
  J1: sma 2,2 mirror CH0
  C1: capacitor 3,2 5,2 39p
  C2: capacitor 6,2 6,4 100p
  R1: resistor 7,2 9,2 3.3
  L1: inductor 10,2 10,4 1u l=$L_1$
  G1: ground 2,3
  G2: ground 6,4
  G3: ground 10,4
wires:
  - J1.1 -- 3,2
  - 5,2 -- 6,2 -- 7,2
  - 9,2 -- 10,2
  - J1.2 -- 2,3
notes:
  - text 11.2,3 left: ループ (損失 0.5 Ω を含む)
```

## 部品

| 部品 | 値 | メモ |
| --- | --- | --- |
| C1 | 39 pF | セラミック (C0G / NP0)、リード品。計算値 38.4 pF を E12 に丸めた |
| C2 | 100 pF | セラミック (C0G / NP0)、リード品 |
| R1 | 3.3 Ω | 1/4 W 炭素皮膜。ダンピング抵抗 |
| L1 | 1.0 µH (目安) | ループ。線径 1 mm のエナメル線を 6 cm × 6 cm の四角に 3 回巻く (目安。巻いたら先に測る) |
| J1 | SMA (メス、端面) | NanoVNA の CH0 へ |
| 基板 | 7×5 cm (24 × 18 穴)、1.6 mm の FR-4 | 部品は 3 つだけ。13.56 MHz は基板の範囲 (10 MHz) を超えるが、線を数 mm に縮めた端面 SMA の治具はこの冊では 300 MHz まで perfboard に組む (前書き) |

## 掃引の設定

計器は VNA。この本の図は NanoVNA-H4 で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。

| 項目 | 値 |
| --- | --- |
| 範囲 | 12.8 MHz〜14.3 MHz |
| 点数 | 301 (5 kHz おき) |
| 校正 | SOLT (CH0 の同軸の先端で) |
| 表示 | S11 の Smith チャートと SWR |
| 置き方 | ループの周り 20 cm に金属・IC カード・スマートフォンを置かない (結合して共振がずれる) |

**まずループだけを測る**: 部品を付ける前に、ループの両端を J1 の中心と外皮に直に付け、13.56 MHz の X を読む。
L = X / (2π × 13.56 MHz) で、X = 85.2 Ω なら 1.00 µH。L が違えば、C1・C2 を計算し直す (見るべき値の最後)。

  **R1 は帯域のためだけでなく、整合の一部**でもある

## 見るべき値

計算値 (L1 = 1.0 µH・R<sub>loss</sub> = 0.5 Ω は目安)。

| 周波数 | 図3 の Z (R1 あり) | 図3 の SWR | 図4 の Z (R1 なし) | 図4 の SWR |
| --- | --- | --- | --- | --- |
| 13.32 MHz | 41.9 − j31.4 Ω | 2.00 | 5.6 − j27.1 Ω | 11.63 |
| 13.56 MHz | 49.9 + j4.0 Ω | 1.08 | 6.7 + j9.8 Ω | 7.81 |
| 13.76 MHz | 58.6 + j38.2 Ω | 2.03 | 7.8 + j45.7 Ω | 11.77 |

- **SWR 2 の幅は 13.32〜13.76 MHz (434 kHz)**。副搬送波の側帯波 (12.71 MHz・14.41 MHz) は SWR 2 の外になるが、
  読み取り装置で側帯波を受けるのは受信の側の回路なので、送る側の整合はこの幅で足りる (目安)。
  帯域が足りないときは R1 を大きくする (4.7 Ω で Q ≈ 16、そのぶん C1・C2 を計算し直す)
- 谷が 13.56 MHz からずれたら、**C2 で谷の周波数を、C1 で谷の深さを**合わせる (並列の C2 は共振を、直列の C1 は
  点を R の円に沿って中心へ動かす)。合わせには 10 pF ほどのトリマを C2 に並列に足すとよい
- 測った L が 1.0 µH と違うときの C の決め方 (計算値): L = 0.8 µH なら C2 = 125 pF・C1 = 48 pF、
  L = 1.2 µH なら C2 = 83 pF・C1 = 32 pF (R の合計は同じ 3.8 Ω とした)
- この題は VNA の小さな出力で測るだけ。このループを大きな電力の送信回路で駆動して読み取り装置にするときは、
  電波法の手続き (高周波利用設備) が要ることがある

## 出典

自作。13.56 MHz の近接型 IC カードの方式と副搬送波 (f / 16) は ISO/IEC 14443 による。2 つのコンデンサで
ループを整合し、抵抗で Q を下げる作り方は、読み取り装置の IC のメーカーのアンテナ設計の手引きに載っている形を、
50 Ω の単端の形に描き直したもの。値はこの題で選んだもの。
