# 7-19 スロットアンテナ

地の銅の面に**細長い切れ目 (スロット)** を入れると、それがアンテナになる。銅の線を残して作る
ダイポールの「裏返し」で、切れ目の長さが半波長のとき共振する。飛行機の胴体や基板の地の面に
埋め込めて、出っ張りが無い。

この題では、両面の銅張り基板の**裏の地にスロットを切り**、表のマイクロストリップでスロットを横切って給電する。
線路はスロットを越えた先で 1/4 波長だけ伸ばして先を開く (オープンスタブ)。この長さを間違えると
整合が崩れることも画面で確かめる。

## この実験で確かめる式

| 式 | 値 |
| --- | --- |
| **Babinet (バビネ) の原理: Z<sub>slot</sub> × Z<sub>dipole</sub> = η<sub>0</sub>² / 4** | η<sub>0</sub> (イータ) = 376.7 Ω (空間のインピーダンス)、半波長ダイポール 73.1 Ω → 半波長スロットの真ん中で **485 Ω** |
| **端から d の所の抵抗: R(d) = 485 × sin²(π d / L<sub>s</sub>)** | スロットの電圧は真ん中で最大、両端 (短絡) で 0。L<sub>s</sub> = 46 mm、d = 4.5 mm で **44 Ω** |
| **スロットの長さ L<sub>s</sub> ≈ λ<sub>0</sub> / (2√ε<sub>s</sub>)** | λ<sub>0</sub> = 122.9 mm (2.44 GHz)。基板の片側だけが FR4 なので ε<sub>s</sub> ≈ 1.8 (目安) → **46 mm** |
| **スタブ λ<sub>g</sub>/4 = λ<sub>0</sub> × v<sub>f</sub> / 4** | マイクロストリップの v<sub>f</sub> = 0.55 で **16.8 mm** |

- スロットの真ん中は 485 Ω と高すぎるので、**端寄り (4.5 mm) で給電する**。485 Ω も sin² の式も、
  無限に広い薄い銅の板の値で、基板の上では下がる (目安)。最後は測って確かめる
- 1/4 波長の開放スタブは、共振の周波数でスロットの位置を**短絡**に見せる。線路の電流がスロットの真上で最大になり、
  スロットを強く励振する

## 回路図

スロットの位置から見た**等価回路** (共振の近くだけ)。マイクロストリップがスロットを横切る所では、
スロットは線路に**直列**に入る (線路の地の電流がスロットを回り込むため)。スロットそのものは
並列共振 (L1 ∥ R1 ∥ C1) で、その先にスタブ T1 が付く。

```circuit
# 回路図 (tommie-fence の circuit フェンス)
title: 図1 スロットとスタブの等価回路 (スロットは線路に直列)
parts:
  J1: sma 2,2 mirror CH0
  L1: inductor 5,2 7,2 0.36n
  R1: resistor 5,3.5 7,3.5 44
  C1: capacitor 5,5 7,5 11.8p
  T1: tline 9,2 11,2 50
  G1: ground 2,3
wires:
  - J1.1 -- 4,2
  - 4,2 -- 5,2
  - 4,2 -- 4,5
  - 4,3.5 -- 5,3.5
  - 4,5 -- 5,5
  - 7,2 -- 8,2
  - 8,2 -- 8,5
  - 7,3.5 -- 8,3.5
  - 7,5 -- 8,5
  - 8,2 -- 9,2
  - 11,2 -- 12,2
  - J1.2 -- 2,3
notes:
  - text 12.2,2 left small: 開放
  - text 10,2.6 small: 16.8 mm
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/circuit/19-slot-antenna.svg)

R1 = 44 Ω (上の式)、L1・C1 は共振 2441.9 MHz・Q = 8.0 にした**等価回路**の値 (目安)。T1 の先は開放。
共振で T1 (λ<sub>g</sub>/4) は短絡に見え、CH0 には R1 = 44 Ω だけが残る。

## 実体配線図

5×7 cm の両面の FR4 (厚さ 1.6 mm) から 60 mm × 40 mm を切り出す。**表**は給電の線だけを残して剥がし、
**裏**は全面の銅を残して、スロット (破線の枠。裏から見た図で銅の無い横の帯) だけを切り取る。

```copper
# 銅張り基板の寸法図 (tommie-fence の copper フェンス)
board:
  size: 60x40mm
  ground: back
title: 図2 マイクロストリップで給電するスロットアンテナ (2.44 GHz)
f: 2.44G
copper:
  F1: line 11.5,40 11.5,3.2 3.06mm
  X1: slot 30,20 46x2mm
parts:
  J1: sma bottom 11.5 CH0
notes:
  - dim 7,24 53,24
  - dim 7,28 11.5,28
  - dim 5,3.2 5,20
  - text 32,16: 裏の地に切るスロット (幅 2 mm)
```

![銅張り基板の寸法図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/copper/19-slot-antenna.svg)

| 何 | 寸法・置き方 |
| --- | --- |
| スロット (裏) | 長さ 46 mm・幅 2 mm。裏の銅を、上の縁から 19〜21 mm、左の縁から 7〜53 mm の帯だけ剥がす |
| 給電の線 (表) | 幅 3.06 mm (50 Ω の計算値)。下の縁の SMA から上へ、スロットを横切って、スロットの中心線から 16.8 mm 先 (上の縁から 3.2 mm) で止める。先は開放 (どこにもつながない) |
| 給電の位置 | 線の中心がスロットの左の端から 4.5 mm |
| 端面 SMA (J1) | 下の縁の左から 11.5 mm。中心ピンを線へ、外皮の脚は裏のベタへ |

- スロットは裏から見た図の銅の無い帯。カッターで 2 本の切れ目を入れ、間の銅を剥がす。
  表と裏で位置を合わせるには、板の縁から測るか、細い穴をスロットの両端に開けて裏へ印を写す
- 線の上の 16.8 mm は、スロットの真ん中 (上の縁から 20 mm) から測る。長すぎたら切って詰められる
- 4.5 mm の寸法線は線の上に重なる (スロットの端から線の中心までを測るため)
- FR4 は 1 GHz を超えると損失と εr のばらつきが効く。スロットの長さ (共振) とスタブの長さを測って合わせる題なので、FR4 のまま使う

## 掃引の設定

計器は VNA。この題の図は NanoVNA V2 (歴史的な機種) で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。
NanoVNA-H4 は 1.5 GHz までなので測れない。

| 項目 | 値 |
| --- | --- |
| 範囲 | 2.0 GHz〜3.0 GHz |
| 点数 | 201 (5 MHz おき) |
| 校正 | SOLT (ケーブルの先の SMA で)。そのあと**ポート延長で基準面をスロットの上へ** (SMA から 20 mm、速度係数 0.55 で約 121 ps。1-10) |
| 表示 | S11 の SWR、Smith チャート |

- スロットは表と裏の両方へ電波を出す (向きは板に垂直な 2 方向)。板の両側 20 cm に物や手を置かない
- **電波が出る**: 掃引は測る間だけにする (7-12・7-13 と同じ)

スタブが λ<sub>g</sub>/4 (16.8 mm) のときの**見えるはずの画面**。

dut:
  - series L 0.36n rp 44 cp 11.8p
  - line 50 16.8mm vf 0.55
  - open
traces:
  - S11 swr
  - S11 smith
markers:
  - 2402M
  - 2440M
  - 2480M

- 図3 は谷が帯域の真ん中 (2.44 GHz) にあり、Smith チャートの点は中心の少し左 (44 Ω) を通る
- 図4 はスタブが長い分、開放スタブが共振の周波数で短絡にならず、**誘導性のリアクタンス (+j19.5 Ω) が直列に残る**。
  Smith チャートの線が上 (誘導性の側) へ持ち上がり、谷は 2.49 GHz へ動いて浅くなる
- スタブが長すぎたら、線の先を切って詰める。**1 mm で約 5 Ω**のリアクタンスが動く (2.44 GHz の近く、目安)

## 見るべき値

計算値 (等価回路。R・L・C は目安、スタブは損失の無い 50 Ω の線)。

| スタブ | 2402 MHz | 2440 MHz | 2480 MHz | SWR 2 以下の幅 |
| --- | --- | --- | --- | --- |
| 16.8 mm (図3) | 41.2 + j9.2 Ω、SWR 1.32 | 44.0 + j0.1 Ω、SWR 1.14 | 41.5 − j9.4 Ω、SWR 1.32 | 2334〜2552 MHz (218 MHz、8.9 %) |
| 20.8 mm (図4) | 41.2 + j28.1 Ω、SWR 1.89 | 44.0 + j19.5 Ω、SWR 1.54 | 41.5 + j10.6 Ω、SWR 1.35 | 2392〜2578 MHz |

- スロットの帯域 (8.9 %) は 7-14 の逆 F (6 %) より広く、7-15 のパッチ (2.5 %) よりずっと広い。
  幅のある切れ目が地の面の大きな電流を使うので、Q が低い (目安)
- スタブを 4 mm 間違えても SWR 2 は超えない。ただし帯域の下の端 (2402 MHz) が SWR 1.9 に近づく。
  スロットの長さの誤差 (共振のずれ) とスタブの誤差は、Smith チャートで区別できる: 共振のずれは**点が円の上を回り**、
  スタブの誤差は**線全体が上か下へずれる** (直列のリアクタンスが足される)

## LTspice での確かめ

`sim/19-slot-antenna.cir` で、図の `dut:` の模型 (直列に入る L ∥ R ∥ C と、先を開いたスタブ) を LTspice の AC 解析にかけた
(50 Ω の電源。スタブは損失の無い T 素子で Td = l / (0.55 × 299792458)。コイルの直列抵抗は 1 µΩ に固定)。
CH0 の電圧から |Γ| = |2·V − 1| と Z = 50·V / (1 − V) を `.meas` で読んだ。理想の模型どうしの比べで、実測ではない。
Babinet の 485 Ω・端寄りの 44 Ω・スロットとスタブの長さは算術 (Python) による。スロットの電磁界は LTspice では計算できない。

| 図 | 周波数 | 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- | --- | --- |
| 図3 | 2402 MHz | SWR | 1.32 | 1.322 | 合う |
| 図3 | 2440 MHz | SWR / R | 1.14 / 44.0 Ω | 1.137 / 43.99 Ω | 合う |
| 図3 | 2480 MHz | SWR | 1.32 | 1.320 | 合う |
| 図4 | 2402 MHz | SWR | 1.89 | 1.894 | 合う |
| 図4 | 2440 MHz | SWR / \|X\| | 1.54 / 19.5 Ω | 1.541 / 19.55 Ω | 合う |
| 図4 | 2480 MHz | SWR | 1.35 | 1.347 | 合う |

LTspice の `.meas` は虚部の符号を落とした (大きさだけが返る) ので、X は大きさで比べた。符号 (誘導性) はスタブの式
−jZ<sub>0</sub> cot βl (βl が 90° を超えると正) による。

## 出典

自作。スロットとダイポールの関係 (Z<sub>slot</sub> Z<sub>dipole</sub> = η<sub>0</sub>² / 4) は
[Babinet's principle (Wikipedia)](https://en.wikipedia.org/wiki/Babinet%27s_principle) と
[Slot antenna (Wikipedia)](https://en.wikipedia.org/wiki/Slot_antenna) による。マイクロストリップの Z<sub>0</sub> と速度係数は 9-3 と同じ。
