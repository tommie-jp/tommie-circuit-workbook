# 7-5 バーアンテナ + バリコン (中波)

フェライトバーアンテナ (ループスティック) のコイルとバリコン (可変コンデンサ) で
中波放送帯の同調回路を作り、バリコンを回すと共振周波数がどう動くかを NanoVNA の
S11 で確かめる。

**フェンスの制約**: 使っているフェンスの `dut:` には可変コンデンサ用の
特別な記号は無く、`capacitor` の値を変えて模型を作り直すしかない。
回路図のほうは circuit フェンスの可変コンデンサ (`capacitor-var`) で描く。

## この実験で確かめる式

同調周波数は **f₀ = 1 / (2π√(LC))**。ループスティックのインダクタンス
L = 330 µH (実効値)、バリコン C = 20〜260 pF (2 連バリコンの片側を想定) として、

| C | f₀ (計算値) |
| --- | --- |
| 20 pF (最小) | 1959 kHz |
| 100 pF | 876 kHz |
| 260 pF (最大) | 543 kHz |

中波放送帯 (531〜1602 kHz) の大部分をカバーする。

**給電の作り方**: コイルの巻き始めから数ターンの位置に**タップ**(または細い
リンク巻線) を設け、そこに同軸を直結する。タップの位置で見かけのインピーダンスが
下がり、共振点で 50 Ω に近い値になるよう調整する (ここでは変換後の実効抵抗を
20 Ω と仮定)。コイルの端に直結すると見かけのインピーダンスが高すぎて
(数 kΩ)、ほとんど反射したまま変化が見えない。

## 回路図

```circuit
title: 図1 タップ付きループスティックの給電点 (等価回路)
parts:
  J1: sma 2,2 mirror CH0
  R1: resistor 4,2 6,2 20
  L1: inductor 6,2 8,2 330u
  C1: capacitor-var 8,2 10,2 l=$\mathrm{VC}_1$
  G1: ground 2,3
  G2: ground 10,3
wires:
  - J1.1 -- 4,2
  - 10,2 -- 10,3
  - J1.2 -- 2,3
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/circuit/05-loopstick-varicap.svg)

- R1 = 20 Ω は**実在の抵抗ではなく**、タップで下がった見かけのインピーダンス
  (共振点での値)。実際に基板にはんだ付けするのは L1 (コイル) と C1 (バリコン) だけ
- C1 のラベル VC1 が可変コンデンサ (バリコン)。極板を斜めの矢が貫く記号で、矢が「回して容量を変える」印。
  図には容量を書かず、狙う値 (100 pF) は下の表に書く

![ユニバーサル基板の実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/perfboard/05-loopstick-varicap.svg)

- L1 がループスティックのコイル (330 µH)。実物はフェライト棒に巻いた線だが、
  ここでは軸物インダクタの記号で表す。記号は 2 端子なので、J1 からの線 (i3) は
  実物では**タップ**へつなぐ (上の「給電の作り方」)。図1 の R1 (20 Ω) は
  このタップで下がった見かけの抵抗なので、基板には現れない
- C1 がバリコン。実物は 2 本の端子を持つ可変コンデンサで、つまみを回して
  容量を変える

## 掃引の設定

計器は VNA。この本の図は NanoVNA-H4 で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。

| 項目 | 値 |
| --- | --- |
| 範囲 | 800 kHz〜960 kHz (バリコン中間、100 pF の共振 876 kHz のまわり。谷が狭いので幅は 160 kHz に絞る) |
| 点数 | 201 |
| 校正 | SOLT |
| 表示 | S11 の Log Mag、SWR |

C = 100 pF (可変範囲のほぼ中間) の**見えるはずの画面**。

```vna
device: h4
sweep: 800k-960k 201
title: 図3 バリコン 100 pF — 876 kHz で SWR が 2.50 まで下がり、X が 0 を横切る
dut:
  - series R 20
  - series L 330u
  - series C 100p
  - short
traces:
  - S11 swr
  - S11 x
markers:
  - 850k
  - 876k
  - 900k
```

![NanoVNA の画面](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/vna/05-loopstick-varicap.svg)

- 共振 (876 kHz) で SWR は最小 2.50 (タップの見かけ抵抗 20 Ω と 50 Ω の比)。
  完全な 1.00 にはならないが、共振点だけ大きく谷ができるのが分かる
- 共振から 30 kHz 離れただけで SWR は 18〜19 まで悪化する — **とても狭い**
  (Q が高いので、放送局を選び分ける力が強いことの裏返し)

## 見るべき値

計算値。バリコンを回して C を変えたときの共振周波数 (R = 20 Ω、L = 330 µH は固定)。

| C | f₀ (計算値) | 受信できる放送局の目安 |
| --- | --- | --- |
| 20 pF | 1959 kHz | 中波の上端より上 (国内 AM の範囲外) |
| 60 pF | 1131 kHz | 中波の上の方 |
| 150 pF | 715 kHz | 中波の下の方 |
| 260 pF | 543 kHz | 中波の下端付近 |

- バリコンを回すと同調周波数が動く。**容量を増やすほど周波数は下がる**
  (f₀ ∝ 1/√C)。20 pF から 260 pF まで C を 13 倍にすると、√C は約 3.6 倍になり、f₀ は約 1/3.6 になる
- 実際のタップの効き (見かけの抵抗が本当に 20 Ω に近いか) は、タップの位置を
  変えて SWR の最小値を測れば確かめられる。タップをコイルの接地側の端に近づけるほど抵抗は
  下がり、SWR の最小値は 1 に近づくが、コイルの負荷がかかって Q が下がり
  谷が浅く広くなる (トレードオフ)

## 出典

自作。中波放送帯 (531〜1602 kHz)、ループスティックの実効インダクタンスの目安は
一般的なラジオ工作の資料による。
