# 7-10 λ/4 グラウンドプレーン

4 分の 1 波長の垂直エレメントと、給電点から張り出した 4 本の**ラジアル**で作る
グラウンドプレーン (GP) アンテナを 145 MHz で測る。7-3 のホイップと同じ仲間だが、
ここでは**ラジアルの角度で給電点の R が変わる**ことを見る。ラジアルを水平に張ると
約 36 Ω、**斜め下に 45° ほど垂らすと約 50 Ω** に近づき、整合回路なしで SWR が 1 近くまで下がる。

## この実験で確かめる式

| 式 | 意味 |
| --- | --- |
| **l ≈ 71.5 / f[MHz] [m]** | 垂直エレメントの長さの目安 (7-3 と同じ)。145 MHz で 49 cm |
| ラジアルの長さ ≈ エレメントの約 1.05 倍 | 目安。145 MHz で 52 cm を 4 本 |
| 給電点の R ≈ **36 Ω** (水平) → **約 50 Ω** (45° 下向き) | ラジアルを垂らすほど R が上がる (目安。周りの物で動く) |
| **SWR = 50 / R** (R < 50 Ω のとき、共振点) | 共振点で X = 0 なら SWR は R と 50 Ω の比 |

## 回路図

GP を給電点の等価回路 (直列 R-L-C) で表す。R1 だけがラジアルの角度で変わり、
L1・C1 は 145 MHz で共振する値 (エレメントの長さで決まる) のまま。板は使わない。

```circuit
title: 図1 GP の給電点 (直列 RLC の等価回路)
parts:
  J1: sma b2 mirror CH0
  R1: resistor b4 b6 l=$R_1$
  L1: inductor b6 b8 250n
  C1: capacitor b8 b10 4.82p
  G1: ground c2
  G2: ground c10
wires:
  - J1.1 -- b4
  - b10 -- c10
  - J1.2 -- c2
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/circuit/10-ground-plane.svg)

- R1 は水平のラジアルで 36 Ω、45° 下向きで 50 Ω (下の表)。**等価回路**の値
- L1 = 250 nH は 7-2 のダイポール (500 nH) の半分。GP はダイポールの片側を地面の鏡で
  補ったものなので、R も X もダイポールの約半分になる

作り方の目安:

| 項目 | 値 |
| --- | --- |
| 垂直エレメント | 直径 2 mm 前後の銅線かアルミ棒、49 cm。SMA (メス、パネル取付) の芯にはんだ付け |
| ラジアル | 同じ線を 52 cm × 4 本、SMA のフランジの 4 つの穴に 1 本ずつ |
| 給電 | SMA に校正した NanoVNA を直結 (または SOLT した同軸の先に) |

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 120 MHz〜170 MHz (共振 145 MHz が中央) |
| 点数 | 201 |
| 校正 | SOLT |
| 表示 | S11 の SWR、Smith チャート |

**電波が出る**: アンテナをつないで掃引すると、NanoVNA の出力がそのまま電波になる。
免許の要らない微弱無線局の上限は、3 m の距離で 500 µV/m (322 MHz 以下)・35 µV/m
(322 MHz〜10 GHz) (電波法施行規則 第 6 条。9-5)。1 mW に満たない出力 (0-3) でもアンテナから
出ればこれを超えうるので、**掃引は測る間だけにし、つないだまま掃引を続けない**。

ラジアルを水平に張ったときの**見えるはずの画面**。

```vna

sweep: 120M-170M 201

  - S11 swr

```

- 図2 の Smith は共振点で中心より左 (r = 0.72)、図3 は**ちょうど中心**に来る
- SWR の谷は図2 で 1.39、図3 で 1.00。谷の幅 (SWR 2 以下) は図3 のほうが広い
- SWR の枠の目盛は図が値に合わせて決めるので、図2 (1/目盛) と図3 (0.5/目盛) で違う。
  **幅や高さは目盛ではなく、読み値と見るべき値の表で比べる**

## 見るべき値

計算値 (等価回路。R1 の 36 Ω・50 Ω は目安の値)。

| ラジアル | 145 MHz の Z | 145 MHz の SWR | 140 MHz の SWR | 150 MHz の SWR | SWR 2 以下の幅 |
| --- | --- | --- | --- | --- | --- |
| 水平 | 36 + j0 Ω | 1.39 | 1.64 | 1.63 | 136.8〜153.7 MHz (16.9 MHz) |
| 45° 下向き | 50 + j0 Ω | 1.00 | 1.37 | 1.36 | 134.2〜156.7 MHz (22.5 MHz) |

- **ラジアルの角度だけで R が変わり、整合回路なしで 50 Ω に合う**。垂らした分だけ
  共振も少し上がるので、実物ではエレメントを少し長めに切っておき、SWR を見ながら詰める (7-2 と同じ手順)
- ラジアルを外すと、同軸の外皮がラジアルの代わりになる。すると同軸を握るだけで SWR が動く —
  7-8 の「バランなし」と同じ現象。**ラジアルは同相の電流を止める役も持つ**
- 145 MHz 付近のアマチュア無線のバンドは 144〜146 MHz。どちらの形でも SWR は十分低い

垂らすと約 50 Ω に近づく) はアンテナ工学の教科書やアマチュア無線のアンテナの解説書に
