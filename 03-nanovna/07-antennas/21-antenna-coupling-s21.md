# 7-21 アンテナ間の結合 — S21 で距離と偏波

ここまでの題はアンテナを 1 本ずつ CH0 に繋ぎ、S11 (反射) だけを見てきた。この題では **2 本のアンテナを
CH0 と CH1 に 1 本ずつ繋ぎ、片方から出た電波がもう片方にどれだけ届くかを S21 で測る**。
同じ 435 MHz の半波長ダイポール (7-2 と同じ作り) を 2 本向かい合わせ、**距離を 2 倍にすると S21 が 6 dB 下がる**こと
(自由空間の損失)、**片方を回すと偏波の向きがずれて S21 が下がる**ことを確かめる。S21 の群遅延からは、
電波が空中を進んだ時間 (1 m で 3.34 ns) も読める。

## この実験で確かめる式

| 式 | 意味 |
| --- | --- |
| **S21 [dB] = G<sub>t</sub> + G<sub>r</sub> − 20 log<sub>10</sub>(4πd / λ) − M** | フリスの伝達公式を dB で書いたもの。π (パイ) は円周率。G は利得 (dBi)、d は距離、λ (ラムダ) は波長、M は 2 本の反射の損 |
| **G = 2.15 dBi** | 半波長ダイポールの利得 (真横の向き) |
| **M = 2 × (−10 log<sub>10</sub>(1 − \|Γ\|²))** | 給電点 70 Ω (オーム) のダイポールは \|Γ\| (ガンマ) = 0.167 で、1 本 0.12 dB、2 本で 0.24 dB |
| **偏波の損 = 20 log<sub>10</sub>\|cos θ\|** | 2 本の素子の向きが θ (シータ) ずれたときの損。45° で −3.0 dB、90° で理論上 −∞ |
| **τ = d / c** | τ (タウ) は電波が d を進む時間。c = 3 × 10⁸ m/s で 1 m あたり 3.34 ns |
| **d > 2D² / λ** かつ **d > λ** | フリスの式が使える遠方界の目安。D はアンテナの長さ (0.33 m) で、435 MHz (λ = 0.690 m) なら d > 0.69 m |

435 MHz・d = 1 m なら 20 log<sub>10</sub>(4π × 1 / 0.690) = 25.2 dB で、S21 = 2.15 + 2.15 − 25.2 − 0.24 = **−21.2 dB**。

## 回路図

CH0 と CH1 に同じ長さの同軸を付け、その先に 1:1 のバラン (7-8) とダイポールを付ける。
基板は使わない。

```circuit
# 回路図 (tommie-fence の circuit フェンス)
title: 図1 2 本のダイポールを CH0 と CH1 に付けて向かい合わせる
parts:
  J1: sma 2,4 mirror CH0
  E1: antenna 4,3
  E2: antenna 10,3
  J2: sma 12,4 CH1
  G1: ground 2,5
  G2: ground 12,5
wires:
  - J1.1 -- 4,4 -- 4,3
  - J2.1 -- 10,4 -- 10,3
  - J1.2 -- 2,5
  - J2.2 -- 12,5
notes:
  - text 7,2.6 center: 距離 d (1 m・2 m・4 m)
  - text 7,4.4 center: 同軸・バランは図から省く
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/circuit/21-antenna-coupling-s21.svg)

- E1・E2 は 435 MHz の半波長ダイポール。全長は 7-2 の l ≈ 143 / f[MHz] から約 33 cm (目安。切って合わせる)。
  先に 1 本ずつ CH0 で SWR を見て、2 本とも 435 MHz に共振させておく
- 2 本の素子は平行にそろえ (偏波 0°)、向かい合わせる。距離は素子の中心どうしで測る
- 同軸は 2 本とも 2 m ほど。**Thru の校正は 2 本の同軸の先端どうしを中継で繋いで行う** (校正面がアンテナの根元に来る)

## 掃引の設定

計器は VNA。この本の図は NanoVNA-H4 で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。

この題は実体配線図を付けない — アンテナ本体を測る題で、基板に載せる回路が無い。

| 項目 | 値 |
| --- | --- |
| 範囲 | 400 MHz〜470 MHz |
| 点数 | 141 (0.5 MHz おき) |
| 校正 | SOLT (2 本の同軸の先端で。Thru を含む) |
| 表示 | S21 の Log Mag と群遅延 (delay) |
| 置き方 | 屋外。2 本とも地上 1.5 m 以上、間に人が立たない。周り 3 m に金属の物を置かない |

**電波が出る**: アンテナをつないで掃引すると、NanoVNA の出力がそのまま電波になる。
免許の要らない微弱無線局の上限は、3 m の距離で 500 µV/m (µ はマイクロ) (322 MHz 以下)・35 µV/m
(322 MHz〜10 GHz) (電波法施行規則 第 6 条)。1 mW に満たない出力 (0-3) でもアンテナから
出ればこれを超えうるので、**掃引は測る間だけにし、つないだまま掃引を続けない**。

H4 のダイナミックレンジは 300〜900 MHz で約 60 dB (0-1)。S21 が −60 dB に近づくと雑音に埋もれる。
偏波を 90° にずらした測りは、この床に当たることがある。

画面の模型は、距離の分の遅れを空気の線路 (`line 50 1m vf 1`) で、損を整合した抵抗の π 型減衰器で表した
**S21 だけの模型**。アンテナの S11 は 7-2 で見たので、ここでは見ない。

  **435 MHz の値で読む**
- 遅れは校正面 (同軸の先端) から先の時間で、空中の d に、2 本のバランとダイポールの給電部の分がわずかに乗る

## 見るべき値

計算値 (自由空間のフリスの式。G = 2.15 dBi・M = 0.24 dB)。

| 距離 d | 自由空間の損 | S21 | 群遅延 |
| --- | --- | --- | --- |
| 1 m | 25.2 dB | −21.2 dB | 3.34 ns |
| 2 m | 31.2 dB | −27.2 dB | 6.67 ns |
| 4 m | 37.2 dB | −33.2 dB | 13.3 ns |

偏波 (d = 1 m のまま、CH1 の側のダイポールを、2 本を結ぶ線を軸に回す):

| 回した角 θ | 偏波の損 | S21 |
| --- | --- | --- |
| 0° | 0 dB | −21.2 dB |
| 30° | −1.2 dB | −22.4 dB |
| 45° | −3.0 dB | −24.2 dB |
| 60° | −6.0 dB | −27.2 dB |
| 90° | 理論上 −∞ (実物は 20〜30 dB 下、目安) | −41〜−51 dB (目安) |

- **距離を 2 倍にするごとに 6 dB 下がる**ことを、1 m・2 m・4 m の 3 点で確かめる。合わなければ、
  地面や近くの物からの反射が足されている (遅れの違う波が重なり、S21 が周波数で波打つのが合図)。
  アンテナを高くするか、地面に反射の少ない広い場所に移す
- 群遅延は d に比例する。**1 ns が 30 cm** にあたるので、遅れから距離を逆に読める
- 90° の値は、素子のわずかな傾き・同軸の外皮に流れる電流 (バランの効き、7-8)・周りの反射で決まる。
  理論の −∞ にはならない。**偏波をそろえないと 20 dB 以上損をする**ことが分かれば十分
- 1 m の測りの絶対値から利得を出すこともできる (2 本が同じなら G = (S21 + 25.2 + 0.24) / 2)。
  利得の違う 2 本を同じ所に置き換えて S21 の差を読むと、利得の差になる (7-23 で使う)

## LTspice での確かめ

`sim/21-antenna-coupling-s21.cir` で、図の `dut:` の模型を LTspice の AC 解析にかけた (50 Ω の電源と 50 Ω の終端。
空気の線路は損失の無い T 素子で TD = d / c)。フリスの式の値 (自由空間の損) そのものは LTspice では出せないので、
上の表の算術で確かめた。理想の模型どうしの比べで、実測ではない。

| 図 | 周波数 | 項目 | 図の読み値 | LTspice | 判定 |
| --- | --- | --- | --- | --- | --- |
| 図2 | 435 MHz | S21 / 遅れ | −21.16 dB / 3.336 ns | −21.16 dB / 3.336 ns | 合う |
| 図3 | 435 MHz | S21 / 遅れ | −27.18 dB / 6.671 ns | −27.18 dB / 6.671 ns | 合う |

2 点とも図の読み値と合う。遅れは 434.5 MHz と 435.5 MHz の位相の差 (1.201° と 2.402°) から出した。
`.meas` の dB と位相は符号があてにならないので、大きさと差で比べた。

## 出典

自作。自由空間の伝搬の式はフリスの伝達公式 (H. T. Friis, 1946) による。半波長ダイポールの利得 2.15 dBi は
アンテナ工学の教科書に載る標準的な値。
微弱無線局の電界強度の上限 (距離 3 m で 322 MHz 以下は 500 µV/m、322 MHz〜10 GHz は 35 µV/m) は
[電波法施行規則 第 6 条第 1 項第 1 号](https://laws.e-gov.go.jp/law/325M50080000014) による。

参考: [Wikipedia「Friis transmission equation」](https://en.wikipedia.org/wiki/Friis_transmission_equation)、[Wikipedia「偏波」](https://ja.wikipedia.org/wiki/偏波)
