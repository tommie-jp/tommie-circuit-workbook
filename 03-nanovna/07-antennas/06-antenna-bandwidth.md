# 7-6 アンテナの帯域幅 (SWR 2 の幅)

144 MHz にぴったり合わせたダイポール (7-2 の続き) で、**SWR が 2 以下でいられる
周波数の幅**を測る。アンテナの Q が高いほどこの幅は狭くなる。

## この実験で確かめる式

共振点の R = 70 Ω、そこから離れると ±jX が付く直列 RLC の等価回路で表すと、
Q は **Q = 2π f₀ L / R** で決まる。L = 500 nH、f₀ = 144 MHz なら Q ≈ 6.5。

Q が分かれば、比帯域の目安は **Δf / f₀ ≈ 1 / Q** (SWR 2 の全幅はこれより
やや広くなる。50 Ω 系との差 R = 70 Ω も効くため、正確には掃引して探す)。

## 回路図

7-2 と同じ形の等価回路。今度は**ちょうど 144 MHz で共振**するように C を選ぶ。

```circuit
title: 図1 144 MHz にちょうど合わせたダイポール (直列 RLC の等価回路)
parts:
  J1: sma 2,2 mirror CH0
  R1: resistor 4,2 6,2 70
  L1: inductor 6,2 8,2 500n
  C1: capacitor 8,2 10,2 2.44p
  G1: ground 2,3
  G2: ground 10,3
wires:
  - J1.1 -- 4,2
  - 10,2 -- 10,3
  - J1.2 -- 2,3
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/circuit/06-antenna-bandwidth.svg)

## 掃引の設定

計器は VNA。この本の図は NanoVNA-H4 で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。

この題は実体配線図を付けない — アンテナ本体を測る題で、基板に載せる回路が無い。

| 項目 | 値 |
| --- | --- |
| 範囲 | 120 MHz〜170 MHz |
| 点数 | 251 |
| 校正 | SOLT |
| 表示 | S11 の SWR |

**電波が出る**: アンテナをつないで掃引すると、NanoVNA の出力がそのまま電波になる。
免許の要らない微弱無線局の上限は、3 m の距離で 500 µV/m (322 MHz 以下)・35 µV/m
(322 MHz〜10 GHz) (電波法施行規則 第 6 条)。1 mW に満たない出力 (0-3) でもアンテナから
出ればこれを超えうるので、**掃引は測る間だけにし、つないだまま掃引を続けない**。

```vna
device: h4
sweep: 120M-170M 251
title: 図2 144 MHz ダイポールの SWR — 塗った所が SWR 2 以下 (約 11.7 MHz)
dut:
  - series R 70
  - series L 500n
  - series C 2.44p
  - short
traces:
  - S11 swr
markers:
  - 138.3M
  - 144M
  - 150M
notes:
  - band 138.3M 150M: SWR 2 の幅
```

![NanoVNA の画面](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/vna/06-antenna-bandwidth.svg)

- SWR の最小は 144 MHz 付近で 1.40 (R = 70 Ω と 50 Ω の比)
- SWR = 2 になる点はおよそ 138.3 MHz と 150.0 MHz。**帯域幅は約 11.7 MHz**
  (144 MHz に対して比帯域 約 8.1 %)

## 見るべき値

計算値。

| 周波数 | SWR | 分かること |
| --- | --- | --- |
| 138.3 MHz | 2.00 | 帯域の下端 |
| 140 MHz | 1.73 | 帯域内 |
| 144 MHz | 1.40 | 共振点 (最良) |
| 148 MHz | 1.69 | 帯域内 |
| 150.0 MHz | 2.00 | 帯域の上端 |

- **帯域幅 約 11.7 MHz (比帯域 約 8.1 %)** は細い線材の半波長ダイポールとして
  典型的な値。太いエレメント (パイプなど) にすると容量が増えて Q が下がり、
  帯域はもっと広くなる
- SWR 2 を基準にするか SWR 1.5 を基準にするかで帯域の値は変わる。無線機の
  送信許容範囲に合わせて基準を選ぶ (アマチュア無線では SWR 2 以下が目安に
  使われることが多い)
- 同じアンテナでも 7-2 のように長さがずれていると、この帯域の**中心が
  ずれるだけ**で幅そのものは (Q が変わらなければ) ほぼ同じ
