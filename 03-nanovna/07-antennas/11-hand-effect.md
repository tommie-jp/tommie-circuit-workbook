# 7-11 手・近くの物の影響

7-6 で 144 MHz にぴったり合わせたダイポールに、**手を近づける**と SWR がどう動くかを見る。
人の体は水を多く含む誘電体 (比誘電率が大きく、損失もある) なので、エレメントの近くに
来ると**共振周波数が下がり**、**損失で R が増える**。アンテナを調整するとき、
自分の手や机・壁が測る値を変えてしまうことを数で知っておく。

## この実験で確かめる式

| 式 | 意味 |
| --- | --- |
| **f<sub>0</sub> = 1 / (2π√(LC))** | 等価回路の共振。近くの誘電体はエレメントの周りの電界を強め、C が増えたのと同じに働く (f<sub>0</sub> が下がる) |
| **Δf<sub>0</sub> / f<sub>0</sub> ≈ −ΔC / (2C)** | C が 1 % 増えると f<sub>0</sub> は約 0.5 % 下がる |
| R が増える | 体の損失の分。放射に回らない電力が増える |

## 回路図

7-6 と同じ直列 RLC の**等価回路**。手の影響は **C1 と R1 の値の変化**として表す。

```circuit
title: 図1 ダイポールの給電点 (等価回路)。手で R1 と C1 が変わる
parts:
  J1: sma 2,2 mirror CH0
  R1: resistor 4,2 6,2 l=$R_1$
  L1: inductor 6,2 8,2 500n
  C1: capacitor 8,2 10,2 l=$C_1$
  G1: ground 2,3
  G2: ground 10,3
wires:
  - J1.1 -- 4,2
  - 10,2 -- 10,3
  - J1.2 -- 2,3
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/circuit/11-hand-effect.svg)

| 状態 | R1 | C1 | 共振 f<sub>0</sub> |
| --- | --- | --- | --- |
| 手を離す (7-6 のまま) | 70 Ω | 2.44 pF | 144.1 MHz |
| エレメントの先から約 5 cm に手 (仮定) | 80 Ω | 2.58 pF | 140.1 MHz |

手を近づけたときの値は**仮定** (共振が約 3 % 下がり、R が 10 Ω 増える、とした目安)。
変わり方は手の大きさ・距離・どこに近づけるかで大きく違うので、自分で測って下の表を埋める。

## 掃引の設定

計器は VNA。この本の図は NanoVNA-H4 で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。

この題は実体配線図を付けない — アンテナと手の影響そのものを測る題で、基板に載せる回路が無い。

7-6 と同じ設定。

| 項目 | 値 |
| --- | --- |
| 範囲 | 120 MHz〜170 MHz |
| 点数 | 251 |
| 校正 | SOLT (ダイポールにつなぐ同軸の先で) |
| 表示 | S11 の SWR、リアクタンス X |

**電波が出る**: アンテナをつないで掃引すると、NanoVNA の出力がそのまま電波になる。
免許の要らない微弱無線局の上限は、3 m の距離で 500 µV/m (322 MHz 以下)・35 µV/m
(322 MHz〜10 GHz) (電波法施行規則 第 6 条)。1 mW に満たない出力 (0-3) でもアンテナから
出ればこれを超えうるので、**掃引は測る間だけにし、つないだまま掃引を続けない**。

手を離したときの**見えるはずの画面**。

```vna

sweep: 120M-170M 251
title: 図2 手を離す — 144 MHz で SWR 1.40、X はほぼ 0
dut:
  - series R 70
  - series L 500n
  - series C 2.44p
  - short
traces:
  - S11 swr
  - S11 x

  - 140M
  - 144M
```

エレメントの先に手を近づけたときの**見えるはずの画面** (設定は図2 と同じ。R1・C1 だけ仮定の値に)。

```vna

title: 図3 手を近づける — 谷が 140 MHz へ下がり、144 MHz で SWR 1.82
dut:
  - series R 80
  - series L 500n
  - series C 2.58p
  - short

  - S11 x

```

![NanoVNA の画面](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/vna/11-hand-effect-2.svg)

- X の枠の目盛は図ごとに自動で決まる (図2 と図3 で 0 の高さが違う) ので、値は読み値の表で比べる
- SWR の谷が 144 MHz から 140 MHz へ**左に動く**。X が 0 を横切る点も同じだけ動く
- 144 MHz の X は、図2 のほぼ 0 から図3 の +24 Ω へ (誘導性 = 7-2 の「長すぎる」と同じ見え方)。
  **手を近づけたまま切ると、手を離したとき短すぎる**アンテナになる

## 見るべき値

計算値 (等価回路。手の値は仮定)。

| 状態 | 140 MHz の Z | 140 MHz の SWR | 144 MHz の Z | 144 MHz の SWR | SWR 2 以下の幅 |
| --- | --- | --- | --- | --- | --- |
| 手を離す | 70 − j26.1 Ω | 1.73 | 70 − j0.6 Ω | 1.40 | 138.4〜150.1 MHz |
| 手を近づける | 80 − j0.8 Ω | 1.60 | 80 + j24.0 Ω | 1.82 | 134.9〜145.5 MHz |

自分で測って埋める表 (SWR の谷の周波数と、そこでの SWR):

| 近づける物と距離 | 谷の周波数 | 谷の SWR | 分かること |
| --- | --- | --- | --- |
| 何もなし | | | 基準 |
| 手、エレメントの先から 20 cm | | | 遠ければほとんど動かない |
| 手、5 cm | | | 共振が下がり、谷が浅くなる |
| 木の机の上 30 cm に置く | | | 誘電体の影響 |
| 金属の棚・窓枠から 30 cm | | | 金属は R も共振も大きく変える (向きで上にも下にも) |

- **調整は、手も体も離して測る**。NanoVNA を手に持ったまま給電点のすぐ近くで測ると、
  NanoVNA と自分の体もアンテナの周りの物になる。1〜2 m の同軸で離し、同軸の先で校正する
- 同軸を握ると動くのは別の現象 (外皮の同相の電流)。それは 7-8 のバランで止める。
  この題の動きはエレメントそのものの近くの物によるもので、バランでは止まらない
- 仮定の値でも、C1 が 5.7 % 増えると共振は 2.8 % (4 MHz) 下がる — 7-6 の SWR 2 の幅 (11.7 MHz) の 3 分の 1 を手 1 つで動かせる

## 出典

自作。近くの誘電体・導体がアンテナの共振とインピーダンスを変えることはアンテナ工学の
教科書に載る一般的な内容。手を近づけたときの R・C の値は、この題で置いた目安の仮定。
微弱無線局の電界強度の上限 (距離 3 m で 322 MHz 以下は 500 µV/m、322 MHz〜10 GHz は 35 µV/m) は
[電波法施行規則 第 6 条第 1 項第 1 号](https://laws.e-gov.go.jp/law/325M50080000014) による。
