# 7-15 パッチアンテナ 2.4 GHz

両面の銅張り基板の表に**長方形の銅 (パッチ)** を残し、裏の全面を地にすると、それだけでアンテナになる。
**マイクロストリップ・パッチアンテナ**で、正面 (基板の表の向き) に強く電波を出す。
寸法は式で決まるが、式に入る**比誘電率 εr (イプシロン アール)** が FR4 の板ごとに 4.2〜4.7 ほどばらつき、
共振がずれる。パッチは帯域が狭いので、このずれが帯域の外へ出る大きさになる。

この題では、εr = 4.4 で設計したパッチを切り出して V2 で共振を測り、ずれていれば放射する辺を
削って合わせる。FR4 の εr そのものを測る題は 5-15。

## この実験で確かめる式

c は光の速さ (3.00 × 10<sup>8</sup> m/s)、h は基板の厚さ (1.6 mm)、f は 2.44 GHz。

| 式 | 値 (εr = 4.4) |
| --- | --- |
| 幅 **W = c / (2f) × √(2 / (εr + 1))** | 37.4 mm |
| 実効比誘電率 **εeff = (εr + 1)/2 + (εr − 1)/2 × (1 + 12h/W)<sup>−1/2</sup>** | 4.08 |
| 縁の伸び **ΔL = 0.412h × (εeff + 0.3)(W/h + 0.264) / ((εeff − 0.258)(W/h + 0.8))** | 0.74 mm |
| 長さ **L = c / (2f√εeff) − 2ΔL** | 28.9 mm |
| 縁 (給電の辺) で見た抵抗 **R<sub>edge</sub>** (放射のコンダクタンス G1・G12 から) | 321 Ω |
| インセットの深さ **y<sub>0</sub> = (L/π) × arccos √(50 / R<sub>edge</sub>)** | 10.7 mm |

- パッチは**長さ L の方向に半波長**で共振する (縁の伸び ΔL の分だけ短く作る)。
  上下の 2 つの辺 (幅 W の辺) から電波が出る
- 辺の真ん中 (給電の辺) の抵抗は 321 Ω と高い。そこで線をパッチの中へ y<sub>0</sub> だけ差し込み
  (インセット給電)、50 Ω の所で給電する。抵抗は中心へ向かって cos² で下がる
- εr が 4.2 なら共振は 2496 MHz、4.6 なら 2388 MHz (同じ式。どちらも計算値)。**±0.2 の違いで約 ±55 MHz** ずれる

## 回路図

給電点から見たパッチの**等価回路** (共振の近くだけ)。パッチは両端が開いた半波長の共振器で、
給電点では並列共振 (L ∥ R ∥ C) に見える (7-14 の逆 F と同じ形)。

```circuit
# 回路図 (tommie-fence の circuit フェンス)
title: 図1 パッチアンテナの給電点 (並列 RLC の等価回路)
parts:
  J1: sma 2,2 mirror CH0
  R1: resistor 4,2 4,4 50
  L1: inductor 6,2 6,4 0.116n
  C1: capacitor 8,2 8,4 l=$C_1$
  G1: ground 2,5
wires:
  - J1.1 -- 4,2
  - 4,2 -- 6,2
  - 6,2 -- 8,2
  - J1.2 -- 2,4
  - 2,4 -- 2,5
  - 2,4 -- 4,4
  - 4,4 -- 6,4
  - 6,4 -- 8,4
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/circuit/15-patch-2g4.svg)

| 基板 | C1 | 共振 f<sub>0</sub> | Q |
| --- | --- | --- | --- |
| εr = 4.4 (設計どおり) | 36.7 pF | 2439.3 MHz | 28 |
| εr = 4.6 (誘電率が高い板) | 38.3 pF | 2387.8 MHz | 29 |

R1 = 50 Ω はインセットで合わせた後の値。Q = 28 は次の見積りによる (目安):
放射だけの Q は、パッチの帯域の経験式 (SWR 2 で 1.1 %) から約 64、FR4 の損失 (tan δ (タンデルタ) = 0.02) の Q は
1 / tan δ = 50。2 つを合わせて 1 / (1/64 + 1/50) ≈ 28。**放射に回る割合 (効率) は 28 / 64 ≈ 44 %** になる。

## 実体配線図

7×10 cm の両面の FR4 (厚さ 1.6 mm、εr 4.4 の目安) から 70 mm × 70 mm を切り出し、表を剥がしてパッチと給電の線を残す。
裏は全面の銅 (GND) のまま。

```copper
# 銅張り基板の寸法図 (tommie-fence の copper フェンス)
board:
  size: 70x70mm
  ground: back
title: 図2 2.44 GHz のパッチアンテナ (インセット給電)
f: 2.44G
copper:
  P1: pad 35,21.1 37.4x18.2mm
  P2: pad 24.39,35.55 16.16x10.7mm
  P3: pad 45.61,35.55 16.16x10.7mm
  F1: line 35,70 35,30.2 3.06mm
parts:
  J1: sma bottom 35 CH0
notes:
  - dim 16.3,7 53.7,7
  - dim 11,12 11,40.9
  - dim 59,30.2 59,40.9
  - text 42,45: 溝 1 mm (両側)
  - arrow 42,44 37.1,39
```

![銅張り基板の寸法図](https://tommie-jp.github.io/tommie-circuit-workbook/03-nanovna/07-antennas/copper/15-patch-2g4.svg)

| 何 | 寸法・置き方 |
| --- | --- |
| 基板 | 両面の FR4、厚さ 1.6 mm、70 mm × 70 mm。裏は全面の銅 (GND) |
| パッチ (P1〜P3 で 1 枚) | 幅 37.4 mm × 長さ 28.9 mm。上の縁から 12 mm、左右の真ん中。P1・P2・P3 は 1 枚の銅を、溝で切り分けて描いたもの |
| インセット | 下の辺の真ん中から 10.7 mm 差し込む。給電の線の両側に**幅 1 mm の溝** |
| 給電の線 (F1) | 幅 3.06 mm (50 Ω の計算値)。下の縁の SMA からパッチの中 (上の縁から 30.2 mm) まで |
| 端面 SMA (J1) | 下の縁の真ん中。中心ピンを F1 へ、外皮の脚は裏のベタへ |

- パッチのまわりは**地が 10 mm 以上** (厚さの約 6 倍) あるように置いた。地が狭いと共振と向きが変わる
- 70 mm × 70 mm は 5×7 cm の板に収まらない (パッチの幅 37.4 mm に左右の地を足すと 57 mm を超える) ので、
  7×10 cm の板から切り出す
- FR4 は 1 GHz を超えると損失と εr のばらつきが効く。この題はそのばらつきを測って合わせる題なので、FR4 のまま使う
- 溝の 1 mm は幅の目安。溝の幅でも給電点の抵抗が少し動く

## 掃引の設定

計器は VNA。この題の図は NanoVNA V2 (歴史的な機種) で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。
NanoVNA-H4 は 1.5 GHz までなので測れない。

| 項目 | 値 |
| --- | --- |
| 範囲 | 2.2 GHz〜2.7 GHz (εr が 4.2〜4.7 のどれでも谷が入る) |
| 点数 | 201 (2.5 MHz おき) |
| 校正 | SOLT (ケーブルの先で) |
| 表示 | S11 の SWR、Smith チャート |

- パッチの面を上 (天井) に向け、ケーブルの根元で持つ。表の上 10 cm に手や物を置かない (正面に電波が出る)
- **電波が出る**: 掃引は測る間だけにする (7-12・7-13 と同じ)

設計どおり (εr = 4.4) の**見えるはずの画面**。

- 図3 は谷が帯域の真ん中にあるが、谷の幅 (SWR 2 以下で 61 MHz) は帯域 (83.5 MHz) より狭い。
  Smith チャートの線は中心を通る円で、帯域の両端 (マーカー 2・4) では中心から上下へ大きく離れる
- 図4 は谷が帯域の左の端の外 (2388 MHz) に出る。**同じ寸法・同じ切り方でも、板が違えばこうなる**
- 谷が低ければ、パッチの上の辺 (放射する辺) を削って L を短くする。上げたい量を Δf とすると、
  削る長さは (L + 2ΔL) × Δf / f<sub>目標</sub> = 30.4 × 52 / 2440 = **0.65 mm** (図4 から図3 へ)。
  インセットの深さ y<sub>0</sub> は変えない (給電点の抵抗はほとんど動かない)

## 見るべき値

計算値 (等価回路。R・L・C は目安)。

| 基板 | 2388 MHz | 2402 MHz | 2440 MHz | 2480 MHz | SWR 2 以下の幅 |
| --- | --- | --- | --- | --- | --- |
| εr = 4.4 | 20.6 + j24.6 Ω、SWR 3.11 | 28.6 + j24.7 Ω、SWR 2.32 | 50.0 − j0.9 Ω、SWR 1.02 | 26.8 − j24.9 Ω、SWR 2.46 | 2409〜2470 MHz (61 MHz、2.5 %) |
| εr = 4.6 | 50.0 − j0.3 Ω、SWR 1.01 | 44.8 − j15.3 Ω、SWR 1.40 | 19.6 − j24.4 Ω、SWR 3.24 | 8.7 − j19.0 Ω、SWR 6.59 | 2359〜2417 MHz (59 MHz) |

- **パッチの帯域 (2.5 %) は 7-14 の逆 F (6 %) より狭く、2.4 GHz 帯 (3.4 %) を全部は覆えない**。
  Wi-Fi のチャネル 1〜12 の中心 (2412〜2467 MHz) は谷の中にあり、13 (2472 MHz) は谷の縁にかかる
- FR4 のパッチの帯域が 2.5 % もあるのは、**損失で Q が下がっているから**。損失の無い板 (εr 2.2 の PTFE など) なら
  帯域は狭く、効率は高い。S11 の谷が深くても、入った電力の半分ほどは基板の中で熱になる (効率 44 % の見積り)。
  **VNA の S11 では効率は分からない** (7-22 の Wheeler cap で調べる)
- εr の 0.2 の違いが 52 MHz のずれになり、これは帯域 (61 MHz) にほぼ等しい。パッチは**作ってから測って合わせる**のが前提

## 出典

自作。幅・実効比誘電率・縁の伸び・長さ・縁の抵抗 (放射のコンダクタンス G1・G12)・インセット給電の式は、
マイクロストリップ・パッチの伝送線路模型の標準的な式 (C. A. Balanis, *Antenna Theory*, 第 14 章) による。
帯域の経験式 (SWR 2 で 1.1 %) は薄い基板のパッチに使われる近似式で、目安として使った。
