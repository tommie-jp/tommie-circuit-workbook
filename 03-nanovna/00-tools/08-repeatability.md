# 0-8 測定の再現性 — 同じ物を 10 回測る

同じ物を測り直しても読みは毎回少し違う。違いには出どころがいくつかあり、**どれが一番大きいかで
対策が変わる** — 雑音なら平均化 (2-9)、コネクタならトルク (0-2)、ケーブルなら動かさない (0-6)、
校正なら校正の質 (1-7)。この題では、出どころを 1 つずつ残して同じ物を 10 回ずつ測り、
平均とばらつき (標準偏差) を出す。3-9 は SMA の付け外しだけを見た。ここでは 4 つを分けて比べる。

## 4 つの条件

| 条件 | 毎回やること | 変わるもの (ばらつきの出どころ) |
| --- | --- | --- |
| A 触らない | つないだまま 10 回掃引する | 計器の雑音 (トレースの揺れ) |
| B 付け外し | DUT を外して付け直し、トルクで締める | A + コネクタの接触 |
| C ケーブルを動かす | ケーブルを 90° 曲げて戻す | A + ケーブルの曲げ |
| D 校正し直す | SOLT からやり直す | A + 標準器の付け外しのぶんの校正の違い |

A のばらつきは他の 3 つの底になる。B・C・D は A より大きく出るはずで、**A を引いた残り** が
その出どころの大きさ。ばらつきが互いに関係しないなら、2 つの標準偏差は 2 乗で足し引きする
(B の残り = √(σ<sub>B</sub>² − σ<sub>A</sub>²))。

## 測る物

市販の SMA の 10 dB アッテネータを使う (値がほぼ平らで、読みが周波数に左右されない)。

- **S21**: アッテネータを CH0 と CH1 の間に入れる。理想は −10.00 dB
- **S11**: アッテネータの先に付属の Short を付けて CH0 に。往復で 20 dB 落ちるので、理想は
  −20 dB の反射 (40.9 Ω の抵抗と同じ)。**大きさの分かった、小さめの反射**の見本になる

## 掃引の設定

計器は VNA。この本の図は NanoVNA-H4 で書いてあり、標準の LiteVNA64 でも同じ手順で測れる。AD3 とオシロは使わない (S パラメータを見る題)。

この題は実体配線図を付けない — 市販のアッテネータと付属の Short を測る題で、基板に組む物が無い。

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜900 MHz (H4 のダイナミックレンジが段で落ちる 900 MHz まで) |
| 点数 | 101 |
| 校正 | SOLT。両方のケーブルの先で。条件 D 以外は 1 回だけ |
| 平均化 | しない (平均すると A のばらつきが見えなくなる) |

## ばらつきを数にする

1 つの周波数で 10 回の読み x<sub>1</sub>〜x<sub>10</sub> (dB) から、平均と標準偏差を出す。

- 平均 m = (x<sub>1</sub> + … + x<sub>10</sub>) ÷ 10
- 標準偏差 σ = √(Σ(x<sub>i</sub> − m)² ÷ 9) (10 回なので 9 で割る)
- 報告は **m ± 2σ** (10 回の読みのほとんどが入る幅、目安)

Touchstone を Python で読むなら 2-13 の scikit-rf で、`np.std(x, ddof=1)` が 9 で割る標準偏差。

## 小さな反射ほど dB で大きく揺れる

付け外しなどで、読みに大きさ ε の小さな反射が**ベクトルで**足されるとする。読みが |Γ| なら、
dB の読みは 20 log<sub>10</sub>(1 ± ε / |Γ|) の範囲で揺れる。ε が同じでも、読む反射が小さいほど揺れが大きい。

| 読む値 | ε = −60 dB (0.001) | ε = −50 dB (0.0032) |
| --- | --- | --- |
| −10 dB (S21 の 10 dB アッテネータ) | ±0.03 dB | ±0.09 dB |
| −20 dB (図3) | ±0.09 dB | +0.27 / −0.28 dB |
| −30 dB | +0.27 / −0.28 dB | +0.83 / −0.92 dB |
| −40 dB (良い Load) | +0.83 / −0.92 dB | +2.39 / −3.30 dB |

ε の値 (−50 dB・−60 dB) は**比べるための例**。自分の ε は、条件 B の S11 の複素数の読みの
ばらつき (Smith の上の点の散らばりの半径) で読める。**−40 dB の Load を「−38 dB か −42 dB か」と
言い分けるのは、ε が −60 dB より小さい道具でないと無理**。

## 見るべき値

| 項目 | 理想 (計算値) | 実機で確かめること |
| --- | --- | --- |
| 図2 の S21 (100 / 300 / 900 MHz) | −10.00 dB | 10 回の平均が −10 dB に近く、σ が A < B・C・D の順 |
| 図2 の S11 | −89.15 dB | 実機では計器と標準器の限界 (1-7) で −40 dB 前後に止まる |
| 図3 の S11 (100 / 300 / 900 MHz) | −19.99 dB (40.9 Ω) | 平均と σ。σ は S21 より大きく出る (上の表) |
| 条件 A の σ | — | 平均化 (2-9) の回数を決める底 |
| 条件 B の σ と A の σ の差 | — | コネクタのトルク (0-2) を守ると小さくなるか |

- 900 MHz では H4 のダイナミックレンジが 300 MHz までより狭い (70 dB → 60 dB)。同じ条件 A でも
  σ が 300 MHz より大きく出れば、それは雑音の底が上がったぶん
- **σ の一番大きい条件が、その測定の精度を決める**。そこより小さい差を言わない

## LTspice での確かめ

`sim/08-repeatability.cir` で、図2・図3 の `dut:` の模型を LTspice の AC 解析にかけた (50 Ω の電源と 50 Ω の終端。図3 は最後を短絡)。理想の模型どうしの比べで、実測ではない。

| 図 | 周波数 | 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- | --- | --- |
| 図2 | 100 / 300 / 900 MHz | S21 | −10.00 dB | −9.999 dB (3 点とも) | 合う |
| 同 | 同 | S11 | −89.15 dB | −89.15 dB | 合う |
| 図3 (先を短絡) | 同 | S11 / Z | −19.99 dB / 40.9 Ω | −19.99 dB / 40.90 Ω | 合う |

ばらつきの表 20 log<sub>10</sub>(1 ± ε/|Γ|) は算術 (LTspice の対象外)。
