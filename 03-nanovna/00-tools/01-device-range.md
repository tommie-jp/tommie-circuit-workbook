# 0-1 機種と範囲 — H4 (〜1.5 GHz) と V2 (〜3 / 4.4 GHz)、どちらで何が測れるか

NanoVNA には主に 2 系統ある。**NanoVNA-H4** は 1.5 GHz まで、**NanoVNA V2**
(SAA-2N や Plus4 など) は 3〜4.4 GHz まで測れる。この教科書の**必須 50 題は
全部 H4 で測れる**。まずどちらの機種で何が測れるかを表で確かめ、範囲を超えた
掃引を組んだときに何が起きるかを見る。

## 機種

| | NanoVNA-H4 | NanoVNA V2 (SAA-2N) | NanoVNA V2 Plus4 |
| --- | --- | --- | --- |
| 周波数範囲 | 50 kHz〜1.5 GHz | 50 kHz〜3 GHz | 50 kHz〜4.4 GHz |
| 方式 | si5351 の高調波 (300 / 900 MHz で段差) | ADF4350 + ミキサ | 同左 |
| この教科書の印 | `device: H4` | `device: V2` | `device: V2` |

**H4 は 300 MHz と 900 MHz で高調波の次数が変わる** (この段差は 9-10 で測る)。
V2 系は基本波方式なのでこの段差が無い。

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 50 kHz〜1.5 GHz (H4 の全域) |
| 点数 | 101 |
| 校正 | 不要 (0 Ω のスルーの理想値を見るだけ) |
| 表示 | S21 の Log Mag、S11 の Log Mag |

H4 の全域を 1 本のスルー (0 Ω) で見ると、**理想値は端から端まで平ら**になる。

```vna
device: h4
sweep: 50k-1.5G 101
title: 図1 H4 の全域 (0 Ω のスルー)
dut: series R 0
traces:
  - S21 logmag
  - S11 logmag
markers:
  - 50k
  - 1.5G
```

- 50 kHz でも 1.5 GHz でも S21 は 0 dB、S11 は検出限界以下 (実用上 0)。
  **範囲そのものは NanoVNA の中では特別扱いされていない** — H4 の限界は
  電気的な設計 (高調波の作り方) の限界であって、掃引欄に上限の表示は出ない
- 実機でも、この理想からのずれが小さければ「H4 の範囲内でちゃんと動いている」
  という確認になる

範囲を 3 GHz まで広げて `device: h4` のまま掃引すると、フェンス自身が
範囲外だとお知らせで言う。

```vna
device: h4
sweep: 50k-3G 101
title: 図2 H4 のまま 3 GHz まで広げると
dut: series R 0
traces:
  - S21 logmag
  - S11 logmag
markers:
  - 50k
  - 3G
```

- 図は出るが、**「NanoVNA-H4 は 1.5 GHz までです」**と言われる。実機でも
  1.5 GHz より上は測れない (どう見えるかは 9-1 で確かめる)
- 3 GHz まで測りたいなら `device: v2` に替える。V2 なら同じ図がお知らせ無しで出る

## 見るべき値

| 掃引の上限 | `device: H4` | `device: V2` |
| --- | --- | --- |
| 1.5 GHz まで | お知らせ無し | お知らせ無し |
| 1.5 GHz 〜 3 GHz | **お知らせが出る** (範囲外) | お知らせ無し |
| 3 GHz 〜 4.4 GHz | お知らせが出る | お知らせ無し (Plus4 のみ) |
| 4.4 GHz より上 | お知らせが出る | お知らせが出る |

必須 50 題はすべて 1.5 GHz 以下なので H4 だけで進められる。V2 が要る題には
`device: V2` の印が付く (中級の GHz 帯、第 9 章にまとまっている)。
