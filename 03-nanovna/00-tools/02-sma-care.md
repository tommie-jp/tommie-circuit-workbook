# 0-2 SMA の締め方・トルク・ケーブルの扱い

NanoVNA の値の再現性は、**コネクタの締め方**で大きく変わる。緩いと反射が増え、
締めすぎるとコネクタを傷める。正しい締め方を覚えてから測り始める。

## 回路図

```circuit
title: 図1 CH0 にケーブルをつなぐ
parts:
  M1:
    type: device
    at: b2
    label: NanoVNA
    pins: [CH0, CH1]
    turn: mirror
  J1: sma f2 mirror
  G1: ground g2
notes:
  - text f2f0 blue center: ケーブルの SMA (オス)
wires:
  - M1.CH0 -| J1.1
  - J1.2 -- g2
```

- SMA は**ねじ込み式**。まずオスとメスを軽く合わせ、ガタが無いことを確かめて
  から**手でねじを回す** (工具は使わない)
- 最後の締め込みだけトルクレンチを使う。**目安は 8 in-lb (約 0.9 N·m)**。
  手ロレンチ (プラスチックの板レンチ) でも代用できる
- **ケーブル本体をひねらない。** 回すのは金属のナットだけ。ケーブルごと
  回すと、コネクタの中で中心導体がねじれて断線や接触不良の元になる
- 使わないときはオス・メスともキャップをして、中心導体にほこりが入るのを防ぐ
- 曲げるときは**急な角度を付けない** (半径 25 mm 程度より緩やかに)。
  ケーブルの中の芯線が偏心すると、高い周波数で反射が増える (5-18 で測る)

## 掃引の設定

| 項目 | 値 |
| --- | --- |
| 範囲 | 1 MHz〜300 MHz |
| 点数 | 101 |
| 校正 | ケーブルの先で SOLT (1-1) |
| 表示 | S21 の Log Mag、S11 の Log Mag |

正しく締めたケーブルの先を短絡 (Short) してスルーで戻すと、**理想は
0 dB・反射なし**に近い値になる。締め方の良し悪しはこの理想値からの
ずれで見る。

```vna
device: h4
sweep: 1M-300M 101
title: 図2 正しく締めたスルーの理想値
dut: series R 0
traces:
  - S21 logmag
  - S11 logmag
markers:
  - 1M
  - 300M
```

- 理想値は S21 = 0 dB、S11 は検出限界以下 (実用上 0)。**きちんと締めた
  実測はこの理想値にかなり近づく**
- 緩んだままのコネクタでは、この理想値から外れて S11 が持ち上がったり、
  ケーブルを軽く揺すると値がふらつく (再現性は 0-8 で測る)

## 見るべき値

| 締め方 | S11 の目安 | 分かること |
| --- | --- | --- |
| 手でしっかり + トルクレンチ | 理想値に近い (低い) | 正しい締め方 |
| 手締めだけ (緩い) | 理想値より高い、ふらつく | 反射が増え、測るたびに値が変わる |
| 締めすぎ | ねじ山を傷める恐れ | 次に挿すときの再現性が落ちる |

## 出典

自作。SMA のトルクの目安は一般的な RF コネクタの資料 (8 in-lb ≈ 0.9 N·m) による。
