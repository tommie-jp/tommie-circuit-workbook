# FPGA の教科書

> [!WARNING]
> この教科書は AI (Claude) が書いたもので、人間の専門家の校正を受けていない。
> 回路・数値・手順が間違っている可能性がある。組む前に自分で確かめてほしい。

**目次の案の段階。** 題はまだ 1 つも書いていない (下の目次は計画 `plan.yaml` の題名だけ)。
題名と並びはこれから変わる。

1 本の Verilog を **ブラウザ → Raspberry Pi Pico 2 → 実物の FPGA** の 3 つの所で動かし、
同じ信号を Analog Discovery 3 の Logic で測って比べる。第 0〜12 章。

- **Soft-FPGA** は、Verilog を [Verilator](https://veripool.org/guide/latest/) で C++ にして、
  FPGA の無い所で回路を計算で真似る方式。ブラウザで内部の信号を見る
  [soft-fpga](https://github.com/tommie-jp/soft-fpga) (第 4 章) と、Pico 2 のピンから電圧を出す
  [Soft-FPGA-TD4](https://github.com/tommie-jp/Soft-FPGA-TD4) (第 5 章) の 2 つを使う
- **読む順は 3 つの山**: 第 0〜3 章は Verilog を書いて PC の中で確かめる (買う物は無い)。
  第 4〜7 章は Soft-FPGA で動かす (Pico 2)。第 8〜12 章は実物の FPGA と応用
- **機種の印は動かす所**: SIM = PC の Verilator だけ、WEB = ブラウザの soft-fpga、
  PICO = Pico 2 の Soft-FPGA、FPGA = 実物の FPGA。印の無い題は組まない題
- **FPGA のボードが要るのは第 8 章から**。どれを買うかは 8-2 で比べる
  (この本の図と手順は Sipeed Tang Nano 9K で書く)
- **電源は 3.3 V** (Pico 2 の 3V3、FPGA のピン)。教科書の既定の 5 V から外すのは、
  Pico 2 も FPGA もピンに 5 V を入れると壊れるため (0-3)
- **Tang Nano 9K は右の列の `IO79`〜`IO86` が 1.8 V** (BANK3。ほかの IO は 3.3 V)。
  0-3 と 8-5 の題に書く。3.3 V の回路をこの 8 本につながない
- **計器は AD3 の Logic・Patterns・Protocol**。ほかの冊で全題に入れるオシロの図 (`scope`) は、
  この冊ではロジックアナライザの図 (`logic`) にする。SIM と WEB の題は組まないので、
  実体配線図と AD3 を入れない
- **基板の印**: BB = ブレッドボード、— = 基板を使わない。ブレッドボードに出す信号は 3 MHz 以下
  (FPGA の中の速いクロックは分周してから出す。8-13)
- **Soft-FPGA のクロックは回路の規模で変わる**。測り方 (5-5)、規模との関係 (5-6)、
  一定に固定する方法 (5-7)、精密にする方法 (5-11・5-12・5-17) を第 5 章に置く
