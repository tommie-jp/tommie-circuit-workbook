# 5-8 4 ビット CPU の TD4 を動かす — DIP スイッチで入力、LED で出力

> [!WARNING]
> **この題は実機で組んでいない。** Pico 2 のプログラムは `.uf2` までのビルドを確かめたが、書き込んで動かしてはいない。
> 「見るべき値」の LED の並びは、PC の Verilator で同じ `TD4.v` を回して得た値で、実機で測った値ではない。

TD4 は、命令が 8 ビット、データが 4 ビットの小さな CPU。レジスタは A・B・OUT (出力)・PC (プログラムカウンタ) とキャリーフラグ 1 つで、
プログラムは 16 番地の ROM に入る。05-etc 第 1 章の「CPU もどき」(1-4) を、命令の種類と入出力のポートまで揃えたものと考えればよい。

この題では、Verilog で書いた TD4 を Pico 2 の Soft-FPGA で動かす。もとは [Soft-FPGA-TD4](https://github.com/tommie-jp/Soft-FPGA-TD4) で、
DIP スイッチの 4 ビットが TD4 の入力ポート (IN)、LED 4 個が出力ポート (OUT) になる。

Soft-FPGA-TD4 の `main.cpp` とは 2 つ変えた。

| | Soft-FPGA-TD4 の `main.cpp` | この題の `td4_58.cpp` |
| --- | --- | --- |
| クロック | 主ループで `sleep_ms(100)` ごとに反転。USB シリアルへの表示の時間も周期に入る | 5-7 の繰り返しタイマで 50 ms ごとに反転。**10 Hz に固定** |
| 表示 | 1 クロックごとに内部の値を USB シリアルへ出す | 出さない (AD3 の Logic で見る) |
| ピン | LED は GP2〜GP5 (GP2 が bit3)、DIP スイッチは GP10〜GP13 (GP10 が bit3)、内蔵プルアップで ON が 0 → 反転して 1 | 同じ。AD3 用に GP16 (CLK) と GP18〜GP21 (OUT の写し) を足した |

10 Hz は目で追える速さ。1 命令が 0.1 s なので、LED の変化を数えながら見られる。

## TD4 の命令

`TD4.v` は命令の上 4 ビット (オペコード) を 2 つに分けて読む。上 2 ビットが「どこへ書くか」、次の 2 ビットが「何に足すか」。
下 4 ビットは即値 (Im) で、いつも足し算の片方に入る。

| オペコード | 書く先 | 足す元 | 命令 | 働き |
| --- | --- | --- | --- | --- |
| 0000 | A | A | ADD A,Im | A ← A + Im |
| 0001 | A | B | MOV A,B | A ← B (Im = 0) |
| 0010 | A | IN | IN A | A ← IN (Im = 0) |
| 0011 | A | 0 | MOV A,Im | A ← Im |
| 0100 | B | A | MOV B,A | B ← A (Im = 0) |
| 0101 | B | B | ADD B,Im | B ← B + Im |
| 0110 | B | IN | IN B | B ← IN (Im = 0) |
| 0111 | B | 0 | MOV B,Im | B ← Im |
| 1001 | OUT | B | OUT B | OUT ← B (Im = 0) |
| 1011 | OUT | 0 | OUT Im | OUT ← Im |
| 1110 | PC | 0 | JNC Im | 桁上げが無かったら PC ← Im |
| 1111 | PC | 0 | JMP Im | PC ← Im |

足し算の桁上げはキャリーフラグに入る。`TD4.v` はフラグを負論理で持つ (`cflag` が 1 なら桁上げ無し)。

## Verilog

`TD4.v` は Soft-FPGA-TD4 の `verilator-TD4/TD4.v` から 3 つ除いた。値の変わるたびに字を出す `$monitor`、Verilator が扱えない遅延 `#1`、
レジスタの宣言についていた初期値 (`lint` が「リセットで初期化を」と言う) の 3 つ。初期値の代わりに、動かす前にリセット (`reset_n` = 0) をかける。

`TD4.v`:

```verilog
// TD4 (4 ビット CPU)。asfdrwe/simpleTD4 の TD4.v (MIT) を元にした
// tommie-jp/Soft-FPGA-TD4 の TD4.v から、$monitor・#1・初期値を除いたもの。
// 初期値の代わりに、動かす前に reset_n を 0 にする。
// Copyright (c) 2020 asfdrwe (asfdrwe@gmail.com)
// SPDX-License-Identifier: MIT
module TD4 (
    input  wire       clock,
    input  wire       reset_n,
    input  wire [3:0] in_port,
    output wire [3:0] pc_out,
    output wire [7:0] op,
    output wire [3:0] out_port,
    output wire [3:0] alu_data
);
    reg [3:0] reg_a, reg_b, reg_out;
    reg [3:0] pc;
    reg       cflag;
    assign out_port = reg_out;
    assign pc_out = pc;

    reg [7:0] rom [0:15];
    initial begin
        rom[4'b0000] = 8'b1011_0011; // OUT 0011
        rom[4'b0001] = 8'b1011_0110; // OUT 0110
        rom[4'b0010] = 8'b1011_1100; // OUT 1100
        rom[4'b0011] = 8'b1011_1000; // OUT 1000
        rom[4'b0100] = 8'b1011_1000; // OUT 1000
        rom[4'b0101] = 8'b1011_1100; // OUT 1100
        rom[4'b0110] = 8'b1011_0110; // OUT 0110
        rom[4'b0111] = 8'b1011_0011; // OUT 0011
        rom[4'b1000] = 8'b1011_0001; // OUT 0001
        rom[4'b1001] = 8'b1111_0000; // JMP 0000
        rom[4'b1010] = 8'b0000_0000; // ADD A,0 (何もしない)
        rom[4'b1011] = 8'b0000_0000;
        rom[4'b1100] = 8'b0000_0000;
        rom[4'b1101] = 8'b0000_0000;
        rom[4'b1110] = 8'b0000_0000;
        rom[4'b1111] = 8'b0000_0000;
    end

    wire [7:0] opcode = rom[pc];
    assign op = opcode;

    wire [1:0] alu_sel  = (opcode[7:6] == 2'b11) ? 2'b11 : opcode[5:4];
    wire [1:0] load_sel = opcode[7:6];
    wire       jmp      = opcode[4];
    wire [3:0] im       = opcode[3:0];

    wire [3:0] alu_in = (alu_sel == 2'b00) ? reg_a   :
                        (alu_sel == 2'b01) ? reg_b   :
                        (alu_sel == 2'b10) ? in_port :
                                             4'b0000;

    wire [3:0] alu_out;
    wire       nextcflag;
    assign {nextcflag, alu_out} = alu_in + im;
    assign alu_data = alu_out;

    // 負論理の書き込み許可 (0 で書く)
    wire load_a   = (load_sel == 2'b00) ? 1'b0 : 1'b1;
    wire load_b   = (load_sel == 2'b01) ? 1'b0 : 1'b1;
    wire load_out = (load_sel == 2'b10) ? 1'b0 : 1'b1;
    wire load_pc  = (load_sel == 2'b11 && (jmp == 1'b1 || cflag)) ? 1'b0 : 1'b1;

    wire [3:0] next_pc = (load_pc == 1'b0) ? alu_out : pc + 4'd1;

    always @(posedge clock or negedge reset_n) begin
        if (!reset_n) begin
            reg_a   <= 4'b0;
            reg_b   <= 4'b0;
            reg_out <= 4'b0;
            cflag   <= 1'b1;
            pc      <= 4'b0;
        end else begin
            reg_a   <= (load_a   == 1'b0) ? alu_out : reg_a;
            reg_b   <= (load_b   == 1'b0) ? alu_out : reg_b;
            reg_out <= (load_out == 1'b0) ? alu_out : reg_out;
            cflag   <= ~nextcflag;  // 負論理の桁上げ
            pc      <= next_pc;
        end
    end
endmodule
```

lint は警告 0 件で通った (Verilator 5.042 と 5.048 の `--lint-only -Wall`)。もとの `TD4.v` は `#1` のところで止まり、`--no-timing` を付けても警告が 8 件出る。

ROM のプログラム (プログラム A) は、`OUT Im` で LED の点き方を 9 通り出し、`JMP 0000` で頭に戻る。1 命令が 1 クロックなので、**10 クロックで 1 巡**する。
入力ポートは使わない。

### プログラム B — DIP スイッチの値に 1 を足して LED に出す

入力を使うプログラムに替えるには、`initial` の中の 16 行を次に置き換えて、`verilate.sh` からやり直す。

```verilog
        rom[4'b0000] = 8'b0010_0000; // IN  A        A <- DIP スイッチ
        rom[4'b0001] = 8'b0000_0001; // ADD A,0001   A <- A + 1
        rom[4'b0010] = 8'b0100_0000; // MOV B,A      B <- A
        rom[4'b0011] = 8'b1001_0000; // OUT B        LED <- B
        rom[4'b0100] = 8'b1111_0000; // JMP 0000
        rom[4'b0101] = 8'b0000_0000;
        rom[4'b0110] = 8'b0000_0000;
        rom[4'b0111] = 8'b0000_0000;
        rom[4'b1000] = 8'b0000_0000;
        rom[4'b1001] = 8'b0000_0000;
        rom[4'b1010] = 8'b0000_0000;
        rom[4'b1011] = 8'b0000_0000;
        rom[4'b1100] = 8'b0000_0000;
        rom[4'b1101] = 8'b0000_0000;
        rom[4'b1110] = 8'b0000_0000;
        rom[4'b1111] = 8'b0000_0000;
```

TD4 には A を直接 OUT へ出す命令が無いので、`MOV B,A` で B に移してから `OUT B` で出す。5 命令で 1 巡 (0.5 s)。
置き換えた `TD4.v` も lint は警告 0 件で通り、Pico 2 用の `.uf2` までビルドできた。

## Pico 2 のプログラム

作業用のフォルダは 5-5 と共通で、`board.h` `verilate.sh` `CMakeLists.txt` も 5-5 のまま。ビルドの打ち方は [5-1 の「ビルドする」](01-verilator-on-pico.md#ビルドする)。

`td4_58.cpp`:

```cpp
// 5-8 4 ビット CPU の TD4 を動かす — DIP スイッチで入力、LED で出力
#include "board.h"
#include "VTD4.h"

constexpr int64_t HALF_US = 50000;   // 半周期 50 ms → クロック 10 Hz

static VTD4 top;
static unsigned g_count = 0;         // 呼ばれた回数 (半周期の数)

static bool on_half(repeating_timer_t*) {
    const unsigned clk = (g_count & 1u) ? 0u : 1u;   // 立ち上がり → 立ち下がり → …
    top.reset_n = (g_count < 2) ? 0 : 1;             // 初めの 1 クロックはリセット
    top.in_port = read_sw();                         // DIP スイッチ → IN
    top.clock = clk;
    top.eval();
    gpio_put(PIN_CLK, clk);
    put_leds(top.out_port);                          // OUT → LED
    g_count++;
    return true;
}

int main() {
    board_init();
    repeating_timer_t timer;
    add_repeating_timer_us(-HALF_US, on_half, nullptr, &timer);
    while (true) tight_loop_contents();
}
```

- 5-7 と同じく、負の周期の繰り返しタイマで 50 ms ごとに呼ぶ。立ち上がりと立ち下がりを交互に計算するので、クロックは 10 Hz
- 初めの 1 クロック (2 回の呼び出し) は `reset_n` を 0 にして、PC とレジスタを 0 にする
- DIP スイッチは呼ばれるたびに読み、`in_port` に入れる。`IN A` は立ち上がりの時の値を取り込む

5-5 と共通のフォルダを空から作ってビルドし、`build/td4_58.uf2` (95 232 バイト) ができた (プログラム A)。プログラム B もビルドが通ることを確かめた。**実機では動かしていない。**

## 計器の設定

| 計器 | 設定 |
| --- | --- |
| Logic | DIO0 (CLK)・DIO2〜DIO5 (OUT0〜OUT3) を Enable。標本化 1 kHz、120 ms/div (窓 1.2 s) |
| バス | DIO5・DIO4・DIO3・DIO2 の順 (上の桁が先) で 1 本にまとめ、16 進で見る |
| トリガ | DIO0 の立ち上がり。リセットのあと最初の立ち上がりで止める |
| カーソル | X1 を 25 ms、X2 を 1.025 s (どちらも CLK の H の真ん中)。ΔX がプログラム A の 1 巡 |

## Logic に見えるはずの画面

## 見るべき値

LED の並びは PC の Verilator で回した値。クロックの周期は設計値。どれも実機では測っていない。

| 測る所 | 見るべき値 | 分かること |
| --- | --- | --- |
| CLK の周期 | 100 ms (10 Hz、設計値) | 5-7 のタイマでクロックが決まっている |
| プログラム A の OUT の並び | 3・6・C・8・8・C・6・3・1・1 の繰り返し (Verilator の値) | TD4 が ROM の命令を順に実行し、`JMP` で戻る |
| プログラム A の 1 巡 (ΔX) | 1.000 s = 10 クロック (計算値) | 1 命令が 1 クロック |
| プログラム A の LED | 左が下の桁なので、点いた所が左右に往復して見える (見込み) | ブレッドボードの並びと桁の向き |
| プログラム B、DIP スイッチを 5 (0101) | LED が 6 (0110)。リセットのあと 4 クロック目から (Verilator の値) | `IN A` → `ADD` → `MOV` → `OUT` の 4 命令を通った |
| プログラム B、DIP スイッチを F (1111) | LED が 0 (0000)。4 ビットであふれる (Verilator の値) | 足し算の桁上げは LED に出ず、キャリーフラグに入る |
| プログラム B、DIP スイッチを替える | 0.5 s 以内に LED が変わる (計算値) | 1 巡が 5 命令 = 5 クロック |

DIP スイッチの値は、スイッチ 1 が上の桁 (bit3)。ブレッドボードでは右端がスイッチ 1。5 (0101) はスイッチ 2 と 4 を ON にする。
