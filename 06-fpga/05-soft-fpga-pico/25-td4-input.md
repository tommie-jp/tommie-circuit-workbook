# 5-25 TD4 で入力を使う — DIP スイッチの値に 1 を足して LED に出す

> [!WARNING]
> **この題は実機で組んでいない。** `.uf2` までのビルドを確かめたが、書き込んで動かしてはいない。
> 「見るべき値」の LED の値は、PC の Verilator で同じ `TD4.v` を回して得た値で、実機で測った値ではない。

この題は回路図・実体配線図・Logic の図を載せない。5-8 と同じ基板をそのまま使い、ROM のプログラムだけを替える題だから。図は 5-8 (5-5) の図1〜図3 を見る。

5-8 で動かした TD4 のプログラム (プログラム A) は、入力ポートを使わなかった。
この題では ROM のプログラムを替え、DIP スイッチの 4 ビットを `IN A` で読み、1 を足して LED に出す (プログラム B)。
命令の表と `TD4.v` は 5-8、`td4_58.cpp` と作業用のフォルダも 5-8 のまま。

## プログラム B

入力を使うプログラムに替えるには、5-8 の `TD4.v` の `initial` の中の 16 行を次に置き換えて、`verilate.sh` からやり直す。

```verilog
        rom[4'b0000] = 8'b0010_0000; // IN  A        A <- DIP スイッチ
        rom[4'b0001] = 8'b0000_0001; // ADD A,0001   A <- A + 1
        rom[4'b0010] = 8'b0100_0000; // MOV B,A      B <- A
        rom[4'b0011] = 8'b1001_0000; // OUT B        LED <- B
        rom[4'b0100] = 8'b1111_0000; // JMP 0000
        rom[4'b0101] = 8'b0000_0000;
        rom[4'b0110] = 8'b0000_0000;
        rom[4'b0111] = 8'b0000_0000;
        rom[4'b1000] = 8'b0000_0000;
        rom[4'b1001] = 8'b0000_0000;
        rom[4'b1010] = 8'b0000_0000;
        rom[4'b1011] = 8'b0000_0000;
        rom[4'b1100] = 8'b0000_0000;
        rom[4'b1101] = 8'b0000_0000;
        rom[4'b1110] = 8'b0000_0000;
        rom[4'b1111] = 8'b0000_0000;
```

TD4 には A を直接 OUT へ出す命令が無いので、`MOV B,A` で B に移してから `OUT B` で出す。5 命令で 1 巡 (0.5 s)。
置き換えた `TD4.v` も lint は警告 0 件で通り、Pico 2 用の `.uf2` までビルドできた。

5-5 と共通のフォルダでビルドが通ることを確かめた。**実機では動かしていない。**

## 計器の設定

5-8 の表のまま (DIO0 の CLK と DIO2〜DIO5 の OUT を Logic で見る)。DIP スイッチを替えてから LED が変わるまでは、トリガを掛け直して見る。

## 見るべき値

LED の値は PC の Verilator で回した値。どれも実機では測っていない。

| 測る所 | 見るべき値 | 分かること |
| --- | --- | --- |
| DIP スイッチを 5 (0101) | LED が 6 (0110)。リセットのあと 4 クロック目から (Verilator の値) | `IN A` → `ADD` → `MOV` → `OUT` の 4 命令を通った |
| DIP スイッチを F (1111) | LED が 0 (0000)。4 ビットであふれる (Verilator の値) | 足し算の桁上げは LED に出ず、キャリーフラグに入る |
| DIP スイッチを替える | 0.5 s 以内に LED が変わる (計算値) | 1 巡が 5 命令 = 5 クロック |

DIP スイッチの値は、スイッチ 1 が上の桁 (bit3)。ブレッドボードでは右端がスイッチ 1。5 (0101) はスイッチ 2 と 4 を ON にする。

## シミュレーションでの確かめ (対象外を含む)

手元の Verilator 5.042 で、5-8 の `TD4.v` の `initial` の中身を本文の 16 行に入れ替えて lint し、`td4_58.cpp` を替え玉の GPIO とタイマで PC で回した
(`sim/08-td4-b-rom.txt`・`sim/08-td4-b-pc.cpp`)。

| 項目 | 本文の数字 | 実行結果 | 判定 |
| --- | --- | --- | --- |
| lint (プログラム B の `TD4.v`) | 警告 0 件 | 警告 0 件 (Verilator 5.042) | 合った |
| DIP = 5 (0101) | LED が 6、リセットのあと 4 クロック目から | 4 クロック目から 6 | 合った |
| DIP = F (1111) | LED が 0 | 0 | 合った |
| 1 巡 | 5 命令 = 5 クロック | `JMP 0000` が 5 番目 (ROM の 0〜4 番地) | 合った |

### エミュレータ (picoemu) での確かめ

[5-2](02-counter-led.md#エミュレータ-picoemu-での確かめ) と同じ picoemu に、`TD4.v` をプログラム B に替えてビルドし直した `.uf2` (`td4_58_b`) を載せ、DIP スイッチを `-script` で与えた (ms 刻み)。
確かめは `python3 sim/picoemu-check.py --picoemu ./picoemu --uf2 <.uf2 を集めたフォルダ> 5-25`。実時間は対象外 (5-2 と同じ)。

| 項目 | 本文の数字 | picoemu の結果 | 判定 |
| --- | --- | --- | --- |
| DIP = 5 (0101) | LED が 6、リセットのあと 4 クロック目から | 5 番目の立ち上がり (1 番目がリセット) から 6 | 合った |
| DIP を F に替える | 0 になる。0.5 s 以内に変わる | 1 530 ms に替えると 420 ms 後に 0 | 合った |

確かめられなかったもの。
