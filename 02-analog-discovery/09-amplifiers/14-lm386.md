# 9-14 LM386 の周波数特性と歪

LM386 は 8 ピンのオーディオ用パワーアンプで、スピーカーを直に鳴らせる。1・8 番 (GAIN) を開けたままなら利得は 20 倍 (26 dB) で、
外付けは出力の結合コンデンサ・BYPASS のコンデンサ・発振止めの Zobel (10 Ω (オーム) + 47 nF) だけ。回路の教科書の 12-6 (インターホン) で使う IC の
性能を、ここで計器で押さえる。

- **Network** で 10 Hz〜1 MHz の利得を掃き、低い側 (出力の結合コンデンサと負荷で決まる) と高い側 (IC の帯域) の −3 dB を読む
- **Spectrum** で 1 kHz の出力の高調波を読み、THD (全高調波ひずみ率) を出す

負荷はスピーカーの代わりに 8.2 Ω の抵抗にする (音を出さずに測れ、インピーダンスが周波数で変わらない)。

## 回路図

  G3: ground 10,7.25

  Cz: capacitor 13,6.5 13,8 47n

  - AD.1+ -| 7,5
  - AD.W1 -| 6.5,5

  - U1.2 -| 7.5,6.5
  - U1.GND -- 10,7.25
  - U1.BYPASS |- 11.5,8
  - U1.VOUT -- 13,5
  - 13,5 -- 14,5

  - AD.2- -| 3,8

```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/02-analog-discovery/09-amplifiers/circuit/14-lm386.svg)

- 3=+INPUT に W1 を直に入れる (LM386 の入力は IC の中で 50 kΩ で GND に落ちていて、直流を切らなくてよい)。2=−INPUT は GND
- 6=VS は AD3 の V+ (5 V)。LM386N-1 の電源電圧の範囲は 4〜12 V。Cs (0.1 µF。µ はマイクロ) を VS の根元に
- 7=BYPASS は Cbyp (10 µF) で GND へ。1・8 (GAIN) は開けたまま (利得 20 倍)
- 5=VOUT は直流 2.5 V。Cout (470 µF) で直流を切って RL (8.2 Ω) へ。Rz・Cz は資料の応用例の 10 Ω + 0.05 µF を E12 の 47 nF にした Zobel
- CH1 は 3=+INPUT、CH2 は RL の両端 (Cout の後ろで直流は無い)

```

![ブレッドボードの実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/02-analog-discovery/09-amplifiers/breadboard/14-lm386.svg)

- U1 は 9-2 と同じ `r180` で置く。上の列が 4=GND (e12)・3=+INPUT (e13)・2=−INPUT (e14)・1=GAIN1 (e15)、
  下の列が 5=VOUT (f12)・6=VS (f13)・7=BYPASS (f14)・8=GAIN8 (f15)。入力が AD3 に近い上の側、出力と電源が下の側に来る
- 6=VS は `j13 -- +b13` で下の + レールへ (上と 29 列で渡す)。Cs (i13〜i16) は 16 列から − レールへ
- 出力: Cout (h12 が +、h6 が −) から RL (j6 から下の − レールへ直に挿す)。2+ (灰) は 6 列の g6。Zobel の Rz (i12〜i10) と Cz (j10 から − レール)
- Cbyp (h14 が +、h19 が −) は 19 列から − レールへ。電解コンデンサの + は直流のある側 (VOUT・BYPASS)

## 計器の設定

| 計器 | 設定 |
| --- | --- |
| Supplies | V+ = 5 V、Master Enable を入れる (出力 0.8 V<sub>p</sub> で 34 mA ほど、170 mW。USB 給電の 250 mW の内側) |
| Network | 掃引 10 Hz〜1 MHz、点数 101、振幅 20 mV (出力 0.4 V)、Reference = CH1、DUT = CH2 |
| Wavegen (歪み) | W1: Sine、1 kHz、Amplitude 40 mV |
| Spectrum | Range 0〜10 kHz、窓 Flat Top、CH2。Measurements の THD (4-4 と同じ) |
| Scope | CH1 20 mV/div、CH2 500 mV/div、500 µs/div |

## 見るべき値

資料の代表値は V<sub>S</sub> = 6 V で: 利得 26 dB (1・8 開放)、帯域 300 kHz、THD 0.2 % (8 Ω、125 mW、1 kHz)、入力抵抗 50 kΩ、
静止電流 4 mA。ここは 5 V なので、同じ値を目安に置く。

| 項目 | 計算値・目安 | 分かること |
| --- | --- | --- |
| 中域の利得 | 25.8 dB (19.5 倍) | 26 dB から、出力抵抗 (0.2 Ω と仮定) と 8.2 Ω の分圧の分だけ低い |
| 低い側の −3 dB | 40.3 Hz (= 1 / (2π (パイ) × 8.4 Ω × 470 µF)) | 8 Ω 級の負荷では結合コンデンサが大きくないと低音が落ちる |
| 高い側の −3 dB | 約 300 kHz (目安) | 音声帯域 (20 kHz) の 15 倍。20 kHz での低下は 0.02 dB |
| 1 kHz・0.78 V<sub>p</sub> の THD | 約 0.2 % (目安) | 2 次が基本波の 54 dB 下 (下の図5) |

図5 は THD 0.2 % をすべて 2 次に置いた目安で、どの次数がどれだけ出るかは測って確かめる。0.78 V<sub>p</sub> は 50 Ω の電力に直すと +7.84 dBm、
その 0.2 % (−54 dB) が −46.1 dBm。THD = √(Σ V<sub>n</sub><sup>2</sup>) / V<sub>1</sub> で、Spectrum の Measurements が出す値と比べる。

- 振幅を上げると、5 V では出力が 1.5 V<sub>p</sub> 前後で頭打ちになり THD が急に増える (9-5 と同じ形。目安)。上げるときは電流が
  Supplies の 250 mW を超えないか見る
- Network の振幅を 20 mV にしたのは、出力を小さくして高調波と電流を抑え、利得だけを見るため

## LTspice での確かめ

LM386 の SPICE の模型は手元に無いので、`sim/14-lm386.cir` では LM386 を**振る舞いの模型** (入力 50 kΩ、利得 20 倍、300 kHz の 1 極、
出力の直流 2.5 V、出力抵抗 0.2 Ω) で置き、外付けの部品 (Cout・RL・Zobel) の効き方を交流で解いた。**模型は仮定で、ひずみは入っていない** (THD は LTspice の対象外。資料の値を目安に置いた)。

| 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| 1 kHz の利得 | 19.5 倍 (25.8 dB) | 19.51 倍 | 合う |
| 低い側の −3 dB | 40.3 Hz | 40.3 Hz | 合う |
| 高い側の −3 dB | 約 300 kHz | 295 kHz | 合う (模型の 300 kHz に Zobel・Cout の影響) |
| 20 Hz・20 kHz の利得 | 8.7 倍・19.5 倍 | 8.68・19.48 倍 | 合う |
