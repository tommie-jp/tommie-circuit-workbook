# 1-6 画面の構成 — 計器の窓、Run / Stop / Single、Help

WaveForms の画面そのものに慣れる題。0-3 のループバックを画面に出したまま、
**計器の窓の開き方・並べ方**と、**Run / Stop / Single** の違いを確かめる。

## 回路図

```circuit
title: 図1 ループバック配線 (0-3 と同じ)
parts:
  W1: sine a1 c1 1
  M1: voltmeter a3 c3 l=$\mathrm{CH1}$
  G1: ground c1
wires:
  - a1 -- a3
  - c1 -- c3
```

## 計器の設定

| 計器 | 設定 |
| --- | --- |
| Wavegen (W1) | 正弦波、1 kHz、振幅 1 V |
| Scope (CH1) | DC、Auto トリガ |

## 画面の読み方

- **計器の窓**: メニューバーの各計器名 (Scope / Wavegen / Supplies …) を
  クリックすると窓が開く。窓はドラッグで動かせ、端をつまむと他の窓と
  タブでまとめられる。**Window > Save Layout** で窓の配置だけを保存できる
  (0-4 のワークスペース保存は設定ごと、こちらは配置だけ)
- **Run**: 選んだトリガ条件で繰り返し取り込み続ける (既定)
- **Stop**: 取り込みを止め、直前の波形を画面に残す。値をゆっくり読みたい
  ときに押す
- **Single**: 条件に合った瞬間を **1 回だけ**取り込んで止まる。単発の現象
  (2-18 の突入電流など) を捉えるときに使う
- **Help**: 各計器の窓の右上に `?` があり、押すとその計器の公式マニュアルの
  該当ページが開く

## 見るべき値

| 操作 | 期待する見え方 | 分かること |
| --- | --- | --- |
| Run 中 | 波形が絶えず更新される | 既定の動き |
| Stop を押す | 波形が止まって残る | 更新が止まるだけで、それまでの波形は消えない |
| 再度 Run を押す | また更新が始まる | Stop は一時停止であって、設定は消えない |
| Single を押す | 次にトリガ条件に合った瞬間だけ取り込んで自動的に止まる | Run との違いは「1 回で止まる」こと |
