# 番外の工作

> [!WARNING]
> この本は AI (Claude) が書いたもので、人間の専門家の校正を受けていない。
> 回路・数値・手順が間違っている可能性がある。組む前に自分で確かめてほしい。

4 冊で扱った部品と測り方を組み合わせて作る工作。1 章に 1 つの作品を置く。

- 第 1 章 CPU もどき: カウンタと ROM で番地を回す。1-5 は ROM の代わりになるメモリの原理 (DRAM のセル 1 個を 2N7000 で組み、漏れて消えるのを見る)。DRAM の配列とリフレッシュは中級には重いので外した (参考回路は [archive/01-dram](../archive/01-dram/README.md))
- 第 2 章 中波ラジオの時報で動く時計: NHK ラジオ第 1 の時報 (440 Hz × 3 回 + 880 Hz) を検出し、正時に 1 パルスを出す
- 第 3 章 2SC1815 のミキサー: 手に入りやすい 2SC1815 で、中波 (0.53〜1.6 MHz) を 455 kHz の IF に変える。1 石と差動対 (シングルバランス) を組み、第 4 章の 3SK291 と並べて比べる。入出力 50 Ω・電源 5 V。おすすめは差動対。ダイオードリング (DBM) を載せない理由は 3-3
- 第 4 章 デュアルゲート FET ミキサー (参考): 3SK291 で同じ仕様のミキサーを組む。入手しにくく LO も大きく要るので参考に留める。シミュレーションで特性を見る
- 第 5 章 10BASE-T のイーサネット: 使わなくなったルータを相手に、Raspberry Pi Pico 2 の PIO とディスクリート部品 (抵抗・74HC14) で 10BASE-T を送受し、ARP と ping に答えるまで。信号は 10 MHz なのでユニバーサル基板

**第 2 章の時計は、ロジックを学ぶか、時計を作るかで道を選ぶ。** 全部をロジックで組むのは 2-7 だけで、
回路の規模が中級の上限を超えるので「中級 (大規模)」の印を付けて残す (知識は中級までで、規模が大きいという意味)。
