# 番外の工作

> [!WARNING]
> この本は AI (Claude) が書いたもので、人間の専門家の校正を受けていない。
> 回路・数値・手順が間違っている可能性がある。組む前に自分で確かめてほしい。

4 冊で扱った部品と測り方を組み合わせて作る工作。1 章に 1 つの作品を置く。

- 第 1 章 CPU もどき: カウンタと ROM で番地を回す
- 第 2 章 中波ラジオの時報で動く時計: NHK ラジオ第 1 の時報 (440 Hz × 3 回 + 880 Hz) を検出し、正時に 1 パルスを出す
- 第 3 章 デュアルゲート FET ミキサー: 3SK291 で中波 (0.53〜1.6 MHz) を 455 kHz の IF に変える。入出力 50 Ω・電源 5 V、シミュレーションで特性を見る
- 第 4 章 2SC1815 のミキサー: 第 3 章と同じ仕様で、2SC1815 の 1 石と差動対 (シングルバランス) を組み、3SK291 と並べて比べる

図のうち回路図などはフェンスで書く。ブロック図は ` ```plantuml ` で書き、
GitHub では他の図と同じく画像の行 (Pages の SVG) で見せる。
