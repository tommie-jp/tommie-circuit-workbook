# 6-7 同調式のスモールループ — 直径 60 cm の輪とバリコンで 7 MHz に合わせ、ヌルでノイズを消す

[6-2](02-wire-antenna.md) のワイヤは張るだけで聞こえるが、部屋の中の雑音 (スイッチング電源・LED 照明・パソコン) も
同じ強さで拾う。ここでは **直径 60 cm の輪 1 回とバリコン**で、受信専用の**同調式スモールループ** (磁界ループ) を作る。
波長 (42 m) に比べてずっと小さい輪は、磁界だけを拾うコイルとして働き、2 つの性質を持つ。

- **同調する**: 輪のインダクタンスとバリコンが共振し、合わせた周波数の周り 約 60 kHz だけを通す。
  受信機の前に置いた Q (共振の鋭さ) 100 のフィルタになり、帯域の外の強い局を落とす
- **ヌルがある**: 感度は 8 の字で、**輪の軸 (輪の面に垂直な向き) の方向からの波は拾わない**。
  軸を雑音源に向ければ、その雑音だけが消える

中波ラジオのバーアンテナ ([05-etc 2-12](../02-radio-clock/12-antenna-compare.md)、
[03-nanovna 7-5](../../03-nanovna/07-antennas/05-loopstick-varicap.md)) と同じ仕組みで、ラジオを回すと局が消える向きがあるのと同じことを、
7 MHz で、手で回せる輪でやる。周が約 1 波長の輪 ([03-nanovna 7-7](../../03-nanovna/07-antennas/07-loop-antenna.md)) とは別物で、
あちらは輪そのものが共振し、こちらはコンデンサを足して共振させる。

この題に**基板は無い** (輪と線とバリコンだけで、基板に載せる回路が無い)。実体配線図の代わりに、寸法と結線を図1 と表に書く。
見るのは反射 (S11) とスペクトルなので、計器は LiteVNA64 と tinySA Ultra を使い、**Analog Discovery 3 とオシロの図は入れない**
(反射は VNA、スペクトルは tinySA の仕事で、時間波形を見る所が無い)。

> [!NOTE]
> この輪は**受信専用**。送信機をつなぐと、5 W でもバリコンに実効値で 200 V を超える電圧が掛かり (計算値)、
> ポリバリコンは耐えない。送信に使えるアンテナは第 8 章で扱う。受信だけなので免許は要らない。

## この実験で確かめる式

| 式 | 意味 | この輪の値 (計算値) |
| --- | --- | --- |
| L = µ<sub>0</sub> r (ln(8r/a) − 2) | 半径 r・線の半径 a の円形の輪 1 回のインダクタンス。µ<sub>0</sub> (ミュー・ゼロ) は真空の透磁率 | r = 0.3 m、a = 1 mm で **2.18 µH** (マイクロヘンリー) |
| f = 1 / (2π√(LC)) | 同調の周波数。π (パイ) は円周率 | 7.0 MHz に 237 pF、7.45 MHz に 209 pF |
| R<sub>rad</sub> = 320π<sup>4</sup> (A/λ²)² | 小さい輪の放射抵抗。A は輪の面積、λ (ラムダ) は波長 | A = 0.283 m²、λ = 42.2 m で **0.78 mΩ** (オーム) |
| Q = ωL / R | 無負荷の Q。R は線・コンデンサの損失と放射抵抗の和 | 97.3 Ω ÷ 0.45 Ω = **216** (見積り) |
| R<sub>in</sub> = (ωM)² / R | 結合ループから見た共振時の抵抗。M は 2 つの輪の相互インダクタンス | M = 103 nH で **47 Ω** |
| 感度 ∝ sin θ | θ (シータ) は輪の軸と電波の来る向きのなす角 | 軸から 6° で −20 dB、90° (輪の面の向き) で最大 |

放射抵抗 0.78 mΩ に対して損失が 0.45 Ω あるので、**効率は 0.17 % (−27.6 dB)** しかない。送信なら話にならない数だが、
受信では困らない。7 MHz では外から来る雑音が大きく、住宅地の人工雑音は熱雑音より 約 49 dB 高い
([ITU-R 勧告 P.372](https://www.itu.int/rec/R-REC-P.372/en) の中央値の式 72.5 − 27.7 log f[MHz])。
輪で 28 dB 失っても、アンテナから出てくる雑音はまだ熱雑音より 21 dB 高い。**受信機の雑音指数が 21 dB より良ければ、
聞こえる限界を決めるのは外の雑音のまま**で、信号と雑音が同じだけ小さくなるだけだ ([6-5](05-direct-conversion.md) の受信機は
音量を上げれば足りる)。そのうえヌルで雑音だけを消せるので、信号対雑音比はワイヤより良くなることがある。

## 回路図

```circuit
# 回路図 (tommie-fence の circuit フェンス)
title: 図1 同調式スモールループの結線と寸法
parts:
  C2: capacitor 2,2 2,3.5 100p
  VC1: capacitor-var 2,3.5 2,5 260p
  C1: capacitor 4,2 4,5 180p
  L1: inductor 6,2 6,5 2.2u
  L2: inductor 9,2.5 9,4.5 0.45u
  J1: sma 11.5,2.5
  G1: ground 11.5,5
wires:
  - 2,2 -- 4,2 -- 6,2
  - 2,5 -- 4,5 -- 6,5
  - 9,2.5 -- J1.1
  - 9,4.5 -- 11.5,4.5
  - J1.2 -- 11.5,4.5 -- 11.5,5
notes:
  - box 1.2,1 7.3,5.5 blue
  - text 4,1.4 blue center: 主ループ L1 (直径 60cm・1 回)。どこにもつながない
  - text 9.6,5.2 blue center: 結合ループ L2 (直径 16cm)
  - text 7.8,3.5 small center: M
  - text 11,1.6 small center: 同軸で受信機へ
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/05-etc/06-ham-receiver/circuit/07-small-loop.svg)

- **L1 (主ループ)** は φ2 mm の銅線を直径 60 cm の輪にしたもの。輪の切れ目 (上) にコンデンサをつなぐ。
  **主ループは受信機にも GND にもつながない** (青い枠の中で閉じている)
- **同調のコンデンサ**は C1 (180 pF) と、「VC1 (ポリバリコン 20〜260 pF) と C2 (100 pF) の直列」の並列。
  VC1 だけで 230 pF を作ると、帯域 60 kHz を動かすのにつまみを 3° しか回せない。C2 を直列に入れて
  VC1 の効きを 17〜72 pF に縮め、C1 で底上げすると、合計 202〜257 pF (浮遊 5 pF を含む見積り) で
  **6.72〜7.59 MHz** を半回転に広げられる (バンドスプレッド)
- **L2 (結合ループ)** は同じ線の直径 16 cm の輪。主ループの内側の、コンデンサと反対の側 (下) に、
  同じ平面で線どうしを 5 mm まで寄せて置く。主ループとは磁界だけで結合し (M)、両端を同軸の芯線と外皮につなぐ
- 結合ループの大きさは「主ループの 1/5」が目安とされるが、それは損失の小さい送信用の輪の話。
  この輪は損失が 0.45 Ω あるので、1/5 (12 cm) では 21 Ω にしかならず SWR が 2.6 になる (計算値)。
  **約 1/4 の 16 cm** にして 47 Ω に合わせた

## 寸法と組み立て

| 部分 | 寸法・材料 | 備考 |
| --- | --- | --- |
| 主ループ L1 | φ2 mm の銅線 1.89 m を直径 60 cm の輪に | フラフープや木の十字に結束バンドで留める。5D-2V などの同軸の外皮を使ってもよい (太いぶん L が 1.8 µH に下がり、コンデンサが 約 270 pF 要る。計算値) |
| 輪の切れ目 | 上に 2 cm | 両端をコンデンサの箱 (樹脂のケース) へ。ここは電圧が高い側なので、手や金属から離す |
| 結合ループ L2 | φ2 mm の銅線 50 cm を直径 16 cm の輪に | 主ループの下の内側。線の間隔 5 mm。結束バンドで主ループに留める |
| 同軸 | 50 Ω (RG-58 か 1.5D-2V)、2〜3 m | 結合ループの両端に芯線と外皮を半田付け。受信機側は SMA |
| 支え | 木か樹脂の棒 | 輪を**縦に立てて、手で回せる**ようにする。金属の棒は輪の中を通さない |

輪は縦に立てる (面が鉛直)。水平に寝かせると軸が真上を向き、水平方向のどの向きにもヌルが向かない。

## 計器の設定

### LiteVNA64 で同調点を見る

結合ループの同軸を CH0 につなぎ、**S11 だけ**を測る。校正 (SOL) は同軸の先 (結合ループをつなぐ所) で行う。

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| 掃引 (探すとき) | 6〜9 MHz、401 点 | まずくぼみがどこにあるかを見つける。くぼみの幅は 20 kHz ほどなので、点が粗いと見落とす |
| 掃引 (読むとき) | 6.9〜7.3 MHz、401 点 | 1 点 1 kHz。くぼみの形が 20 点以上で描ける |
| トレース | S11 の SWR と Smith | 同調点は SWR の底、結合の強さは Smith の円の大きさで読む |
| マーカー | SWR の底、その両側 | 底の周波数と SWR、幅を読む |

```vna

title: 図2 結合ループから見た S11 (7.1 MHz に合わせたとき)
sweep: 6.9M-7.3M 401
dut:

  - open
traces:
  - S11 swr 1
  - S11 smith
markers:
  - 7.076M
  - 7.105M

  - band 7.0M 7.2M: 7 MHz 帯

  - match: 範囲の外です
    why: 同調を外れた輪はほぼ全部を反射する。底の周りを読む尺度にした
```

![NanoVNA の画面](https://tommie-jp.github.io/tommie-circuit-workbook/05-etc/06-ham-receiver/vna/07-small-loop.svg)

- 図2 の模型は、2 つの輪を T 型の等価回路に直したもの: 直列に L2 − M (345 nH)、GND へ M (103 nH)、
  同じ節から GND へ「L1 − M (2077 nH)・C (230.5 pF)・損失 0.45 Ω の直列」
- **SWR の底は 1.24 (7.105 MHz、マーカー 2)**。共振 (7.100 MHz) より少し上にずれるのは、結合ループ自身のインダクタンス
  (0.45 µH、+j20 Ω) を、共振の少し上で輪が見せる容量性の分が打ち消すため
- 両側のマーカー (7.076 MHz と 7.135 MHz) は、**受ける電力が半分になる点** (SWR 5.8)。幅は 59 kHz
- 掃引の大半で SWR は 8 目盛の外 (9 以上) に出る。同調を外れた輪はほぼ全部を反射する、という意味で、図の上の縁に沿う線はそのまま読む

### 合わせ方

1. VC1 を回して、SWR の底を聞きたい周波数に持っていく。CW なら 7.015 MHz (7.000〜7.030 MHz が幅 59 kHz に収まる)、
   短波放送なら聞く局の周波数。底は VC1 の 14° ほどで 59 kHz 動く (見積り)
2. 底の SWR が 2 を超えるときは結合を直す。**Smith の円が中心に届かない (R が 50 Ω より低い) なら結合が足りない**ので、
   結合ループを主ループに寄せるか大きくする。円が中心を通り越す (R が高い) なら離すか小さくする。
   損失の見積り (0.45 Ω) は実物で 2 倍ほど動くので、ここは現物合わせになる
3. 読むときは輪から 1 m 離れる。体が近いと同調が数十 kHz ずれる
4. 同軸を受信機 (か tinySA) につなぎ替える。**SWR は 3 でも不整合の損失は 1.2 dB**で、受信には効かない。底の位置だけ合っていればよい

### tinySA Ultra でヌルを見る

輪を tinySA Ultra の入力につなぎ、輪の同調を短波放送の 1 局 (例として 7.260 MHz) に合わせる。

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| 中心 / 幅 | 7.26 MHz / 200 kHz | 輪が通す幅 (59 kHz) の 3 倍。同調の外が落ちるのも見える |
| RBW | 3 kHz | 放送の搬送波と、雑音の線 (65 kHz おき) を分ける |
| 基準レベル | −60 dBm | 搬送波 (−70 dBm) が上から 1 目盛。6-2 の図と同じ |
| LNA | on | 輪の出力が小さいので、計器のフロアを下げる |

- 図3・図4 は**見積り**。7.260 MHz の線は放送の搬送波で、6-2 と同じく電界 50 dBµV/m (316 µV/m) の強い局を仮定した。
  損失の無い等方性アンテナなら −44.4 dBm、この輪は指向性 1.5 倍と効率 −27.6 dB で **−70 dBm** (計算値)。
  6-2 のワイヤ (−71 dBm) とほぼ同じで、輪にしても信号は弱くならない
- 7.215 MHz と 7.280 MHz の線は、部屋の中のスイッチング電源の高調波 (65 kHz おき) を仮定した例。強さは置いた数で、家ごとに違う
- 輪を縦の軸の周りに回し、雑音の線が一番小さくなる向きで止める (図4)。そのとき**輪の軸が雑音源を指している**。
  軸から 6° 以内に合わせて −20 dB (sin θ)。実物は輪の左右の不釣り合いで浅くなり、20 dB 前後が目安
- 放送の線はほとんど変わらない。電離層で返ってきた波は高い角度から、偏波も向きも乱れて届くので、鋭いヌルに入らない。
  **ヌルが効くのは、近くから水平に届く雑音**だ
- 6-2 のワイヤを同じ設定でつなぐと、7.16〜7.36 MHz の全部の局が同じ画面に並ぶ (同調が無い)。
  輪は合わせた局の周りだけが立ち、100 kHz 離れた局は 10 dB 以上落ちる

## 見るべき値

計算値と見積り。**実機では組んでいない (未測定)**。

| 測る所 | 期待する値 |
| --- | --- |
| VC1 を回したときの同調の範囲 (SWR の底) | 6.72〜7.59 MHz (浮遊 5 pF を仮定) |
| 7.1 MHz に合わせたときの SWR の底 | 1.24 (7.105 MHz)。結合ループ 16 cm・間隔 5 mm・損失 0.45 Ω のとき |
| SWR 2 以下の幅 | 20 kHz |
| 受ける電力が半分になる幅 (SWR 5.8 の間) | 59 kHz (負荷時の Q 約 108) |
| 結合ループを 12 cm (1/5) にしたときの SWR の底 | 2.6 (R = 21 Ω) |
| 輪を回したときの雑音の線 | 面を向けて最大、軸を向けて 20 dB 前後下がる (半回転で 2 回) |
| 輪を回したときの放送の線 | 数 dB しか動かない |
| 電界 50 dBµV/m の局のレベル | −70 dBm (6-2 のワイヤは −71 dBm) |

- SWR の底が 7.59 MHz より上にしか来ないときは、L1 が計算より小さい (輪が小さい・線が太い)。C1 を 220 pF に替える
- 底が浅い (SWR 3 以上) のに幅が広いときは損失が大きい。VC1 の端子と輪の継ぎ目の半田を見直す。
  輪の損失の半分はコンデンサ (Q 400 と仮定) なので、ここの接触が Q を決める
- ヌルが浅いときは、同軸の外皮がアンテナとして働いている (外皮を伝って雑音が入る)。
  同軸にクランプ式のフェライトを 2〜3 個付けるか、同軸を輪の真下へまっすぐ下ろす

| 軸から 6° の感度 | −20 dB | −19.6 dB | 合う |

見積りのままの値: コンデンサの Q (400 と置いた)、浮遊容量 (5 pF)、実物のヌルの深さ、雑音の線の強さ。
線の抵抗は表皮の深さ (24.5 µm) から出した値で、継ぎ目の抵抗は入れていない。
