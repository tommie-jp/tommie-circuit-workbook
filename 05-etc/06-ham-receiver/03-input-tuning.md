# 6-3 入力の同調回路 — T37-2 のトロイダルコイルを NanoVNA で 7 MHz に合わせる

[6-2](02-wire-antenna.md) のワイヤアンテナには、7 MHz 帯の信号のほかに中波放送や短波の強い局が全部乗っている。
受信機の最初に置く**入力の同調回路**は、7 MHz の周りだけを通してミキサー (SA612) に渡す。
この題では、同調回路だけをユニバーサル基板に組み、LiteVNA64 で通過特性 (S21) と反射 (S11) を見て、
トリマコンデンサで山を 7.1 MHz に合わせる。ここで決めた巻き数と値を、[6-5](05-direct-conversion.md) の受信機からそのまま使う。

- 回路は並列共振 1 個。コイルは鉄粉のトロイダルコア T37-2 に手で巻く (材質の違いは [03-nanovna 4-14](../../03-nanovna/04-components/14-toroid-materials.md))
- アンテナ (50 Ω (オーム)) は 4 回の**リンク巻線**でつなぎ、SA612 の入力 (1.5 kΩ) は 2 次の全体につなぐ
- 治具は [03-nanovna 3-6](../../03-nanovna/03-fixtures/06-fixture-limit.md) と同じ作り (ユニバーサル基板 + 端面 SMA)。この治具は 30 MHz まで信じられるので、7 MHz は範囲の内
- ブレッドボードは使わない。7 MHz は 3 MHz を超え、穴の列の間の容量 (数 pF) が同調をずらすため

## この題で決める数

コイル L とコンデンサ C の並列共振の周波数は **f<sub>0</sub> = 1 / (2π (パイ)√(LC))**。
トロイダルコアのインダクタンスは巻き数 N の 2 乗に比例し、**L = A<sub>L</sub> × N²**。
T37-2 の A<sub>L</sub> は 4.0 nH/回² (メーカーの表の値。使える範囲は 2〜30 MHz)。

| 決めること | 値 | 理由 |
| --- | --- | --- |
| 2 次の巻き数 | 32 回 → L = 4.0 nH × 32² = **4.10 µ (マイクロ) H** | 7.1 MHz でのリアクタンス X<sub>L</sub> = 2πf<sub>0</sub>L = 183 Ω。SA612 の 1.5 kΩ をつないで Q が 5 前後になる大きさ |
| 同調の容量 | 合計 **123 pF** (7.1 MHz) | C1 100 pF (固定) + TC1 (トリマ、約 20 pF) + 浮遊と SA612 の入力 (約 3 pF) |
| リンクの巻き数 | **4 回** (巻数比 8) | 下の表。選択度と損失の折り合い |

**負荷を付けたときの Q と帯域。** 共振のとき、2 次の両端には 3 つの抵抗が並列に付く:
アンテナの 50 Ω を巻数比の 2 乗で持ち上げた 50 Ω × 8² = 3.2 kΩ、SA612 の 1.5 kΩ、コイル自身の損失 (無負荷 Q を 150 と見積もると 150 × 183 Ω = 27.4 kΩ)。
合わせて R = 985 Ω で、**Q<sub>L</sub> = R ÷ X<sub>L</sub> = 5.4**、−3 dB の幅は f<sub>0</sub> ÷ Q<sub>L</sub> = **1.3 MHz**。
7 MHz 帯 (7.0〜7.2 MHz) も、試し受信に使う短波放送 (7.2〜7.45 MHz) も、合わせ直さずに入る幅である。

**リンクの巻き数の選び方** (計算値。負荷は SA612 の 1.5 kΩ、結合係数 1、無負荷 Q 150)。

| リンク | アンテナ側から見た抵抗 | Q<sub>L</sub> | −3 dB の幅 | 損失 (整合からの不足とコイル) |
| --- | --- | --- | --- | --- |
| 3 回 | 12.5 Ω | 6.2 | 1.14 MHz | 2.2 dB |
| **4 回** | **22.2 Ω** | **5.4** | **1.32 MHz** | **0.9 dB** |
| 6 回 | 50.0 Ω | 3.9 | 1.82 MHz | 0.2 dB |

6 回なら 50 Ω にぴったり合うが、幅が広がって帯域の外の局が通りやすくなる。3 回は損失が増える。
短波の受信機では、外から来る雑音が受信機の雑音よりずっと大きいので、1 dB の損失は聞こえ方に効かない。**4 回で選択度を取る。**
リンクを巻き直すだけで替えられるので、6-5 を組んでから 3 回・6 回を試してもよい (同じ考え方をアンプの負荷で確かめるのが [03-nanovna 8-21](../../03-nanovna/08-amplifiers/21-tuned-load-link.md))。

**どれだけ落とせるか** (共振の山からの減衰。計算値)。

| 周波数 | 何があるか | 山からの減衰 |
| --- | --- | --- |
| 1 MHz | 中波放送 (近くに送信所があると、受信機の中で検波されて全面に聞こえる) | 31.7 dB |
| 14.2 MHz | 2 倍 | 18.4 dB |
| 21.3 MHz | 局発 7.1 MHz の 3 倍 (方形波の局発は 3 倍でも混合する) | 23.4 dB |

共振 1 個なので、離れた周波数での落ち方はゆるい (遠くでは 1 オクターブで 6 dB)。それでも中波を 30 dB 落とせるのが、この 1 段の一番の働き。

### コイルを巻く

- 線は φ0.3 mm のポリウレタン銅線 (UEW)。2 次に 45 cm、リンクに 10 cm を切る (1 回が約 12 mm。32 回で 39 cm、4 回で 5 cm に、リードのぶんを足した)
- **穴を 1 回通るごとに 1 回**と数える。外側を回した回数ではない。32 回は、コアの円周の 3/4 ほどに重ねずに並べる
  (内周 16.4 mm に、2 次とリンクで 36 回 × 0.33 mm = 11.9 mm)
- リンクの 4 回は、2 次の **GND 側の端**の上か隣に巻く。熱い側 (C1 につなぐ端) から離すと、巻線の間の容量を通る漏れが減る
- 線の端は 5 mm ほど被覆を落とす。UEW は半田ごてを当て続けると被覆が溶けて半田が乗る (乗らなければ紙やすりで削る)
- 巻きを寄せると L は数 % 増え、広げると減る。大きくずれたらトリマの前に巻きの間隔で寄せる

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/05-etc/06-ham-receiver/circuit/03-input-tuning.svg)

- **J1 (CH0)** がアンテナの端子にあたる。T1 の 1 次 (A1-A2) がリンク 4 回、2 次 (B1-B2) が 32 回
- **C1 と TC1** が 2 次と並列共振する。C1 は温度で値の動かない C0G (CH) のセラミック
- **R1 (1.5 kΩ) は SA612 の入力の代わり。** VNA の CH1 は 50 Ω なので、そのままつなぐと同調回路が 50 Ω で潰れて山が消える。
  R1 を直列に入れると、2 次から見た負荷は 1.5 kΩ + 50 Ω = 1.55 kΩ になり、SA612 をつないだときとほぼ同じ Q になる
  (SA612 の入力容量 3 pF のぶんは、TC1 を少し多めに回して代える)
- 代わりに、CH1 に届くのは R1 と 50 Ω で分けた電圧だけになる。負荷に入った電力のうち CH1 に届くのは 50 ÷ 1550 で、
  **S21 は 10 log(1550 ÷ 50) = 14.9 dB 低く出る**。これは治具の見かけの損失で、受信機に組めば無い

## 計器の設定

計器は LiteVNA64。**Analog Discovery 3 とオシロの図は入れない** (S パラメータを見る題で、図は vna にする)。
AD3 の Scope を熱い側に直に挟むと、入力の約 24 pF が同調の容量に足されて、共振が 7.1 MHz から 6.49 MHz へ下がる (計算値)。
同調回路の熱い側は、計器を直に当てて測れない所だと覚えておく。

図4 の帯は、受ける範囲 (7 MHz 帯の 7.0〜7.2 MHz と、短波放送の 7.2〜7.45 MHz)。

**図3・図4 の `dut:` は、図1 を 1 次側 (CH0 側) に換算した等価回路**。vna フェンスの模型にはトランスが無いので、
巻数比 8 の理想トランス (結合係数 1) と置いて、2 次側の値を 8² = 64 で割った (コンデンサは 64 を掛けた)。

| `dut:` の行 | 図1 の何か |
| --- | --- |
| `shunt L 64n rp 428.3` | 2 次の 4.096 µH ÷ 64。`rp` はコイルの損失 27.4 kΩ ÷ 64 |
| `shunt C 7.8513n` | 同調の容量 122.68 pF × 64 |
| `shunt R 27.68` と `series R 143.75` | R1 と CH1 の 50 Ω。1 次から見て 1550 Ω ÷ 64 = 24.2 Ω に見え、CH1 に届く電圧が 8 × 50 ÷ 1550 倍になる組み合わせ |

この換算で S21 と S11 は図1 の回路と同じになる (下の「LTspice での確かめ」で、結合コイルの回路と突き合わせた)。

### 合わせる手順

1. 図3 の範囲で掃引する。7 MHz の辺りに山が 1 つ見えればよい。見えなければ T1 の線の被覆が落ちていない
2. 図4 の範囲に替えて校正を取り直す。S21 の山は平たい (幅が 1.3 MHz ある) ので、**SWR の谷で合わせる**
3. 樹脂かセラミックのドライバで TC1 を回し、SWR の谷 (マーカー 2) を 7.1 MHz に寄せる。谷の深さは 2.2 前後で、1 までは下がらない
   (リンク 4 回では 50 Ω に合わせ切っていない。上の表)
4. TC1 を回し切っても届かないときは、巻きの間隔を寄せる (下がる)・広げる (上がる)。それでも届かなければ 1 回ほどいて 31 回にする (約 3 % 上がる)

計算値 (結合係数 1、コイルの無負荷 Q 150 の見積り)。**実機では組んでいない (未測定)。**

| 測る所 | 期待する値 | 分かること |
| --- | --- | --- |
| 山の周波数 (TC1 を回して) | 7.1 MHz。TC1 は約 20 pF の位置 | TC1 が 6〜50 pF なら 7.5〜6.4 MHz を動かせる (浮遊 3 pF として) |
| 山の S21 | −15.8 dB | R1 の見かけの損失 14.9 dB + 同調回路の損失 0.9 dB |

| −3 dB の幅 | 6.48〜7.77 MHz = 1.29 MHz | Q<sub>L</sub> = 5.5 (負荷 1.55 kΩ。SA612 の 1.5 kΩ なら 5.4) |
| 7.45 MHz (短波放送の上の端) | 山から 1.1 dB 下 | 合わせ直さずに試し受信ができる |
| 1 MHz | −47.5 dB (山から 31.7 dB 下) | 中波放送の落とし方 |
| 14.2 MHz / 21.3 MHz | −34.2 dB / −39.2 dB (山から 18.4 dB / 23.4 dB 下) | 2 倍・3 倍の落とし方 |
| 2 次の両端の電圧 (治具では測れない) | アンテナの端子を 50 Ω で受けたときの 4.9 倍 (+13.8 dB) | リンクで電圧を持ち上げて SA612 に渡している |

- 無負荷 Q が 150 より低いと、山が下がり幅が広がる。Q 100 で山は 0.2 dB 下がる程度で、負荷の 1.5 kΩ が支配するので差は小さい
- 結合係数は 1 より小さい (リンクが 4 回と少なく、鉄粉のコアは透磁率が低い)。0.9 と置くと山は −16.2 dB、幅は 1.21 MHz (LTspice)。
  実測の幅が計算より狭ければ、結合が弱いと読む
- 30 MHz に近い側の落ち方は、治具の線と巻線の間の容量で頭打ちになる。図3 の 20 MHz から上は目安
