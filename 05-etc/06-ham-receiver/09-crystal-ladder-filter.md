# 6-9 水晶ラダーフィルタ — 4.9152 MHz の水晶 4 個で CW の帯域を作り NanoVNA で測る

[6-5 のダイレクトコンバージョン受信機](05-direct-conversion.md) は、局発の上 700 Hz の局と下 700 Hz の局が同じ音になり、
聞き分けられない。[6-10 のスーパーヘテロダイン](10-cw-superhet.md) は、信号をいったん 4.9152 MHz の中間周波 (IF) に移し、
そこに**幅 500 Hz ほどの帯域通過フィルタ**を置いて、片側だけを通す。この題では、その IF フィルタを作って測る。

同じ周波数の水晶 4 個を直列に並べ、間を同じ値のコンデンサで GND へ落とす。はしごの形なので**水晶ラダーフィルタ**と呼ぶ。
水晶 3 個の入門は [03-nanovna の 6-7](../../03-nanovna/06-filters/07-crystal-ladder.md) にある。ここで足すのは次の 3 つ。

- 水晶を 4 個にし、コンデンサを全部同じ値にする形 (Cohn の最小損失型)。部品を選びやすい
- 終端の抵抗を 50 Ω (オーム) ではなく、**フィルタに合った 200 Ω** にする。山が平らになり、損失が減る
- 水晶を 1 個ずつ測って定数を出し、周波数のそろった 4 個を選ぶ手順

**Analog Discovery 3 とオシロスコープの図は入れない。** 見る量は S パラメータ (S21) で、5 MHz の近くを 25 Hz 刻みで掃引するので、
計器は NanoVNA (標準の LiteVNA64) だけを使う。電源も要らない (受動の回路)。

## 水晶の等価回路 (見積り)

水晶振動子は、直列の L<sub>m</sub>・C<sub>m</sub>・R<sub>s</sub> に、電極の容量 C<sub>0</sub> が並列に付いた回路で表せる
([03-nanovna の 4-6](../../03-nanovna/04-components/06-crystal.md))。4.9152 MHz の HC-49/S (背の低い形) の定数は品物で違うので、
下の値は**典型の見積り**。この題の数は全部この見積りから計算した。実物は「水晶を測って選ぶ」の手順で測り、計算をやり直す。

| 定数 | 見積りの値 | 意味 |
| --- | --- | --- |
| f<sub>s</sub> | 4.915200 MHz | 直列共振の周波数 |
| C<sub>m</sub> | 15 fF | 直列の容量 (動容量)。帯域の広さを決める |
| L<sub>m</sub> | 69.9 mH | f<sub>s</sub> と C<sub>m</sub> から決まる。L<sub>m</sub> = 1 ÷ ((2πf<sub>s</sub>)² × C<sub>m</sub>)。π (パイ) は円周率 |
| R<sub>s</sub> | 30 Ω | 直列の損失。フィルタの損失を決める |
| C<sub>0</sub> | 4 pF | 電極とケースの容量 |
| Q | 約 72,000 | 2πf<sub>s</sub>L<sub>m</sub> ÷ R<sub>s</sub> |

## コンデンサの値と帯域

図1 の形で、コンデンサ 5 個を全部同じ値 C にする。**C が大きいほど水晶どうしの結合が弱く、帯域が狭い** (結合の強さは C<sub>m</sub> ÷ C)。
終端を 200 Ω にしたときの計算値は次のとおり。

| C (5 個とも) | −3 dB の幅 | −6 dB の幅 | −60 dB の幅 | 損失 | 中心 (f<sub>s</sub> から) |
| --- | --- | --- | --- | --- | --- |
| 150 pF | 680 Hz | 765 Hz | 3.28 kHz | 2.7 dB | +447 Hz |
| 180 pF | 565 Hz | 645 Hz | 2.92 kHz | 3.2 dB | +378 Hz |
| **220 pF** | **461 Hz** | **534 Hz** | **2.58 kHz** | **4.0 dB** | **+314 Hz** |
| 270 pF | 376 Hz | 440 Hz | 2.30 kHz | 5.1 dB | +258 Hz |
| 330 pF | 305 Hz | 362 Hz | 2.06 kHz | 6.4 dB | +214 Hz |

この章は **C = 220 pF・終端 200 Ω** を使う。−3 dB の幅は 461 Hz で、700 Hz の CW の音を 1 局ぶん通す。
−60 dB と −6 dB の幅の比 (形状比) は 4.8。

- **両端の直列のコンデンサ (C1・C5) の役目。** 中の水晶 (X2・X3) は両側に C が付き、端の水晶 (X1・X4) は片側にしか付かない。
  このままだと端の水晶だけ共振が低く、通過帯域が傾く。端に同じ C を直列に足すと 4 個の共振がそろう。
  C1・C5 を省くと、同じ 220 pF でも −3 dB の幅は 332 Hz に狭まり、山が片側に寄る (計算値)
- **終端の抵抗。** 200 Ω より低いと山が丸く狭くなり、高いと通過帯域に波 (リップル) が出る。
  270 Ω までは波が出ず、390 Ω で 1.1 dB、680 Ω で 2.9 dB の波になる (計算値)
- **損失の大半は水晶の R<sub>s</sub>。** R<sub>s</sub> が 10 Ω なら 1.6 dB、30 Ω で 4.0 dB、50 Ω で 6.3 dB、80 Ω で 9.7 dB (計算値)。
  背の低い HC-49/S は R<sub>s</sub> が大きめの品があるので、測って小さい物を選ぶ

- 信号は左の CH0 (VNA の出力) から右の CH1 (VNA の入力) へ流れる

  (電力の比 50 ÷ 200 が 2 回)。フィルタそのものの損失は「測った値 − 12.0 dB」

## 水晶を測って選ぶ

組む前に、水晶を 1 個ずつ測る。[03-nanovna の 4-6](../../03-nanovna/04-components/06-crystal.md) の直列治具 (CH0 と CH1 の間に水晶 1 個) を使う。
水晶は 4 個ちょうどではなく、**同じ袋の物を 10 個ほど**買って選ぶ。

1. **f<sub>s</sub> と R<sub>s</sub>**: S21 の山の周波数が f<sub>s</sub>。山の高さから R<sub>s</sub> = 100 Ω × (1 ÷ |S21| − 1)。
   見積りの水晶なら山は −2.28 dB で、R<sub>s</sub> = 30 Ω
2. **L<sub>m</sub>**: 山の −3 dB の幅 Δf (デルタエフ) から L<sub>m</sub> = (100 Ω + R<sub>s</sub>) ÷ (2π × Δf)。
   見積りの水晶なら Δf = 296 Hz で 70 mH
3. **C<sub>m</sub>**: C<sub>m</sub> = 1 ÷ ((2πf<sub>s</sub>)² × L<sub>m</sub>)。確かめに、水晶と直列に 33 pF を入れて山のずれ Δf<sub>s</sub> を読み、
   C<sub>m</sub> = 2 × Δf<sub>s</sub> × (33 pF + C<sub>0</sub>) ÷ f<sub>s</sub>。見積りの水晶なら 997 Hz ずれて 15 fF
4. **選ぶ**: f<sub>s</sub> の差が小さい 4 個を選ぶ。その中で R<sub>s</sub> が小さい物を優先する

**そろえる理由。** 4 個の共振が 1 つの通過帯域を作るので、f<sub>s</sub> がばらつくと山が崩れる。
4 個の f<sub>s</sub> をずらしたときの計算値は次のとおり。差は帯域の 1/10 (約 50 Hz) 以内が目安。

| 4 個の f<sub>s</sub> の差 | 損失 | −3 dB の幅 | 通過帯域の波 |
| --- | --- | --- | --- |
| ±10 Hz | 4.0 dB | 462 Hz | なし |
| ±50 Hz | 4.7 dB | 485 Hz | なし |
| ±150 Hz | 6.3 dB | 539 Hz | 3.2 dB |
| ±300 Hz | 9.5 dB | 680 Hz | 10.3 dB |

## 計器の設定

LiteVNA64 の CH0 を J1、CH1 を J2 に SMA ケーブルでつなぐ。

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| 範囲 | 4.913 MHz〜4.918 MHz (幅 5 kHz) | 通過帯域 (幅 461 Hz) の約 10 倍。両側の裾まで入る |
| 点数 | 201 | 1 点 = 25 Hz。−3 dB の幅に 18 点入る |
| 校正 | SOLT (スルーを含む)。**この範囲・この点数で**取り直す | 範囲を変えると校正は補間になり、狭い掃引では当てにならない |
| 表示 | S21 の Log Mag、10 dB/目盛 | 山 (−16 dB) から裾 (−70 dB 以下) まで見る |
| 帯域幅 (IFBW・平均) | 狭くする (掃引を遅くする) | 下の「掃引の速さ」 |

狭い掃引には注意が 3 つある。

- **周波数の刻み。** 1 点が 25 Hz なので、周波数の読みは ±12.5 Hz より細かくならない。帯域の端を細かく読みたいときは、
  範囲を 1 kHz に狭めて (1 点 = 5 Hz) 校正し直す。VNA の信号源の周波数の刻みが 25 Hz より粗い機種では、点が階段になる
- **掃引の速さ。** Q が 7 万の水晶は、信号を入れてから振れが落ち着くまで数 ms かかる (時定数は Q ÷ (π × f<sub>s</sub>) = 約 4.7 ms)。
  1 点に留まる時間がこれより短いと、山が低く、右へ流れた形に見える。VNA の受信の帯域幅 (IFBW) を狭くするか平均を増やし、
  **掃引を遅くしても形が変わらなくなる所**で読む
- **絶対の周波数。** VNA の基準の誤差が 1 ppm でも 5 Hz ずれる。6-10 の BFO を合わせるときは、同じ VNA で測った値どうしで比べるか、
  受信機に組んでから音で合わせる

## 見るべき値

計算値 (見積りの水晶による)。**実機では組んでいない (未測定)。** 図の読み値の表は周波数を丸めて出すので、周波数はこの表で読む。

| マーカー | 周波数 | S21 (図3、直列抵抗つき) | フィルタだけ (−12.0 dB を除く) | 意味 |
| --- | --- | --- | --- | --- |
| 1 | 4.914814 MHz | −53.0 dB | −41.0 dB | 中心の 700 Hz 下 |
| 2 | 4.915283 MHz | −19.0 dB | −7.0 dB | 通過帯域の下の端 (山から −3 dB) |
| 3 | 4.915514 MHz | **−16.0 dB** | **−4.0 dB** | 山 (中心) |
| 4 | 4.915744 MHz | −19.0 dB | −7.0 dB | 通過帯域の上の端 |
| — | 4.916214 MHz | −57.7 dB | −45.7 dB | 中心の 700 Hz 上 (マーカーは 4 つまでなので、周波数を合わせて読む) |

| 項目 | 値 |
| --- | --- |
| 中心 | 4.915514 MHz (水晶の f<sub>s</sub> の 314 Hz 上) |
| −3 dB の幅 | 461 Hz (4.915283〜4.915744 MHz) |
| −6 dB / −60 dB の幅 | 534 Hz / 2.58 kHz (形状比 4.8) |
| 通過帯域の波 | なし (山は 1 つ) |
| 中心の 1.4 kHz 下 (4.914114 MHz) | 山から −58.6 dB |
| 中心の 1.4 kHz 上 (4.916914 MHz) | 山から −69.2 dB |

- **中心は水晶の f<sub>s</sub> より上にずれる。** 直列・並列の C が水晶の共振を引き上げるため。4.9152 MHz ちょうどには来ない
- **裾は上側のほうが急。** 水晶の C<sub>0</sub> が通過帯域の上に並列共振 (通さない点) を作るため。
  同じ 700 Hz 離れでも、下は −37 dB、上は −42 dB (山から)
- **裾の深い所は VNA の限界で頭打ちになる。** 山が −16 dB なので、山から 60 dB 下は −76 dB。LiteVNA64 のノイズフロアと基板の漏れに近く、
  計算どおりには下がらない。見えるのは山から 50〜60 dB 下までと考える
- 山が −16 dB より 3 dB 以上低い、または通過帯域が波打つときは、水晶の R<sub>s</sub> が大きいか、f<sub>s</sub> がそろっていない
- 山が 2 つ・3 つに分かれるときは、終端が高すぎる。R1・R2 が 150 Ω か、SMA の中心導体までつながっているかを確かめる

## 6-10 でのつなぎ方

6-10 では、フィルタの前後が SA612 になる。SA612 の出力も入力も約 1.5 kΩ で、フィルタの 200 Ω とは合わない。
**L 型の整合 (直列のコイル 18 µH (マイクロヘンリー) と、SA612 の側の並列のコンデンサ 47 pF) を両端に入れる。**

| 部品 | 値 | 置き場所 |
| --- | --- | --- |
| コイル | 18 µH (FT37-61 に 18 回。A<sub>L</sub> 55 nH/回² で 17.8 µH) | フィルタの端 (C1・C5 の外) と SA612 の間に直列 |
| コンデンサ | 47 pF (C0G) | SA612 のピンと GND の間 |

- 18 µH と 47 pF で、1.5 kΩ はフィルタの側から約 240〜260 Ω に見える (SA612 の入力の 3 pF を足すと 236 Ω)。波が出ない範囲 (270 Ω まで) の内
- 両端を 1.5 kΩ にしたときの計算値は、損失 **4.5 dB** (コイルの Q を 80 とすると 4.8 dB)、−3 dB の幅 **464 Hz**、中心 **4.915514 MHz** で、波は出ない
- 抵抗で落とす方法 (SA612 のピンに 220 Ω を並列) は部品が少ないが、損失が 21.8 dB になる (計算値)。IF の増幅段が無い受信機には重いので使わない
- 測るための R1・R2 (150 Ω) は外す
- **BFO は通過帯域の上に置く** (中心 + 700 Hz = 4.916214 MHz 付近)。逆サイドの信号は IF で中心の 1.4 kHz 上に来て、急な上側の裾 (−69 dB) で落ちる。
  下に置くと −59 dB で、10 dB 浅い

## LTspice での確かめ

本文の数は ABCD 行列の算術 (`sim/09_ladder_design.py`・`sim/09_ladder_values.py`・`sim/09_ladder_match.py`) で出し、
同じ回路を LTspice の AC 解析にかけて突き合わせた (`sim/09-ladder-200ohm.cir` は 200 Ω の終端、`sim/09-ladder-jig50.cir` は図3 と同じ 50 Ω 系の治具)。
理想の模型どうしの比べで、実測ではない。

| 確かめること | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| 山の損失 (200 Ω の終端、4.915514 MHz) | 4.0 dB | 3.98 dB | 合う |
| 山の S21 (50 Ω 系の治具) | −16.0 dB | −16.02 dB | 合う |
| −3 dB の端 | 4.915283 / 4.915744 MHz | 4.915282 / 4.915745 MHz | 合う |
| −3 dB の幅 | 461 Hz | 463 Hz | 合う (算術は 1 Hz 刻み) |
| 通過帯域の波 | なし | 0 dB | 合う |
| 中心の 700 Hz 下 / 上 (200 Ω) | −41.0 / −45.7 dB | −40.99 / −45.68 dB | 合う |
| 中心の 1.4 kHz 下 / 上 (山から) | −58.6 / −69.2 dB | −58.6 / −69.2 dB | 合う |

LTspice で確かめていない物: C を替えた表・水晶のばらつきの表・L 型の整合の数 (算術だけ)。
水晶の定数そのもの (C<sub>m</sub>・R<sub>s</sub>・C<sub>0</sub>) は見積りで、実物を測るまで決まらない。
