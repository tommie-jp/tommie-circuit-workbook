# 4-3 3 つのミキサーをシミュレーションで比べる — 変換利得・漏れ・P1dB

4-1 (2SC1815 の 1 石)・4-2 (2SC1815 の差動対)・3-1 (3SK291) の 3 つを、同じ仕様 (RF 0.53〜1.6 MHz、IF 455 kHz、電源 5 V) で**同じ手順で解析**して比べる。
比べる項目は、変換利得の LO 電力・RF 周波数・RF 電力への依存、LO と RF の漏れ、P1dB、電源電流。
3 つとも同じ出力回路 (455 kHz の同調回路 → R7 2 kΩ → セラミックフィルタ → 50 Ω (Ω はオーム) の IF OUT) を持ち、変換利得は同じ定義 (IF OUT の電力 ÷ RF の有能電力) で読める。

## 結論 — おすすめは差動対 (4-2)

**中波のスーパーヘテロダインに 1 つ選ぶなら、2SC1815 の差動対 (4-2) をすすめる。** 理由は 4 つある。

- **利得が条件に左右されない**: +0.3 dB。LO が −5〜+16 dBm でも、LO の源が 0 Ω でも 50 Ω でも ±0.2 dB しか動かない。
  1 石の +9.3 dB は LO の源が 0 Ω (Wavegen) のときだけで、50 Ω の発振器では +1.2 dB になる。3SK291 は LO +7 dBm で +1.4 dB
- **中波の全域で平ら**: 0.53〜1.6 MHz で +0.3〜+0.4 dB。1 石は低い側で約 2 dB 落ちる
- **LO が小さくて済む**: −10 dBm で足りる (0 dBm より 1.1 dB 低いだけ)。3SK291 は +7 dBm 要る
- **RF が打ち消される**: フィルタの前で RF は IF より 36 dB 低い (1 石は 7 dB 高い)。電流は 1.45 mA と小さく、部品はリード線の付いた 2SC1815 が 3 本と 2SA1015 が 2 本で、手に入りやすい

差動対を使うときに守ることは 2 つある。

- **左右を揃える**: ミラーのエミッタの 220 Ω を 1 % の品にし、トランジスタは同じ袋から選ぶ。220 Ω が 4.5 % ずれると打ち消しが 32 dB に浅くなる (解析)
- **IF のフィルタは要る**: LO は打ち消されず、フィルタの前で IF より 10 dB 高く出る

目的によっては、ほかの 2 つが向く。

| 目的 | すすめるもの | 理由 |
| --- | --- | --- |
| 中波のラジオを 1 台作る | **差動対 (4-2)** | 上の 4 つ |
| 部品を最小にして、混ぜる仕組みを見る | 1 石 (4-1) | トランジスタ 1 本。LO を 0 Ω の源 (Wavegen) で入れれば +9.3 dB と 3 つで最も大きい。ただしコレクタに RF も LO も IF より高く出て、P1dB は約 −14 dBm |
| 強い放送局の近くで、大きな入力に耐えたい | 3SK291 (3-1) | P1dB は約 0 dBm と 3 つで最も高く、RF と LO を別のゲートから入れる。ただし LO に +7 dBm、電流に約 10 mA 要り、部品は面実装 |

この結論は代用のモデルによるシミュレーションだけから出したもので、実機では確かめていない (下の注意)。
特に差動対の打ち消しの深さは、実物では 20〜30 dB に浅くなると見込む。
**3 つの変換利得はどれも 0〜+1.5 dB 台に並ぶ** (1 石を 0 Ω の源で駆動する場合を除く)。中波のラジオでは、ミキサーの後ろに IF の増幅が要る。

> [!WARNING]
> **どれもシミュレーションだけで、実機では測っていない。** 2SC1815・2SA1015 は hFE・fT・Cob の目安から作った代用のモデル、
> 3SK291 も 3-2 の代用モデル。**代用モデルどうしの比較は傾向を見るためのもの**で、数値は実機で変わる。
> 主な点 (変換利得 6 点) は LTspice でも照合し、ngspice と 0.1 dB 以内で合った (下の「照合したこと」)。

この題は実体配線図・Analog Discovery 3・オシロの図を付けない — シミュレーションの結果だけを見る題で、組む回路が無い (組む回路は 4-1・4-2・3-1 の図)。

## 解析の方法

- 道具: ngspice 39 (Debian の Docker イメージ)。ネットリストは SPICE の標準の素子だけで書いてある。
  1 石の再現は [sim/](sim/) の `lib.py` (回路の記述と FFT) と `main.py` (掃引) で、結果は [sim/results.json](sim/results.json)。
  差動対 (4-2) は `diff_output.py` (結果は [sim/diff_output.json](sim/diff_output.json))、条件をそろえた比べは `compare_gain.py` (結果は [sim/compare_gain.json](sim/compare_gain.json))。
  1 石と差動対のネットリストは [sim/single.cir](sim/single.cir)・[sim/diff.cir](sim/diff.cir)
- 2SC1815 の代用モデル: IS = 2 × 10<sup>−14</sup>・BF = 250・VAF = 100・RB = 30 Ω・CJE = 8 pF・CJC = 2 pF・TF = 2 ns。**値は一般に知られた目安 (hFE 約 250・fT 約 80 MHz・Cob 約 2 pF) から作った仮定**で、データシートの本文は直接読んでいない。
  2SA1015 (4-2 のカレントミラー) は同じ作りで BF = 200・VAF = 50・CJC = 4 pF の PNP (仮定)
- 3SK291 は 3-2 の解析の値をそのまま使った (代用モデル。LO +7 dBm が標準)
- セラミックフィルタ: 3-2 と同じ。1.5 kΩ・帯域 約 12 kHz の 3 次の LC 梯子 (実物の型番のモデルではない。阻止域は実物より深すぎる)
- 条件: RF −30 dBm (10 mV<sub>p</sub>)、LO 0 dBm (0.32 V<sub>p</sub>)、LO = RF + 455 kHz。**LO も RF も正弦波。信号源は 0 Ω (Wavegen と同じ)** で、振幅はポートの電圧 (50 Ω に整合した電力に相当) にした。過渡解析 1.4 ms の最後の 1 ms を FFT (ハニング窓)
- **変換利得 = IF OUT (50 Ω) の電力 ÷ RF の有能電力** (dB)。50 Ω の負荷なので、IF の電圧 ÷ RF のポートの電圧と同じ値
- 漏れ (LO・RF) は、1 石ではコレクタ、差動対ではミラーの出力 (どちらもフィルタの前) で測った

## 3SK291 の利得が小さい理由 — 条件をそろえて切り分ける

3SK291 の +1.4 dB は、1 石の +9.3 dB より小さい。**FET だから低いのか、測り方・条件のせいか**を、同じ条件で解析し直して切り分けた。
再現は [sim/compare_gain.py](sim/compare_gain.py) (結果は [sim/compare_gain.json](sim/compare_gain.json))。ngspice の過渡解析で、モデルと回路の値は上の解析と同じ。

> [!WARNING]
> **代用モデルの上の切り分けで、実機は測っていない。** 3SK291 の SPICE モデルは無く、2SC1815 とともに代用 (平方則の MOSFET と、目安から作ったバイポーラ)。
> 主な点は LTspice でも照合した (下の「照合したこと」)。dB の差は傾向として読み、小数の値に意味を持たせない。

### 条件のそろえ方

- **利得の定義**: 「負荷に出る 455 kHz の電力 ÷ RF の有能電力」(電力の利得)。RF の有能電力は、50 Ω に整合した源が作るポートの電圧 (−30 dBm で 10 mV<sub>p</sub>) の電力。50 Ω の負荷では電圧の比と同じ値になる
- **出力回路**: 3 つとも「同調回路 (220 µH・560 pF) → R7 (2 kΩ) → セラミックフィルタ → 50 Ω」。差動対は今の 4-2 (カレントミラーで差を 1 本に)
- **信号源**: 4-1・4-2 と同じ 0 Ω (Wavegen) を基準にし、LO だけ 50 Ω の源にした場合も測った。3SK291 は元の 3-2 の 50 Ω の源でも測った
- **負荷に依らない比べ方**: 出力を 0 V の電流計 (短絡) に流して、**変換コンダクタンス** G<sub>c</sub> = IF の短絡電流 ÷ RF のポートの電圧 を出した。出力回路が違っても素子どうしを比べられる

### 結果 — 同じ出力回路での変換利得

| LO +7 dBm、R7 あり | +10.6 | +0.4 | +1.2 |

- 3SK291 と差動対は、信号源を 0 Ω にしても 50 Ω にしても利得が ±0.1 dB しか変わらない (LO の入口が高インピーダンス)。**1 石は LO の源が 0 Ω か 50 Ω かで 8 dB 変わる**: エミッタの入力が約 30 Ω と低く、0 Ω の源は電圧を保ったまま振れるが、50 Ω の源は電圧が下がる

### 結果 — 素子そのものの比べ (変換コンダクタンス)

出力を短絡して測った G<sub>c</sub> (負荷に依らない)。I<sub>DD</sub> は信号を入れたときの電源の電流 (差動対はミラーの出力の分圧を除く)。

| --- | --- | --- | --- |
| 1 石、LO の源 0 Ω、LO 0 dBm | 19.9 mS | 1.27 mA | 15.7 mS/mA |
| 1 石、LO の源 50 Ω、LO 0 / +7 dBm | 7.8 / 7.8 mS | 1.14 / 1.65 mA | 6.8 / 4.7 mS/mA |
| 3SK291、LO 0 dBm | 4.3 mS | 9.6 mA | 0.45 mS/mA |
| 3SK291、LO +7 dBm | 8.0 mS | 8.5 mA | 0.94 mS/mA |

FET が不利なのは利得そのものより、**同じ変換コンダクタンスに要る電流と LO の大きさ** (平方則の FET は g<sub>m</sub> ÷ I<sub>D</sub> が小さい) である。

### 3SK291 が +1.4 dB に留まる原因ごとの効き

3SK291 (LO +7 dBm、信号源 0 Ω で +1.24 dB) を基準に、条件を 1 つずつ変えたときの変化。

| 原因 | 利得への効き | 切り分け |
| --- | --- | --- |
| (a) RF 側 51 Ω の約 6 dB | **0 dB** | 利得の基準は「整合した源のポートの電圧」で、ポートの 51 Ω の分圧は含まれない (実際のゲートの電圧は基準より 0.1 dB 高いだけ)。3-2 の「約 6 dB の減衰を含む」は誤りで、直した。1 石・差動対も同じ基準 |
| (b) R7 = 2 kΩ (IF OUT を 50 Ω に合わせる代償) | **−5.0 dB** (R7 なしで +6.3 dB) | 1 石も −5.2 dB、差動対も −4.7 dB で、**3 つの比べには差を生まない**が、絶対値は小さく見える。R7 を外すと IF OUT は 50 Ω に合わず、−3 dB の幅が 11.6 kHz から 7.8 kHz に狭まり、±20 kHz の阻止が 30 dB から 17〜20 dB に浅くなる (3-2) |
| (c) 元の 4-2 の尺度 | 元の 4-2 だけ +33 dB 見かけが大きかった | +12.1 dB は 3.3 kΩ ずつの出力の電圧の比。同じ出力回路では −20.7 dB。3SK291 と 1 石の間には無関係。今の 4-2 は同じ出力回路で +0.3 dB |
| (d) G2 = 1.41 V | **0〜0.1 dB** | LO +7 dBm では 1.3〜1.5 V で最大 (+1.1〜+1.25 dB)。LO 0 dBm では最適が 1.6 V 付近にずれ、そこで +2 dB 良い (LO 0 dBm は標準でない)。ずれる理由は 3-2 (中点の振れの上端を M1 の飽和の境目に合わせる所が、LO が小さいほど G2 の高い側に来る) |
| (e) G1 (ドレイン電流) | **0 dB** | 1.24 V (8.5 mA) で最大。1.4 V (10.7 mA) は −0.1 dB、1.0 V (5 mA) は −3.2 dB |
| (f) LO が +7 dBm | **+1.3 dB** (+13 dBm)、+1.5 dB (+16 dBm) | +7 dBm で曲がり、以降は伸びが小さい。LO 0 dBm では −5.5 dB |
| (g) 素子 (FET の性質) | 50 Ω の LO 源の 1 石・差動対に対して **0 dB** (G<sub>c</sub> 8.0 と 7.8・7.6 mS) | 0 Ω の LO 源の 1 石 (+9.3 dB) に対しては約 8〜9 dB 小さいが、これは 1 石が 0 Ω の源で有利になる分。FET の不利は**電流 5 倍・LO +7 dBm 以上** |
| (h) 3SK291 の実物のしきい値・容量 | **未確認** | 代用モデルの λ・しきい値・G2 側の容量は仮定。実機で変わる |

**答え: 利得が小さいのは主に出力回路 (R7) と、元の比較で 1 石が 0 Ω の LO 源という有利な条件だったことによる。FET だから利得が低いわけではない。** 3SK291 の弱みは、利得ではなく**電流 (約 8.5 mA) と LO の大きさ (+7 dBm 以上)** に出る。
強みは P1dB (約 0 dBm。ただしモデルは楽観的) と、RF・LO を別のゲートに入れられることのほうである。

条件をそろえて 3SK291 を良くするなら、R7 を外し、LO を +13 dBm にして +7.7 dB (信号源 0 Ω、G2・G1 は元のまま。ただし IF OUT は 50 Ω に合わず、帯域が狭まる)。
IF の負荷を 20 kΩ にそろえた値 (フィルタの前の電力) では、LO +7 dBm で 3SK291 +12.1 dB、1 石 +23.8 dB。この負荷でも、FET と 1 石の差は主に 1 石の LO の源が 0 Ω であることによる (G<sub>c</sub> の表)。

## 照合したこと

- **LTspice**: 3SK291 と 1 石 (LO +7 dBm、R7 あり・なし) と差動対 (LO 0 dBm、R7 あり・なし) の変換利得 6 点を LTspice でも解析し、ngspice と **0.1 dB 以内**で合った
  (3SK291 +1.24 / +1.20 dB、R7 なし +6.27 / +6.20 dB、1 石 +10.58 / +10.56 dB、R7 なし +15.80 / +15.76 dB、差動対 +0.34 / +0.33 dB、R7 なし +5.05 / +5.03 dB。前が ngspice)。
  ネットリストと表は [sim/ltspice/](sim/ltspice/README.md)。同じ代用モデルを 2 つの解析器で解いた照合で、モデルの正しさの照合ではない

## 確かめていないこと

- **実機との対応**: どのモデルも代用。特に 2SC1815 の利得 (+9 dB 前後) と P1dB は、hFE・fT・ベース抵抗の実物で変わる
- **差動対の打ち消しの深さ**: 左右が同じモデルなので実物より深い。実物の 20〜30 dB を見込む (ミラーの 220 Ω が 4.5 % ずれると 32 dB、解析)
- **1 石の 0.53 MHz での利得低下の原因**: 未確認
- **3 つの比較の公平さ**: LO の標準が違う (2SC1815 は 0 dBm、3SK291 は +7 dBm)。図 1 と図 4 は同じ軸に並べたので、LO を同じにした比較はそこで読む
- **セラミックフィルタの阻止域**: モデルは理想の LC 梯子で深すぎる。IF OUT に残る LO・RF の高さは実物のフィルタで決まる
- 前置の同調回路が無いので、影像や強い放送波の混変調は抑えられない (3-1 と同じ)
