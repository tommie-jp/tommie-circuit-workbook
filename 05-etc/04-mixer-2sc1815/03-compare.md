# 4-3 3 つのミキサーをシミュレーションで比べる — 変換利得・漏れ・P1dB

4-1 (2SC1815 の 1 石)・4-2 (2SC1815 の差動対)・3-1 (3SK291) の 3 つを、同じ仕様 (RF 0.53〜1.6 MHz、IF 455 kHz、電源 5 V) で**同じ手順で解析**して比べる。
比べる項目は、変換利得の LO 電力・RF 周波数・RF 電力への依存、LO と RF の漏れ、P1dB、電源電流。

> [!WARNING]
> **どれもシミュレーションだけで、実機では測っていない。** 2SC1815 は hFE・fT・Cob の目安から作った代用のモデル、
> 3SK291 も 3-2 の代用モデル。**代用モデルどうしの比較は傾向を見るためのもの**で、数値は実機で変わる。
> LTspice では解析していない (ngspice のみ)。

この題は実体配線図・Analog Discovery 3・オシロの図を付けない — シミュレーションの結果だけを見る題で、組む回路が無い (組む回路は 4-1・4-2・3-1 の図)。

## 解析の方法

- 道具: ngspice 39 (Debian の Docker イメージ)。ネットリストは SPICE の標準の素子だけで書いてある。再現は [sim/](sim/) の `lib.py` (回路の記述と FFT) と `main.py` (掃引) で、結果は [sim/results.json](sim/results.json)。1 石と差動対のネットリストは [sim/single.cir](sim/single.cir)・[sim/diff.cir](sim/diff.cir)
- 2SC1815 の代用モデル: IS = 2 × 10<sup>−14</sup>・BF = 250・VAF = 100・RB = 30 Ω・CJE = 8 pF・CJC = 2 pF・TF = 2 ns。**値は一般に知られた目安 (hFE 約 250・fT 約 80 MHz・Cob 約 2 pF) から作った仮定**で、データシートの本文は直接読んでいない
- 3SK291 は 3-2 の解析の値をそのまま使った (代用モデル。LO +7 dBm が標準)
- セラミックフィルタ (1 石のみ): 3-2 と同じ。1.5 kΩ・帯域 約 12 kHz の 3 次の LC 梯子 (実物の型番のモデルではない。阻止域は実物より深すぎる)
- 条件: RF −30 dBm (10 mV<sub>p</sub>)、LO 0 dBm (0.32 V<sub>p</sub>)、LO = RF + 455 kHz。**LO も RF も正弦波。信号源は 0 Ω (Wavegen と同じ)** で、振幅はポートの電圧 (50 Ω に整合した電力に相当) にした。過渡解析 1.4 ms の最後の 1 ms を FFT (ハニング窓)
- **変換利得 = IF の電圧 ÷ RF のポートの電圧** (dB)。1 石と 3SK291 は IF OUT が 50 Ω なので電力の利得と同じ値。**差動対は出力が 50 Ω ではない (3.3 kΩ ずつ)** ので、OUT A − OUT B の電圧の比で表す。3 つの値を並べて読めるが、差動対だけ電力の利得ではない
- 漏れ (LO・RF) は、1 石ではコレクタ (フィルタの前)、差動対では OUT A − OUT B (差)、で測った

## 結果の要約

| 項目 | 1 石 (4-1) | 差動対 (4-2) | 3SK291 (3-1) |
| --- | --- | --- | --- |
| 変換利得 (LO 0 dBm) | **+9.3 dB** | **+12.1 dB** (電圧の比) | −4.1 dB |
| 変換利得 (LO の標準) | +9.3 dB (0 dBm) | +12.1 dB (0 dBm) | +1.4 dB (+7 dBm) |
| LO が足りる下限 (利得が 2 dB 以内) | **−10 dBm** | **−10 dBm** | +4 dBm |
| LO を上げたとき | +7 dBm で +10.6 dB (緩やかに増える) | **+4 dBm 以上で下がる** (+7 dBm で +9.6 dB) | +10 dBm で +2.2 dB (増え続ける) |
| 中波内の変換利得の揺れ | 7.5〜9.6 dB (0.53 MHz で低い) | 12.1〜12.3 dB | 1.4 dB 前後 (±0.1 dB) |
| 入力 1 dB 圧縮点 (P1dB) | 約 −14 dBm | 約 −12 dBm | 約 0 dBm (モデルは楽観的) |
| LO の漏れ (フィルタの前で IF との差) | IF より +8.9 dB 高い | **差で +38 dB 高い** (消えない) | 3-2 のドレインの LO は 1.17 V<sub>p</sub> |
| RF の漏れ (フィルタの前で IF との差) | IF より +7.3 dB 高い | **差で −36 dB** (打ち消される) | 3-2 のドレインの RF は 52 mV<sub>p</sub> |
| 電源の電流 (信号なし) | 0.84 mA | 1.33 mA | 約 10 mA |
| 部品 | トランジスタ 1 本 | トランジスタ 3 本 | FET 1 個 (SMD) |
| 出力 | 50 Ω (フィルタ付き) | 差動 (フィルタ無し) | 50 Ω (フィルタ付き) |

- **1 石は LO が小さくて済む** (−5 dBm で利得がほぼ頭打ち) が、**コレクタに RF も LO も IF より高く出る**。IF のフィルタで落とす前提
- **差動対は RF が打ち消される** (差で IF より 36 dB 低い) が、**LO は消えない**。LO を大きくしすぎると打ち消しが浅くなり、+7 dBm ではほぼ消えない (4-2 の「注意」)
- **3SK291 は利得が小さく、LO が +7 dBm 要る**。LO を上げるほど利得が増え続ける。2 つのゲートで RF と LO を**別の入口**から入れるので、1 本のトランジスタのように RF と LO が同じ接合に入ることはない (漏れの大きさの比較は、3-2 がフィルタの後の値だけで、この表には並べられない)

## 確かめていないこと

- **実機との対応**: どのモデルも代用。特に 2SC1815 の利得 (+9〜12 dB) と P1dB は、hFE・fT・ベース抵抗の実物で変わる
- **LTspice での照合**: していない
- **差動対の打ち消しの深さ**: Q1・Q2 が同じモデルなので実物より深い。実物の 20〜30 dB を見込む
- **差動対で LO が +4 dBm を超えると打ち消しが浅くなる原因**: 解析で現象は確かめたが、切り分けていない
- **1 石の 0.53 MHz での利得低下の原因**: 未確認
- **3 つの比較の公平さ**: LO の標準が違う (2SC1815 は 0 dBm、3SK291 は +7 dBm)。図 1 は同じ軸に並べたので、LO を同じにした比較はそこで読む
- 前置の同調回路が無いので、影像や強い放送波の混変調は抑えられない (3-1 と同じ)
