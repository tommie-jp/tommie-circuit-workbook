# 3-2 ミキサーの特性をシミュレーションで見る — 変換利得・インピーダンス・FFT

[3-1](01-mixer.md) のミキサーを ngspice で解析した結果。変換利得の周波数特性、IF の通過特性、
LO 電力と G2 バイアスへの依存、入出力インピーダンス、出力の FFT、入出力特性を見る。

> [!WARNING]
> 3SK291 の SPICE モデルが無かったので、**代用のモデル**の上での値。利得・最適な G2・P1dB は
> 実機で変わる。変換利得の主な点 (LO +7 dBm、R7 あり・なし) は LTspice でも解析し、ngspice と 0.1 dB 以内で合った
> ([4-3](../04-mixer-2sc1815/03-compare.md) の「照合したこと」)。実機で測ったら、図のフェンスに `data:` で重ねる。

この題は実体配線図・Analog Discovery 3・オシロの図を付けない — シミュレーションの結果だけを見る題で、組む回路が無い (組む回路は 3-1 の図)。

## 解析の方法

- 道具: ngspice 42。ネットリストは SPICE の標準の素子だけで書いてあり、LTspice でも読める
  (変換利得を 2 点照合した。4-3)。[sim/mixer.cir](sim/mixer.cir) に置いた
- 3SK291 の代用モデル: Level 1 の N チャネル MOSFET を 2 つ直列 (M1 が G1 側、M2 が G2 側)
- データシートに合わせた値 (出典は 3-1): VDS = 6 V・VG2S = 4.5 V・ID = 10 mA のとき |Yfs| = 26 mS、
  Ciss = 2 pF、Crss = 0.016 pF
- **仮定した値** (出典なし): しきい値 0.4 V、λ = 0.03、G2 側の容量、M2 の寸法
- セラミックフィルタ: 1.5 kΩ・帯域 約 12 kHz・Q 約 1500 の 3 次の LC 梯子に置き換えた
  (実物の型番のモデルではない。阻止域は実物より深すぎる)
- 条件: RF −30 dBm、LO +7 dBm (どちらも 50 Ω の有能電力、**LO も RF も正弦波**。LO を方形波にした解析はしていない)、LO = RF + 455 kHz。過渡解析 1.4 ms の最後の 1 ms を FFT
- 変換利得 = IF OUT の 455 kHz の電力 (50 Ω 負荷) − RF の有能電力。基準は整合した 50 Ω の源がポートに作る電圧なので、RF 側の 51 Ω の分圧による約 6 dB の減衰は含まない (信号源の起電力を基準にすれば 6 dB 小さく出る)。1 石・差動対と同じ条件にそろえて比べ直した値は [4-3](../04-mixer-2sc1815/03-compare.md) の「3SK291 の利得が小さい理由」
- 入出力インピーダンスはバイアス点の小信号 AC 解析 (LO を加えたときの時間変化は含まない)
- 再現: [sim/](sim/) の `main2.py` と `ac.py` を回し、`export_points.py` で下の点列を書く

### LO が小さいと G2 の最適が上へずれる理由

LO 0 dBm では、G2 の最適が 1.41 V から 1.6 V 付近へずれる (4-3 の表)。M1 (G1 側) の動作点と g<sub>m</sub> の波形を解析で取り出して確かめた。
再現は [sim/r7_g2_probe.py](sim/r7_g2_probe.py) (結果は [sim/r7_g2_probe.json](sim/r7_g2_probe.json)。信号源 0 Ω、出力は短絡して IF の電流を測った)。

2 段の FET の中点 (M1 のドレイン) の電圧は、G2 の電圧から M2 の V<sub>GS</sub> を引いた所に来る。
M1 は中点が V<sub>G1</sub> − V<sub>T</sub> (0.84 V) より低いと三極管領域にいて、g<sub>m</sub> が中点の電圧に比例して小さい。高いと飽和で、g<sub>m</sub> は最大で一定になる。
LO は G2 から中点を振り、**M1 の g<sub>m</sub> を LO の周期で変える。この g<sub>m</sub> の振れが変換を起こす**。

| G2 | LO | 中点の振れ | M1 が飽和にいる時間 | g<sub>m1</sub> の LO の成分 | 変換コンダクタンス G<sub>c</sub> |
| --- | --- | --- | --- | --- | --- |
| 1.2 V | 0 dBm | 0.15〜0.56 V | 0 % | 7.0 mS | 3.1 mS |
| 1.41 V | 0 dBm | 0.26〜0.74 V | 0 % | 8.1 mS | 4.3 mS |
| **1.6 V** | 0 dBm | 0.38〜0.92 V | 22 % | 8.5 mS | **5.4 mS** |
| 1.8 V | 0 dBm | 0.53〜1.12 V | 46 % | 5.8 mS | 4.0 mS |
| 2.0 V | 0 dBm | 0.69〜1.31 V | 67 % | 2.2 mS | 1.7 mS |
| 1.2 V | +7 dBm | 0.01〜0.91 V | 14 % | 15.1 mS | 7.4 mS |
| **1.41 V** | +7 dBm | 0.07〜1.12 V | 29 % | 14.9 mS | **8.0 mS** |
| 1.6 V | +7 dBm | 0.15〜1.31 V | 39 % | 13.3 mS | 7.6 mS |
| 1.8 V | +7 dBm | 0.26〜1.50 V | 48 % | 10.8 mS | 6.6 mS |
| 2.0 V | +7 dBm | 0.39〜1.70 V | 57 % | 7.8 mS | 5.1 mS |

- G<sub>c</sub> は g<sub>m1</sub> の LO の成分のほぼ 0.5〜0.65 倍で、山の位置もほぼ同じ (LO 0 dBm で 1.5〜1.6 V、+7 dBm で 1.3〜1.4 V)
- **G<sub>c</sub> が最大になるのは、中点の振れの上端が飽和の境目 (0.84 V) を少し越え、M1 が 1 周期の 2〜3 割だけ飽和にいる所**。
  三極管領域だけで振れると g<sub>m</sub> の振れが小さく、飽和にいる時間が長いと g<sub>m</sub> が一定の時間が増えて振れが減る
- LO 0 dBm では中点の振れが ±0.24 V と小さく、G2 1.41 V では上端 (0.74 V) が境目に届かない。G2 を 1.6 V に上げると上端が境目を越え、最大になる。
  LO +7 dBm では振れが ±0.53 V あり、1.41 V で既に越えている。**最適の G2 が LO で変わるのは、振れの幅が LO で変わるから**
- 「LO で平均のドレイン電流が変わるから」という見方は主因ではない。LO 0 dBm・G2 1.41 V の平均の電流は 9.5 mA で、LO の無いときの 9.8 mA とほとんど同じ
- 代用モデル (Level 1 の平方則) の上の話で、実物の境目の電圧と g<sub>m</sub> の形は違う。実機では G2 を LO の大きさに合わせて探し直す

## 出力の FFT

RF 1.000 MHz (−30 dBm) + LO 1.455 MHz (+7 dBm) を入れたときのスペクトル (1 ms の窓、分解能 約 1.5 kHz)。

| 成分 | 周波数 | ドレイン (フィルタの前) | IF OUT (フィルタの後) |
| --- | --- | --- | --- |
| **IF (LO − RF)** | **455 kHz** | −13.0 dBm 相当 (71 mV) | **−28.6 dBm (11.7 mV)** |
| RF | 1.000 MHz | −15.7 dBm 相当 (52 mV) | −120 dBm 以下 |
| LO | 1.455 MHz | +11.4 dBm 相当 (1.17 V) | −120 dBm 以下 |
| LO + 455 kHz (影像側) | 1.910 MHz | −49.9 dBm 相当 (1.0 mV) | −120 dBm 以下 |
| RF + LO | 2.455 MHz | −30.4 dBm 相当 (9.6 mV) | −120 dBm 以下 |
| 2 × LO | 2.910 MHz | −7.5 dBm 相当 (133 mV) | −120 dBm 以下 |

ドレインの値は 50 Ω に換算した電力 (ドレインは 50 Ω ではない)。ドレインには LO が波高値 1.17 V 出る。
**フィルタの後の −120 dBm 以下は、モデルのフィルタが理想的な LC 梯子で深すぎる値**。
実物のセラミックフィルタの阻止域は数十 dB 程度のはずで (未確認)、RF・LO はもっと高く出る。

## 解析で直した 3 点

1. **G2 の電圧 (4.5 V → 1.41 V)**: 最初の設計は G2 をデータシートの測定条件の 4.5 V にして、変換利得が −27 dB まで落ちた (図 4)
2. **ドレインの同調 (1 mH・120 pF → 220 µH・560 pF)**: 前者は RF の周波数で利得が約 5 dB 揺れた (電源 6 V の設計のとき)。
   後者はドレインが RF・LO に低いインピーダンスを見せて、帯域内の揺れが 0.1 dB に収まった
3. **フィルタの終端 (R7 = 2 kΩ を追加)**: R7 が無いと IF OUT は 6.6 − j12.6 Ω (リターンロス 2 dB) で 50 Ω にならなかった。
   1.5 kΩ ではリターンロス 20 dB、3 kΩ では 14 dB で、2 kΩ が最もよかった。代わりに変換利得は約 5 dB 下がる (+6.3 dB → +1.2 dB。信号源 0 Ω、LO +7 dBm)。
   R7 を外すと通過帯域の形も崩れる (下の図 7)

RF を動かして IF を 435〜475 kHz に振った。R7 を外すと、中心の利得は 5 dB 上がるが、帯域が 3 割狭まって頭が丸くなり、**±20 kHz の阻止が 10 dB 以上浅くなる** (隣の放送局を落としにくい)。
フィルタの源のインピーダンス (1.5 kΩ が規定) が決まらず、フィルタが規定の形で働かないため。R7 は残す。
再現は [sim/r7_g2_probe.py](sim/r7_g2_probe.py)。モデルのフィルタは理想の LC 梯子なので、実物のセラミックフィルタでの形は未確認

## 確かめていないこと

- **LTspice での照合**: 変換利得の 2 点 (LO +7 dBm、R7 あり・なし) だけ照合し、ngspice と 0.1 dB 以内で合った (+1.24 / +1.20 dB、+6.27 / +6.20 dB)。
  G2・LO の掃引、インピーダンス、FFT は ngspice だけ。どちらも同じ代用モデルを解いたもので、モデルの正しさの照合ではない
- **3SK291 の実測との対応**: 代用モデルの λ・しきい値・G2 側の容量・膝の位置は仮定。
  利得・最適な G2・P1dB は実機で値が変わる
- **G1 の電圧**: データシートの ID–VG1S の図を**読めていない**。1.24 V は代用モデルで ID = 10 mA になる値で、
  VR1 で合わせる前提
- **セラミックフィルタ**: 型番ごとの入出力インピーダンス・通過帯域・阻止域は未確認
- **3SK291 の型**: RS の掲載情報は「Depletion」だが、データシートの IDSS が最大 0.1 mA であることと、
  複数のブログの記述から**エンハンスメント型**と判断した。データシート本文は直接読めていない
- 前置の同調回路が無いので、影像や強い放送波の混変調は抑えられない
