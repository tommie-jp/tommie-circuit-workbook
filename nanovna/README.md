# NanoVNA の教科書

NanoVNA で 10 kHz〜4.4 GHz を測る。校正と画面 (第 1〜2 章)、治具 (第 3 章) から
始めて、部品 → 伝送線路 → フィルタ → アンテナ → アンプと測る物を広げ、第 9 章で
GHz 帯の作法をまとめる。

- **機種の印**: H4 = NanoVNA-H4 (〜1.5 GHz。V2 でもできる)、V2 = NanoVNA V2
  (〜3 / 4.4 GHz。1.5 GHz より上で要る)。**必須の題は全部 H4 でできる**
- **板の印**: PF = perfboard + 端面 SMA の治具 (300 MHz くらいまでが目安)、
  銅 = 銅張り基板・マイクロストリップの治具 (それより上)、— = 治具なし
  (ケーブルやアンテナを直に繋ぐ)
- **安全**: CH1 に入れてよい電力を超えない (アンプの出力にはアッテネータを挟む)。
  アンテナは放電してから繋ぐ。SMA は締めすぎない
- 10 MHz より下の時間波形・FFT・ボード線図は
  [Analog Discovery の教科書](../analog-discovery/README.md) で測る
