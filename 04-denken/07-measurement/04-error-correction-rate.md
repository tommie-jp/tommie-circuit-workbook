# 7-4 誤差率と補正率 — 1 % の抵抗を測って計算する

計器で測った**測定値**と、本当の**真の値**とのずれを、誤差・誤差率・補正・
補正率という 4 つの言葉で表す。1 % 級の抵抗 (公称 1 kΩ) を、7-3 と同じ
「電流計が先」のつなぎ方で測り、電流計自身の抵抗による誤差から計算する。

## この実験で確かめる式

| 式 | 意味 |
| --- | --- |
| 誤差 = 測定値 − 真の値 | 測ったときのずれ (符号つき) |
| 誤差率 = 誤差 / 真の値 × 100 % | 真の値を基準にした割合 |
| 補正 = 真の値 − 測定値 (= −誤差) | 測定値を真の値に直すために足す量 |
| 補正率 = 補正 / 測定値 × 100 % | **測定値を基準**にした割合 (誤差率と分母が違う) |

## 回路図

```circuit
title: 図1 電流計が先で Rx を測る
parts:
  V1: vsource a1 c1 5
  Rlim: resistor a1 a5 4k
  Ra: resistor a5 a9 8 i=I
  Rx: resistor a9 a13 1k
  G1: ground c1
wires:
  - c1 -- c13
  - a13 -- c13
style:
  standard: jis
  grid: on
```

- R_x は公称 1 kΩ (1 % 級) の抵抗。あらかじめ精密な方法 (7-10 の 4 端子法など)
  で真の値を測ると **992 Ω** だったとする (公称の −0.8 %、1 % の規格内)
- R_a (8 Ω) は電流計の内部抵抗の模型。7-3 の「電流計が先」と同じつなぎ方で、
  電圧計は R_a + R_x の両端 (a5、GND 基準) にかける
- R_lim (4 kΩ) は電流を程よい大きさに抑える抵抗

## 実体配線図

```breadboard
title: 図2 ブレッドボードと Analog Discovery
board: half
parts:

  Ra: resistor e7 e11 8R
  Rx: resistor c11 c15 1k
  AD:
    type: device
    at: top
    label: Analog Discovery
    pins: [V+, GND, 1+, 1-, 2+, 2-]

  - AD.V+ -- +t4 red
  - +t3 -- a3 red

  - AD.1- -- a11 green

  - AD.2- -- -t19 black
```

- CH1 (差動) は R_a (8 Ω) の両端で電流を読む。CH2 は R_a + R_x の両端
  (GND 基準) で電圧計の読みになる

## 計器の設定

| 計器 | 設定 |
| --- | --- |
| Supplies | V+ = 5 V |
| Scope | CH1 = R_a の両端 (差動、電流)、CH2 = R_a + R_x の両端 (GND 基準、電圧計の読み) |

### オシロスコープと発振器

汎用の計器での読み替えは[回路の本の 0-3](../../01-circuits/00-measure/03-oscilloscope.md) と
[0-6](../../01-circuits/00-measure/06-bench-supply-limiting.md)。この題は直流なので発振器は使わない。

AD の CH1 は R_a の両端 (8 mV) を差動で挟んでいる。CH2 (1.000 V) の 1 % にも満たないので、
2 本の先端で引く方法は使えない。7-3 と同じく **R_a を GND 側へ移し** (R_x と R_a の順を
入れ替え)、CH1 の 1 本で直に読む (図3)。回路図は図1 (電流計が上) から変わるが、
直列の順を入れ替えただけなので、電流 (1.000 mA) も CH2 (R_a + R_x の両端、1.000 V) も変わらない。

```circuit
title: 図3 汎用オシロでの測り方
parts:
  V1: vsource b2 f2 5
  Rlim: resistor b2 b4 4k
  M2: voltmeter b5 f5 l=$\mathrm{CH2}$
  Rx: resistor b7 d7 1k
  Ra: resistor d7 f7 8 i=I
  M1: voltmeter d9 f9 l=$\mathrm{CH1}$
  G1: ground f2
wires:
  - b4 -- b5 -- b7
  - d7 -- d9
  - f2 -- f5 -- f7 -- f9
style:
  standard: jis
  pitch: 1.3
```

- ブレッドボードは R_a (e7–e11) と R_x (c11–c15) を入れ替え、7〜11 列に R_x、11〜15 列に
  R_a を挿す。11 列が R_x と R_a の間になる
- AD の 1+ (a7) と 1− (a11) の線を外し、CH1 の先端を 11 列に当てる。CH2 の先端は 17 列
  (橙の線で 7 列とつながったまま)。グランドクリップはどちらも − レール
- 電源は安定化電源 5 V、電流制限 10 mA (流れるのは 1.0 mA)。入力の結合は DC、Measure の Mean で読む

**この題の誤差 (+0.8 %) は、汎用オシロでは読み分けられない。** 直流の確度が数 % ある機種が
多く (仕様を見る)、8 mV の CH1 はオフセットの数 mV にも左右される。オシロは配線と桁の確かめに
使い、値は 8 mV を 0.01 mV まで読めるテスターの直流電圧で、11 列と 7 列を
− レールに対して読む。

## 見るべき値

計算値。真の値 T = 992 Ω、R_lim = 4 kΩ、R_a = 8 Ω としたときの
電流は I = 5 V ÷ (4000 + 8 + 992) = 1.000 mA (きれいな値になるように選んである)。

| 測る所 | 期待する値 |
| --- | --- |
| CH1 (電流) | 1.000 mA |
| CH2 (電圧計の読み) | 1.000 V |
| 測定値 M (= CH2 / CH1) | 1000 Ω |
| 真の値 T (あらかじめ分かっている) | 992 Ω |
| 誤差 (= M − T) | +8 Ω |
| 誤差率 (= 誤差 / T × 100) | +0.81 % |
| 補正 (= T − M) | −8 Ω |
| 補正率 (= 補正 / M × 100) | −0.80 % |

分かること:

- **誤差の正体は電流計の内部抵抗 R_a そのもの。** 測定値 M = R_a + T = 8 + 992
  = 1000 Ω と、電流計の抵抗を測定物にそのまま足した形になる (7-3 の式と同じ)
- **誤差率と補正率は分母が違うので、値も少し違う** (+0.81 % と −0.80 %)。
  値が小さいうちは近い数字になるが、混同しないよう式を確認する
- この抵抗は表示 1 kΩ・1 % 級で、真の値 992 Ω は表示から −0.8 % — 規格の
  ±1 % の中に収まっている。**測定の誤差率 (+0.81 %) は抵抗自体の精度とは
  別物**で、電流計の抵抗を測定物の抵抗に足してしまったことによる
