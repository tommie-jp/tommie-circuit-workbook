# 8-4 効率 — 負荷を変えて最大効率 (鉄損 = 銅損)

変圧器の損失は、負荷によらずほぼ一定の**鉄損**と、負荷電流の 2 乗で増える**銅損**の 2 つに分かれる。
軽い負荷では鉄損が、重い負荷では銅損が効くので、効率はその間のどこかで最大になる。
8-1〜8-3 と同じ小型トランス (10 kΩ:8 Ω) の 2 次に抵抗を替えてつなぎ、出力を測って、
8-2 の鉄損と 8-3 の等価抵抗から効率を出す。**効率が最大になるのは銅損が鉄損に等しい所**であることを確かめる。

## この実験で確かめる式

| 式 | 意味 |
| --- | --- |
| P2 = V2² / RL | 出力。2 次の電圧 V2 (実効値) と負荷 RL から |
| Pc = I2² × Req2 | 銅損。I2 は 2 次の電流 (= V2 / RL)、Req2 は 2 次に換算した巻線抵抗 |
| η = P2 / (P2 + Pi + Pc) | 効率 (規約効率)。損失を測った値から計算する |
| Pc = Pi のとき η が最大 | 最大効率の条件。そのときの電流は I2 = √(Pi / Req2) |

この題の値 (8-2・8-3 の計算値を使う):

| 量 | 値 | どこから |
| --- | --- | --- |
| 鉄損 Pi | 1.05 µW | 8-2 の P0 (1 次に振幅 2 V、1 kHz) |
| 等価抵抗 Req (1 次換算) | 925 Ω | 8-3 |
| Req2 = Req / n² | 0.74 Ω | n² = 10000 / 8 = 1250 |
| 最大効率の電流 I2 = √(Pi / Req2) | 1.19 mA (実効値) | 負荷にすると RL ≒ 33 Ω |

- W1 は AD の波形発生器 (Wavegen)。1 kHz、振幅 2 V。8-2 の無負荷試験と同じ電圧にする
  (鉄損は電圧で決まるので、8-2 の Pi がそのまま使える)
- 8-1 と違い、1 次にシャントを入れない。W1 の出力抵抗はほぼ 0 Ω なので、V1 は負荷によらず 2 V に保たれる
- RL は 3.3・8・33・100・330 Ω に替える。8 Ω は 8-1 と同じく 16 Ω を 2 本並列にして作る
- M1 (CH1) は RL の両端 (V2)、M2 (CH2) は 1 次巻線の両端 (V1)。V1 は 2 V のままかを見るだけ

- T1 は 8-1 と同じ挿し方。1 次 (10 kΩ 側) を上のブロックの 15・18 列、2 次 (8 Ω 側) を下のブロックの 15・18 列

## 計器の設定

| 計器 | 設定 |
| --- | --- |
| Wavegen | W1: Sine、1 kHz、Amplitude 2 V |
| Scope | CH1 = RL の両端 (V2、差動)。CH2 = 1 次巻線の両端 (V1) |
| Measure | CH1・CH2 の Amplitude。V2 は数十 mV なので Average を 16 回にして雑音を減らす |

RL を 5 通りに替え、そのたびに V2 を読む。表の計算で使うのは実効値 (振幅 ÷ √2)。

RL = 33 Ω (最大効率の所) の画面。V2 は V1 の 1/36 ほどなので、CH1 だけ 20 mV/div に上げてある。

### オシロスコープと発振器

汎用の計器での読み替えは[回路の本の 0-3](../../01-circuits/00-measure/03-oscilloscope.md) と
[0-6](../../01-circuits/00-measure/06-bench-supply-limiting.md)。

CH2 (V1) は GND 基準で、先端を 15 列 (上のブロック)、グランドクリップを青レールに当てる。
CH1 (V2) は 2 次の両端を差動で挟んでいるが、2 次は 1 次から絶縁されていて、どこにもつながっていない。
そこで 8-1 の 2 回目と同じく、**CH1 のグランドクリップを 2 次の片側 (j15) の 1 か所にだけ当て**、先端を j18 に当てる。
2 次が 1 点で大地につながるだけなので、電流の輪はできない。2 次の両端にクリップを当てると 2 次が短絡する。

- W1 は FG の OUT (High-Z、Sine、1 kHz、振幅 2 V。Vpp で入れる機種なら 4 Vpp)。FG の GND は青レール
- FG から見た負荷は、一番重い RL = 3.3 Ω でも 1 次で約 5 kΩ (3.3 Ω × 1250 + 925 Ω)。FG の 50 Ω で V1 が
  下がるのは 1 % ほど (計算値)。V1 は CH2 で読んでいるので、下がった分は読みで分かる
- CH1 は 20 mV/div (55 mV の山を 10 mV/div にすると画面の外に出る)、Average を 16 回以上。8 bit のオシロでは 55 mV の読みに ±1 mV ほどの幅が残る。
  効率の差 (1 %) より V2 の読みの幅 (2 %) のほうが大きいので、V2 は Measure の RMS を 10 回ほど読んで平均する

## 見るべき値

計算値。8-3 の Req = 925 Ω・Xeq = 300 Ω と 8-2 の励磁アドミタンスを使った等価回路で計算した。
Pi は 8-2 の値 (1.05 µW) を全部の行で同じに使う。

| RL | V2 (振幅) | I2 (実効値) | P2 | Pc | η |
| --- | --- | --- | --- | --- | --- |
| 無負荷 | 56.6 mV | 0 | 0 | 0 | 0 % |
| 3.3 Ω | 46.1 mV | 9.88 mA | 322 µW | 72.3 µW | 81.5 % |
| 8 Ω | 51.8 mV | 4.58 mA | 167 µW | 15.5 µW | 91.0 % |
| 33 Ω | 55.3 mV | 1.19 mA | 46.4 µW | 1.04 µW | **95.7 %** (最大) |
| 100 Ω | 56.2 mV | 0.397 mA | 15.8 µW | 0.117 µW | 93.1 % |
| 330 Ω | 56.4 mV | 0.121 mA | 4.83 µW | 0.011 µW | 82.0 % |

- **RL = 33 Ω で Pc (1.04 µW) が Pi (1.05 µW) とほぼ等しく、η が最大 (95.7 %)** になる。
  それより重い負荷 (RL が小さい) では銅損が、軽い負荷では鉄損が効率を下げる
- 8 Ω (このトランスの定格の負荷) での銅損は 15.5 µW。最大効率になる負荷の割合は
  √(Pi / Pc) = √(1.05 / 15.5) ≒ 0.26 で、**定格の約 26 % の負荷で効率が最大**になる。
  電験の式「最大効率の負荷率 = √(鉄損 / 全負荷銅損)」と同じ形
- 無負荷の V2 (56.6 mV) から、負荷をつなぐと V2 が下がる。この下がり方が 8-5 の電圧変動率

実物の小型トランスで測ると、鉄損がこの模型と違えば最大の位置も動く。**どこで最大になっても、
その所で Pc ≒ Pi になっていること**を確かめる。効率を V1 × I1 から直に測る方法 (入力 − 出力) は、
差が数 µW しか無く、測った値の誤差に埋もれる。損失を別々に測って効率を出すのはそのため
(試験の「規約効率」がこれ)。
