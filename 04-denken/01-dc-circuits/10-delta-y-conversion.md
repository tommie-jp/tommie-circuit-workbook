# 1-10 Δ-Y 変換 — 端子間の抵抗が同じになることを測る

3 本の抵抗を三角につないだ **Δ (デルタ) 結線**と、1 点から 3 本を出した **Y (スター) 結線**は、
値を決めれば**外の 3 つの端子から見て区別できない**。Δ のままでは直列にも並列にもほどけない回路
(ブリッジなど) も、一部を Y に置き換えるとほどける。Δ と Y を同じブレッドボードに組み、端子の間の抵抗と、電圧を
掛けたときの電圧が同じになることをテスターで確かめる。三相の負荷の Y-Δ 変換 (4-7) の直流版。

## この実験で確かめる式

| 式 | 意味 |
| --- | --- |
| Ra = Rab Rca / (Rab + Rbc + Rca) | Δ → Y。端子 A につく Y の抵抗は、A を挟む Δ の 2 本の積を 3 本の和で割る |
| Rb = Rab Rbc / Σ、Rc = Rbc Rca / Σ | B・C も同じ形 |
| R_Y = R_Δ / 3 | 3 本が等しいときは 1/3 |
| R_AB = Rab // (Rbc + Rca) = Ra + Rb | 端子 A-B の間の抵抗 (C は開放)。Δ と Y で等しい |

## 回路図

```circuit
title: 図1 デルタ結線 (左) とスター結線 (右)
style:
  standard: jis
  pitch: 1.2
parts:
  Rab: resistor c2 h2 1.1k
  Rca: resistor c8 h8 4.7k
  Rbc: resistor h4 h6 4.3k
  Ra: resistor c15 f15 510
  Rb: resistor f15 f12 470
  Rc: resistor f15 f18 2k
wires:
  - c2 -- c5 -- c8
  - b5 -- c5
  - h2 -- h4
  - h6 -- h8
  - h2 -- i2
  - h8 -- i8
  - b15 -- c15
  - f12 -- i12
  - f18 -- i18
notes:
  - text b5 left: A
  - text i2 left: B
  - text i8 left: C
  - text b15 left: A
  - text i12 left: B
  - text i18 left: C
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/04-denken/01-dc-circuits/circuit/10-delta-y-conversion.svg)

- 左が Δ: Rab = 1.1 kΩ (A-B)、Rbc = 4.3 kΩ (B-C)、Rca = 4.7 kΩ (C-A)。3 本の和は 10.1 kΩ
- 右が Y: 変換の式で Ra = 1.1 × 4.7 / 10.1 = 512 Ω、Rb = 1.1 × 4.3 / 10.1 = 468 Ω、
  Rc = 4.3 × 4.7 / 10.1 = 2.00 kΩ。E24 の **510 Ω・470 Ω・2 kΩ** にした (ずれは 0.4 % 以内)
- A・B・C が外へ出る端子。Δ と Y の同じ名前の端子どうしを比べる

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| Rab・Rbc・Rca | 抵抗 (1/4 W) | 1.1 kΩ・4.3 kΩ・4.7 kΩ |
| Ra・Rb・Rc | 抵抗 (1/4 W) | 510 Ω・470 Ω・2 kΩ |
| — | 電源 | 5 V (USB の 5 V か単 3 電池 3 本)。電圧で確かめる段だけ使う |

3 本とも等しい組 (Δ に 3.3 kΩ を 3 本、Y に 1.1 kΩ を 3 本) もあれば、R_Y = R_Δ / 3 を確かめられる。

## 実体配線図

```breadboard
title: 図2 Δ (3〜13 列) と Y (18〜29 列)
board: half
parts:
  Rab: resistor a3 a8 1.1k
  Rbc: resistor c8 c13 4.3k
  Rca: resistor e3 e13 4.7k
  Ra: resistor a18 a22 510
  Rb: resistor c22 c26 470
  Rc: resistor e22 e29 2k
notes:
  - text: "Δ の端子: A = 3 列、B = 8 列、C = 13 列"
  - text: "Y の端子: A = 18 列、B = 26 列、C = 29 列 (22 列が Y の中心)"
```

![ブレッドボードの実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/04-denken/01-dc-circuits/breadboard/10-delta-y-conversion.svg)

- Δ は 3 列 (A)・8 列 (B)・13 列 (C) の 3 列で 3 本がつながる。Rca は 3 列から 13 列まで長く渡す
- Y は 22 列が中心の点。Ra・Rb・Rc の片方のピンがすべて 22 列に入る
- 線は 1 本も要らない。テスターの棒を端子の列に当てる

## 計器の設定

| 計器 | 設定 |
| --- | --- |
| テスター (抵抗) | 抵抗レンジ (4 kΩ か 20 kΩ)。端子の組 (A-B、B-C、C-A) に当てる。電源はつながない |
| テスター (電圧) | 直流電圧レンジ (20 V)。5 V の + を端子 A、− を端子 B につなぎ、端子 C と B の間を読む |

電圧の段では、電源の + を A の列、− を B の列に線でつなぐ (Δ と Y を順に)。AD は使わない。

## 見るべき値

計算値。Y は E24 に丸めた値 (510・470・2000 Ω) で計算した。

| 測る所 | Δ | Y | 分かること |
| --- | --- | --- | --- |
| R_AB (C は開放) | 980 Ω | 980 Ω | 1.1k // 9.0k = 510 + 470 |
| R_BC (A は開放) | 2.47 kΩ | 2.47 kΩ | 4.3k // 5.8k = 470 + 2000 |
| R_CA (B は開放) | 2.51 kΩ | 2.51 kΩ | 4.7k // 5.4k = 2000 + 510 |
| A と、B・C をつないだ点の間 | 891 Ω | 891 Ω | 1.1k // 4.7k = 510 + 470 // 2000。3 つめの端子を使っても同じ |
| A に 5 V、B を 0 V、C の電圧 | 2.39 V | 2.40 V | Δ は Rca と Rbc の分圧、Y は Ra と Rb の分圧 (C に電流は流れない) |
| そのとき電源から出る電流 | 5.10 mA | 5.10 mA | 5 V / 980 Ω |
| 3 本が等しい組 (3.3k と 1.1k) の R_AB | 2.20 kΩ | 2.20 kΩ | 3.3k // 6.6k = 1.1k + 1.1k |

分かること:

- **端子の 3 つの組のどれで測っても、Δ と Y の抵抗は同じになる。** 1 組だけ合うのではなく
  3 組とも合うので、外から見て区別できない。変換の式は、この 3 組の等式を解いたもの
- 3 つめの端子に電流を流す使い方 (A と B・C の間) でも同じになる。等価は「端子の開放」だけの話ではない
- 電圧の段の 2.39 V と 2.40 V の差 (0.4 %) は、Y を E24 に丸めた分。抵抗の誤差 (5 % 品なら ±5 %) の方が大きい
- 使い方: ブリッジ (1-6) で平衡していないとき、上の 3 本を Δ → Y に置き換えると、あとは直列と並列だけで
  合成抵抗が出る。三相の負荷 (4-7) では、Δ の負荷を 1/3 の Y に置き換えて 1 相分で計算する
