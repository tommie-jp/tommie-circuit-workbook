# 1-8 最大電力の伝達 — 負荷抵抗 = 内部抵抗

内部抵抗 r のある電源に負荷 RL をつなぐと、RL を小さくすれば電流は増えるが電圧は下がり、RL を大きく
すれば電圧は上がるが電流は減る。負荷が受け取る電力 P = V I は、その間のどこかで最大になる。
その点が **RL = r** であることを、抵抗 7 本を挿し替えて確かめる。

内部抵抗は、電池の本物の r (1-7、0.2 Ω ほど) では小さすぎて負荷が熱くなるので、5 V の電源に
220 Ω を直列に入れて**内部抵抗の役**をさせる。1-5 のテブナンの等価回路を、そのまま組んだ形。

## この実験で確かめる式

| 式 | 意味 |
| --- | --- |
| P = V² / RL = E² RL / (r + RL)² | 負荷の電力 |
| RL = r のとき P_max = E² / (4 r) | 最大電力の伝達の条件。負荷の電圧は E / 2 |
| η = RL / (r + RL) | 効率。電源が出す電力のうち負荷に渡る割合。最大電力のときは 50 % |

## 回路図

```circuit
title: 図1 内部抵抗 r の電源と負荷 RL
style:
  standard: jis
  pitch: 1.2
parts:
  E1: vsource d2 h2 5 l=$E$
  Ri: resistor d2 d4 220 l=$r$
  RL: resistor d7 h7 l=$\mathrm{R_L}$
  V1: voltmeter d9 h9
wires:
  - d4 -- d7 -- d9
  - h2 -- h7 -- h9
notes:
  - box c1f5 h5 blue
  - text i3 blue: 電源 (テブナンの等価回路)
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/04-denken/01-dc-circuits/circuit/08-maximum-power-transfer.svg)

- 点線の枠が電源。E = 5 V (USB の 5 V か単 3 電池 3 本)、r = 220 Ω (本物の抵抗)
- RL は 47・100・150・220・330・470・1000 Ω の 7 段を挿し替える
- V1 (テスターの直流電圧レンジ) で RL の両端を読み、電流と電力は計算で出す (I = V / RL、P = V² / RL)

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| r | 抵抗 (1/4 W) | 220 Ω (RL = 47 Ω のとき 77 mW で一番大きい) |
| RL | 抵抗 (1/4 W) | 47・100・150・220・330・470 Ω・1 kΩ (どれも 30 mW 以下) |
| — | 電源 | 5 V (USB の 5 V か単 3 電池 3 本) |

単 3 電池 3 本 (4.5 V) にすると、電圧は 0.9 倍、電力は 0.81 倍になる。電池の本物の内部抵抗 (3 本で 0.6 Ω
ほど) は 220 Ω に比べて小さく、結果にほぼ効かない。

## 計器の設定

| 計器 | 設定 |
| --- | --- |
| テスター | 直流電圧レンジ (20 V)。RL の両端 (12 列と 18 列)。0.01 V の桁まで読む |

電流計は入れない。RL の値は挿す前に抵抗レンジで測っておき、I = V / RL を実測の RL で計算する。AD は使わない。

## 見るべき値

計算値 (E = 5 V、r = 220 Ω)。

| RL | V (V1) | I = V / RL | P = V² / RL | 効率 η |
| --- | --- | --- | --- | --- |
| 47 Ω | 0.88 V | 18.7 mA | 16.5 mW | 17.6 % |
| 100 Ω | 1.56 V | 15.6 mA | 24.4 mW | 31.2 % |
| 150 Ω | 2.03 V | 13.5 mA | 27.4 mW | 40.5 % |
| 220 Ω | 2.50 V | 11.4 mA | **28.4 mW** (最大) | 50.0 % |
| 330 Ω | 3.00 V | 9.09 mA | 27.3 mW | 60.0 % |
| 470 Ω | 3.41 V | 7.25 mA | 24.7 mW | 68.1 % |
| 1 kΩ | 4.10 V | 4.10 mA | 16.8 mW | 82.0 % |

電力と効率を RL の対数の横軸に描くと図3 になる。電力は RL = r = 220 Ω で山になり、山の左右はほぼ
対称 (47 Ω と 1 kΩ は r の約 1/4.7 倍と 4.5 倍で、電力はどちらも 16〜17 mW)。

```graph
title: 図3 負荷の電力は RL = 220 Ω で最大、そのとき効率は 50 %
x: 負荷抵抗 Ω log 20..2k
y:
  - 負荷の電力 mW 0..30
  - 効率 % 0..100
lines:
  負荷の電力 mW: 25 * x / (220 + x)^2 * 1000
  効率 %: 100 * x / (220 + x)
notes:
  - mark 47
  - mark 220
  - mark 1000
```

![グラフ](https://tommie-jp.github.io/tommie-circuit-workbook/04-denken/01-dc-circuits/graph/08-maximum-power-transfer.svg)

分かること:

- **P の最大は 28.4 mW、そのとき RL = r、V = E / 2 = 2.50 V。** 表の 150 Ω と 330 Ω でも 27 mW 台で、
  山の頂上は平ら。最大の所をはっきり見るには RL を細かく刻む
- **最大電力のときの効率は 50 %。** 電源の中の r でも同じ 28.4 mW が熱になる。電力系統は効率が大事なので、
  負荷を r よりずっと大きくして使う (効率 90 % 以上)。最大電力の伝達を狙うのは、アンテナや
  スピーカーのように信号の電力を少しでも多く取りたい所 (整合)
- 1-5 の回路 (5 V、1.5 kΩ と 3 kΩ) なら、r = R1 // R2 = 1 kΩ で、RL = 1 kΩ のときに最大になる
  (P_max = 3.33² / (4 × 1 kΩ) = 2.78 mW)
