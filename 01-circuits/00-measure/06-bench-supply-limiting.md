# 0-6 安定化電源とファンクションジェネレータ — 電流制限を掛けて実験する

実験用の安定化電源 (バイポーラ電源、ラボ電源) は電圧を決めるだけでなく
**電流制限 (CC、Constant Current)** を掛けられる。負荷が小さい (抵抗が小さい)
うちは決めた電圧をそのまま出す **CV (Constant Voltage)** で動き、電流が
制限値に達すると電圧を下げてでも電流を制限値に抑える。配線を間違えたときの
保険として、電源を入れる前に**電流制限を低めに決めておく**のが実験の作法。

## 回路図

```circuit
title: 図1 安定化電源の CV / CC の切り替わり
parts:
  PSU:
    type: device
    at: c1
    label: PSU
    pins: ["+", "-"]
    turn: mirror
  RL: resistor-var g3 g5 100
  G1: ground g5
wires:
  - PSU.+ -| g3
  - PSU.- -| g5
style:
  grid: on
```

電源を **5V、電流制限 10mA** に設定し、負荷 `RL` の値を変えて出力を見る。

- **RL = 1kΩ のとき**: 5V を出すのに必要な電流は 5V/1kΩ = 5mA。制限値 10mA
  より小さいので **CV のまま** — 出力は設定どおり **5.0 V**、電流 **5 mA**
- **RL = 100Ω のとき**: 必要な電流は 5V/100Ω = 50mA。制限値 10mA を超えるので
  **CC に切り替わり** — 電源は電流を 10mA に抑えたまま電圧を下げる。
  出力電圧は I<sub>limit</sub> × RL = 10mA × 100Ω = **1.0 V** (計算値、
  設定した 5V よりずっと低い)

CC に入ると出力電圧が設定値より下がる、というのが**電流制限が効いている**
サイン。ここでは可変抵抗で負荷を変えて確かめたが、実際の実験では
「配線を間違えてほぼ短絡した」状態も同じように CC が守ってくれる。

電流制限を掛けたまま、2-1 (トランジスタスイッチ) と同じ LED 回路を、
ファンクションジェネレータの方形波で光らせる。

```circuit
title: 図2 電流制限を掛けた電源 + ファンクションジェネレータで 2-1 を動かす
parts:
  PSU:
    type: device
    at: c1
    label: PSU
    pins: ["+", "-"]
    turn: mirror
  R1: resistor e5 g5 330
  D1: led g5 i5
  Q1: npn k7
  RB: resistor e9 g9 10k
  FG:
    type: device
    at: c11
    label: FuncGen
    pins: [OUT, GND]
  G2: ground m7
wires:
  - PSU.+ -| e5
  - i5 -| Q1.C
  - g9 -| Q1.B
  - Q1.E -| m7
  - FG.OUT -| e9
  - PSU.- -| m7
  - FG.GND -| m7
style:
  grid: on
```

回路の中身は 2-1 と同じ (`R1` = 330Ω、`RB` = 10kΩ、Q1 = 2SC1815)。
電源の + を電池の代わりに、ファンクションジェネレータの方形波を手動スイッチの
代わりに使っている。FG は **0V/5V の方形波、1Hz** に設定 (人の目で点滅が
分かる速さ)。

- 2-1 と同じ計算で、LED 点灯時の電流は約 **8.5 mA**
- 電源の電流制限 (20mA) はこの 8.5mA よりずっと大きいので、**CC は効かず
  CV のまま**動く — 電流制限は「もしもの保険」であって、正常時の動作には
  影響しない
- もし `R1` を短絡するなど配線を間違えても、電流は 20mA までしか流れない
  ので、電源やブレッドボードの配線が高温になる前に守られる

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| R1 | 抵抗 (1/4 W) | 330 Ω |
| RB | 抵抗 (1/4 W) | 10 kΩ |
| D1 | LED (赤、5 mm) | V<sub>F</sub> ≈ 2.0 V |
| Q1 | NPN トランジスタ | 2SC1815 |
| — | 安定化電源 | CV/CC 機能つき (5V、電流制限可変) |
| — | ファンクションジェネレータ | 方形波、0〜5V |

## 計器の設定

| 項目 | 値 |
| --- | --- |
| 電源の電圧設定 | 5.0 V |
| 電源の電流制限 (図1) | 10 mA |
| 電源の電流制限 (図2) | 20 mA (8.5mA の動作に十分な余裕) |
| FG の波形 | 方形波、0〜5V |
| FG の周波数 | 1 Hz |

## 見るべき値

| 測る所 | 期待する値 | 分かること |
| --- | --- | --- |
| 図1、RL = 1kΩ のときの出力電圧 | 5.0 V (CV) | 制限電流 (10mA) より必要な電流 (5mA) が小さい |
| 図1、RL = 100Ω のときの出力電圧 | 約 1.0 V (CC、計算値) | 電源が電流を 10mA に抑えるため、電圧が大きく下がる |
| 図2、LED 点灯時の R1 の両端 | 約 2.8 V (÷330Ω で約 8.5mA) | 2-1 と同じ値。電流制限は動作に影響していない |
| 図2 で電流制限を 5mA まで下げたとき | LED が暗くなる (CC に入り、出力電圧が下がる) | 電流制限を動作電流より低く設定すると、正常時でも動きが変わってしまう例 |
