# 0-2 ブレッドボードの導通と回路図の読み方 — 同じ列、レール、ネット

ブレッドボードは、縦に並んだ 5 個の穴が板の中で 1 本の金具でつながっている。
回路図で線でつながった所 (1 つの**ネット**。同じ電圧になる点の集まり) は、
ブレッドボードでは「同じ列の穴」か「配線」のどちらかで表す。これが分かると、
回路図と実体配線図 (部品をどの穴に挿すかを描いた図) が同じ回路だと読めるようになる。
LED 2 個の回路を組み、テスターの導通チェックでつながりを確かめる。

## 回路図

```circuit
title: 図1 2 つの LED を並列に点ける
parts:
  V1: vsource a2 e2 5
  G1: ground e2
  R1: resistor a4 c4 330
  D1: led c4 e4
  R2: resistor a6 c6 330
  D2: led c6 e6
wires:
  - a2 -- a4 -- a6
  - e2 -- e4 -- e6
style:
  grid: on
  pitch: 1.2
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/00-measure/circuit/02-continuity.svg)

図1 の `R1` と `R2` は電源の同じ + 端子から出ている (回路図では線でつながっていれば
同じネット)。LED の足は、電流が入る側を**アノード** (A)、出る側を**カソード** (K) と呼ぶ
(回路図の記号では三角の向きに電流が流れ、棒の側がカソード)。`D1` と `D2` のカソードは
同じ GND のネットに集まる。LED と抵抗の関係は 1-1 で詳しく扱う。

## 実体配線図

```breadboard
title: 図2 同じ列は 1 つのネット
# 上の赤いレール = +5V、青いレール = GND
board: half
parts:
  R1: resistor b8 b13 330
  D1: led d13(A) d14(K) red
  R2: resistor c8 c4 330
  D2: led e4(A) e3(K) green
  PS:
    type: device
    at: top
    label: 電源 5V
    pins: [+5V, GND]
wires:
  - PS.+5V -- +t1 red
  - PS.GND -- -t2 black
  - +t8 -- a8 red
  - a14 -- -t14 black
  - b3 -- -t3 black
```

![ブレッドボードの実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/00-measure/breadboard/02-continuity.svg)

- 図2 の `R1` は列 8 の `b8`、`R2` も列 8 の `c8` に挿してある。別の穴だが同じ列
  (上ブロック a〜e) なので、線を引かなくても中でつながっている。電源は
  どちらか片方 (図では空いている `a8`) に 1 本挿すだけでよい。`R1` は右へ、
  `R2` は左へ伸ばして、2 つの枝の足が同じ穴の並びに重ならないようにした。
- 同じ理屈で、`R1` の他端 (`b13`) と `D1` のアノード (`d13`) も列 13 で
  つながっている。`R2` の他端 (`c4`) と `D2` のアノード (`e4`) も列 4 で
  つながっている。部品の足どうしをジャンパ線でつながなくてよいのは、
  **同じ列に挿したときだけ**。
- 板の上下の端にある横長の穴の並び (**レール**) は、電源と GND を配るための列。
  上の赤レールは、板の端から端までつながった 1 本のネット。青レールも同じ。
  ただし上のレールと下のレールは板の中でつながっていない。下のレールも使うときは、+ どうし・
  − どうしを線で渡す。

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| R1, R2 | 抵抗 (1/4 W) | 330 Ω |
| D1 | LED (赤、5 mm) | V<sub>F</sub> ≈ 2.0 V (光っているときの両端の電圧。1-1) |
| D2 | LED (緑、5 mm) | V<sub>F</sub> ≈ 2.1 V |
| — | 電源 | 5 V |

## 見るべき値

テスターの導通チェック (2 点の間の抵抗がほぼ 0 Ω のときにブザーが鳴るレンジ) で、
実際にどこがつながっているかを確かめる。導通チェックは**電源を外してから**行う。
空いた穴には短いジャンパ線を挿し、その先にテスターの棒を当てる。

| 当てる 2 点 | 鳴るか | 理由 |
| --- | --- | --- |
| `a8` と `c8` | 鳴る | 同じ列 (上ブロック) |
| `a8` と `b8` | 鳴る | 同じ列 (上ブロック)。R1 と R2 の電源側 |
| `a8` と `f8` | 鳴らない | 列の番号は同じでも、上ブロックと下ブロックは別のネット |
| `+t8` と `+t20` | 鳴る | 同じレールは板のどこでも 1 本のネット |
| `+t8` と `-t14` | 鳴らない | + レールと − レールは別のネット (R と LED を通る道はあるが、ほぼ 0 Ω ではないので鳴らない) |

確かめたら電源をつなぐ。LED はそれぞれ約 9.1 mA (赤、(5 − 2.0) V ÷ 330 Ω) と
約 8.8 mA (緑、(5 − 2.1) V ÷ 330 Ω) が流れて点く。部品を別の列に挿し間違えると、
そのネットから外れて LED は点かない。その原因を導通チェックで探せるようになることが、
この題の一番のねらい。
