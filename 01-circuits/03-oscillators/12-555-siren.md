# 3-12 555 を 2 段 — サイレン

3-2 の 555 非安定を 2 つ使い、**ゆっくりの 555 (U1) で、速い 555 (U2) の音の高さを切り替える**。
U1 は約 1 Hz で High と Low を繰り返し、U2 は 1 kHz 前後の音を圧電スピーカーに出す。U1 の出力を抵抗 RM で U2 の 5 番 (CONT) につなぐと、
U2 の音が 1 秒ごとに 2 つの高さを行き来する。救急車のような「ピー・ポー」の 2 音のサイレンになる。

- **5 番 (CONT) は 555 の中の分圧の点**: 555 の中には 5 kΩ (Ω はオーム) の抵抗が 3 本直列に入っていて、5 番はその上から 1 本目の下 (V<sub>CC</sub> の 2/3) に出ている。
  コンデンサの電圧はこの 5 番の電圧 (上のしきい値) と、その半分 (下のしきい値) の間を上下する
- **5 番の電圧を下げると音が高くなる**: しきい値が下がると、コンデンサが充電する幅が狭くなり、1 周期が短くなる
- **U1 の出力で 5 番を動かす**: 5 番を中から見ると 3.33 V に 3.33 kΩ の抵抗がつながった形 (テブナンの等価)。外から RM (10 kΩ) で U1 の出力
  (High 3.5 V・Low 0.1 V) をつなぐと、5 番は 3.38 V と 2.53 V の 2 つの値を取る

3-13 では、5 番を Analog Discovery 3 (AD3) の信号発生器で連続に動かし、電圧と周波数の関係を測る。この題はその 2 点だけを使う形である。

- 図1 の左が U1 (Ra1・Rb1・C1 で約 1 Hz)、右が U2 (Ra2・Rb2・C2 で 1 kHz 前後)。どちらも 3-2 と同じ非安定の接続 (2 番と 6 番を直結、7 番を Ra と Rb の間に)
- **U1 の 3 番 (OUT) が RM を通って U2 の 5 番 (CONT) へ**。U2 の 5 番にはノイズ対策のコンデンサを付けない (付けると切り替わりが鈍る)。U1 の 5 番には 3-2 と同じく Cc1
- U2 の 3 番から R3 (1 kΩ) を通して圧電スピーカー SP を鳴らす。CH1 は U1 の出力、CH2 は U2 の出力

図2 は full のブレッドボードの左に U1、右に U2 を置いた。どちらの 555 のまわりも 3-2 の図2 と同じ並び (U1 は 3-2 と同じ穴、U2 はそれを 30 列右へずらした形) で、
3-2 を組んだことがあれば同じ形を 2 つ作ればよい。

- 電源は AD3 の Supplies (V+ を 5 V)。上の + レールと − レールへ入れ、1 列の線で下のレールへ渡す。**full のブレッドボードはレールが真ん中 (31〜33 列) で切れていることがある**ので、
  4 本のレールとも短い線でまたぐ。流れる電流は 555 が 2 つで 4〜12 mA ほど (NE555 の電源電流は 5 V で 1 個 2〜3 mA、最大 6 mA。データシートの値) で、V+ の範囲に収まる
- U1 の 3 番 (OUT、12 列) から RM (`g12`–`g18`) を出し、18 列から黄の線で h 行を右へ 47 列まで渡す。47 列で溝をまたいで上へ、`d47`–`d43` で U2 の 5 番 (CONT、43 列) へ
- U2 の 5 番の上は `d43` に黄の線が来るだけで、3-2 の Cc は挿さない。U2 のタイミングのコンデンサ C2 (68 nF) はフィルムなので向きは無い
- U2 の 3 番 (OUT、42 列) から白の線で 44 列へ、R3 (`i44`–`i48`) と圧電スピーカー SP (`g48`–`g52`) を通して 52 列から下の − レールへ
- Scope の 1+ (青) は U1 の出力 (`j12`)、2+ (緑) は U2 の出力 (`j42`)。1− と 2− は下の − レールへ

## 計器の設定

オシロには AD3 の Scope を使う。U1 の切り替わりの前後で U2 の周期が変わる所を、時間の波形で見る題で、10 MHz よりずっと遅いから。
U1 の立ち上がりでトリガを掛け、画面の左半分に切り替わる前、右半分に切り替わった後を出す。

| 設定 | 値 |
| --- | --- |
| Scope CH1 (U1 の出力、12 列) | DC、1 V/div |
| Scope CH2 (U2 の出力、42 列) | DC、1 V/div (0 V を中央に。CH1 は 0 V を下の端に) |
| Time | 1 ms/div (左右 5 ms ずつ) |
| Trigger | CH1、立ち上がり、1.8 V |

図3 は LTspice の値 (周波数) と計算の値 (High の割合) で描いた想定の波形で、実測ではない。左半分 (U1 が Low、5 番が 2.53 V) は U2 が 989 Hz、
右半分 (U1 が High、5 番が 3.38 V) は 706 Hz。カーソルの間隔 1.416 ms が右半分の 1 周期 (1/706 Hz)。
2 つの波は同じ尺度 (1 V/div) で、重ならないように 0 V の位置だけをずらした (CH1 は下の端、CH2 は中央)。
U1 の 1 周期 (約 1 秒) の全体を見るなら Time を 100 ms/div にし、AD3 の Scope の FFT か Spectrum で 2 つの音の高さを読む。

## 見るべき値

U2 の 5 番の電圧 V<sub>c</sub> は、中の 3.33 V・3.33 kΩ と、外の RM・U1 の出力の 2 つの電源の重ね合わせ:
V<sub>c</sub> = (3.33 V / 3.33 kΩ + V<sub>U1</sub> / 10 kΩ) ÷ (1 / 3.33 kΩ + 1 / 10 kΩ)。
U2 の High の時間は (Ra2 + Rb2) × C2 × ln((5 − V<sub>c</sub>/2) / (5 − V<sub>c</sub>))、Low の時間は Rb2 × C2 × ln 2 (5 番の電圧によらない)。

| 測る所 | 期待する値 | 分かること |
| --- | --- | --- |
| U1 の周期 (CH1) | 約 1.0 秒 (High 約 0.53 秒・Low 約 0.46 秒) | 3-2 と同じ式。f = 1.44 / ((Ra1 + 2Rb1) × C1) ≈ 0.99 Hz |
| U2 の 5 番の電圧 (テスター。U1 が High / Low) | 約 3.38 V / 約 2.53 V | RM と 5 番の中の分圧の重ね合わせ。5 番を開放したときは 3.33 V |
| U2 の周波数 (U1 が High のとき) | 約 0.70 kHz (計算 694 Hz) | 5 番が高いと充電の幅が広く、周期が長い |
| U2 の周波数 (U1 が Low のとき) | 約 0.98 kHz (計算 969 Hz) | 5 番が低いと周期が短い |
| U2 の High の割合 (U1 が High / Low) | 約 67 % / 約 54 % | 変わるのは High の時間だけ。Low の時間 (0.47 ms) は同じ |

RM を 22 kΩ にすると、5 番の振れが小さくなり、2 つの音は 1.01 kHz と 1.22 kHz に近づく (計算)。RM を小さくするほど 2 つの音は離れるが、
U1 の出力の電流が増え、下がりすぎると 555 が発振しにくくなる (5 番を 1.5 V より下げない)。
U1 の出力の代わりに U1 の C1 の電圧 (1.67〜3.33 V の三角に近い波) を 5 番へつなぐと、音が連続に上下する「ウー」のサイレンになる (3-13 の VCO の形)。

## LTspice での確かめ

`sim/12-555-siren.cir` で図1 を 4 秒の過渡解析で走らせ、2 秒より後で U1 の周期と、U1 が High の間・Low の間の U2 の周波数を読んだ。
NE555 は 3-2 と同じ動作の模型、圧電スピーカーは 22 nF の容量と仮定した。どれも仮定であり、実測ではない。

| 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| U1 の周期 | 約 1.0 秒 | 0.996 秒 | 合う |
| U1 の High の時間 | 約 0.53 秒 | 0.531 秒 | 合う |
| U2 の 5 番の電圧 (U1 が High / Low) | 約 3.38 V / 約 2.53 V | 3.375 V / 2.525 V | 合う |
| U2 の周波数 (U1 が High) | 約 0.70 kHz (計算 694 Hz) | 706 Hz | 合う (計算より 1.7 % 高い。3-2 と同じ模型のずれ) |
| U2 の周波数 (U1 が Low) | 約 0.98 kHz (計算 969 Hz) | 989 Hz | 合う (計算より 2 % 高い) |

電源の電流は模型が 555 の中の電流を入れていない (1.3 mA と出る) ので、表に入れずデータシートの値で書いた。
