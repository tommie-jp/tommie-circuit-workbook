# 3-7 ウィーンブリッジ — OP アンプで正弦波

555 や CMOS インバータの発振は方形波か三角波だが、**きれいな正弦波**を
LC も水晶も使わずに作れるのがウィーンブリッジ発振器。正弦波は音のテストやフィルタの
測定 (1-5) の信号源になる。直列 RC と並列 RC の 2 つの RC 回路と、利得ちょうど 3 倍の
非反転アンプを組み合わせる。振幅が勝手に大きくなり続けないよう、負帰還の抵抗に
逆向き 2 本のダイオードを並べ、振幅が増えると利得が下がるようにする。
ここでは AD3 (Analog Discovery 3) の Supplies で ±5 V を作って電源にし、Scope で出力の正弦波を見る。

**OP アンプ** (U1) は、+ 入力と − 入力の電圧の差を大きく増幅する IC。出力から − 入力へ
抵抗で戻す (**負帰還**) と、利得が抵抗の比だけで決まるアンプになる。+ 入力に信号を入れる
**非反転アンプ**の利得は 1 + Rf/Rg (Rf は出力と − 入力の間、Rg は − 入力と GND の間の抵抗)。
ここではこの式だけを使い、OP アンプのくわしいしくみは第 4 章 (4-2) で扱う。

## 回路図

```circuit
title: 図1 ウィーンブリッジ発振器 (ダイオードで振幅を安定化)
parts:
  VCC: vcc b2 5V
  VEE: vee c2 5V
  U1: opamp d9 +up
  C1: capacitor b5 b7 10n
  R1: resistor b8 b10 16k
  C2: capacitor d3 f3 10n
  G3: ground f3
  R2: resistor d5 f5 16k
  G2: ground f5
  R4: resistor f7 f9 10k
  R3: resistor f9 f11 12k
  D1: diode h7 h9 1N4148
  D2: diode j9 j7 1N4148
  Rg: resistor j7 l7 10k
  G4: ground l7
  OUT: port d12
wires:
  - b7 -- b8
  - b10 -- b11 -- d11
  - U1.out -- d11 -- d12
  - b5 -- c5g0f0 -- d5
  - c5g0f0 |- U1.+
  - d3 -- d5
  - f7 |- U1.-
  - f11 -- d11
  - f7 -- h7 -- j7
  - f9 -- h9 -- j9
notes:
  - text c7e7 tiny: PIN 3
  - text d7f7 tiny: PIN 2
  - text c10h0 tiny: PIN 1
  - text a2c5 small left: U1 の PIN 8 へ
  - text c2h5 small left: U1 の PIN 4 へ
style:
  grid: on
  pitch: 1.2
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/03-oscillators/circuit/07-wien-bridge.svg)

- 図1 左上の **+5V と −5V は、AD3 の Supplies の V+ と V−**。U1 の PIN 8 が +5V、PIN 4 が −5V
  (回路図の OP アンプには電源のピンを描かないので、記号に注記を添えた)。
  ほかの GND の記号は AD3 の GND。各レールの電流は、LM358 が 1 回路あたり最大 0.6 mA (5 V、
  データシートの値) で、2 回路入りでも数 mA に収まる。AD3 の Supplies の限度 (各レール 50 mA、
  USB 給電で 250 mW) に十分収まる。電池で作るなら 006P (9 V) を 2 本と 7805・7905 でもよい
- 図1 の **並列 RC (R2・C2、+ 入力の点から GND へ)** と
  **直列 RC (R1・C1、出力から + 入力の点へ)** が「ウィーンブリッジ」の周波数を決める部分。R1=R2=16 kΩ、
  C1=C2=10 nF が等しいとき、発振周波数は **f = 1 / (2πRC) = 1 / (2π × 16 kΩ × 10 nF) ≈ 995 Hz**
- 出力の正弦波は直列 RC と並列 RC で 1/3 の大きさに分けられて + 入力へ戻る。
  戻った波の位相 (山の時刻のずれ。1-5) が出力とちょうど揃うのがこの f だけで、
  ほかの周波数は位相がずれて発振が育たない。「一回りして戻った波が、同じ位相で
  元の大きさ以上になる」のが発振の条件 (バルクハウゼンの条件と呼ぶ)
- 戻る波が 1/3 になるので、**非反転アンプの利得を 3 倍にする**のがもう 1 つの条件 (1 + Rf/Rg = 3)。
  帰還側 Rf は R3 (12 kΩ) と R4 (10 kΩ) の直列、接地側は Rg (10 kΩ)
- 振幅が小さいうちはダイオードが導通せず、利得は 1 + (12 k + 10 k)/10 k
  = 3.2 倍。3 倍を超えるので、電源を入れると発振が育つ
- **振幅が大きくなると D1・D2 が導通し、R4 を短絡ぎみにする。** Rf は最小で R3 だけ
  (1 + 12 k/10 k = 2.2 倍) まで下がるので、利得は 3.2 倍と 2.2 倍の間を動き、
  1 周期の平均が 3 倍になる所で振幅が釣り合う。SPICE (下の「見るべき値」) では、
  R4 の両端の電圧が最大で約 0.39 V (ダイオードの電流が増え始める付近) の所で止まり、
  出力は **約 3.2 Vpp (0 V を中心に ±1.6 V ほど)** になる (計算値。ダイオードの
  個体差で 2.5〜3.5 Vpp ほど振れる)
- ダイオードの曲がりは豆電球 (1939 年の Hewlett の方式) より急なので、
  波形がひずむ (SPICE で THD 約 4 %)。代わりに部品が安く、調整が要らない
- **LM358 の出力 High は Vcc−1.5 V (≈ +3.5 V) まで**しか振れない。
  ±1.6 V ほどの振幅ならこの範囲に収まる

## 実体配線図

```breadboard
title: 図2 ブレッドボードに組む
# 上の青レールが GND。−5V は GND でレールが埋まるので AD3 の V- から PIN 4 へ直接引く
board: half
parts:
  AD3:
    type: device
    at: top
    label: AD3 (Supplies ±5V・Scope)
    pins: [V+, GND, V-, 2+, 2-, 1+, 1-]
  U1: dip8 @ e14 r180 LM358
  R2: resistor b6 b10 16k
  C2: capacitor e6 e10 10n
  C1: capacitor a10 a13 10n
  R1: resistor b13 b17 16k
  Rg: resistor a16 -t16 10k
  R3: resistor b22 b25 12k
  R4: resistor g19 g22 10k
  D1: diode i19(A) i22(K) 1N4148
  D2: diode a22(A) a19(K) 1N4148
wires:
  - AD3.V+ -- +t2 red
  - AD3.GND -- -t3 black
  - AD3.V- -- a14 blue
  - AD3.2+ -- a15 green
  - AD3.2- -- -t18 black
  - AD3.1+ -- a25 orange
  - AD3.1- -- -t27 black
  - +t1 -- +b1 red
  - j17 -- +b17 red
  - a6 -- -t6 black
  - d15 -- d10 green
  - c16 -- c19 yellow
  - d17 -- d25 orange
  - e19 -- f19 yellow
  - e22 -- f22 brown
notes:
  - text below: 上の赤 = +5V、上の青 = GND、−5V は PIN 4 へ直接
```

![ブレッドボードの実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/03-oscillators/breadboard/07-wien-bridge.svg)

- 図2 の上の箱が AD3。**V+ (+5 V) は赤い線で上の赤レール (左端の列) へ、GND は黒い線で上の青レールへ**入れる。
  赤レールは左端の列で下の赤レールとつなぎ、U1 の PIN 8 (V+) は下の赤レールから挿す。
  **V− (−5 V) は青い線で U1 の PIN 4 へ直接引く。** 上の青レールが GND で埋まるので、−5 V をレールに載せない
- U1 は LM358 の片方だけ使う。DIP8 を溝をまたいで 14〜17 列に挿し、左右を逆 (丸い印が右) にして、
  上の行に PIN 4・3・2・1 (V−・IN+・IN−・OUT) が並ぶ。出力 (PIN 1、17 列) が右、+ 入力 (PIN 3、15 列) が左に来るので、
  図1 と同じく信号が左から右へ流れる。もう片方 (PIN 5〜7) は使わず、PIN 8 は下の赤レールへ
- **周波数を決める部分**: R2 (16 kΩ) と C2 (10 nF) を 6〜10 列に置き、10 列を `d10--d15` の緑の線で + 入力 (15 列) へ渡す。
  C1 (10 nF) と R1 (16 kΩ) は 10 列から 13 列、13 列から 17 列 (出力) に直列に置く
- **帰還と振幅の安定化**: − 入力 (16 列) を `c16--c19` で下ブロックの 19 列へ渡し、R4 (10 kΩ) と D1 を 19 列から 22 列へ、
  D2 を上ブロックで逆向きに並べる (D2 は 22 列が A、19 列が K)。R3 (12 kΩ) は 22 列から出力側の 25 列へ。
  出力は `d17--d25` の橙の線で R3 の右端へ。Rg (10 kΩ) は 16 列から GND (上の青レール) へ立てて挿す
- **AD3 の Scope**: 1+ (橙) を出力 (25 列)、2+ (緑) を + 入力 (15 列) へ。1− と 2− (黒) は GND へ

## 計器の設定

計器: **Analog Discovery 3 (AD3) の Scope** (約 1 kHz の波形の形と振幅を見るので、オシロで足りる。電源も同じ AD3 の Supplies)。

Supplies:

| 項目 | 値 |
| --- | --- |
| V+ / V− | +5 V / −5 V (Master Enable を入れる) |

Scope:

| 項目 | 値 |
| --- | --- |
| 結合 | CH1・CH2 とも DC |
| 電圧レンジ | CH1・CH2 とも 500 mV/div (出力 3.2 Vpp が 6.4 目盛、+ 入力 1.1 Vpp が 2.2 目盛に入る) |
| 時間レンジ | 500 µs/div (1 周期 1.01 ms が約 2 目盛。5 周期ほど見える) |
| トリガ | CH1、立ち上がり、レベル 0 V |
| 測定 | CH1 の Vpp・Freq、CH2 の Vpp |

1+ を出力 (CH1)、2+ を + 入力 (CH2) につなぐ。同じ尺度で見るので、CH2 の高さは CH1 の 1/3 に見える。

```scope
title: 図3 出力 (CH1) と + 入力 (CH2) — 振幅は 1/3 で同相、1 周期が約 1.01 ms
time: 500us/div
trigger: ch1 rising 0V
ch1: {wave: "= 1.628V * sin(2 * pi * 986.55Hz * t + 0.027) + 65.2mV * sin(6 * pi * 986.55Hz * t - 0.671)", range: 500mV/div}
ch2: {wave: "= 542.6mV * sin(2 * pi * 986.55Hz * t + 0.032) + 16.1mV * sin(6 * pi * 986.55Hz * t - 1.377)", range: 500mV/div}
cursors: [0, 1.0136ms]
measure: [vpp, freq, phase]
```

![オシロスコープの画面](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/03-oscillators/scope/07-wien-bridge.svg)

図3 は、下の SPICE の波形 (基本波と 3 次の高調波) から作った画面。カーソルの 1 周期の間隔 (ΔX) は約 1.01 ms で、1/ΔX が約 987 Hz。
CH2 (+ 入力) は CH1 (出力) の 1/3 の高さで、山と谷の時刻がほぼ同じ (同相)。頭がわずかに平らに見えるのが、ダイオードによる歪み。

## 見るべき値

OUT と GND の間を AD3 の Scope (0-3) で見て、周期と振幅 (山から谷まで) を読む。
1 kHz を正しく読めるテスター (1-5) の交流電圧レンジなら実効値 (正弦波は Vpp ÷ 2.83、3.2 Vpp で約 1.1 V) が出る。

下の値は SPICE (LTspice。LM358 の GBW 1 MHz・出力振幅の限界を入れた簡易モデルと、1N4148 のモデル。部品の誤差は入れていない) で
回路を解いた結果。f = 1 / (2πRC) の計算値と並べる。振幅はダイオードの特性で決まるので目安。

| 測る所 | 期待する値 | 分かること |
| --- | --- | --- |
| 出力の周波数 | 約 987 Hz (目安 950〜1000 Hz) | 計算値 995 Hz より約 1 % 低い。SPICE で OP アンプの帯域 (GBW 1 MHz) を 100 倍にすると 991 Hz なので、帯域の位相遅れで約 4 Hz、ダイオードで約 4 Hz 下がる。R・C の誤差 (抵抗 ±5 %、セラミック ±10〜20 %) はこれより大きい |
| 出力の振幅 | 約 3.2 Vpp (目安 2.5〜3.5 Vpp)、0 V を中心 | D1・D2 が導通して利得が 3 倍に落ち着く。R4 の両端の最大は約 0.39 V |
| + 入力の振幅 | 約 1.1 Vpp (出力の 1/3)、同相 | 直列 RC と並列 RC で 1/3 になる (SPICE で 0.333 倍、位相差は 1° 未満) |
| 波形 | 正弦波に近い。歪み率 (THD) 約 4 % (目安) | ダイオードは豆電球より急な非線形なので、3 次の高調波が基本波の約 4 % (−28 dB) 出る |
| D1・D2 を外したとき | 出力が電源近くまで振れて頭が潰れる | 利得 3.2 倍のまま抑えが効かない (クリップ発振。SPICE で +3.5 V・−4.9 V まで) |

3-2・3-3 の 555 は方形波、3-5 の水晶発振は周波数の精度が高いが正弦波ではない。
この回路は精度こそ水晶に劣るが、**LC も水晶も使わずに正弦波が作れる**のが
特徴。オーディオ帯の低歪み発振器として長く使われてきた回路。

安定化に置き換えた。
