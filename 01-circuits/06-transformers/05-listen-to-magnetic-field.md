# 6-5 磁界を聞く — コイル + 音

トランスや AC アダプタの近くには、漏れ出た交流磁界がある。**コイルを置くだけで
その磁界が電圧を誘導する**ので、感度の良いクリスタルイヤホン (9-2・9-3 でも使う
ものと同じ) につなげば、電源周波数のブーンという音として耳で聞ける。
アンプ 1 つ要らない、最も簡単な「磁界のセンサー」。

## 回路図

```circuit
title: 図1 コイルで磁界の音を拾う
parts:
  L1: inductor a2 c2 1H
  EAR: earphone a6 c6 l=$\mathrm{EAR}$
wires:
  - a2 -- a6
  - c2 -- c6
style:
  grid: on
  pitch: 1.2
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/06-transformers/circuit/05-listen-to-magnetic-field.svg)

- L1 は太めのボビンや空のフィルムケースなどに**細いエナメル線を 1000 回ほど**
  巻いた自作コイル。部品としてはただのコイルだが、ここでは**周りの磁界を
  拾うアンテナ**として使う
- 部品はコイルとイヤホンの 2 つだけ。回路として閉じてはいるが、どこにも
  電源につながず GND も無い**浮いた閉ループ**なので、ERC は「電源に
  つながっていない」と言う。これは意図どおり (磁界からもらう起電力だけで
  動く回路なので、書き足す電源は無い)
- L1 を 6-1 のトランスや、動作中の AC アダプタのそばに近づけると、
  漏れ磁界がコイルを貫いてわずかな交流電圧を誘導する。**コイルの向きで
  音の大きさが変わり**、磁束線をまっすぐ貫く向き (コイルの軸を磁束の
  向きに合わせる) で最大になる。直角にすると音はほぼ消える
  (向きと結合の話は 6-8 でもう少し詳しく扱う)
- **イヤホンのインピーダンス**: EAR は、いま売られているセラミック (圧電) 型の
  クリスタルイヤホンを想定する (容量 約 15nF、直流では 20MΩ 以上)。電気的には
  コンデンサなので、インピーダンスは周波数で変わり、**50Hz で約 210kΩ**
  (1/(2π×50Hz×15nF) ≈ 212kΩ)、1kHz で約 10kΩ。
  コイル (1H) は 50Hz で約 314Ω しかないので、誘導された起電力はほとんどそのまま
  イヤホンにかかる。8Ω や 32Ω のダイナミック型のイヤホンでは、コイルの抵抗に
  電圧を取られて聞こえない
- セラミックイヤホンの周波数範囲は 200〜8000Hz ほどで、50Hz・60Hz そのものは
  よく鳴らない。聞こえるブーンには、100Hz・150Hz などの倍音が多く混じる

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| L1 | 自作コイル (エナメル線を約 1000 回巻き) | インダクタンスは目安で 1 H 程度 (巻き方次第でばらつく) |
| EAR | クリスタルイヤホン (セラミック型、9-2 と同じ) | 容量 約 15nF (50Hz で約 210kΩ、1kHz で約 10kΩ)。mV 級の電圧でも聞こえる |

## 見るべき値

計算値 (目安)。ファラデーの法則 EMF ≈ N × A × B<sub>peak</sub> × ω
(N = 巻数、A = コイルの断面積、ω = 2πf) で見積もる。コイル直径 2 cm
(A ≈ 3.14×10<sup>-4</sup> m²)、漏れ磁束密度 B<sub>peak</sub> ≈ 0.05 mT
(小さな AC アダプタの数 cm 手前、という**仮定の目安値**) とする。

| 条件 | 誘導される起電力 (計算値、目安) | 分かること |
| --- | --- | --- |
| 50 Hz 地域 (東日本、ω ≈ 314 rad/s) | 約 4.9 mV (振幅) | クリスタルイヤホンでかすかに聞こえる大きさ |
| 60 Hz 地域 (西日本、ω ≈ 377 rad/s) | 約 5.9 mV (振幅) | 周波数が高い分、同じ磁束でも起電力はやや大きい |
| コイルをアダプタに密着させたとき | 数 10 mV に増える (目安) | 距離の 2〜3 乗で磁界が弱まるため、近づくほど大きく効く |
| コイルを磁束と直角にしたとき | ほぼ 0 V | 鎖交する磁束が無くなる (A × cosθ の θ = 90°) |

**巻数を増やす (2000 回にする) と、起電力もほぼ比例して 2 倍になる。** 一方で
線を細くして巻数を稼ぐと、コイルの直流抵抗が上がり負荷をつないだときの
出力が下がるので、実用では巻数と線の太さのバランスを取る。
