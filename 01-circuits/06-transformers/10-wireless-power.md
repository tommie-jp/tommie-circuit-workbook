# 6-10 ワイヤレス給電 — 共振コイルで LED

スマートフォンの置くだけ充電 (Qi) や電動歯ブラシは、線をつながずに電力を送る。中身は**コアの無いトランス**で、
送りのコイル (1 次) と受けのコイル (2 次) の間は空気だけ。6-3 のトランスと違って結合係数 k が 0.1〜0.3 ほどしかないので、
そのままでは 2 次にほとんど電圧が出ない。そこで**両方のコイルに C をつないで同じ周波数で共振させ**、小さな結合でも電力が渡るようにする。

- **送り**: L1 (空芯、47 µH。µ はマイクロ) と C1 (3.3 nF) の直列共振 (約 404 kHz)。共振では L1 と C1 のリアクタンスが打ち消し合い、
  小さな電圧で大きな電流が流れる。L1 の両端の電圧は電源の数倍になる
- **受け**: 同じ L2・C2 の直列共振。L2 に出る電圧 (相互誘導、6-8) を、共振で打ち消し合う C2 を通して取り出し、D1・D3 で整流し、CF で平らにして LED を点ける
- **駆動**: W1 の方形波 (0/5 V) を、2SC1815 と 2SA1015 のプッシュプル (2-10 の B 級と同じ形のエミッタフォロア) で電流を増やして送りの共振回路に入れる。W1 だけでは 10 mA ほどしか出せない

コイルを近づけるほど k が大きくなり、LED が明るくなる。周波数をずらすと、共振から外れて LED が消える。
周波数は 404 kHz で、ブレッドボードの範囲 (3 MHz 以下) の中。

図2 は下のブロックに送り、右上に受けを置いた。**L1 と L2 は空芯のコイルで、ブレッドボードの外**にあり、図の L1・L2 はその線の端を挿す所を示す。

- コイル: 直径 40 mm の筒 (乾電池の単 1 やペットボトルのふたなど) に 0.4 mm のエナメル線を 30 回すき間なく巻き、抜いてテープで止める。L は約 47 µH の目安 (Wheeler の式)。
  同じ物を 2 つ作り、面を向かい合わせて置く
- 電源は AD3 の Supplies (V+ を 5 V)。上のレールへ入れ、1・2 列の線で下のレールへも渡す。電源の電流は約 23 mA (V+ の範囲の中)
- **2SC1815 と 2SA1015 はどちらも平らな面を手前にして左から E・C・B**。Q1 (5〜7 列) の C は下の + レールへ、Q2 (9〜11 列) の C は下の − レールへ。
  ベース (7・11 列) は橙の線で、エミッタ (5・9 列) は青の線でつなぐ
- W1 (黄) は `j3`、RB1 (`i3`–`i7`) でベースへ。RS (`i9`–`i13`)、C1 (`h13`–`h16`)、L1 (`g16`–`g20`、20 列から − レール) の順
- 受け: L2 (`b18`–`b22`、18 列が GND)、C2 (`c22`–`c25`)、D3 (− レールから 25 列へ、カソードが 25 列)、D1 (`d25`–`d28`)、CF (28 列から − レールへ)、R2 (`b28`–`b30`)、LED (アノード 30 列・カソード 29 列から − レールへ)
- Scope の 1+ (橙) は L1 の上 (`j16`)、2+ (緑) は CF の上 (28 列を白の線で下へ出した `j28`)。1− と 2− は下の − レールへ
- **ブレッドボードの範囲**: L1 の上の電圧は山で約 11 V (共振で 5 V より上がる)、ピーク 20 V 以下。電流の山は約 70 mA で 2SC1815 の 150 mA 以下

## 計器の設定

オシロには AD3 の Scope を使う。404 kHz の共振の正弦波の大きさと、受けの直流を見る題で、10 MHz より低いから。

| 設定 | 値 |
| --- | --- |
| Wavegen W1 | Square、404 kHz (L1 の電圧が一番大きくなる所に合わせる)、0〜5 V (振幅 2.5 V・オフセット 2.5 V) |
| Scope CH1 (L1 の上、16 列) | DC、5 V/div |
| Scope CH2 (CF の上、28 列) | DC、1 V/div、0 V を下から 1 目盛 |
| Time | 1 µs/div (10 µs に約 4 周期) |
| Trigger | CH1、立ち上がり、0 V |

## 見るべき値

共振の周波数 f = 1 / (2π√(47 µH × 3.3 nF)) ≈ 404 kHz (π はパイ)。コイルの L は手巻きでずれるので、W1 の周波数を 350〜450 kHz で動かし、CH1 が一番大きい所に合わせる。
受けの C2 も同じ値なので、2 つのコイルが同じなら受けも同じ周波数で共振する。

| 結合係数 k (コイルの間を近づけるほど大きい) | LED の電流 (LTspice) | 受けの直流 (CH2) | L1 の上 (CH1) |
| --- | --- | --- | --- |
| 0.05 | 0 (点かない) | 0.5 V | 22.9 Vpp |
| 0.1 | 0 (点かない) | 1.3 V | 22.9 Vpp |
| 0.2 | 2.2 mA (光る) | 2.0 V | 21.8 Vpp |
| 0.3 | 6.2 mA (明るい) | 2.3 V | 18.0 Vpp |

| 測る所 | 期待する値 | 分かること |
| --- | --- | --- |
| L1 の上の電圧 (CH1、受けを遠ざけて) | 約 23 Vpp | 共振で電源 (5 V) の 4 倍以上に上がる |
| 受けを近づけたときの CH1 | 小さくなる (k = 0.3 で 18 Vpp) | 受けが電力を持っていくので、送りの共振が弱まる (受けが送りの負荷に見える) |
| LED が点き始める近さ | k ≈ 0.15〜0.2 (目安) | 受けの直流が LED の電圧 (約 1.8 V) を超える所 |
| W1 を 300 kHz にずらしたとき | CH1 が小さくなり、LED は消える | 共振でしか電力が渡らない |
| 電源の電流 | 約 23 mA (115 mW) | k = 0.2 で LED に 4 mW。効率は数 % |

k は 6-8 の方法で測れる: 受けの C2 を外して L2 の両端の電圧 V2 を見ると、L1 の両端 V1 との比 V2 / V1 がほぼ k (同じコイルのとき)。
k と距離の関係はコイルの大きさで決まり、直径 40 mm のコイルでは、面の間が直径の半分 (2 cm) ほど離れると k は 0.1 を下回る (目安)。

## LTspice での確かめ

`sim/10-wireless-power.cir` で結合係数 k を 0.05・0.1・0.2・0.3 に振って (距離の代わり) 2 ms の過渡解析を走らせ、終わりの 0.5 ms で読んだ。
コイルの L と交流の抵抗 (1 Ω)、トランジスタの模型 (3-1 の 2SC1815 とその PNP 版)、LED の模型はどれも仮定で、実測ではない。

| 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| LED の電流 (k = 0.2 / 0.3) | 約 2.2 / 6.2 mA | 2.21 / 6.25 mA | 本文の値は LTspice の読み |
| 受けの直流 (k = 0.05 / 0.1 / 0.2 / 0.3) | 0.5 / 1.3 / 2.0 / 2.3 V | 0.50 / 1.33 / 2.02 / 2.28 V | 合う |
| L1 の上 (k = 0.05 / 0.3) | 約 23 / 18 Vpp | 22.9 / 18.0 Vpp | 合う |
| 送りの電流の山 (k = 0.05) | 約 70 mA | 71 mA | 合う |
| 電源の電流 (k = 0.2) | 約 23 mA | 21.5 mA | 近い (k = 0.05 で 23.0 mA) |
| LED の電力 (k = 0.2) | 約 4 mW | 4.2 mW | 合う |

距離と k の関係は模型に入れていない (k を直接振った)。直径 40 mm での距離と k の目安は確かめていない。
