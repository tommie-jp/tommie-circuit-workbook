# 8-3 タッチスイッチ (人体)

指で 2 つの端子に触れるだけで LED が点く回路を作る。人の肌は数百 kΩ という
大きな抵抗を持ち、指を通って流れる電流はわずか数 µA しかない。トランジスタ 2 段 (ダーリントン接続、2-4 で見た) で
増幅率を hFE の 2 乗まで稼げば、そのわずかな電流でも十分スイッチとして働く。
半導体が高くて貴重だった時代からある、古典的な回路だ。

## 回路図

```circuit
title: 図1 指で触れると LED が点く
parts:
  VCC: vcc a2 5V
  TPA: port c2
  TPB: port c3
  R1: resistor c4 e4 1M
  G1: ground e4
  Q1: npn c6 2SC1815
  R3: resistor f6 h6 100k
  G2: ground h6
  R4: resistor a8 c8 330
  D1: led c8 e8
  Q2: npn f8 2SC1815
  G4: ground g8
wires:
  - a2 -- c2
  - a2 -- a6 -- a8
  - c3 -- c4 -- Q1.B
  - a6 -- Q1.C
  - Q1.E -- f6 -- Q2.B
  - e8 -- Q2.C
  - Q2.E -- g8
style:
  grid: on
  pitch: 1.2
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/08-sensors/circuit/03-touch-switch.svg)

- TPA (電源側の端子) と TPB (Q1 のベース側の端子) の間に指を置くと、肌の抵抗
  (数百 kΩ) を通してわずかな電流が流れ込む。R1 (1 MΩ) はベースを GND に軽く引くプルダウンで、
  指からの電流がこれに勝つと、Q1 のベース電圧が上がる
- Q1 のエミッタが Q2 のベースに直結するのが、ダーリントン接続だ。R3 (100 kΩ) は
  Q2 のベースを軽く GND に引くブリーダー抵抗 (8-2 で見た) で、Q1 が OFF のとき Q2 も
  確実に OFF にする
- D1 (LED) は R4 と一緒に、Q2 のコレクタに直列 (+5 V → R4 → D1 → Q2 → GND)
  につないである。触れていないときは Q2 が OFF で、D1 の通り道が切れて消えている。
  触れると Q2 が ON になって通り道ができ、D1 が点く
- 2 段の増幅率は hFE1 × hFE2 (2SC1815 どうしなら 1 万倍ほど)。
  ベース電流をこれだけ増幅すれば、LED に要る電流を軽く超える。肌の抵抗が
  1.6 MΩ ほどまでなら (計算値、下の「見るべき値」)、触れると LED は R4 で決まる電流まで目一杯点灯する

## 実体配線図

```breadboard
title: 図2 ブレッドボードに組む
# 上の赤いレール = +5V、青いレール = GND (29・30 列で下のレールへ渡す)
board: half
parts:
  PSU:
    type: device
    at: top
    label: 電源 5V
    pins: ["+", "-"]
  Q1: transistor c8(B) c9(C) c10(E) 2SC1815
  R3: resistor b15 b18 100k
  Q2: transistor c20(B) c21(C) c22(E) 2SC1815
  R1: resistor g4 g8 1M
  D1: led h25(A) h21(K) red
  R4: resistor f25 f28 330
wires:
  - PSU.+ -- +t1 red
  - PSU.- -- -t2 black
  - +t9 -- a9 red
  - a10 -- a15 yellow
  - -t18 -- a18 black
  - d15 -- d20 yellow
  - -t22 -- a22 black
  - e8 -- f8 green
  - j4 -- -b4 black
  - h8 -- h11 green
  - j13 -- +b13 red
  - e21 -- f21 orange
  - j28 -- +b28 red
  - -t29 -- -b29 black
  - +t30 -- +b30 red
notes:
  - text: 触れる 2 点は下のブロックの 11 列 (ベース側) と 13 列 (+5V 側)
```

![ブレッドボードの実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/08-sensors/breadboard/03-touch-switch.svg)

- 電源の + と GND は上のレールに入れ、右端 (29・30 列) で下のレールへ渡す
- 触れる 2 点は、下のブロックの 11 列 (緑の線で Q1 のベースの 8 列とつながる) と 13 列 (下の + レールへつながる)。
  i11 と i13 にむき出しの線かワニ口クリップを挿して出しておき、2 本に指の腹を同時に当てる。触れた瞬間に LED が点く
- Q1・Q2 (2SC1815) は、平らな面を手前にして見ると左から E・C・B。ここでは平らな面を奥 (a 行側) に向けて挿し、
  c 行に B・C・E の順に入れる。Q1 のベース (8 列) は緑の線で下のブロックへ渡し、R1 (4→8 列) を通して下の − レールへ
- Q1 のエミッタ (10 列) から黄色の線で R3 (15→18 列) と Q2 のベース (20 列) へつなぐ
- Q2 のコレクタ (21 列) はオレンジの線で下のブロックへ渡し、LED のカソード (21 列) につなぐ。
  LED のアノード (25 列) から R4 (25→28 列) を通して下の + レールへ。LED のカソードは GND ではなく、Q2 のコレクタにつながる

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| R1 | 抵抗 (ベースのプルダウン) | 1 MΩ |
| Q1・Q2 | NPN トランジスタ | 2SC1815 |
| R3 | 抵抗 (ブリーダー) | 100 kΩ |
| R4 | 抵抗 | 330 Ω |
| D1 | LED (赤) | V<sub>F</sub> ≈ 2.0 V |

## 見るべき値

表の値は計算値。指の抵抗は個人差・湿り気の差が大きいので、ここでは目安として 470 kΩ とする。
ダーリントンのベースは、V<sub>BE</sub> 2 つ分の約 1.4 V になるとした。

| 状態 | ベース電流 (Ib1、計算値) | Q2 のコレクタ電流 (計算値) | LED |
| --- | --- | --- | --- |
| 触れていない | 0 (R1 が完全に引き下げる) | 0 | 消灯 |
| 指で触れる (肌抵抗 約 470 kΩ) | 約 6.3 µA | 約 8.5 mA (= (5 − 2.0 − 0.2) / 330 Ω、R4 で頭打ち) | 点灯 |

指の抵抗 (470 kΩ) を通ってベースの節点に入る電流は (5 V − 1.4 V) / 470 kΩ ≈ 7.7 µA。
そのうち R1 (1 MΩ) が 1.4 V / 1 MΩ ≈ 1.4 µA を GND へ引き取るので、Q1 のベースに
実際に入るのは、差し引き約 6.3 µA (計算値) になる。

hFE = 100 と仮定すると、ダーリントンの合成増幅率は 1 万倍。
6.3 µA を 1 万倍すれば 63 mA にもなり、LED に要る 8.5 mA を大きく超える。
だから指の抵抗がもっと大きくても (乾いた指でも)、たいてい確実に点灯する。
LED が点き切るのに要るベース電流は 8.5 mA / 10000 = 0.85 µA で、これを流せる指の抵抗の上限は
3.6 V / (0.85 + 1.4) µA ≈ 1.6 MΩ になる。

LED の点灯は目で見る。Q2 のコレクタの電圧 (21 列と GND の間) をテスターの DC 電圧レンジで測ると、触れたときに 0.2 V ほどまで下がる。
