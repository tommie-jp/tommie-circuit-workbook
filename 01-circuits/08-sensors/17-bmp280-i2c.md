# 8-17 気圧 (I2C)

BMP280 (Bosch) は、気圧と温度を測って I2C (アイ・スクエアド・シー) で数字として送るセンサーである。気圧の分解能が高く、
相対精度は ±0.12 hPa (ヘクトパスカル)。地上の近くでは高さ 1 m で気圧が約 0.12 hPa 変わるので、**1 m の高さの違い**が分かる
(データシートの「±0.12 hPa、±1 m に相当」)。スマートフォンの階の判定や、ドローンの高度の保持に使われる。

I2C は、**SCL (クロック) と SDA (データ) の 2 本**で、1 台の親 (マスター) が何台もの子 (スレーブ) と話す決まりである。
どの子も 7 ビットの**番地 (アドレス)** を持ち、親は番地を最初に送って相手を選ぶ。2 本とも、どの機器も **L に引くか放すかだけ**
(開放ドレイン) で、H は**プルアップの抵抗**が作る。このため、

- H への立ち上がりは、プルアップの抵抗 R<sub>p</sub> と、線の容量 C<sub>b</sub> の RC で決まる (1-3 の充電)
- R<sub>p</sub> が大きすぎると立ち上がりが遅れ、速いクロックでは H に上がり切らない。小さすぎると、L に引く機器に大きな電流が要る

この題では、BMP280 を載せた小さな基板を、Analog Discovery 3 (AD3) の Protocol (I2C の親) で読む。最初に BMP280 の**チップの番号** (0x58) を読み出し、
オシロで SCL の立ち上がりを測って、R<sub>p</sub> の選び方を確かめる。プログラム (Pico 2) で気圧を計算して表示する方法は、この題では扱わない
(I2C のセンサーをプログラムで読む流れは 11-5 の温度センサーと同じ)。

## 回路図

```circuit
title: 図1 BMP280 の基板の SCL・SDA を 4.7 kΩ で 3.3 V に引き上げる
parts:
  M1:
    type: device
    at: 2,5
    label: BMP280
    pins: [VCC, CSB, SCL, SDA, SDO, GND]
    turn: mirror
  VCC: vcc 4,2 3.3V
  RP1: resistor 7,2 7,5 4.7k
  SCL: port 9,5
  VCC: vcc 10,3 3.3V
  RP2: resistor 10,3 10,5.4 4.7k
  SDA: port 12,5.4
  G1: ground 3.8,7
wires:
  - 4,2 -- 5,2 -- 7,2
  - M1.VCC -| 4,2
  - M1.CSB -| 5,2
  - M1.SCL -- 7,5 -- 9,5
  - M1.SDA -- 10,5.4 -- 12,5.4
  - M1.SDO -| 3.8,6.2
  - 3.8,6.2 -- 3.8,7
  - M1.GND -- 3.8,6.2
notes:
  - text 6,8 blue left: "SCL に AD3 の DIO 0 と CH1、SDA に DIO 1 と CH2 をつなぐ"
  - text 6,9 blue left: "SDO を GND にすると番地は 0x76、CSB を 3.3V にすると I2C"

  grid: on
  pitch: 1.2
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/08-sensors/circuit/17-bmp280-i2c.svg)

- **BMP280 の基板 (M1)**: VCC と GND に 3.3 V。BMP280 は 1.71〜3.6 V で動き、**5 V は入れられない** (データシート)。
  CSB を 3.3 V にすると I2C で、SDO を GND にすると番地は **0x76** (3.3 V にすると 0x77)。基板によっては CSB・SDO が基板の上で決めてあるので、印字と抵抗で確かめる
- **RP1・RP2 (4.7 kΩ)**: SCL と SDA を 3.3 V に引き上げる。基板にもプルアップ (10 kΩ など) が載っていることが多く、そのときは並列になる (10 kΩ と 4.7 kΩ で 3.2 kΩ)
- **R<sub>p</sub> の上限**: I2C の決まり (NXP の UM10204) では、立ち上がり (30 % → 70 %) の時間 t<sub>r</sub> は
  100 kHz で 1,000 ns 以下、400 kHz で 300 ns 以下。t<sub>r</sub> = 0.8473 × R<sub>p</sub> × C<sub>b</sub> なので、C<sub>b</sub> を 50 pF と**仮定**すると、
  4.7 kΩ では **約 200 ns** (400 kHz でも間に合う)、47 kΩ では約 2,000 ns (100 kHz でも間に合わない)
- **R<sub>p</sub> の下限**: L のとき、引く機器は 3 mA 以上を 0.4 V 以下で流せればよい (同じ決まり)。(3.3 − 0.4) V ÷ 3 mA ≈ 1 kΩ より大きくする。4.7 kΩ なら L で 0.7 mA
- **AD3 の DIO 0 (SCL) と DIO 1 (SDA)**: WaveForms の Protocol の I2C で親になり、番地 0x76 に書き込み・読み出しをする。AD3 の DIO は 3.3 V の論理なので、電源を 3.3 V にそろえた

![ブレッドボードの実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/08-sensors/breadboard/17-bmp280-i2c.svg)

- 3.3 V は AD3 の Supplies の V+ (WaveForms で 3.3 V にする) から下の + レールへ。右端で上のレールへ渡す。**5 V にしない** (BMP280 の上限は 3.6 V)
- **BMP280 の基板**はブレッドボードに挿さず、メス-オスのジャンパ線で上からつなぐ (高さを変えて気圧の変化を見るため。線は 30 cm 以内)。
  VCC を + レール、GND を − レール、CSB を + レール、SDO を − レールへ。SCL (黄) を列 10、SDA (青) を列 14 へ
- **プルアップ**: RP1 は列 6〜10 (列 6 を + レールへ)、RP2 は列 14〜18 (列 18 を + レールへ)
- 列 10 と列 14 は短い線で下のブロックへ渡し、AD3 の DIO 0 を `j10` (SCL)、DIO 1 を `j14` (SDA) に挿す。オシロは 1+ を列 12 (SCL から延ばした所)、2+ を列 16 (SDA) に
- 電流は BMP280 の測る間の 1 mA 以下 (データシート)、プルアップの L の間の 0.7 mA × 2。AD3 の Supplies とブレッドボードの範囲に十分収まる

## 計器の設定

計器は AD3。Supplies の V+ を 3.3 V。WaveForms の **Protocol** を開き、**I2C** の画面で SCL に DIO 0、SDA に DIO 1 を選び、速さを 100 kHz にする。

1. **チップの番号を読む**: 番地 0x76 に、レジスタの番号 0xD0 を書いて (Write)、続けて 1 バイト読む (Read)。返る値が **0x58** なら、配線と番地が合っている
   (BMP280 の「id」レジスタ。データシートの値)。返事が無い (NAK) ときは、番地 (0x77 か)、CSB・SDO、プルアップを見直す
2. **1 回測らせる**: レジスタ 0xF4 (ctrl_meas) に 0x25 を書く (温度・気圧を 1 回ずつ測る forced mode)。数 ms 後に 0xF7 から 6 バイトを読むと、
   気圧と温度の生の値が並ぶ。気圧 (hPa) に直すには、0x88 から読む校正の値とデータシートの計算式が要る (この題では生の値まで)
3. **立ち上がりを測る**: 1 の読み出しを Protocol で繰り返しながら、Scope の CH1 (SCL) を横 200 ns/div、縦 500 mV/div、CH1 の立ち上がり 0.99 V でトリガして見る。
   Measurements の Rise Time は 10〜90 % の時間なので、I2C の 30〜70 % はカーソルで読む (図3)

見えるはずの画面 (SCL の 1 つの立ち上がり。線の容量 50 pF を**仮定**した計算値で、実測ではない)。

```scope
# オシロスコープの画面 (tommie-fence の scope フェンス)
title: 図3 4.7 kΩ と 50 pF の SCL の立ち上がり (30 % → 70 % で約 200 ns)
time: 200ns/div
trigger: ch1 rising 0.99V at -4div
ch1: {wave: "= 3.3V * step(t + 84ns) * (1 - exp(-(t + 84ns) / 235ns))", range: 500mV/div, position: -3div}
cursors: [0, 199ns]
measure: [vmax, vmin]
notes:
  - mark 0 0.99V
  - mark 199ns 2.31V
  - text 400ns 1.5V: 30 % (0.99 V) → 70 % (2.31 V)
```

![オシロスコープの画面](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/08-sensors/scope/17-bmp280-i2c.svg)

- 立ち上がりは指数の曲線 (1-3 の充電) で、時定数は 4.7 kΩ × 50 pF = 235 ns。カーソルの X1 を 30 % (0.99 V)、X2 を 70 % (2.31 V) に置くと、ΔX は約 200 ns
- 立ち下がりは、AD3 (か BMP280) が L に引くので速い (数十 ns)
- **RP1 を 47 kΩ に替えて比べる**: 時定数が 10 倍の 2.35 µs になり、30〜70 % で約 2 µs。100 kHz の H の 5 µs の間に 3.3 V の 8 割ほど (2.7 V) までしか上がらない。
  I2C の決まり (100 kHz で 1 µs 以下) を外れ、読み出しを繰り返すと失敗が混じることがある
- **高さを変える**: 2 の手順で生の値を読みながら基板を床から 1 m ほど持ち上げると、気圧の生の値が変わる (hPa に直せば約 0.12 hPa 下がる。生の値は温度でも動くので、何度か読んで比べる)

## LTspice での確かめ

BMP280 の中と I2C の取り決め (番地・レジスタ) は SPICE の対象外。`sim/17-bmp280-i2c.cir` で SCL の電気の側だけを、
「開放ドレインのスイッチ + プルアップ + 線の容量 50 pF (仮定)」で解き、R<sub>p</sub> を 4.7 kΩ と 47 kΩ に振った。チップの番号 (0x58) と番地 (0x76) はデータシートの値。

| 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| 立ち上がり (30〜70 %)、4.7 kΩ | 約 200 ns | 199 ns | 合う |
| 立ち上がり (30〜70 %)、47 kΩ | 約 2 µs | 1.99 µs | 合う |
| 47 kΩ のとき、H の 5 µs 後の電圧 | 約 2.7 V (3.3 V の 8 割) | 2.67 V | 合う |
| L の電流、4.7 kΩ | 約 0.7 mA | 0.70 mA | 合う |
| L の電圧 | 0.1 V 以下 | 0.014 V | 合う (スイッチの 20 Ω は仮定) |
