# 8-5 赤外線 LED とフォトトランジスタ — 遮光検出

赤外線 (IR) LED を光らせっぱなしにして、向かい合わせたフォトトランジスタ (光が当たるとコレクタ電流が流れるトランジスタ) で
受け続ける。間に物が入って光が遮られると、光を受け取れなくなる。これを検出して、インジケータの LED を点ける。
コピー用紙の通過の検知やドアの開閉の検知など、遮光検出は現場でよく使われる。

## 回路図

```circuit
title: 図1 光を遮るとインジケータが点く
parts:
  VCC: vcc a2 5V
  R1: resistor a2 c2 220
  D1: led c2 e2
  G1: ground e2
  VCC: vcc a4 5V
  R2: resistor a4 c4 10k
  Q1: phototransistor d4 NJL7502L
  G2: ground e4
  R3: resistor c4 c6 10k
  VCC: vcc a7 5V
  R4: resistor a7 c7 330
  D2: led c7 e7
  Q2: npn f7 2SC1815
  G3: ground g7
wires:
  - c4 -- Q1.C
  - Q1.E -- e4
  - c6 |- Q2.B
  - e7 -- Q2.C
  - Q2.E -- g7
style:
  grid: on
  pitch: 1.2
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/08-sensors/circuit/05-photointerrupter.svg)

- D1 (赤外線 LED) は、R1 (220 Ω) で決まる電流で光りっぱなしになる。赤外線は人の目には見えない
  (スマートフォンのカメラ越しに見ると、紫っぽく光って見えることがある)
- Q1 (フォトトランジスタ) は D1 の光を受けると電流を流し、R2 (10 kΩ のプルアップ) と Q1 の接点の電圧が下がる。
  以下、この点を「分圧点」と呼ぶ。光が遮られると Q1 は電流を流せなくなり、分圧点は
  R2 を通して引き上げられる (Q2 のベースへ電流が流れるので、約 2.9 V)
- 分圧点の電圧を、R3 (10 kΩ) を通して Q2 のベースに入れる。遮られて分圧点が高いときだけ
  Q2 が ON になる。D2 (インジケータの LED) は R4 と一緒に、Q2 のコレクタに直列
  (+5 V → R4 → D2 → Q2 → GND) につないである。Q2 が ON のときだけ電流が流れて
  点くので、「光が来ている」ではなく「光が遮られた」ことを示す回路になる
- 遮っていないときは分圧点が 0.2〜0.4 V しかなく、Q2 のベースは 0.6 V に届かない。
  Q2 は OFF で、D2 の通り道が切れて消えている

## 実体配線図

```breadboard
title: 図2 ブレッドボードに組む
# 上の赤いレール = +5V、青いレール = GND (29 列で下の − レールへ渡す)
board: half
parts:
  PSU:
    type: device
    at: top
    label: 電源 5V
    pins: ["+", "-"]
  R1: resistor b3 b6 220
  D1: led d6(A) d9(K)
  R2: resistor b12 b16 10k
  Q1: phototransistor d16(C) d19(E)
  D2: led d26(A) d22(K) red
  R4: resistor b26 b29 330
  R3: resistor g16 g20 10k
  Q2: transistor h21(B) h22(C) h23(E) 2SC1815
wires:
  - PSU.+ -- +t1 red
  - PSU.- -- -t2 black
  - +t3 -- a3 red
  - a9 -- -t9 black
  - +t12 -- a12 red
  - a19 -- -t19 black
  - +t29 -- a29 red
  - e16 -- f16 yellow
  - f20 -- f21 green
  - e22 -- f22 orange
  - j23 -- -b23 black
  - -t30 -- -b30 black
notes:
  - text: D1 (赤外線 LED) と Q1 (フォトトランジスタ) を向かい合わせて置き、間に紙を通す
```

![ブレッドボードの実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/08-sensors/breadboard/05-photointerrupter.svg)

- 電源の + と GND は上のレールに入れ、右端 (30 列) で下の − レールへ渡す
- D1 (赤外線 LED、6→9 列) と Q1 (フォトトランジスタ、16→19 列) は上のブロックに挿し、
  リード線を曲げて、光る面と受ける面を向かい合わせる。図2 では D1 を赤い LED の形で描いているが、実物は無色透明か薄い青の胴が多い。
  Q1 の C・E の見分け方 (足の長さ・平らな面) は品ごとに違うので、データシートで確かめる
- 分圧点 (16 列) は黄色の線で下のブロックへ渡し、R3 (16→20 列) と緑の線を通して Q2 のベース (21 列) へつなぐ
- Q2 (2SC1815) は、平らな面を手前にして見ると左から E・C・B。ここでは平らな面を奥 (f 行側) に向けて挿し、
  B・C・E を h 行の 21・22・23 列に入れる。エミッタ (23 列) は下の − レールへ
- コレクタ (22 列) はオレンジの線で上のブロックへ渡し、D2 のカソード (22 列) につなぐ。
  D2 のアノード (26 列) から R4 (26→29 列) を通して + レールへ

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| D1 | 赤外線 LED | V<sub>F</sub> ≈ 1.2 V |
| R1 | 抵抗 | 220 Ω |
| Q1 | フォトトランジスタ | NJL7502L など (赤外線に感度のある品を選ぶ) |
| R2・R3 | 抵抗 | 10 kΩ |
| Q2 | NPN トランジスタ | 2SC1815 |
| R4 | 抵抗 | 330 Ω |
| D2 | LED (赤、インジケータ) | V<sub>F</sub> ≈ 2.0 V |

## 見るべき値

表の値は計算値。電圧はテスターの DC 電圧レンジで、− 側の棒を GND に当てて測る。分圧点は上のブロックの 16 列。

| 測る所 | 期待する値 | 分かること |
| --- | --- | --- |
| D1 (赤外線 LED) の電流 | 約 17.3 mA (= (5 − 1.2) / 220 Ω) | R1 で決まる |
| 分圧点の電圧 (光が通っているとき) | 約 0.2〜0.4 V (Q1 が飽和) | Q1 が光を受けて電流を流している |
| 分圧点の電圧 (光を遮ったとき) | 約 2.9 V (= 0.7 + 4.3 V × 10 kΩ / 20 kΩ) | Q1 に電流が流れなくなり、R2 → R3 → Q2 のベースへ電流が流れる。Q2 のベースが 0.7 V に抑えるので 5 V までは上がらない |
| Q2 のベース電流 (遮ったとき) | 約 215 µA (= (5 − 0.7) / (R2 + R3) = 4.3 V / 20 kΩ) | hFE が 70 でも 15 mA まで流せ、D2 の電流 (約 8.5 mA) に対して Q2 を飽和させるのに十分 |
| D2 の電流 (遮ったとき) | 約 8.5 mA (= (5 − 2.0 − 0.2) / 330 Ω、0.2 V は Q2 の V<sub>CE(sat)</sub>) | R4 で決まる |
| D2 (インジケータ) | 遮ったときだけ点灯 | 「遮光検出」の名前どおりの動き |
