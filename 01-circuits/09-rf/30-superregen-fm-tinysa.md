# 9-30 超再生 FM ラジオの発振を tinySA で見る — クエンチの側波と同調の範囲

9-6 で組んだ超再生 FM ラジオを、そのまま tinySA で測る題。受信機が漏らす自分の発振の周波数と、
クエンチが作る側波を見る。VC1 を回したときに発振が動く範囲も見て、銅張り基板の浮遊容量とピンで下がる見積もりと比べる。
題材が FM 放送帯 (75〜110 MHz) で、9-6 と同じ銅張り基板を使うので入門に置く。

回路図・実体配線図・Analog Discovery 3・オシロの図は入れない (9-6 と同じ基板をそのまま使い、測り方だけを足す題。図は 9-6 の図1・図2)。

> [!WARNING]
> 9-6 と同じく、**微弱無線局**の範囲 (322 MHz 以下、距離 3m で電界強度 500 µV/m 以下、電波法施行規則第 6 条) に収める。
> **アンテナは短く・結合は弱く (Cant は小さいまま)**。確かめる間だけ電源を入れる。

## 同調の範囲が下がる見積もり

9-6 の計算値 79〜110 MHz は、銅張り基板の島とピンで下がる。見積もりは次のとおり (目安で、実測はしていない)。

- **島の浮遊容量**: 一番大きい島は、タンクの節点 COL (5×13.5mm)。裏の GND の面との容量は、
  C = ε<sub>0</sub>ε<sub>r</sub>A/h (ε<sub>r</sub> = 4.4、h = 1.6mm、A = 67.5mm²) で **約 1.6 pF** (縁を含めて 2 pF 前後)。
  タンクの容量の **4〜8%** で、同調範囲は 110 MHz 側で約 4%、79 MHz 側で約 2% 下がるだけで、VC1 で追える。
  ほかの島 (4×4mm で約 0.4 pF) は、容量の大きい部品に並ぶか高周波が通らない節点なので、同調にほとんど効かない
- **ピンのインダクタンス**: 直径 0.5mm のピンは **1mm あたり 0.7 nH 前後** (L ≈ 2l[ln(4l/d) − 0.75] nH、l と d は cm。9-27 と同じ見積もり)。
  タンクの輪に入る C1 (島の間 4mm) と C2 (6mm) のピンで **約 7 nH**、L1 (100 nH) の 7%。
  配線の分を足すと同調範囲はさらに約 3% 下がり、およそ **74〜102 MHz** (FM 放送帯 76.1〜95.0 MHz を含む)。
  ピンを切り詰めて島の間を詰めるのが、この組み方の効きどころ

## クエンチの周波数

9-6 の LTspice では、hFE = 300 の個体は約 68 kHz でクエンチし、hFE = 50・100 ではクエンチせずに連続して発振した。
クエンチするかどうかは、発振が育ったときにベースの直流電位が Cq 越しに下がるほど振れが大きいかで決まる。hFE が小さい個体は振れが足りず、連続発振のままになる
(9-6 が「感度が足りなければ、hFE の大きい個体を選ぶ」と書くのと同じ向き)。クエンチの周波数は Rq×Cq だけでなく、ベースの充電にかかる時間と発振が育つ時間でも決まるので、
1/(Rq×Cq) は目安の下限に近い。図1 の側波の間隔 (30.3 kHz) は「クエンチがその周波数で働いたとき」の姿として読み、実物は tinySA の側波の間隔から f<sub>q</sub> を読んで合わせる。

## 計器の設定

**tinySA Ultra** (手のひらのスペクトラムアナライザ、通常モードで 100 kHz〜800 MHz、入力は SMA) で、
この回路が出す**自分の発振**を見る。超再生検波は受信中もつねに発振していて、ごくわずかに電波が漏れる
(9-6 の警告)。だから受信機を鳴らしながら、**発振している周波数**と、クエンチが作る**側波**
(9-4 で見たのと同じく、搬送波の両側に立つ線) を確かめられる。
**なぜ tinySA か。** 75〜110 MHz は Analog Discovery の帯域 (10 MHz 以下) の外で、見たいのは
波形ではなくスペクトル (搬送波の位置と側波の間隔) だから。

tinySA の入力 (LOW) に、**アンテナ線を数十 cm** (20〜30cm) 付けるか、tinySA 付属のアンテナを
受信機のアンテナ線の近く (数 cm〜10cm) に置く。回路と直接はつながず、**電波で拾う**。
アンテナ線を長くしたり、受信機に近づけすぎたりしない (上の警告のとおり、微弱無線局の範囲は
322 MHz 以下、距離 3m で 500 µV/m 以下)。**確かめる間だけ電源を入れ**、見終わったら切る。
入力は +0 dBm 以下に保つ (tinySA Ultra の絶対最大は +6 dBm、直流は ±5 V まで)。ここで拾う電力は −50 dBm 台で、上限よりずっと小さい。

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| 中心 / 幅 | 85 MHz / 500 kHz | 発振の 85 MHz (VC1 で 74〜102 MHz の間を動く) を真ん中に、側波が両側に入る。広く見るときは 70〜110 MHz |
| 点数 | 450 | 1 点 = 約 1.1 kHz。側波の間隔 30.3 kHz は 27 点ぶん |
| RBW | 3 kHz | 側波の間隔の 1/10。3 kHz なら隣の線が分かれる。フロアは約 −112 dBm |
| 基準レベル (REF) | −40 dBm | 搬送波 (−55 dBm) が上端から 1.5 目盛下 |
| 縦の目盛 | 10 dB/div | 既定 |
| 減衰 (ATT) | 自動 | 入力は −55 dBm と上限より小さい |
| マーカー | 1 = peak (発振)、2 = 下の側波、3 = 上の側波 | 本文の順 |

手順は、まず VC1 を真ん中付近にして電源を入れ、幅を 70〜110 MHz にして発振の山を探す (RBW 100 kHz、
MAX HOLD にして VC1 を端から端まで回すと、山の動いた範囲が見える)。山が見つかったら、そこを中心に
幅 500 kHz・RBW 3 kHz に狭めて側波を見る。近くの FM 放送局の山が同じ画面に映ることもある。
発振の山は VC1 を回すと動き、放送局の山は動かないので見分けられる。

## 計器の画面

搬送波と、クエンチ周波数 f<sub>q</sub> = 30.3 kHz おきに並ぶ側波。図の値は**目安**で、次の仮定を置いた。
実物は結合の強さ・アンテナの向き・距離で **±20 dB くらい**動く。

- 搬送波 −55 dBm (85 MHz、tinySA 付属のアンテナを受信機から 10cm に置いたときの目安)
- 側波は 1 次が搬送波の 12 dB 下、2 次が 20 dB 下、3 次が 26 dB 下 (仮定。実物はクエンチの波形で変わる。
  さらに外側は幅の広い裾になって、フロアが持ち上がって見える)。左右は同じ高さとした

```spectrum
# スペクトラムアナライザの画面 (tommie-fence の spectrum フェンス)
title: 図1 搬送波とクエンチの側波 (30.3kHz おき)
device: tinysa-ultra
center: 85MHz
span: 500kHz
points: 450
rbw: 3kHz
ref: -40dBm
signal:
  - sine 85MHz -55dBm
  - sine 84.9697MHz -67dBm
  - sine 85.0303MHz -67dBm
  - sine 84.9394MHz -75dBm
  - sine 85.0606MHz -75dBm
  - sine 84.9091MHz -81dBm
  - sine 85.0909MHz -81dBm
markers: [peak, 84.9697MHz, 85.0303MHz]
```

![スペクトラムアナライザの画面](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/09-rf/spectrum/30-superregen-fm-tinysa-1.svg)

- マーカー 1 が発振 (搬送波)。2・3 がその両側の 1 次の側波で、間隔は f<sub>q</sub> = 1/(Rq×Cq) の
  **30.3 kHz** (計算値)。Rq や Cq を替えると、この間隔が動く
- 側波の間隔が f<sub>q</sub> に合わないときは、クエンチが働いていない (ふつうの連続発振になっている)
  か、Cq・Rq の値を疑う

VC1 を端から端まで回したときの、発振の動く範囲は次のとおり。tinySA を MAX HOLD にすると、VC1 を回すあいだに
山の動いた跡が最大値の線として残っていく。実機では回した分だけ線が伸びていくが、
図は 74〜102 MHz を回し終えた後の姿で、保持したトレースの線とその下の薄い塗りの帯として描いた。
RBW 100 kHz では側波が搬送波に含まれて、山が約 0.6 dB 高く出る (−54.4 dBm)。

```spectrum
# スペクトラムアナライザの画面 (tommie-fence の spectrum フェンス)
title: 図2 VC1 を回したときの発振の範囲 (MAX HOLD)
device: tinysa-ultra
sweep: 70M-110M 450
rbw: 100kHz
ref: -40dBm
hold: sine 74MHz..102MHz -54.4dBm
markers: [74M, 102M]
```

![スペクトラムアナライザの画面](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/09-rf/spectrum/30-superregen-fm-tinysa-2.svg)

- マーカー 1・2 は帯の両端 (74 MHz と 102 MHz) で、どちらも保持したトレースの値。
  74 MHz は VC1 が最大 (24.5 pF)、102 MHz が最小 (4.5 pF) のときで、上の銅張り基板の見積もり
  (浮遊容量とピンのインダクタンスで下がった 74〜102 MHz) の値。実測はしていない。
  日本の FM 放送帯 (76.1〜95.0 MHz) はこの間に入る

## 見るべき値

計算値。tinySA の高さは目安 (計算した値ではなく、上の仮定の値)。

| 確かめること | 期待する値 |
| --- | --- |
| tinySA の発振のマーカー 1 (幅 500 kHz、RBW 3 kHz) | 85 MHz、約 −55 dBm (目安。10cm、アンテナ利得 0dBi の仮定で ±20 dB) |
| tinySA のマーカー 2・3 (側波) | 85 MHz の ±30.3 kHz (f<sub>q</sub> の計算値)、約 −67 dBm (搬送波の 12 dB 下、仮定) |
| tinySA で VC1 を端から端まで回す (幅 70〜110 MHz、MAX HOLD) | 山の動いた跡 (最大値の線) が約 74〜102 MHz の帯になる。図のマーカーは両端で約 −54.4 dBm (計算値。実測はしていない) |
