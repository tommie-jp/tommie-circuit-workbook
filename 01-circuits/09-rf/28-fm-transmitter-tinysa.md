# 9-28 FM 送信機の搬送波と高調波を tinySA で見る

**先に 9-4 (FM 送信機、1 石) を組んでおく。** この題は 9-4 の送信機の電波を tinySA Ultra で拾い、
搬送波の周波数と、2 倍・3 倍の高調波の高さを見る。回路・銅張り基板の島の配置・電波法の注意は 9-4 のまま。
回路が働く周波数は 80 MHz (FM 放送帯) で 3 MHz を超えるが、題材が FM 放送帯で 9-4 と同じ銅張り基板に組むので入門に置く。

この題は実体配線図・Analog Discovery 3 の図を付けない。9-4 と同じ基板をそのまま使い、測り方だけを足す (図は 9-4 の図1・図2)。

## 計器の設定

この題はオシロの図を付けない。搬送波は 80 MHz で、AD3 の Scope の範囲 (10 MHz 以下) の外にあり、波形では見えない。
図1 の tinySA のスペクトルで確かめる。電源は 9-4 のとおり AD3 (Supplies) から入れる。

**なぜ tinySA か。** 搬送波は 80 MHz 前後で、Analog Discovery の入力の範囲 (10 MHz 以下) の外にある。
この題で見たいのは波形の形ではなく、**搬送波の周波数と、2 倍・3 倍の高調波の高さ**、つまりスペクトルなので、
0〜5.3 GHz を見られる **tinySA Ultra** (手のひらのスペクトラムアナライザ) を使う。
スペクトラムアナライザ (スペアナ) は、横軸に周波数、縦軸に信号の強さをとって、
どの周波数にどれだけの信号があるかを見る計器。強さは **dBm** (1 mW を 0 dBm とした電力の dB。
−10 dBm が 0.1 mW、−50 dBm が 10 nW) で読む。

**拾い方。** 送信機のほうは何もつながず、電波を短い距離で拾う。

- 基本は、tinySA Ultra の入力 (SMA) に付属のアンテナ (または 20cm ほどの線) を挿し、送信機から
  **数十cm** 離して置く。近づけすぎると tinySA の入力が飽和し、送信機のタンクも引っ張られて周波数がずれる
- 山が小さすぎて見えないときだけ、アンテナ線 (ANT の島) を外して短い線を近づけて拾う。
  **同軸ケーブルで直接つなぐのは、山が高すぎるとき (−10 dBm を超えるとき) に SMA の減衰器 (20 dB など) を
  介して**だけ。この回路の Cant (2.2 pF) は 80 MHz で約 900 Ω のインピーダンスなので、50 Ω の入力を直に
  つなぐと発振がほとんど止まる
- **電波法の範囲を超えない。** 322 MHz 以下の微弱無線局は距離 3m で 500 µV/m 以下。この図の拾い方は
  アンテナ 20cm・電流 0.75 mA のままで、ここで増幅器やアンテナを足して山を高くしてはいけない
- **入力の上限は、tinySA Ultra で絶対最大 +6 dBm (推奨は +0 dBm 以下、直流は ±5 V まで)。** この回路を数十cm 先で拾った山は −50 dBm ほど (下の目安) で、上限よりずっと低く、減衰器なしで収まる

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| 開始 / 終了 | 0 / 359.2 MHz | 搬送波 (80 MHz) と 2 倍 (160 MHz)・3 倍 (240 MHz) が 1 画面に入る。この幅だと 3 本とも点の真上に載る |
| 点数 | 450 | 1 点 = 0.8 MHz。3 本は 80 MHz ずつ離れている |
| RBW (分解能帯域幅。一度に見る周波数の幅で、狭いほど近い線を分けられ、雑音の床 = フロアも下がる) | 100 kHz | フロアは約 −97 dBm (−102 dBm @ 30 kHz から換算)。FM の振れ (数十 kHz) は 1 本の線に収まる |
| 基準レベル (REF) | −30 dBm | 搬送波 (−50 dBm) が上端から 2 目盛下。高調波 (−70・−80 dBm) も画面に入る |
| 縦の目盛 | 10 dB/div | 既定 |
| マーカー | 1 = 80 MHz、2 = 160 MHz、3 = 240 MHz | peak で 1 を取り、周波数で 2・3 を置く |

**周波数を合わせるとき。** 上の広い掃引で搬送波の場所を見つけたら、中心をその周波数に、幅を 2 MHz 程度に、
RBW を 10 kHz 程度に狭めて読む。島の浮遊容量とピンのインダクタンスのため (見積もりは 9-27)、搬送波は **73〜80 MHz** の間に
出る見込みで、**コイルの巻きを少し広げて 80 MHz へ合わせる** (巻きを広げると上がる)。

## 計器の画面

```spectrum

```

![スペクトラムアナライザの画面](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/09-rf/spectrum/28-fm-transmitter-tinysa.svg)

- **図の高さはすべて目安 (見積もり)**。仮定は 3 つ。(1) 搬送波は、アンテナ 20cm と結合 2.2 pF から
  tinySA へ数十cm で拾って **−50 dBm** (アンテナの向き・机や手の反射で ±15 dB は動く)。
  (2) 2 倍は搬送波の 20 dB 下 (**−70 dBm**)、3 倍は 30 dB 下 (**−80 dBm**)。1 石のコルピッツはタンクの
  共振で高調波が落ちるが、コレクタ電流が歪んでいるので、その程度は残ると見た。(3) 高調波は
  それぞれの周波数で拾いやすさが違い、アンテナの利得も変わるので、実物は ±10 dB 以上ずれうる
- 実物の搬送波は、マイクの音声で 80 MHz の前後に数十 kHz 振れる。RBW 100 kHz では 1 本の線に見える
  (この振れを見たいときは、9-18 のとおり、幅を 10 kHz・RBW を 200 Hz まで絞る)
- 画面には近くの FM 放送局 (76〜95 MHz) の線が別に出ることがある。搬送波と紛れるときは
  送信機の電源を切って消えるほうを搬送波とする

## 見るべき値

見積もり。

| 確かめること | 期待する値 |
| --- | --- |
| tinySA のマーカー 1 (搬送波) | 73〜80 MHz の間 (ピン・浮遊容量の見積もり、9-27)。コイルを広げて **80 MHz** に合わせる |
| tinySA のマーカー 1 の高さ | 約 −50 dBm (数十cm で拾うとき、目安。±15 dB) |
| マーカー 2 (160 MHz、2 倍) | 約 −70 dBm (搬送波の 20 dB 下、仮定) |
| マーカー 3 (240 MHz、3 倍) | 約 −80 dBm (搬送波の 30 dB 下、仮定)。RBW 100 kHz のフロア (−97 dBm) の上 |

## LTspice での確かめ (対象外)

回路は 9-4 の図1 と同じで、動作点と発振周波数の突き合わせは 9-4 と 9-27 の「LTspice での確かめ」にある。
tinySA の高さ・高調波の dBm は、アンテナと結合の仮定を置いた見積もりで、ここでは走らせていない (対象外)。
