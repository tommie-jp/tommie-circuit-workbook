# 9-1 LC 同調 — 共振を LED で見る

コイルとコンデンサを直列につなぐと、ある周波数だけでインピーダンス (交流の流れにくさ。
抵抗と、次に説明するリアクタンスを合わせたもの) が最小になる。
これが**直列共振**で、その周波数 f<sub>0</sub> は 1 / (2π√(LC)) で決まる。ファンクションジェネレータの
周波数を動かし、共振点の近くだけ LED が光るようすを見る。ラジオの同調回路と同じ原理。
あわせてオシロスコープで輪を流れる電流を読み、**周波数と電流のグラフ (共振曲線)** を描く。

## 回路図

```circuit
# 回路図 (tommie-fence の circuit フェンス)
title: 図1 R1 の電圧でトランジスタをオンにして LED を点ける
parts:
  V1: sine 1,6 1,8 3
  M1: voltmeter 3,6 3,8 l=$\mathrm{CH1}$
  L1: inductor 4,6 5,6 10m
  C1: capacitor 5,6 6,6 10n
  R1: resistor 7,6 7,8 100 i=I
  M2: voltmeter 9,6 9,8 l=$\mathrm{CH2}$
  R2: resistor 10,6 11,6 10k
  VCC: vcc 12,3 5V
  R3: resistor 12,3 12,4 330
  D1: led 12,4 12,5 red
  Q1: npn 12,6 2SC1815
  G1: ground 1,8
wires:
  - 1,6 -- 3,6 -- 4,6
  - 6,6 -- 7,6 -- 9,6 -- 10,6
  - 11,6 -- Q1.B
  - 12,5 -- Q1.C
  - Q1.E -- 12,8
  - 1,8 -- 3,8 -- 7,8 -- 9,8 -- 12,8
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/09-rf/circuit/01-lc-resonance.svg)

L1・C1・R1 が直列の 1 つの輪になっている。LED はこの輪の外にあり、別の 5 V から点ける。

- 共振周波数 f<sub>0</sub> = 1 / (2π√(10 mH × 10 nF)) **≈ 15.9 kHz**
- コイルとコンデンサが交流を妨げる度合いを**リアクタンス**という。コイルは
  X<sub>L</sub> = 2πfL で周波数が高いほど、コンデンサは X<sub>C</sub> = 1/(2πfC) で
  周波数が低いほど大きい。直列では 2 つが逆向きに働き、差し引きになる
- f<sub>0</sub> では X<sub>L</sub> と X<sub>C</sub> が等しく (どちらも約 1 kΩ) 打ち消し合い、
  輪に残るのは R1 とコイルの巻線抵抗 (小さな 10 mH のコイルで実測 20 Ω ほど) だけになる。
  離れると打ち消し合わなくなり、インピーダンスが跳ね上がって電流が減る

**R1 の電圧で LED を点ける。** 輪の電流 I は R1 に I × 100 Ω の電圧を作る。

- 正の半周期でこれが約 0.6 V を超えると Q1 がオンになり、VCC (5 V) → R3 → D1 → Q1 の道で LED に電流が流れる
- ベースの電流は R2 (10 kΩ) で絞られ、多くて 0.2 mA ほど。輪の電流 (共振で 17.6〜24.9 mA) の
  1% に満たない。LTspice (回路の電圧と電流をパソコンで計算する無料のシミュレータ) で、
  Q1 を外したときとの差は 0.5% 未満
- LED の電流は、Q1 がオンの間は (5 V − 1.8 V − 0.2 V) ÷ 330 Ω ≈ 9 mA
  (1.8 V は LED の順方向電圧、0.2 V はオンの Q1 に残る電圧)。
  オンは正の半周期の頂上の近くだけなので、平均では 3 mA ほど
- 負の半周期は R1 の電圧が Q1 のベースを逆向きに押すが、最大でも 2.5 V
  (出力 ≈ 0 Ω の発生器のとき) で、2SC1815 のエミッタ・ベース間の耐圧 5 V より小さい
- MOSFET (2N7000 など) は、しきい値電圧が 0.8〜3 V とばらつき、R1 の電圧 (共振で 1.8 V ほど、出力 50 Ω のとき) では
  オンにならない個体があるので使わない

**LED は輪の中に入れない。** 輪の電流を半周期ごとの細い山に刻み、共振を乱すため (LTspice の値は 9-32)。

**R1 は GND の側に置く。** プローブの GND クリップは GND にしか付けられない。R1 の下の端を GND にしておけば、
CH2 で R1 の上の端を測るだけで、輪の電流が I = V<sub>R1</sub> / 100 Ω で分かる。CH1 は発生器の出力を見る。

![ブレッドボードの実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/09-rf/breadboard/01-lc-resonance.svg)

- AD3 の W1 (Wavegen) が図1 の V1 で、オシロは Scope の 1 (CH1) と 2 (CH2)
- 上の半分が共振の輪。列 3 に W1 (b3)・CH1 の 1+ (a3)・L1 の左のピン、
  列 10 に C1・R1・CH2 (a10) が集まる。R1 の右の端 (列 14) は上の − レールへ
- 列 10 の輪の電圧を青の線で下の半分へ渡し、R2 で Q1 のベース (列 15) に入れる。
  2SC1815 は平らな面を見て左から E・C・B なので、平らな面を奥 (f 行側) に向けて左から B・C・E に挿す
- コレクタ (列 16) は緑の線で上の半分の D1 のカソードへ。D1 のアノード (列 17) から R3 を通って上の + レール (5 V) へ
- エミッタ (列 17 の下の半分) は下の − レールへ。上下の − レールは 29 列の黒線でつなぐ。上の + レールには AD3 の V+ (5 V) だけを入れる

## 計器の設定

計器は Analog Discovery 3 (AD3) の Wavegen (W1)・Scope・Supplies (V+ = 5 V) で、2〜32 kHz は Scope の範囲に入る。PC オシロでも同じ設定でよい。

発生器:

| 項目 | 値 |
| --- | --- |
| 波形 | 正弦波 |
| 振幅 | 3 V<sub>peak</sub> (6 Vpp)、オフセット 0 V |
| 周波数 | 2 kHz〜32 kHz (下の表の周波数に順に合わせる) |

オシロスコープ:

| 項目 | 値 |
| --- | --- |
| 結合 | CH1・CH2 とも DC |
| 電圧レンジ | CH1 2 V/div、CH2 1 V/div (共振点の 3.5〜5.0 Vpp が 3.5〜5 目盛りに入る) |
| 時間レンジ | 20 µs/div (15.9 kHz の 1 周期 63 µs が約 3 目盛り)。周波数を変えたら 2〜3 周期が見えるように合わせ直す |
| トリガ | CH1、立ち上がり、レベル 0 V |
| 測定 | CH2 の Vpp (自動測定があれば使う) |

LED を光らせる 5 V の電流 (約 3〜9 mA) は AD3 の電源 1 系統の約 50 mA に収まる。
共振から離れると CH2 は 0.1 Vpp ほどまで小さくなるので、読みにくければ CH2 のレンジを下げる。

## 見るべき値

周波数ごとに CH2 の Vpp を読み、電流のピーク I<sub>peak</sub> = (CH2 の Vpp ÷ 2) ÷ 100 Ω に直す (例: 3.52 Vpp → 17.6 mA)。

表は LTspice のシミュレーション値 (LED は赤色で順方向電圧 約 1.8 V、コイルの巻線抵抗は 20 Ω)。
多くのファンクションジェネレータは出力に 50 Ω の抵抗を持ち、それが輪に直列に入るので、
出力がほぼ 0 Ω の発生器 (AD3 の W1 など) の値も並べた。LED の電流は出力 50 Ω のときの平均。

| --- | --- | --- | --- | --- | --- | --- | --- |
| 2 kHz | 0.08 Vpp | 0.38 mA | 0 | 0.08 Vpp | 0.38 mA | | |
| 5 kHz | 0.21 Vpp | 1.0 mA | 0 | 0.21 Vpp | 1.0 mA | | |
| 8 kHz | 0.40 Vpp | 2.0 mA | 0 | 0.40 Vpp | 2.0 mA | | |
| 10 kHz | 0.61 Vpp | 3.1 mA | 0 | 0.62 Vpp | 3.1 mA | | |
| 12 kHz | 1.01 Vpp | 5.0 mA | 0 | 1.03 Vpp | 5.1 mA | | |
| 13 kHz | 1.36 Vpp | 6.8 mA | 0.03 mA | 1.41 Vpp | 7.1 mA | | |
| 14 kHz | 1.95 Vpp | 9.7 mA | 1.1 mA | 2.11 Vpp | 10.6 mA | | |
| 15 kHz | 2.89 Vpp | 14.4 mA | 2.7 mA | 3.55 Vpp | 17.7 mA | | |
| **15.9 kHz (f<sub>0</sub>)** | **3.52 Vpp** | **17.6 mA** | **3.1 mA** | **4.99 Vpp** | **24.9 mA** | | |
| 17 kHz | 2.78 Vpp | 13.9 mA | 2.6 mA | 3.36 Vpp | 16.7 mA | | |
| 18 kHz | 2.00 Vpp | 10.0 mA | 1.2 mA | 2.18 Vpp | 10.9 mA | | |
| 20 kHz | 1.22 Vpp | 6.1 mA | 0 | 1.26 Vpp | 6.3 mA | | |
| 25 kHz | 0.63 Vpp | 3.2 mA | 0 | 0.64 Vpp | 3.2 mA | | |
| 32 kHz | 0.39 Vpp | 2.0 mA | 0 | 0.40 Vpp | 2.0 mA | | |

- **f<sub>0</sub> で電流が最大になる。** 輪の中の抵抗は R1・巻線・発生器の出力の 170 Ω だけになる。
  山の鋭さは Q で表し、直列共振では Q = (1/R) × √(L/C) (R は輪の中の抵抗の合計)。
  Q = (1/170 Ω) × √(10 mH / 10 nF) = 1000 Ω / 170 Ω ≈ 5.9 (出力 ≈ 0 Ω なら 120 Ω で Q ≈ 8.3)
- **LED は 14〜18 kHz の間だけ点く。** R1 の電圧が約 0.6 V を超える山の頂上の近くだけを切り取るので、
  明るさからは山の鋭さを読めない。山の形は CH2 で読む
- **共振では C1 の両端に発生器の約 Q 倍の電圧がかかる。** C1 のリアクタンスは 15.9 kHz で約 1 kΩ なので、
  17.6 mA × 1 kΩ ≈ 17.6 V<sub>peak</sub> (出力 ≈ 0 Ω なら約 25 V<sub>peak</sub>) で、発生器の 3 V<sub>peak</sub> よりずっと大きい。
  C1 は耐圧 50 V のセラミックコンデンサを使う

### グラフに描く

測った I<sub>peak</sub> を、横軸に周波数 (2〜32 kHz の 16 倍の幅があるので対数)、縦軸に電流をとって片対数の方眼紙に描き、
f<sub>0</sub> = 15.9 kHz で頂点になる山 (共振曲線) を見る。見えるはずの曲線は図3 (上の表のシミュレーション値)。

  (f<sub>0</sub> は √(LC) に反比例し、L と C がともに 10% 大きければ約 9% 下がる)
- 対数の横軸では山が左右で揃う。f<sub>0</sub>/2 の 8 kHz と 2f<sub>0</sub> の 32 kHz が、どちらも 2.0 mA

## LTspice での確かめ

**計算の確かめ (LTspice)**: 上の表は `sim/01-lc-resonance.cir` を過渡解析 (30 周期、最後の 2 周期の CH2 の Vpp と R3 の平均電流を読む) で
走らせ直して突き合わせた。図1 の部品を全部入れ (L1 は巻線 20 Ω)、Q1 は 2SC1815 の代用モデル
(`sim/agc.cir` と同じ。目安から作った仮定で、実測の値ではない)、赤色 LED は 3 mA で約 1.8 V になる仮のダイオードとした。
CH2 の Vpp は 14 周波数 × 出力抵抗 2 通りの全部が表と 0.03 V 以内で合った (例: 15.9 kHz は出力 50 Ω で 3.52 Vpp、≈ 0 Ω で 4.99 Vpp。2 kHz は 0.077 Vpp、32 kHz は 0.39 Vpp)。
LED の平均電流 (出力 50 Ω) も 14〜18 kHz の間だけ流れ、14 kHz 1.2 mA・15 kHz 2.6 mA・15.9 kHz 3.0 mA・17 kHz 2.5 mA・18 kHz 1.3 mA と、
表 (1.1・2.7・3.1・2.6・1.2 mA) に 0.1 mA ほどで合う。13 kHz (0.11 mA、表は 0.03 mA) と 20 kHz (0.02 mA、表は 0) は、
オンになるかならないかの境で LED の仮のモデルに敏感なので、桁が小さいことだけを見る。判定: 合う (本文は直さない)。
Q の値 5.9・8.3 や C1 の電圧 17.6 V は式の計算で、シミュレーションを走らせていない。
