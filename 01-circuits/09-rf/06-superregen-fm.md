# 9-6 超再生 FM ラジオ

**超再生検波**は、9-4 と同じコルピッツ発振回路を、**わざと間欠的に発振・
停止させながら**受信に使う方式。発振が立ち上がる速さが電波の強さで変わる
ことを利用し、1 石だけで高い感度を得る、古くからの方式。
この題では FM 放送を 1 石で受けてイヤホンで聞き、受信機が自分で出している発振を tinySA で見る。
9-4 の送信機と同じ発振回路が、受信にも使えることを確かめる。

> [!WARNING]
> この回路は**受信専用**だが、超再生検波は原理上つねに自分でも高周波を
> 発振していて、アンテナから**ごくわずかに電波が漏れ出す**。9-4 と同じく
> 電波法の**微弱無線局**の範囲 (322MHz 以下、距離 3m で電界強度 500µV/m
> 以下、電波法施行規則第 6 条) に収めるため、**アンテナは短く・結合は弱く
> (Cant は小さいまま)** にする。長いアンテナに張り替えたり、後段に高周波
> 増幅を足したりしない。

この題の流れ:

1. 回路図 (図1): 9-4 との違い (VC1 の同調とクエンチ回路)、超再生で受かるしくみ、音声の取り出し
2. 実体配線図 (図2): 銅張り基板に組む理由と、島の配置
3. 計器の設定と計器の画面 (図3・図4): tinySA で発振とクエンチの側波、VC1 で動く範囲を見る
4. 見るべき値: 聞いて・測って確かめることの一覧

- **タンクと発振回路は 9-4 とほぼ同じ**: L1 (今回は 100nH) と C1・C2 (今回は
  33pF・33pF) のコルピッツ。合成容量 C<sub>s</sub> = 33p×33p/(33p+33p) **= 16.5pF**
- **同調は VC1 で合わせる**: 9-4 はコイルの巻きで周波数を合わせたが、ここでは
  L1 と並列に **VC1 (ポリバリコンの FM 側、4.5〜24.5pF)** を入れ、つまみを回して
  合わせる。タンクの容量は C<sub>s</sub> + VC1 = 21〜41pF で、
  f<sub>0</sub> = 1/(2π√(100nH×C)) **≈ 79〜110MHz** (計算値)。配線の
  浮遊容量と、Q1 の帰還容量 C<sub>re</sub> (2SC3355 のデータシートで最大 1.0pF、VCB=10V・1MHz) が
  数 pF 乗ると全体に数 MHz 下がる。ピンのインダクタンスまで含めると、およそ 74〜102MHz になる (下の「実体配線図」の見積もり。実測はしていない)。日本の FM 放送帯 (76.1〜95.0MHz、ワイド FM 含む) の
  大半を回せる
- **Q1 を 2SC3355L (UTC、TO-92、秋月電子で 1 本 20 円) にした理由**: 100MHz 前後で発振させるので、
  トランジスタの電流増幅率が 1 より十分大きくないと、発振も検波の感度も出ない。2SC1815 は fT の保証が
  最小 80MHz (VCE=10V・IC=1mA) しかなく、|h<sub>fe</sub>| ≈ f<sub>T</sub>/f は 75〜110MHz で
  **約 0.7〜1.1** (典型値の 100MHz でも 1 前後) にしかならない。超再生検波は発振の立ち上がりを
  使うので、この余裕では足りない。UTC のデータシートでは 2SC3355 の fT は**典型 7GHz** (VCE=10V・IC=20mA)
  で、同じ式で 100MHz の |h<sub>fe</sub>| は約 70 (試験条件の電流での値)。この回路の電流は次のとおり 1mA 以下で、
  fT はそれより下がる (データシートに電流ごとの曲線は無く、値は言えない) が、100MHz に対して
  桁で余裕がある。帰還容量 C<sub>re</sub> は最大 1.0pF と小さく、タンクの容量 21〜41pF を乱さない。
  定格は VCEO 12V・VCBO 20V・VEBO 3V・IC 100mA・PC 600mW (TO-92)、h<sub>FE</sub> は 50〜300
  (VCE=10V・IC=20mA) で、5V の電源に対して十分
- **バイアスの電流 (h<sub>FE</sub> 50〜300 で確かめる)**: Rb1・Rb2 の中点は 5V×4.7k/14.7k ≈ 1.6V
  (内部抵抗 10k∥4.7k ≈ 3.2kΩ)。ベースへは Rq (330kΩ) 越しに電流が入り、V<sub>BE</sub> を 0.7V とすると
  I<sub>C</sub> ≈ (1.6V−0.7V) / (Re×(1+1/h<sub>FE</sub>) + (Rq+3.2kΩ)/h<sub>FE</sub>)。
  h<sub>FE</sub> = 50・100・300 で **I<sub>C</sub> ≈ 0.13mA・0.24mA・0.57mA** (計算値)。
  Rq が大きいので h<sub>FE</sub> に比例して電流が動くが、コレクタは 5V に直結なので V<sub>CE</sub> は 4.7V 以上あり、
  h<sub>FE</sub> が 50〜300 のどれでも飽和も破損もしない。超再生は発振の立ち上がりを使う回路で、
  クエンチの周波数は Rq×Cq が決めるため、抵抗の値は替えない。感度が足りなければ、
  h<sub>FE</sub> の大きい個体を選ぶ (hFE が測れるテスターの端子で確かめる)
- VC1 は AM/FM 2 連のポリバリコンの FM 側の 1 連だけを使う (AM 側の端子は使わない)。
  回転子 (E) を GND にしておくと、つまみに手を近づけたときの周波数のずれが小さい
- **クエンチ回路が 9-4 との違い**: Rb1・Rb2 (10kΩ・4.7kΩ) で作ったバイアスの
  中点から、**Rq (330kΩ) を通して**ベースへ電流を送り、ベースには
  **Cq (100pF)** だけを GND へ。Rq・Cq の時定数で、発振が育つとベースの
  直流電位がわずかに動いて発振が止まり (クエンチ)、Cq が Rq を通して
  放電しきるとまた発振が始まる、を繰り返す
- **クエンチ周波数** f<sub>q</sub> ≈ 1/(Rq×Cq) = 1/(330kΩ×100pF)
  **≈ 30.3kHz** (時定数だけの概算。LTspice で確かめた実際の値は下の「LTspice との突き合わせ」のとおり、hFE と発振の強さで変わる)。
  可聴域のすぐ上なので、無信号時はザーッというクエンチ雑音がかすかに聞こえることがある
- **受信の仕組み**: 発振は止まるたびに、タンクに残った小さな電圧 (ふだんは雑音) を種にして
  育ち直す。電波がアンテナ (Cant 経由) からタンクに入っていると、種が大きいぶん発振が
  早く立ち上がる。立ち上がるまでの時間の平均が信号の強さに応じて動くので、電波の強弱が
  音の大小に変わる。**FM は振幅が一定**なので、タンクの同調を放送波の中心から少しだけずらして
  受信する。共振の山の斜面では、周波数のゆれが振幅のゆれに変わって拾える
  (このやり方を傾斜検波 = スロープ検波といい、9-13 で詳しく扱う)
- **音声の取り出し**: Raf (4.7kΩ) と Caf (0.01µF) の CR ローパス
  (カットオフ f<sub>c</sub> = 1/(2πRC) ≈ 3.4kHz) が、80MHz 前後の RF も
  30.3kHz のクエンチも落とし、残った可聴域の音声だけを Cout (1µF) 経由で
  EAR (クリスタルイヤホン) へ渡す
- **イヤホンのインピーダンス**: EAR は、いま売られているセラミック (圧電) 型の
  クリスタルイヤホンを想定する (容量 約 15nF、直流では 20MΩ 以上)。電気的には
  コンデンサなので、インピーダンスは周波数で変わり、**1kHz で約 10kΩ**
  (1/(2π×1kHz×15nF) ≈ 10.6kΩ)、100Hz で約 100kΩ。8Ω や 32Ω のダイナミック型の
  イヤホンでは、4.7kΩ の Raf を通した小さな電流では鳴らない
- イヤホンの容量は Cout (1µF、15nF よりずっと大きい) を通して Caf と並列に入る。
  合わせて約 25nF になり、ローパスの実際のカットオフは 1/(2π×4.7kΩ×25nF)
  **≈ 1.4kHz** に下がる。声は聞き取れるが、こもった音になる

### LTspice との突き合わせ

`sim/06-superregen-fm.cir` で、図1 の回路 (Cant は 50 Ω の負荷につないだ) を電源の立ち上げから 60 µs の過渡解析で走らせた。
Q1 は 2SC3355 の代用モデル (`sim/04-fm-transmitter.cir` と同じ。目安から作った仮定で、実測の値ではない)。島の浮遊容量とピンのインダクタンスは入れていない。
動作点は発振させない DC を `.op` で、周波数とクエンチは過渡解析の波形から読んだ。

| 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| Re の両端の直流 (hFE 50・100・300) | 0.06〜0.27 V (I<sub>C</sub> 0.13・0.24・0.57 mA) | 0.07・0.13・0.30 V (I<sub>C</sub> 0.15・0.27・0.63 mA) | 合う (本文は V<sub>BE</sub> = 0.7 V、モデルは約 0.6 V の差で 1 割ほど) |
| 発振の周波数 (VC1 = 4.5 pF / 24.5 pF) | 計算 110 / 79 MHz、浮遊容量とピン込みで 102 / 74 MHz | 102.2 / 75.8 MHz (Cant と Q1 の容量だけを入れた値) | 合う (範囲は 74〜102 MHz のままでよい) |
| 発振の中央 (VC1 = 14.5 pF) | 計算 約 90 MHz (21〜41 pF の中ほど) | 86.5 MHz | 合う |
| クエンチ周波数 | f<sub>q</sub> ≈ 30.3 kHz (= 1/(Rq×Cq)) | hFE = 300 で約 68 kHz (周期 14.6 µs、発振している時間は 3.3 µs)。hFE = 50・100 では**クエンチせず**、小さな振幅 (0.3〜0.7 V<sub>pp</sub>) で連続して発振する | 直した (上の項目と見るべき値の表に注意を足した) |

クエンチするかどうかは、発振が育ったときにベースの直流電位が Cq 越しに下がるほど振れが大きいかで決まる。hFE が小さい個体は振れが足りず、連続発振のままになる
(本文が「感度が足りなければ、hFE の大きい個体を選ぶ」と書くのと同じ向き)。クエンチの周波数は Rq×Cq だけでなく、ベースの充電にかかる時間と発振が育つ時間でも決まるので、
1/(Rq×Cq) は目安の下限に近い。図3 の側波の間隔 (30.3 kHz) は「クエンチがその周波数で働いたとき」の姿として読み、実物は tinySA の側波の間隔から f<sub>q</sub> を読んで合わせる。
この結果はモデルの仮定に強く依存し、実測の値ではない。受信感度と音は、アンテナと放送の強さに依るので対象外。

## 実体配線図

**銅張り基板にした理由**: この回路は 75〜110MHz で発振する。ブレッドボードの目安 (3MHz 以下) も
perfboard の目安 (10MHz 以下) も大きく超える。タンクの容量は 21〜41pF しかなく、
穴どうしの容量や、差し直すたびに変わる接触、穴ピッチに合わせて長くなるピンが、同調の位置と
発振の条件をずらしてしまう。そこで、裏を切れ目の無い GND の面にした銅張り基板に、部品を
短いピンで島から島へ渡す Manhattan 方式で組む。島は回路図の節点ごとに 1 つで、GND の節点は島にせず、
via で裏の GND の面へ直に落とす。見積もりは次のとおり (どちらも目安で、実測はしていない)。

- **島の浮遊容量**: 一番大きい島は、タンクの節点 COL (Q1 のコレクタ・L1・C1・Cant・VC1・Raf が
  集まる島、5×13.5mm)。裏の GND の面との間の容量は、平行板の式 C = ε<sub>0</sub>ε<sub>r</sub>A/h
  (ε<sub>r</sub> = 4.4、h = 1.6mm、A = 67.5mm²) で **約 1.6pF**。縁の広がりを含めても 2pF 前後で、
  タンクの容量 21〜41pF の **4〜8%** (1.6pF で数えたとき)。同調範囲は 110MHz 側で約 4%、
  79MHz 側で約 2% 下がるだけで、VC1 で追える。ほかの島 (4×4mm 1 つで約 0.4pF) は、容量の大きい
  部品 (33pF・0.1µF) に並ぶか、高周波が通らない節点なので、同調にほとんど効かない
- **ピンのインダクタンス**: 直径 0.5mm のピンは、L ≈ 2l[ln(4l/d) − 0.75] nH (l と d は cm) で、
  長さ 10mm のピンなら約 7nH (**1mm あたり 0.7nH 前後**、9-4 と同じ見積もり)。
  タンクの輪に入る C1 (島の間 4mm) と C2 (6mm) のピンを合わせて 10mm 分で **約 7nH**、L1 (100nH) の 7% に
  あたる。ここに配線の分を足すと、同調範囲はさらに約 3% 下がり、およそ **74〜102MHz** になる。
  日本の FM 放送帯 (76.1〜95.0MHz) は含まれる。ピンを長くするほど下がるので、切り詰めて島の間を
  詰めるのがこの組み方の効きどころ
- **なぜ perfboard でないか**: 穴ピッチ (2.54mm) に合わせて部品を渡すので、島から島へ渡す
  今の図よりピンが長くなりやすく、裏の連続した GND の面も無い。10MHz 以下の回路には十分でも、
  100MHz 前後で GND のインダクタンスが要る回路には向かない

**範囲の確認**: 電圧 5V、電流は 1mA 以下 (分圧の約 0.34mA と Q1 の 0.13〜0.57mA を合わせても電力は数 mW、100mW 以下)、周波数 75〜110MHz は、
銅張り基板の範囲 (10MHz 超〜1GHz) に収まる。島の幅は最小 4mm (3mm 以上)。島どうしの溝は
最小 1.5mm (0.3mm 以上)。商用電源は使わない。

  | AF | Raf の下・Caf の上・Cout の左 |
  | OUT | Cout の右・イヤホンの A |
  | GND (via の島) | Cb・Rb2・Cq・C2・Re・Caf の下、電源の −、VC1 の E、イヤホンの B。**すべて via で裏の GND の面** |

- Q1 (2SC3355L-T92、TO-92) は図の黒い丸い胴で、3 本のピンを 3 つの島へ広げて半田付けする。ピンは B が
  左の島 (BASE)、C が右上の島 (COL)、E が右下の島 (EMI)。2SC3355L-T92 は平らな面を見て左から
  B・E・C の並び (UTC のデータシートの端子の順。2SC1815 の E・C・B とは違う) で、メーカーによって
  違うことがあるので、組む前にテスターの hFE 端子でピンの並びを確かめてから、B のピンを BASE へ、
  C を COL へ、E を EMI へ折り曲げて渡す。図の胴は C1 に触れない位置に置いてある
- **銅張り基板の外のもの (図の黒い箱と、そこから引いた直線)**。銅は作らず、線は島へ半田付けする線を表す。
  - 電源 5V: 赤い線 (+) を左上の VCC の帯の左端へ、黒い線 (−) を左の GND の島 (GCb の via) へ。
    GND の島はどれも裏の GND の面につながるので、− はどの GND の島へ付けてもよい
  - VC1 (ポリバリコンの FM 側): 銅張り基板の外に置き、A の線を COL の島へ、E (回転子) の線を右の GND の島
    (via) へ渡す。線は短く
  - アンテナ線 (20cm): 上から ANT の島へ半田付けする
  - イヤホン (クリスタル): A の線を OUT の島へ、B の線を右下の GND の島 (via) へ渡す
- 高周波の線 (L1・C1・C2・Q1・VC1) はなるべく短く。特に C1・C2 のピンは 5mm 前後にとどめる。
  アンテナ線は 20cm ほどにとどめる (上の警告のとおり)
- L1 は市販の 100nH (0.1µH) のアキシャルのコイル。巻いて作る必要は無い。
  受信周波数は VC1 のつまみで合わせる
- 島は組む前に紙で配置を決め、切り出したら島どうしと GND の面の導通をテスターで確かめる
  (削り残しの銅で短絡していないか)

## 計器の設定

**tinySA Ultra** (手のひらのスペクトラムアナライザ、通常モードで 100kHz〜800MHz、入力は SMA) で、
この回路が出す**自分の発振**を見る。超再生検波は受信中もつねに発振していて、ごくわずかに電波が漏れる
(上の警告)。だから受信機を鳴らしながら、**発振している周波数**と、クエンチが作る**側波**
(9-4 で見たのと同じく、搬送波の両側に立つ線) を確かめられる。
**なぜ tinySA か。** 75〜110MHz は Analog Discovery の帯域 (10MHz 以下) の外で、見たいのは
波形ではなくスペクトル (搬送波の位置と側波の間隔) だから。

tinySA の入力 (LOW) に、**アンテナ線を数十 cm** (20〜30cm) 付けるか、tinySA 付属のアンテナを
受信機のアンテナ線の近く (数 cm〜10cm) に置く。回路と直接はつながず、**電波で拾う**。
アンテナ線を長くしたり、受信機に近づけすぎたりしない (上の警告のとおり、微弱無線局の範囲は
322MHz 以下、距離 3m で 500µV/m 以下)。**確かめる間だけ電源を入れ**、見終わったら切る。
入力は +0dBm 以下に保つ (tinySA Ultra の絶対最大は +6dBm、直流は ±5V まで)。ここで拾う電力は −50dBm 台で、上限よりずっと小さい。

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| 中心 / 幅 | 85MHz / 500kHz | 発振の 85MHz (VC1 で 74〜102MHz の間を動く) を真ん中に、側波が両側に入る。広く見るときは 70〜110MHz |
| 点数 | 450 | 1 点 = 約 1.1kHz。側波の間隔 30.3kHz は 27 点ぶん |
| RBW | 3kHz | 側波の間隔の 1/10。3kHz なら隣の線が分かれる。フロアは約 −112dBm |
| 基準レベル (REF) | −40dBm | 搬送波 (−55dBm) が上端から 1.5 目盛下 |
| 縦の目盛 | 10dB/div | 既定 |
| 減衰 (ATT) | 自動 | 入力は −55dBm と上限より小さい |
| マーカー | 1 = peak (発振)、2 = 下の側波、3 = 上の側波 | 本文の順 |

手順は、まず VC1 を真ん中付近にして電源を入れ、幅を 70〜110MHz にして発振の山を探す (RBW 100kHz、
MAX HOLD にして VC1 を端から端まで回すと、山の動いた範囲が見える)。山が見つかったら、そこを中心に
幅 500kHz・RBW 3kHz に狭めて側波を見る。近くの FM 放送局の山が同じ画面に映ることもある。
発振の山は VC1 を回すと動き、放送局の山は動かないので見分けられる。

## 計器の画面

搬送波と、クエンチ周波数 f<sub>q</sub> = 30.3kHz おきに並ぶ側波。図の値は**目安**で、次の仮定を置いた。
実物は結合の強さ・アンテナの向き・距離で **±20dB くらい**動く。

- 搬送波 −55dBm (85MHz、tinySA 付属のアンテナを受信機から 10cm に置いたときの目安)
- 側波は 1 次が搬送波の 12dB 下、2 次が 20dB 下、3 次が 26dB 下 (仮定。実物はクエンチの波形で変わる。
  さらに外側は幅の広い裾になって、フロアが持ち上がって見える)。左右は同じ高さとした

```spectrum
title: 図3 搬送波とクエンチの側波 (30.3kHz おき)
device: tinysa-ultra
center: 85MHz
span: 500kHz
points: 450
rbw: 3kHz
ref: -40dBm
signal:
  - sine 85MHz -55dBm
  - sine 84.9697MHz -67dBm
  - sine 85.0303MHz -67dBm
  - sine 84.9394MHz -75dBm
  - sine 85.0606MHz -75dBm
  - sine 84.9091MHz -81dBm
  - sine 85.0909MHz -81dBm
markers: [peak, 84.9697MHz, 85.0303MHz]
```

![スペクトラムアナライザの画面](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/09-rf/spectrum/06-superregen-fm-1.svg)

- マーカー 1 が発振 (搬送波)。2・3 がその両側の 1 次の側波で、間隔は f<sub>q</sub> = 1/(Rq×Cq) の
  **30.3kHz** (計算値)。Rq や Cq を替えると、この間隔が動く
- 側波の間隔が f<sub>q</sub> に合わないときは、クエンチが働いていない (ふつうの連続発振になっている)
  か、Cq・Rq の値を疑う

VC1 を端から端まで回したときの、発振の動く範囲は次のとおり。tinySA を MAX HOLD にすると、VC1 を回すあいだに
山の動いた跡が最大値の線として残っていく。実機では回した分だけ線が伸びていくが、
図は 74〜102MHz を回し終えた後の姿で、保持したトレースの線とその下の薄い塗りの帯として描いた。
RBW 100kHz では側波が搬送波に含まれて、山が約 0.6dB 高く出る (−54.4dBm)。

```spectrum
title: 図4 VC1 を回したときの発振の範囲 (MAX HOLD)
device: tinysa-ultra
sweep: 70M-110M 450
rbw: 100kHz
ref: -40dBm
hold: sine 74MHz..102MHz -54.4dBm
markers: [74M, 102M]
```

![スペクトラムアナライザの画面](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/09-rf/spectrum/06-superregen-fm-2.svg)

- マーカー 1・2 は帯の両端 (74MHz と 102MHz) で、どちらも保持したトレースの値。
  74MHz は VC1 が最大 (24.5pF)、102MHz が最小 (4.5pF) のときで、上の銅張り基板の見積もり
  (浮遊容量とピンのインダクタンスで下がった 74〜102MHz) の値。実測はしていない。
  日本の FM 放送帯 (76.1〜95.0MHz) はこの間に入る

## 見るべき値

計算値。tinySA の高さは目安 (計算した値ではなく、上の仮定の値)。

| 確かめること | 期待する値 |
| --- | --- |
| 無信号時にイヤホンを聞く | ザーッというクエンチ雑音 (30.3kHz は時定数の概算。LTspice では 68kHz。クエンチしない個体もありうる) |
| Re (470Ω) の両端の直流電圧 | 約 0.06〜0.27V (Q1 の hFE 50〜300 で I<sub>C</sub> 0.13〜0.57mA の計算値。発振で少し動く目安) |
| VC1 をゆっくり回して近くの FM 放送局に合わせる | 雑音が消えて放送が聞こえる |
| VC1 を端から端まで回す | 受信できる周波数が約 74〜102MHz (79〜110MHz の計算値から、浮遊容量とピンのインダクタンスで下がった見積もり) の間で動く |
| tinySA の発振のマーカー 1 (幅 500kHz、RBW 3kHz) | 85MHz、約 −55dBm (目安。10cm、アンテナ利得 0dBi の仮定で ±20dB) |
| tinySA のマーカー 2・3 (側波) | 85MHz の ±30.3kHz (f<sub>q</sub> の計算値)、約 −67dBm (搬送波の 12dB 下、仮定) |
| tinySA で VC1 を端から端まで回す (幅 70〜110MHz、MAX HOLD) | 山の動いた跡 (最大値の線) が約 74〜102MHz の帯になる。図のマーカーは両端で約 −54.4dBm (計算値。実測はしていない) |
| Cant を大きくする (結合を強める) | 感度は上がるが、発振がタンクの外へ漏れやすくなる (微弱無線の範囲を超えやすい方向。既定の 2.2pF のままにする) |
