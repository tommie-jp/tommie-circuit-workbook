# 9-4 FM 送信機 (1 石)

トランジスタ 1 石だけの**コルピッツ発振回路**を FM 放送帯 (80 MHz 前後、日本の
FM 放送は 76〜95 MHz) で組み、マイクの音声で発振周波数をわずかに揺らす。
FM (周波数変調) は、音声で搬送波の**周波数**を変えて送る方式 (9-2 の AM は振幅を変える)。
発振器の周波数を音声で直に動かすので、これを直接 FM という。
電波を出す側の回路を、部品 10 個あまりで一通り体験できる。

> [!WARNING]
> 日本の電波法では、322 MHz 以下の微弱無線局は**距離 3m での電界強度が
> 500 µV/m 以下**なら免許が要らない (電波法施行規則第 6 条)。この題の
> 定数 (短いアンテナ・小さな結合コンデンサ・弱いバイアス電流) はその範囲に収める
> ための設計で、**アンテナを伸ばしたり石を足して増幅したりすると免許なしでは
> 違法**になる。実験は屋内で短時間、電波を出したまま放置しない。

Q1 に 2SC3355 を選び銅張り基板に組む理由と、発振周波数が計算より下がる見積もりは 9-27、
tinySA で搬送波と高調波を見る手順は 9-28、マイクの代わりに AD の信号発生器 (1 kHz) で変調して側波を見る手順は 9-18 に分けた。

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/09-rf/circuit/04-fm-transmitter.svg)

- **タンク**: L1 (260 nH の手巻きコイル) と C1・C2 (コルピッツの
  分圧) で並列共振回路を作る。コルピッツ発振回路は、コイル 1 つとコンデンサ 2 つの
  共振で周波数を決め、2 つのコンデンサの分圧で出力の一部を入力へ戻して発振を続ける回路。
  コレクタは L1 を介して Vcc につながるので、L1 は「タンクの一部」と「コレクタの負荷」を兼ねる
  (ふつうは RFC = 高周波チョーク、高周波だけを止めるコイルを置く所)
- **帰還**: C1 と C2 の分圧点がエミッタ。発振周波数は C1・C2 の直列合成 C<sub>s</sub> と L1 で
  決まる (下の計算)
- **ベース接地**: C3 (0.001 µF) がベースを高周波で GND に落とす (80 MHz で約 2 Ω)。
  エミッタから入れてコレクタから出すこの使い方をベース接地といい、C1・C2 の分圧でエミッタへ戻した帰還が
  利く。C3 は音声の周波数 (1 kHz で約 160 kΩ) ではほとんど効かないので、マイクの音声は
  ベースに残る。Cb (0.1 µF) は電源のパスコンで、L1 の電源側を高周波で GND に落とす
- **直接 FM**: MIC (エレクトレットマイク) の音声を Cmic でベースへ結合する。
  ベースの直流電位がわずかに揺れると、Q1 のベース-エミッタ間容量 (C<sub>be</sub>) も
  わずかに変わり、C2 と一緒にタンクの容量を揺らして周波数が動く
- **アンテナ**: Cant (2.2 pF) の小さな結合でコレクタから取り出す。結合を弱くする
  ほど発振回路への負荷が軽く保たれ、輻射も弱くなる (微弱無線の条件そのもの)

**発振周波数の計算値**: C<sub>s</sub> = C1·C2/(C1+C2) = 22p·47p/69p ≈ 15 pF。

f<sub>0</sub> = 1 / (2π√(L1·C<sub>s</sub>)) = 1 / (2π√(260 nH × 15 pF)) **≈ 80.6 MHz**。共振周波数は
L1・C1・C2 だけで決まり電源電圧には依らないので、Rb1・Rb2 を電源電圧に
合わせて選び直しても周波数はそのまま。

**動作点の計算値** (V<sub>CC</sub> = 5 V、設計値 hFE = 100、V<sub>BE</sub> = 0.6 V、
Rb1 = 10 kΩ、Rb2 = 2.4 kΩ、Re = 470 Ω): ベースの分圧を電源と抵抗 2 本の
等価 (V<sub>th</sub> = 5 V × 2.4k/12.4k ≈ 0.97 V、R<sub>th</sub> = Rb1∥Rb2 ≈ 1.9 kΩ) に直すと
I<sub>C</sub> = (V<sub>th</sub> − V<sub>BE</sub>) / (Re + R<sub>th</sub>/hFE) ≈ 0.37 V / 489 Ω
**≈ 0.75 mA**、V<sub>CE</sub> ≈ 4.6 V。
hFE のばらつき (50〜300) に動作点がほとんど左右されないことは 9-27。Rb2 を 4.7 kΩ にすると
I<sub>C</sub> は約 2.0 mA まで増える。電流が多くても発振は保てるが、ここでは 0.75 mA に抑える。

コイルの巻きを少し広げる (実効インダクタンスが下がる) と周波数は上がり、
詰めると下がる。実測ではコイル 1 巻きぶんの調整で数 MHz 動くので、
**近くの FM ラジオで一番静かな (放送局の無い) 周波数に合わせる**。

## 実体配線図

**銅張り基板に組む**: 80 MHz で発振するので、裏を切れ目の無い GND の面にした銅張り基板に、部品を短いピンで
島から島へ渡す Manhattan 方式で組む (理由は 9-27)。
島は回路図の節点ごとに 1 つで、GND の節点は島にせず、via (銅張り基板に穴をあけて線を通し、
表の島と裏の銅を半田でつないだ所) で裏の GND の面へ直に落とす。

![銅張り基板の寸法図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/09-rf/copper/04-fm-transmitter.svg)

- 銅張り基板は 5×7cm (標準の先頭) を横に置いた 70×50mm。FR-4・1.6mm・両面 1oz。
  表の銅は図の島だけを残して剥がし (または別の銅板の小片を貼って島にする)、**裏の銅は全面を GND に**
  する。図の下の段が裏から見た図。丸い印が via (裏の GND へ落とす穴と、その島)。島は銅張り基板の端から
  5mm 以上離してある
- **図の島と回路図の節点の対応** (`copper-fence check` のネットリストと回路図の接続は一致する)

  | 図の島 | 回路図の節点 (つながるピン) |
  | --- | --- |
  | VCC (VA・VB の張り出しを含む) | +5 V (Cb の上・L1 の上・Rb1 の上・Rmic の上)・電源の + (PWR.V+)。上の帯 |
  | MIC | Rmic の下・Cmic の左・マイクの + (MK.+) |
  | BASE | Q1 のベース・Cmic の右・Rb1 の下・Rb2 の上・C3 の上 |
  | COL | Q1 のコレクタ・L1 の下・C1 の上・Cant の左 |
  | EMI | Q1 のエミッタ・C1 の下・C2 の上・Re の上 |
  | ANT | Cant の右・アンテナ線 (WIRE.A) |
  | GND (via の島) | Cb・Rb2・C3・C2・Re の下と、電源の − (PWR.GND)・マイクの − (MK.-)。**すべて via で裏の GND の面** |

- Q1 (2SC3355L-T92) の胴は図の黒い半円で、
  B を左の島 (BASE)、C を右上の島 (COL)、E を右下の島 (EMI) へ広げて半田付けする。2SC3355L-T92 は平らな面を見て
  左から B・E・C (データシートの端子表は 1 = B、2 = E、3 = C [[1]](#出典)) で、
  よく使う 2SC1815 の E・C・B とは並びが違う。平らな面を見ながらピンを曲げて、この 3 つの島へ渡す。
  メーカーによって並びが違うことがあるので、組む前にテスターの hFE 端子
  (トランジスタのピンの並びを確かめる端子) に挿して、B・E・C の向きを実物で確かめる
- 銅張り基板の外の機器 (図の黒い箱) は 3 つ。線は銅を作らず、島の上に半田付けする。
  **AD3 の Supplies (V+ = 5 V)** は + (赤) を上の VCC の帯の左端へ、− (黒) を左下の GND の島 (GMIC の via) へ渡す。
  **マイク** (エレクトレット) は銅張り基板の下に置き、+ を MIC の島へ、− を GND の島 (GMIC) へ渡す。
  **アンテナ線**は銅張り基板の右に置き、ANT の島へ半田付けする
- **アンテナ線は 20cm ほど**にとどめる (伸ばすと電波法の範囲を超えやすい。
  結合コンデンサ Cant (2.2 pF) も指定どおりの小さい値で)
- 高周波の線 (L1・C1・C2・Q1) はなるべく短く。特に C1・C2 のピンは 10mm 前後にとどめる
- L1 (部品の表の手巻きのコイル) は、両端を島へ合わせて曲げる
- 島は組む前に紙で配置を決め、切り出したら島どうしと GND の面の導通をテスターで確かめる
  (削り残しの銅で短絡していないか)

## 計器の設定

この題はオシロの図を付けない。搬送波は 80 MHz で、AD3 の Scope の範囲 (10 MHz 以下) の外にあり、波形では見えない。
電源は AD3 (Supplies) から入れ、近くの FM ラジオで受けて確かめる。tinySA で搬送波と高調波を見る手順 (拾い方・入力の上限) と画面は 9-28 に分けた。

## 見るべき値

計算値・実測を併用。

| 確かめること | 期待する値 |
| --- | --- |
| 近くの FM ラジオで受信 | 80 MHz 付近 (計算値) の**静かな周波数**でノイズが変わる |
| マイクに向かって話す | ラジオから声が (小さく歪みつつ) 聞こえる |
| コイルの巻きを少し広げる | 受かる周波数が上がる方向へ動く |
| アンテナを外す | 数十cm 以内でしか受からなくなる (電波法の範囲内であることの目安) |

## LTspice での確かめ

**LTspice との突き合わせ**: `sim/04-fm-transmitter.cir` で、図1 の回路を電源の立ち上げ (50 ns) から過渡解析で走らせ、発振の周波数と動作点を読んだ。
Q1 は 2SC3355 の代用モデル (`sim/agc.cir` の 2SC1815 と同じ IS・BF・VAF・IKF・RB で、f<sub>T</sub> を 7 GHz に合わせて TF = 23 ps、
CJE = 1 pF、CJC = 0.6 pF とした。目安から作った仮定で、実測の値ではない)。

| 項目 | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| 動作点 (発振させない DC) | I<sub>C</sub> ≈ 0.75 mA、V<sub>CE</sub> ≈ 4.6 V | 0.69 mA、4.67 V (V<sub>BE</sub> = 0.63 V) | 合う (本文は V<sub>BE</sub> = 0.6 V の仮定。0.63 V なら 1 割ほど少ない) |
| 発振周波数 (理想: 浮遊容量・Q1 の容量・Cant なし) | ≈ 80.6 MHz | 80.4 MHz | 合う |

Q1 の容量・Cant・島の浮遊容量・ピンのインダクタンスを入れたときの発振周波数 (70〜75 MHz まで下がる) と、発振中の電流は、9-27 の「LTspice での確かめ」。
tinySA の高さ・高調波の dBm は見積もりで、ここでは走らせていない (対象外、9-28)。変調の深さ (β ≈ 1.6) の見積もりは 9-18。
