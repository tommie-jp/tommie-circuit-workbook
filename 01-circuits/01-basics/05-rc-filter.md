# 1-5 RC ローパス・ハイパス

抵抗とコンデンサ 1 つずつで、**低い周波数だけ通す (ローパス)** か
**高い周波数だけ通す (ハイパス)** かが決まる。並び順を入れ替えるだけで
働きが逆になる。

## 回路図

```circuit
title: 図1 RC ローパス
parts:
  IN: port a1
  R1: resistor a1 a2 1.5k
  C1: capacitor a2 b2 100n
  OUT: port a3
  G1: ground b2
wires:
  - a2 -- a3
style:
  grid: on
```

出力を**コンデンサの両端**から取ると、高い周波数はコンデンサで短絡されて
弱まり、低い周波数はそのまま出てくる (ローパス)。

```circuit
title: 図2 RC ハイパス
parts:
  IN: port c1
  C2: capacitor c1 c2 100n
  R2: resistor c2 d2 1.5k
  OUT: port c3
  G2: ground d2
wires:
  - c2 -- c3
style:
  grid: on
```

コンデンサと抵抗の**順番を入れ替え**、出力を**抵抗の両端**から取るとハイパスになる。
低い周波数はコンデンサに阻まれて弱まり、高い周波数はそのまま出てくる。

- 遮断周波数: f<sub>c</sub> = 1 / (2π × R × C) = 1 / (2π × 1.5kΩ × 100nF)
  ≈ **1.1 kHz** (計算値。ローパスもハイパスも同じ式)
- f<sub>c</sub> では、出力は入力の 1/√2 ≈ **70.7%** (−3dB) になる

## 実体配線図

```breadboard
title: 図3 RC ローパスを組む (ハイパスは R と C の順を入れ替える)
board: half
parts:
  R1: resistor a5 a10 1.5k
  C1: capacitor/ceramic b10 b13 100n
wires:
  - a13 -- -t13 black
```

`R1` の右端 (`a10`) と `C1` の上端 (`b10`) は同じ列 10 でつながる。出力は
この列 (`a10` か `b10`) から取る。ハイパスにしたいときは、`R1` と `C1` を
入れ替えて挿し (入力 → C → R → GND)、出力は R の上端から取る。

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| R1 (R2) | 抵抗 (1/4 W) | 1.5 kΩ |
| C1 (C2) | セラミックコンデンサ | 100 nF (0.1µF) |

## 見るべき値

信号発生器 (スマホのトーン生成アプリでも可) で正弦波を入れ、テスターの
交流電圧レンジ (か AC 結合のオシロ) で出力を読む。**ローパス**の場合。

| 入れる周波数 | 期待する出力 (入力を 1 としたとき) | 分かること |
| --- | --- | --- |
| 100 Hz (f<sub>c</sub> の 1/10 以下) | 約 1.0 倍 (ほぼ素通し) | 低い周波数はそのまま通る |
| 1.1 kHz (f<sub>c</sub>) | 約 0.71 倍 (−3dB、計算値) | ここが「効き始め」の目安 |
| 11 kHz (f<sub>c</sub> の 10 倍) | 約 0.10 倍 (−20dB、計算値) | 高くなるほどよく弱まる |

**ハイパス**はこの逆 (100Hz で弱く、11kHz でよく通る) になる。
