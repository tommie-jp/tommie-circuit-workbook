# 2-11 PNP のハイサイドスイッチ

2-1 の NPN スイッチは負荷の**GND 側**に割り込む「ローサイド」だった。
PNP は逆に、負荷の**電源側**に割り込む「ハイサイド」スイッチに向く。
PNP は「エミッタよりベースを下げる」と導通するので、ロジック信号
(0V/5V) をそのままベースに繋げない — 間に NPN を 1 石はさんで、
ベースを浅く引き下げる。

## 回路図

```circuit
title: 図1 PNP ハイサイドスイッチ (NPN で駆動)
parts:
  V1: vsource a1 d1 9
  G0: ground d1
  RB1: resistor a4 c4 10k
  RB2: resistor c4 e4 4.7k
  Q1: pnp c6
  Q2: npn f5
  RB3: resistor f2 f4 10k
  IN: port f2
  RL: resistor d7 d9 470
  D1: led d9 f9
  G1: ground f9
  G2: ground g5
wires:
  - a1 -- a6 -- Q1.E
  - c4 -- Q1.B
  - e4 -| Q2.C
  - f4 -- Q2.B
  - Q1.C -- d6 -- d7
  - Q2.E -- g5
style:
  grid: on
  pitch: 1.2
```

`Q1` (PNP) のエミッタは +9V に直結。`RB1` (10kΩ) はベースをエミッタと
同電位に保つ「切る」抵抗、`RB2` (4.7kΩ) は `Q2` (NPN) が導通したときに
`Q1` のベースを引き下げる電流を決める。

- **`IN` = 0V (Q2 OFF)**: `Q2` に電流が流れないので `RB2` にも電流が流れず、
  `Q1` のベースは `RB1` を通じて +9V と同電位 → V<sub>EB</sub> = 0V → **Q1 OFF**
- **`IN` = 5V (Q2 ON)**: `Q2` のベース電流 = (5−0.7)/10kΩ ≈ 0.43mA で
  `Q2` は飽和。`Q1` のベースは V<sub>EB</sub> ≈ 0.7V (導通に必要な電圧) に
  クランプされるので、V<sub>B</sub>(Q1) ≈ 9 − 0.7 = **8.3 V**
  - `RB2` に流れる電流: (8.3 − 0.2) / 4.7kΩ ≈ **1.72 mA** (Q2 の
    V<sub>CE(sat)</sub> ≈ 0.2V として計算)
  - `RB1` からベースへ流れ込む電流: (9 − 8.3) / 10kΩ ≈ 0.07mA。
    差し引き `Q1` のベース電流 I<sub>B1</sub> ≈ 1.72 − 0.07 ≈ **1.65 mA**
  - 負荷: `RL` (470Ω) + LED (V<sub>F</sub> ≈ 2.0V)。Q1 が飽和
    (V<sub>EC(sat)</sub> ≈ 0.2V) すると、コレクタ電圧 = 9 − 0.2 = 8.8V、
    I<sub>C1</sub> = (8.8 − 2.0) / 470Ω ≈ **14.5 mA**
  - 飽和に要る最小ベース電流 (hFE = 70 の最悪値でも): 14.5mA/70 ≈
    0.21mA。実際のベース電流 1.65mA は約 **8 倍のオーバードライブ**が
    あるので、確実に飽和する

`RB2` を細くしすぎると `Q1` のベース電流が過大になり無駄が大きく、
太くしすぎると飽和しない — 4.7kΩ はこの回路の負荷電流 (約 14.5mA) に対して
十分なオーバードライブを残しつつ、`RB2`・`Q2` の負担を抑える値。

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| RB1 | 抵抗 (1/4 W) | 10 kΩ |
| RB2 | 抵抗 (1/4 W) | 4.7 kΩ |
| RB3 | 抵抗 (1/4 W) | 10 kΩ |
| RL | 抵抗 (1/4 W) | 470 Ω |
| Q1 | PNP トランジスタ | 2SA1015 |
| Q2 | NPN トランジスタ | 2SC1815 |
| D1 | LED (赤、5 mm) | V<sub>F</sub> ≈ 2.0 V |
| — | 電源 | 9V |
| — | ロジック入力 | 0V / 5V |

## 見るべき値

| 測る所 | 期待する値 | 分かること |
| --- | --- | --- |
| IN = 0V のときの Q1 のベース電圧 | 約 9 V (Vcc と同じ) | RB1 が Q1 を確実に OFF にしている |
| IN = 0V のときの LED | 消灯 | Q1 OFF で負荷に電流が流れない |
| IN = 5V のときの Q1 のベース電圧 | 約 8.3 V | Q1 が導通 (V<sub>EB</sub> ≈ 0.7V) |
| IN = 5V のときの LED の電流 (RL の両端 ÷ 470Ω) | 約 14.5 mA (計算値) | 十分なオーバードライブで飽和している |
