# 2-9 JFET の定電流

接合型 FET (JFET) は、2-5 の MOSFET と同じくゲート・ドレイン・ソースの 3 本足で、
ゲートに電流をほぼ流さない部品。MOSFET と違い、ゲートに電圧をかけないとき (V<sub>GS</sub> = 0)
に最も多く電流が流れ (この電流を I<sub>DSS</sub> と呼ぶ)、ゲートをソースより低くするほど電流が減る。
ゲートをソースより V<sub>GS(off)</sub> だけ低くすると、電流は止まる。

この性質を使い、**ソースに抵抗 1 本を足してゲートを直接 GND に落とす**だけで、電源電圧が変わっても
ほぼ一定の電流を流し続ける 2 端子の定電流素子 (定電流ダイオード) になる。2-7 の
カレントミラーより部品の少ない定電流の作り方。この題では電流を計算で決め、可変の電源で
電源電圧を振って、電流が変わらない範囲を確かめる。

## 回路図

```circuit
title: 図1 JFET のセルフバイアスで定電流を作る
parts:
  V1: vsource a1 d1 5
  G0: ground d1
  D1: led a4 c4
  J1: njfet d4
  G1: ground e3
  RS: resistor e4 g4 470
  G2: ground g4
wires:
  - a1 -- a4
  - c4 -- J1.D
  - e3 |- J1.G
  - J1.S -- e4
style:
  grid: on
  pitch: 1.2
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/02-transistors/circuit/09-jfet-current-source.svg)

図1 の `J1` のゲートは `G1` で直接 GND に落としてある。ソースが `RS` を通して
GND から浮くと、ゲート-ソース間には **V<sub>GS</sub> = −I<sub>D</sub> × RS** の
逆バイアス (ゲートをソースより低くする向きの電圧) がかかり、これが FET 自身の電流を絞る (セルフバイアス)。
J1 は 2SK30A の Y ランク (I<sub>DSS</sub> が 1.2〜3.0 mA の組) を想定するが、**同じランクでも個体差が大きく**、
V<sub>GS(off)</sub> の絶対値は 1V 台前半から 2.5V 程度までばらつく。5V の電源では
ドレイン電圧が 5 − V<sub>F</sub> = 3.0V しかなく、V<sub>GS(off)</sub> の絶対値が大きい個体を挿すと
定電流領域を保てなくなる (後述)。そこで**組む前に実際の J1 の
V<sub>GS(off)</sub> を測り、絶対値がおよそ 1.5V 以下の個体を選ぶ**ことを前提に、
代表値として I<sub>DSS</sub> = 1.5mA、V<sub>GS(off)</sub> = −1.5V とする
(計算値、選別した個体の目安)。RS は 1kΩ だと電流が約 0.57 mA と小さく LED が暗いので、
**470Ω に下げて**明るさを確保した (余裕は後述のとおり RS を変えても動かない)。

- ショックレーの式 I<sub>D</sub> = I<sub>DSS</sub>(1 − V<sub>GS</sub>/V<sub>GS(off)</sub>)<sup>2</sup>
  と V<sub>GS</sub> = −I<sub>D</sub>×RS を連立して解くと、RS = 470Ω のとき
  **I<sub>D</sub> ≈ 0.82 mA**、V<sub>GS</sub> ≈ **−0.39 V** (計算値)
- ドレイン-ソース間の最小電圧: V<sub>DS(min)</sub> =
  V<sub>GS</sub> − V<sub>GS(off)</sub> ≈ −0.39 − (−1.5) ≈ **1.11 V**。V<sub>DS</sub> がこれより大きい間は、
  ドレインの電圧を上げても電流がほとんど増えない (ピンチオフ。定電流領域とも呼ぶ)
- LED (V<sub>F</sub> ≈ 2.0V) をつないだときのドレイン電圧は 5 − 2.0 = 3.0V、
  ソース電圧は I<sub>D</sub>×RS ≈ 0.39V、V<sub>DS</sub> ≈ **2.61 V** — 最小値
  1.11V との差、つまり余裕は約 **1.5 V** (計算値)
- この余裕は「ドレイン電圧 3.0V (固定) − V<sub>GS(off)</sub> の絶対値」で決まり、
  **RS を変えても動かない** (RS はドレイン電流だけを決める)。もし選別せず
  V<sub>GS(off)</sub> = −2.5V の個体 (ばらつきの大きい側) をそのまま挿すと、
  余裕は 3.0 − 2.5 = **約 0.5V** まで薄くなり、個体差や温度のばらつきで
  ピンチオフを割り込みかねない — **これが 5V でこの回路を組むときに
  J1 を選別する理由**

電源電圧を 5V から 7V や 9V に変えても、V<sub>DS</sub> が最小値を超えている
限り I<sub>D</sub> はほぼ 0.82mA のまま — **1-1 の「抵抗 1 本で電流を決める」
方法は電源電圧で電流が変わったが、JFET のセルフバイアスは電源電圧に
ほぼ無関係な電流源になる**。

## 実体配線図

電源は Analog Discovery 3 (AD3) の Supplies の +5 V。電流は約 0.8 mA で、各レール約 50 mA・ブレッドボードの 1 穴 200 mA の範囲に収まる。
RS の両端の電圧は AD3 の Scope の 1+ / 1− を電圧計として当てて読む (÷470 Ω で I<sub>D</sub>。テスターの DCV でもよい)。
この題は直流の電流・電圧だけを見るので、オシロの波形の図は付けない。

```breadboard
title: 図2 JFET の定電流を組む (Scope 1+ / 1− を RS の両端へ)
# 上の赤いレール = +5V、青いレール = GND
board: half
parts:
  PS:
    type: device
    at: top
    label: AD3 Supplies 5V
    pins: [V+, GND]
  SC:
    type: device
    at: top
    label: AD3 Scope (DC 電圧計)
    pins: [1+, 1-]
  D1: led b7(A) b10(K) red
  J1: transistor e10(D) e11(S) e12(G) 2SK30A
  RS: resistor a11 -t11 470
wires:
  - PS.V+ -- +t1 red
  - PS.GND -- -t2 black
  - +t7 -- a7 red
  - a12 -- -t12 black
  - SC.1+ -- c11 orange
  - SC.1- -- -t14 black
```

![ブレッドボードの実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/02-transistors/breadboard/09-jfet-current-source.svg)

- J1 を e10 (D)・e11 (S)・e12 (G) に挿す。2SK30A の足の並びはデータシートで確かめ、図の D・S・G の順に合わせる
- D1 (LED) のアノードを b7、カソードを b10 (ドレインの列) に挿す。+5 V は赤の線 `+t7 → a7`
- RS (470 Ω) はソースの列 11 の `a11` から GND のレールへ立てて挿す。ゲート (列 12) は黒の線 `a12 → -t12` で直接 GND へ
- Scope の 1+ (橙) をソースの列 11 (`c11`)、1− (黒) を GND のレールへ。読みが RS の電圧 (約 0.4 V)

## 可変の定電圧電源で電源の電圧を振る

可変の定電圧電源 (安定化電源、0-6) があれば、5V の USB の代わりにつなぎ、
**電源の電圧を変えても電流が変わらないか**を確かめる。定電流の回路の本当の
確かめはこれで、「どこまで下げると定電流でなくなるか」も分かる。

1. 電源を 0V、電流制限を 20 mA ほどにしてから回路につなぐ
2. RS の両端にテスターを当て (÷470Ω で電流)、電源を 12V → 9V → 7V → 5V →
   4V → 3.5V → 3V → 2.5V と下げながら読む
3. 電流が落ち始めた電源の電圧を書き留める。そこから V<sub>F</sub> と RS の電圧を
   引いた値が、この個体の V<sub>DS(min)</sub> (定電流を保てる最小の電圧)

| 電源の電圧 | LED の電流 (計算値) | V<sub>DS</sub> | 状態 |
| --- | --- | --- | --- |
| 12 V | 0.82 mA | 9.6 V | 定電流 (J1 の発熱は約 8 mW で問題ない) |
| 9 V | 0.82 mA | 6.6 V | 定電流 |
| 5 V | 0.82 mA | 2.6 V | 定電流 (この題の既定) |
| 4 V | 0.82 mA | 1.6 V | 定電流 |
| 3.5 V | 0.82 mA | 1.1 V | 定電流の下限ぎりぎり (V<sub>DS(min)</sub> ≈ 1.1 V) |
| 3 V | 0.73 mA | 0.7 V | 定電流が崩れ始める (J1 が線形領域に入る) |
| 2.5 V | 0.44 mA | 0.3 V | 電流が電源の電圧につれて減る — ただの抵抗に近い |
| 2 V 以下 | ほぼ 0 | — | LED の V<sub>F</sub> に届かない |

- 計算は LED の V<sub>F</sub> を 2.0V で一定とした理想の値。実物は電流が減ると
  V<sub>F</sub> も少し下がるので、落ち始めはもう少しなだらかになる。また JFET は
  V<sub>DS</sub> が大きいほど電流がわずかに増える (チャネル長変調) ので、12V では
  5V より数 % 多く読めることがある
- **下限の電圧は V<sub>F</sub> + RS の電圧 + V<sub>DS(min)</sub> ≈ 2.0 + 0.4 + 1.1 = 3.5V**。
  選別していない個体 (I<sub>DSS</sub> = 3mA、V<sub>GS(off)</sub> = −2.5V とすると) なら、
  電流は約 1.5mA に増え、V<sub>DS(min)</sub> は 1.8V ほどに上がって、下限は 4.5V 前後 — 5V の電源では余裕が 0.5V しか残らないことが、
  この実験で目に見える
- 1-1 の抵抗 1 本の回路に同じことをすると、電流は電源の電圧にほぼ比例して変わる。
  並べて測ると違いがはっきりする
