# 2-9 JFET の定電流

接合型 FET (JFET) はゲートに電流をほぼ流さない部品だが、**ソースに抵抗
1 本を足してゲートを直接 GND に落とす**だけで、電源電圧が変わっても
ほぼ一定の電流を流し続ける**定電流ダイオード**として使える。2-7 の
カレントミラーとは違う、もっと部品点数の少ない定電流の作り方。

## 回路図

```circuit
title: 図1 JFET のセルフバイアスで定電流を作る
parts:
  V1: vsource a1 d1 5
  G0: ground d1
  D1: led a4 c4
  J1: njfet d4
  G1: ground e3
  RS: resistor e4 g4 470
  G2: ground g4
wires:
  - a1 -- a4
  - c4 -- J1.D
  - e3 |- J1.G
  - J1.S -- e4
style:
  grid: on
  pitch: 1.2
```

`J1` のゲートは `G1` で直接 GND に落としてある。ソースが `RS` を通して
GND から浮くと、ゲート-ソース間には **V<sub>GS</sub> = −I<sub>D</sub> × RS** の
逆バイアスがかかり、これが FET 自身の電流を絞る (セルフバイアス)。
J1 は 2SK30A (GR ランク) を想定するが、**同じ GR ランクでも個体差が大きく**、
V<sub>GS(off)</sub> の絶対値は 1V 台前半から 2.5V 程度までばらつく。9V 電源なら
どの個体でも V<sub>DS</sub> に十分余裕があったが、5V ではドレイン電圧が
5 − V<sub>F</sub> = 3.0V しかなく、V<sub>GS(off)</sub> の絶対値が大きい個体を挿すと
定電流領域を保てなくなる (後述)。そこで**組む前に実際の J1 の
V<sub>GS(off)</sub> を測り、絶対値がおよそ 1.5V 以下の個体を選ぶ**ことを前提に、
代表値として I<sub>DSS</sub> = 1.5mA、V<sub>GS(off)</sub> = −1.5V とする
(計算値、選別した個体の目安)。RS も 1kΩ から **470Ω に下げ**、LED の
明るさを確保した (余裕度は後述のとおり RS を変えても動かない)。

- シェイクレイの式 I<sub>D</sub> = I<sub>DSS</sub>(1 − V<sub>GS</sub>/V<sub>GS(off)</sub>)<sup>2</sup>
  と V<sub>GS</sub> = −I<sub>D</sub>×RS を連立して解くと、RS = 470Ω のとき
  **I<sub>D</sub> ≈ 0.82 mA**、V<sub>GS</sub> ≈ **−0.39 V** (計算値)
- ドレイン-ソース間の最小電圧 (ピンチオフを保つ条件): V<sub>DS(min)</sub> =
  V<sub>GS</sub> − V<sub>GS(off)</sub> ≈ −0.39 − (−1.5) ≈ **1.11 V**
- LED (V<sub>F</sub> ≈ 2.0V) をつないだときのドレイン電圧は 5 − 2.0 = 3.0V、
  ソース電圧は I<sub>D</sub>×RS ≈ 0.39V、V<sub>DS</sub> ≈ **2.61 V** — 最小値
  1.11V との差、つまり余裕は約 **1.5 V** (計算値)
- この余裕は「ドレイン電圧 3.0V (固定) − V<sub>GS(off)</sub> の絶対値」で決まり、
  **RS を変えても動かない** (RS はドレイン電流だけを決める)。もし選別せず
  V<sub>GS(off)</sub> = −2.5V の個体 (GR ランクの上限寄り) をそのまま挿すと、
  余裕は 3.0 − 2.5 = **約 0.5V** まで薄くなり、hFE や温度のばらつきで
  ピンチオフを割り込みかねない — **これが 5V でこの回路を組むときに
  J1 を選別する理由**

電源電圧を 5V から 7V や 9V に変えても、V<sub>DS</sub> が最小値を超えている
限り I<sub>D</sub> はほぼ 0.82mA のまま — **1-1 の「抵抗 1 本で電流を決める」
方法は電源電圧で電流が変わったが、JFET のセルフバイアスは電源電圧に
ほぼ無関係な電流源になる**。

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| J1 | N チャネル JFET | 2SK30A (GR ランク、V<sub>GS(off)</sub> の絶対値 1.5V 以下を選別)、代表値 I<sub>DSS</sub> = 1.5mA、V<sub>GS(off)</sub> = −1.5V |
| RS | 抵抗 (1/4 W) | 470 Ω |
| D1 | LED (赤、5 mm) | V<sub>F</sub> ≈ 2.0 V |
| — | 電源 | 5V (USB) |

## 見るべき値

| 測る所 | 期待する値 (計算値、個体差あり) | 分かること |
| --- | --- | --- |
| RS の両端の電圧 (÷470Ω で I<sub>D</sub>) | 約 0.4 V (I<sub>D</sub> ≈ 0.8mA) | ソース電流がそのまま LED の電流になる |
| V<sub>GS</sub> (ゲート-ソース間) | 約 −0.4 V | JFET 自身がこの逆バイアスで電流を絞っている |
| 電源電圧を 5V→9V に変えたときの LED の電流 | ほとんど変わらない (V<sub>DS</sub> の余裕が増えるだけ) | 電源電圧に対する定電流性が確かめられる |
| RS を 220Ω に替えたときの電流 | 約 1.1mA 前後に増える (計算値、余裕度は変わらない) | RS はドレイン電流だけを動かし、V<sub>DS</sub> の余裕は変えない |
