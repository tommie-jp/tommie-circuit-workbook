# 5-8 Li-ion 充電 (TP4056 モジュール) と保護

USB の 5 V で Li-ion (リチウムイオン) 電池を充電し、充電しながら負荷 (LED) を動かす。
Li-ion 電池はスマートフォンや携帯機器の電池で、ほかの電池と違って、充電のやり方を間違えると発火・破裂の
危険がある。安全に使うには、決まった手順の充電と、電池を守る保護回路が要る。

- 充電は 2 段階で行う。はじめは一定の電流で充電し (定電流)、電池が 4.2 V に達したら電圧を 4.2 V に保ったまま
  電流を減らしていく (定電圧)
- 保護回路は、過充電・過放電 (電池の電圧が下がりすぎること)・過電流・短絡のときに電池を切り離す

これを 1 枚にまとめたのが定番の TP4056 モジュールで、今回は保護回路つき (DW01A + FS8205A) の基板を使う。

> [!WARNING]
> Li-ion 電池は**取り扱いを誤ると発火・破裂の危険**がある。
> 必ず保護回路つきの電池 (protected cell) を使い、B+/B− や OUT+/OUT− を
> 工具やテスターのリード線で**絶対に短絡させない**こと。ショートさせると
> 電池は数十 A 単位の電流を一瞬で流せてしまい、火傷・発煙・発火の原因になる。
> モジュールの保護回路はあくまで保険であり、それに頼り切らないこと。

## 回路図

```circuit
title: 図1 TP4056 (保護回路つき) での Li-ion 充電
parts:
  J1: usb-c c2
  M1:
    type: device
    at: c11
    label: TP4056 + Protect
    pins: [IN+, IN-, B+, B-, OUT+, OUT-]
  B1: battery e4 e6 3.7
  Rled: resistor d7 f7 390
  Dled: led f7 h7 red
wires:
  - J1.VBUS -- M1.IN+
  - J1.GND -- M1.IN-
  - M1.B+ -| e4
  - M1.B- -| e6
  - M1.OUT+ -| d7
  - M1.OUT- -| h9
  - h9 -- h7
style:
  grid: on
  pitch: 1.2
```

![回路図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/05-power-supplies/circuit/08-liion-charging.svg)

- B1 は保護回路つき (protected) の 18650 セル (直径 18 mm・長さ 65 mm の円筒形の Li-ion 電池) を想定する。
  モジュール側の保護 (DW01A + FS8205A) と、電池自体の保護回路の二重の安全にする
- J1 は USB Type-C で、VBUS (+5 V) と GND だけを使う。C-C ケーブルで給電されないときは、
  CC の 5.1 kΩ が無い基板なので (5-4 で見た)、A-C ケーブルを使う
- B+・B- には電池、OUT+・OUT- には負荷をつなぐ。今回は Rled・Dled で「充電中も動く機器」を
  模している。保護 IC は OUT 側の経路にだけ入っている。電池電圧が
  下がりすぎたり (過放電)、OUT 側で短絡や過電流が起きたりすると、
  OUT を電池から切り離して保護する
- 負荷の輪は OUT+ → Rled → Dled → OUT− で閉じる。Dled の戻りは OUT− へ
  つなぎ、B− (電池の − 側) や USB の GND へは直接つながない。保護 IC の
  スイッチ (FS8205A) は B− と OUT− の間に入っているので、B− と OUT− を外で
  つなぐと、スイッチを素通りして保護が効かなくなる
- 充電電流はモジュール基板上の抵抗 (R<sub>PROG</sub>。多くは 1.2 kΩ で 1 A 設定) で決まり、
  外からは変えられない。電池の定格と充電電流が合っているかを確かめる。
  定格は C という単位で書かれ、1 C は電池の容量 (mAh) の数字をそのまま mA にした電流をいう。
  多くの 18650 は 0.5 C〜1 C までで、2000 mAh なら 1〜2 A まで

## 実体配線図

```breadboard
title: 図2 充電の大電流はブレッドボードを通さず、負荷の LED だけをブレッドボードに組む
# 上の赤レール = OUT+ (電池の電圧)、青レール = OUT− (負荷の GND)。USB の 5 V は M1 の USB ソケットへ、電池は B+ / B− へ (ブレッドボードに入れない)
board: half
parts:
  M1:
    type: device
    at: top
    label: TP4056 + 保護 (USB 入力は基板の USB ソケットへ)
    pins: [B+, B-, OUT+, OUT-]
  PK:
    type: device
    at: top
    label: Li-ion 電池 (18650・保護つき)
    pins: ["+", "-"]
  SC:
    type: device
    at: bottom
    label: AD3 Scope (OUT の電圧を見る)
    pins: [1+, 1-]
  Rled: resistor c10 c14 390
  Dled: led b14(A) b18(K) red
wires:
  - M1.B+ -- PK.+ red
  - M1.B- -- PK.- black
  - M1.OUT+ -- +t1 red
  - M1.OUT- -- -t2 black
  - +t10 -- a10 red
  - a18 -- -t18 black
  - SC.1+ -- +t12 orange
  - SC.1- -- -t13 black
notes:
  - text below: 上の赤レール = OUT+ (電池の電圧、約 3.0〜4.2 V)。USB の 5 V と電池はブレッドボードに入れない
```

![ブレッドボードの実体配線図](https://tommie-jp.github.io/tommie-circuit-workbook/01-circuits/05-power-supplies/breadboard/08-liion-charging.svg)

- **充電電流 (約 1 A) はブレッドボードの 1 穴 200 mA・ブレッドボード全体 500 mA の範囲を超える。そこで USB・モジュール・電池をブレッドボードの外でつなぎ、ブレッドボードには OUT 側の負荷だけを載せる。** ブレッドボードを通る電流は Dled の約 5 mA だけ
- 図2 で USB の 5 V は、M1 の基板に付いている USB ソケット (図1 の J1 に当たる。IN+/IN− がここにつながる) へ USB ケーブルで入れる。電池 (PK) は B+/B- に太めの線で直接つなぐ。B+/B- と OUT+/OUT- をブレッドボードの上で近づけない
  (短絡すると数十 A が流れる。本文冒頭の注意を読み返す)
- OUT+ は上の赤レール、OUT- は上の青レールへ。Rled (390 Ω、10 列〜14 列) は `+t10 → a10` で OUT+ から、Dled (LED) はアノードを 14 列、カソードを 18 列に挿し、`a18 → -t18` で OUT- へ
- AD3 の Supplies は使わない (5 V は USB 充電器が出し、電池が負荷を動かす)。Scope の 1+ (橙) を上の赤レール (OUT+)、1− (黒) を上の青レール (OUT−) につなぐ。AD3 の入力は ±25 V まで (電池の 4.2 V は余裕で入る)

## 計器の設定

オシロには Analog Discovery 3 (AD3) の Scope を電圧計として使う。電池の電圧はゆっくり変わる直流 (満充電の 4.2 V まで数時間) なので、
**オシロの波形の図は付けない** (時間で変わらない量だけを見る題)。

| 設定 | 値 |
| --- | --- |
| Scope CH1 (OUT+、上の赤レール) | DC、1 V/div。Measurements の平均値 (DC) を読む |
| 見る値 | 電池の電圧 (3.0〜4.2 V)。1 A を超える電流は AD3 では測らない |

## 部品

| 記号 | 部品 | 値 |
| --- | --- | --- |
| J1 | USB Type-C (電源のみ、VBUS・GND) | — |
| M1 | Li-ion 充電モジュール (TP4056 + DW01A/FS8205A 保護) | — |
| B1 | Li-ion 電池 (18650、保護回路つき) | 公称 3.7 V |
| Rled | 抵抗 (負荷 LED の電流制限) | 390 Ω |
| Dled | LED (赤、5 mm、負荷の代わり) | V<sub>F</sub> ≈ 2.0 V |
| — | 電源 | USB 5 V (充電器かモバイルバッテリー) |
| — | 計器 | AD3 の Scope 1+ / 1− (電圧計)。電流はテスターの電流レンジ |

## 見るべき値

表の値は計算値か、データシートの代表値。電池の電圧はテスターの DC 電圧レンジで B+ と B- の間を測る。
充電電流は、テスターの電流 (A) レンジを B+ と電池の + の間に直列に入れて測る。
電流レンジのままテスターの棒を電池の両端に当てると短絡になるので、当てる前にレンジを必ず確かめる。

| 測る所 | 期待する値 | 分かること |
| --- | --- | --- |
| 充電電圧の上限 (定電圧域) | 4.20 V ± 1% | TP4056 の固定基準電圧 |
| 充電電流 (定電流域、基板が 1.2 kΩ 設定の場合) | 約 1 A (代表値) | データシートの式 I<sub>chg</sub> (mA) ≈ 1200 / R<sub>PROG</sub> (kΩ) = 1200 / 1.2 |
| 満充電とみなす電流のしきい値 | 充電電流の約 1/10 (約 100 mA) | 定電圧域で電流がこの値まで下がると、基板の赤色 LED が消えて満充電の表示になる |
| Dled (負荷) の電流 | 約 4.9 mA | (3.9 V − 2.0 V) ÷ 390 Ω (電池電圧を平均 3.9 V と仮定) |
| モジュールの過放電しきい値 (DW01A 代表値) | 約 2.4 V で OUT を遮断 | 電池を過放電から守る |
| モジュールの過電流しきい値 (代表値) | 約 3 A で OUT を遮断 | 短絡・過負荷から電池を守る |

モジュール基板には表示の LED (赤 = 充電中、青または緑 = 満充電) がすでに
載っているので、外付けの表示 LED は本来要らない。今回の Dled は、
「充電しながら OUT 側で機器を動かす」ことを見せるための負荷として置いた。
