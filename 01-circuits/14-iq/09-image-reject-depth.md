# 14-9 イメージ除去の深さ — Spectrum で抑圧を読み、VR1 で合わせる

14-3 では、位相法 (Hartley) でイメージ (LO の上の 547.8 kHz) を消す受信の前段を組み、オシロで出力が小さくなるのを見た。
この題では同じ基板のまま、**どれだけ消えたか (イメージ除去の比)** を Analog Discovery 3 の Spectrum で dB で読む。
消え方は部品のそろい方で決まるので、半固定 VR1 で Q 側の利得を合わせ、どこまで深くなるかを確かめる。

回路図・実体配線図・Analog Discovery 3 の配線は 14-3 の図1・図2 のまま (前の題と同じ基板をそのまま使い、測り方だけを足す題なので再掲しない)。
オシロの画面も 14-3 の図3・図4 と同じ。

## 消え方は部品のそろい方で決まる

打ち消しの深さは、2 本の振幅と位相がどれだけそろうかで決まる。理想の部品なら 85 dB 以上下がる (LTspice で 86 dB、網の式で 95 dB)。実物は次の 3 つでずれる。

- **2 つの SA612 の変換利得の差**。振幅が 5 % 違うだけで、消え残りは 32 dB 下までにとどまる (20 log(2/0.05))。
  Q 側の入力抵抗を **91 kΩ + 半固定 20 kΩ (VR1)** にして、Q 側の利得を約 ±10 % の範囲で合わせる
- **2 つの 90° 網 (LO の 680 Ω・470 pF と IF の 6.8 kΩ・470 pF) の部品のばらつき**。位相が 3° ずれるだけで 32 dB にとどまる
- 網の R と C を一様にばらつかせた計算 (2 万回) では、±1 % の部品で中央値 46 dB (悪いほうから 1 割の所で 41 dB)、
  **±5 % で中央値 32 dB (27 dB)**、±10 % で 26 dB (21 dB)。セラミックコンデンサは ±5 % が多いので、**25〜35 dB ほど**を見込む
- VR1 が直せるのは振幅だけで、位相のずれは残る。±5 % の網で振幅だけを合わせきると、中央値 37 dB (悪いほうから 1 割で 30 dB) になる
  (計算値)。さらに深く消したいなら、±1 % の部品を選ぶか、IF の網の 6.8 kΩ の片方を 6.2 kΩ + 1 kΩ の半固定にして位相も合わせる

## 計器の設定

Analog Discovery 3 だけを使う。Supplies・W1・W2 は 14-3 と同じで、出力 (CH2、2− は VREF) を Spectrum で見る。

| 項目 | 設定 |
| --- | --- |
| Supplies | V+ = 5 V (V− は使わない) |
| Wavegen W1 (LO) | Sine、498 kHz、振幅 0.25 V (0.5 Vpp)、オフセット 0 V |
| Wavegen W2 (RF) | Sine、448.2 kHz (LO の下) と 547.8 kHz (LO の上) を切り替える。振幅 10 mV (9-12 と同じ)、オフセット 0 V |
| Spectrum | CH2。開始 0 Hz・終了 1.25 MHz、FFT 16384 点、窓は Flat Top、縦軸 dBm (50 Ω)、Top 3 dBm、20 dB/div |

- Spectrum の分解能は 1.25 MHz × 2.56 ÷ 16384 = 195 Hz。49.8 kHz と、和の 946.2 kHz・1045.8 kHz、LO の漏れの 498 kHz が全部入る
- **VR1 の合わせ方**: W2 を 547.8 kHz (消したい側) にして、Spectrum のマーカー 1 (49.8 kHz) が一番低くなるように VR1 を回す。
  それから W2 を 448.2 kHz に戻し、49.8 kHz が立つのを確かめる
- W1 と W2 の周波数は 0.1 kHz の桁まで合わせる。49.8 kHz からずれると IF の網の振幅がそろわず、消え方が浅くなる
  (網の位相差は 90° のままだが、振幅は 1 kHz ずれると約 2 % 違う)

## 計器の画面

数は計算値 (目安)。出力の大きさの見積りは 14-3 の計器の画面と同じで、W2 = 448.2 kHz のとき 66.9 mV<sub>p</sub> (−13.5 dBm)。
547.8 kHz のときは ±5 % の部品で 30 dB 下がったとして 2.1 mV で描いた。

- 図1 と図2 は同じ尺度 (Top 3 dBm、20 dB/div)。10 dB/div だと図2 の一番高い線が上端から 4 目盛下に潰れる
- マーカー 1 (49.8 kHz) が **−13.5 dBm から −43.6 dBm へ、約 30 dB** 下がる。これがイメージ除去の比 (±5 % の部品の目安。理想の部品なら 85 dB 以上)
- マーカー 2 (498 kHz) は LO の漏れ、マーカー 3 は和 (448.2 + 498 = 946.2 kHz、547.8 + 498 = 1045.8 kHz)。
  片側 (PIN 4) の出力なので LO の漏れは打ち消されずに残る (9-12 の CH2 と同じ)。PIN 4 の 470 pF と U4B の帯域 (約 1 MHz の GBW を 3 倍の雑音利得で割って約 330 kHz) で下がった分を見込んだ**目安**で、
  大きさは実物で確かめる。どちらも W2 を切り替えても大きさはほぼ変わらない
- 9-10 のスーパーヘテロダインなら、ここで 49.8 kHz の IF フィルタを置けば、マーカー 2・3 は落ちる。消えないのはマーカー 1 のイメージだけで、それを位相で消すのが 14-3 の回路

## 見るべき値

計算値。抑圧の dB は網の部品をばらつかせた計算と、LTspice の模型による。

| 確かめること | 期待する値 |
| --- | --- |
| W2 = 448.2 kHz (LO の下) の出力 (マーカー 1) | 49.8 kHz・−13.5 dBm (66.9 mV<sub>p</sub>、目安) |
| W2 = 547.8 kHz (LO の上) の出力 (マーカー 1) | 49.8 kHz・−43.6 dBm。448.2 kHz のときより **25〜35 dB** 低い (±5 % の部品の目安) |
| VR1 で Q 側の振幅を合わせた後 | 中央値で約 37 dB 低い (±5 % の網。位相のずれが残る)。±1 % の部品なら 46 dB 前後 |
| 理想の部品 (LTspice) | 85 dB 以上低い (LTspice 86 dB、網の式 95 dB) |
| 2 つの SA612 の利得が 5 % 違うだけのとき | 32 dB にとどまる |
| 網の位相が 3° ずれるだけのとき | 32 dB にとどまる |
| LO の漏れ (マーカー 2) と和 (マーカー 3) | W2 を切り替えても大きさはほぼ変わらない (目安) |

## LTspice での確かめ

デッキは 14-3 と同じ `sim/03-image-reject-hartley.cir` (過渡解析。模型の仮定は 14-3 の「LTspice での確かめ」)。
LTspice は `reltol = 1e-6` で走らせた (既定の 1e-3 だと、深い打ち消しの数字は数値の誤差で 70 dB 付近に頭打ちになる)。

| 確かめること | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| 理想の部品でのイメージ除去 | 59 dB | 86 dB (LTspice、数値の底)、式で 95 dB | 直した (下記) |
| U2 の利得が 5 % 違う | 32 dB (20 log(2 / 0.05)) | 32.3 dB | 合う |
| IF の網の C16 が +5 % | (本文に無い) | 35.1 dB | 参考 |

- **「理想の部品で 59 dB」は誤りだった**: 加算の 100 kΩ の負荷は I 側 (R3 と C14) と Q 側 (C16 と R4) に対称に付くので、負荷込みでも打ち消しは崩れない (式で 95 dB、`reltol = 1e-6` の LTspice で 86 dB)。
  59 dB は既定の許容誤差による数値の頭打ちと見て、**「理想の部品なら 85 dB 以上」** に直した。実物の抑圧は部品のばらつきで 25〜35 dB 程度に決まるので、結論は変わらない

## 出典

自作。位相法のイメージ除去 (I と Q を 90° ずらして足す) は R. V. L. Hartley の米国特許 [US 1,666,206](https://patents.google.com/patent/US1666206A/en) (1928 年) の考え方による。
抑圧の dB は網の R・C をばらつかせた計算と、掛け算を式で置いた LTspice の模型による計算値。
