# 14-10 IQ 中波ラジオの選択度 — 前置の同調と I のスペクトルで隣の局を見る

14-7 で組んだ IQ 中波ラジオの基板をそのまま使い、Pico 2 に 14-8 のプログラム (`iqradio.c`) を書き込んだまま、
**9 kHz 隣の局がどこまで落ちるか**を Analog Discovery 3 の Spectrum で見る。
バーアンテナの同調 (ポリバリコン) と、IQ と計算による選局の役目の違いを、I だけのスペクトルで確かめる。

回路図・実体配線図・Analog Discovery 3 の配線は 14-7 の図1〜図6 と同じ (前の題と同じ基板をそのまま使い、測り方だけを足す題なので再掲しない)。
オシロの画面は 14-7 の図8〜図10 と同じ。

## 前置の同調と選局は役目が違う

バーアンテナの同調 (ポリバリコン) は、**局を選ぶのではなく、近くを通すだけ**の前置の同調だ。Q を 50 (目安) とすると、
594 kHz の幅は 594 ÷ 50 ≈ 12 kHz で、9 kHz 隣の局は 5 dB ほどしか落ちない。それでも要るのは、
Tayloe 検波器が方形波で切り替えるので、**LO の 3 倍 (1785 kHz) や 5 倍の局も 1/3・1/5 の大きさで下りてくる**からだ。
同調でそれを落とす。局を選ぶのは IQ と計算で、隣の局 (±9 kHz) は計算の低域通過 (±4 kHz) で落とす。

## 計器の設定

計器は Analog Discovery 3 だけを使う。電源・Logic・Scope は 14-7 の「AD3 の設定」と同じで、ここでは W2 と Spectrum を足す。

| 項目 | 設定 |
| --- | --- |
| Wavegen W1 (試験の局) | Sine、594 kHz、振幅は I の円の半径が 0.2 V になるまで (14-7 と同じ)。Modulation を AM (Sine 400 Hz、30 %) |
| Wavegen W2 (隣の局) | Sine、603 kHz、振幅は W1 と同じ |
| ポリバリコン | I の円が一番大きくなる所 (594 kHz に同調) |
| Spectrum (図1) | CH1 (I)、0〜10 kHz、8192 点 (分解能 3.1 Hz)、窓 Flat Top、縦軸 dBm (50 Ω)、Top 23 dBm |

## 計器の画面

図は計算値 (理想)。594 kHz の局を W1 で作り、LO は 595.000 kHz (Δf = −1.000 kHz)。I の大きさは 0.2 V<sub>p</sub> に合わせたとした (14-7 と同じ)。

- 図1 は I だけのスペクトル。1 kHz (マーカー 1) が局の搬送波で、600 Hz と 1.4 kHz (マーカー 2・3) が 400 Hz の AM の側波
- 8 kHz (マーカー 4) が隣の局 (W2 の 603 kHz)。LO から +8 kHz で、タンク (−5.1 dB、Q 50 の目安) と Tayloe の 9 kHz の角 (−2.5 dB) で少し落ちた。
  **I だけでは、587 kHz (LO の 8 kHz 下) の局も同じ 8 kHz に出て区別できない**。I と Q の両方を使う計算 (回し戻しと複素の低域通過) なら、
  上と下を分けて、594 kHz の局だけを残せる
- 0 Hz の線は I の直流 (1.65 V)。プログラムが最初に引く
- 放送を受けたときの画面は、局の数と強さで変わる (未実測)

## 見るべき値

計算値。I の大きさは W1 で合わせた値で、タンクの Q は目安。

| 確かめること | 期待する値 |
| --- | --- |
| I のスペクトル (図1) | 1 kHz −4.0 dBm、600 Hz と 1.4 kHz −20.5 dBm、隣の局 (8 kHz) −11.6 dBm |
| 隣の局 (603 kHz) のタンクでの落ち方 | −5.1 dB (Q 50 の目安)。Tayloe の 9 kHz の角でさらに −2.5 dB |

**比べ: 9-10 のスーパーヘテロダインと 05-etc の時報の受信機。** 9-10 は 455 kHz の IF に下ろして IFT で局を選んだ。
この題は 0 Hz の近くまで下ろし、局を選ぶのは計算の低域通過だ。05-etc/02-radio-clock/02-radio.md (2SC1815 の中波ラジオで NHK の時報を拾う) と同じ局を
この題で受けると、選択度 (隣の局の混ざり方) と、強い局と弱い局の音の大きさの差 (AGC の効き) を聞き比べられる。

## LTspice での確かめ

デッキは `sim/07-tank.cir` (バーアンテナの同調、AC 解析)。模型の仮定は 14-7 の「LTspice での確かめ」と同じ。

| 確かめること | 本文の数字 | LTspice | 判定 |
| --- | --- | --- | --- |
| 同調 594 kHz、Q 50 で 603 kHz | −5.1 dB | −5.13 dB | 合う |

- 図1 の振幅 (200 mV から −4.0 dBm、30 mV の側波が −20.5 dBm、83 mV が −11.6 dBm) は、上の同調 (−5.1 dB) と Tayloe の角 (−2.5 dB) を掛けた算術と合う
- **対象外**: ポリバリコンの実際の Q、放送を受けたときの画面 (局の数と強さで変わる) は実物に依る値で、回路の計算では確かめられない

## 出典

自作。回路は 14-7 と同じ。Tayloe 検波器は D. Tayloe の発表 (2001 年) の形。タンクの落ち方と I のスペクトルの大きさは計算値で、同調は LTspice の AC 解析による。
